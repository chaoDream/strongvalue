## 启动

需要 Python 3.12+、Node.js 22+、pnpm 11。当前工作目录已安装 `.venv` 与前端依赖，直接运行：

```sh
.venv/bin/python scripts/build.py
.venv/bin/python scripts/start.py
```

打开 <http://127.0.0.1:8000>。API 文档：<http://127.0.0.1:8000/docs>。

全新环境安装：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock.txt
cd frontend
pnpm install --frozen-lockfile
cd ..
.venv/bin/python scripts/build.py
.venv/bin/python scripts/start.py
```

首次数据库初始化会在终端显示随机密码。默认账号：`admin`（管理员）、`estimator`（编制）、`reviewer`（专业复核）、`other`（另一测试租户）。本地初始化密码相同；实际使用前为成员分别设定密码。未提供公开注册，浏览器不能通过自报角色或租户越权。

忘记初始化密码时，在本机终端重置（输入不回显，并撤销该账号旧会话）：

```sh
.venv/bin/python scripts/manage.py reset-password admin
.venv/bin/python scripts/manage.py reset-password estimator
.venv/bin/python scripts/manage.py reset-password reviewer
```

创建成员：

```sh
.venv/bin/python scripts/manage.py create-user zhang --tenant local --role estimator
```

`.env.example` 为配置清单；程序读取**环境变量**，不自动加载 `.env`。支持 `QIANG_DATA_DIR`、`QIANG_HOST`、`QIANG_PORT`、`QIANG_SECURE_COOKIE`、首次初始化用的 `QIANG_BOOTSTRAP_PASSWORD`。默认只监听本机。生产 HTTPS 下应启用安全 Cookie。

PDF 会嵌入中文字体子集；macOS 自动选取系统中文字体，Linux 安装 `fonts-wqy-microhei`，或将 `QIANG_PDF_FONT` 指向具有合法嵌入许可的中文 TTF/TTC 字体。Dockerfile 已包含 Linux 字体安装。

可选模型变量为 `QIANG_AI_PROTOCOL`、`QIANG_AI_GATEWAY_URL`、`QIANG_AI_MODEL`、`QIANG_AI_GATEWAY_TOKEN`。文件只有在界面确认接收方后才发送；本次未配置真实服务凭据。

## 可操作闭环

1. 以 `admin` 或 `estimator` 新建工程，选定本次专业范围。系统不预填规模、中标价、图纸或工程量。
2. 上传原始 PDF、DOCX、XLSX、TXT；按实际专业分类。DWG/IFC 可登记并保留原件；ASCII DXF支持受控标注提取及本版直线/三维折线读取，须独立校核后采用，不能视为全图识别。支持多文件、30 MB 限制、内容哈希去重、同名文件版本。
3. 查阅文字候选事实及原件。PDF 支持页码定位；DOCX/XLSX 没有可靠物理页码，证据明确标记“无固定页码”。扫描 PDF可按页请求本机OCR，并对原行高亮核对、追加人工抄录；识别或抄录均须按既有流程复核后采用。
4. 在完整性诊断中提交本专业核查依据，使用独立 `reviewer` 账号确认。项目范围外专业始终保留缺项显示。
5. 在图纸工作台记录页码、图号、原文；为每个尺寸和扣减参数绑定证据，注明计量依据。支持九类受控几何、钢筋表汇总、设计坐标管线三维长度、变断面沟槽及已审体积关联回填，单位以字段标注为准；钢筋参数必须引用结构专业证据。复杂拓扑、配筋建模和未经核定的工法不自动推算。
6. `reviewer` 逐项审定构件；编制账号计算工程量；`reviewer` 审定计算书。再生成候选清单，补充真实编码、特征和工程层级，提交清单复核。
7. 为清单录入获授权的多个定额子目、版本、消耗及换算系数，以及资源来源、许可、地区、期次、税制和有效期。每个定额和资源价格均须关联当前原件证据。消耗量按**每一清单单位**录入，定额单位换算必须落实到系数。修改组价后清单需重新复核。
8. 配置项目适用规则包和按序费用并关联原始依据；费率使用小数，基数可选分部分项或当前累计。规则经独立复核后计算报价快照。无合法定额/价格或规则未审定时阻断，不填补虚构金额。
9. 新建工程默认启用黄金底稿门禁：在算量页导入同构件独立底稿、逐项对照并复核。旧项目可在“取费汇总 → 适用日期与范围”启用。由复核账号审核成果。任何范围资料、事实、工程量、清单、规则或价格门禁未通过时，只能导出显著标记的未完成草稿。已审范围也不等于全厂全专业或具有签章效力。
10. 导出 Excel、PDF 或 JSON 证据包。每次导出按内容哈希持久化，历史文件可以原样重新下载；新文件不覆盖旧件。源图或尺寸变化使当前下游审批失效，历史报价快照保持不变。

## 工程结构

```text
backend/
  main.py       API、会话、权限、审核门禁和编排
  store.py      SQLite 事务、持久化、不可变日志/导出件索引
  engine.py     Decimal 纯函数几何与计价引擎
  parsers.py    PDF/DOCX/XLSX 文本提取及受控事实候选
  reports.py    同版本报表与人民币大写
  recovery.py   进程中断任务恢复为可重试状态
frontend/src/   React + TypeScript 工作台及响应式样式
scripts/        构建、启动和本地账号管理
tests/          数学边界、权限、版本、审核和导出回归
docs/           实现范围、设计与验收记录
data/           运行数据（不入版本库）
```

金额和数量在持久化 JSON 中用**十进制字符串**保存，计算统一转换为 Python `Decimal`，不使用二进制浮点计价。Excel 数值单元格是展示/编辑格式，重新计算应走后端规则引擎。规则包可指定综合单价0至6位及四舍五入、半数取偶、截位；清单合价和每项费用保持两位。支持受控加减乘除费用基数及已算费用引用；不支持任意脚本或 `eval`。不写死 9% 或历史表号。

当前输入上限为 18 位有效数字、18 位小数和 `1e12`，计算上下文为 80 位，最终金额/工程量设定范围保护。超界会要求核对单位，不截断后继续计价。

```sh
.venv/bin/python -m pytest -q
.venv/bin/python scripts/build.py
.venv/bin/python scripts/benchmark.py
```

测试使用临时数据库和明确标注的合成数据，覆盖事实候选区分/冲突、专业缺项、尺寸扣减边界、浮点规避、修约顺序、审核哈希、租户隔离、价格有效期、拒绝下游失效、原件/报价/导出件保留、不可修改审计链及导出跨表一致性。CI 配置位于 `.github/workflows/ci.yml`。

开发前端可运行 `cd frontend && pnpm dev`；请求通过 Vite 代理到 8000。后端启动命令同上。

docker build -t qiangquote:0.63 .
