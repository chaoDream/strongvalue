# 0.82 多定尺联合选材

继续补齐PRD F05材料计量与F09证据报表。在0.81兼容材料混排基础上，同一混排组可从2至5种有原件依据的原材定尺联合选材。明确采用“先最小购入总长度，购长相同再最少根数”双目标；这是备料方案，不自动计价、增加净工程量或办理库存。

## 输入和供应边界

混排组可选`stock_choices`，严格包含`alternatives`、`supply_confirmed: true`、`measurement_basis`、`evidence_id`。原有`stock_length`为S1，`alternatives`须为1至4项，每项仅含`stock_length`与`evidence_id`，依输入顺序为S2至S5。统一采用本组`length_unit`，每种长度独立关联原件，供应与选择口径另有原件；新启用时参数和原件为空，供应确认未勾选。

所有候选必须据原件确认同材质同截面、可按需供应，沿用本组同一每件锯缝、两端切除与余料阈值。不推断供应商库存，不接受有限供应量或不同加工口径。每种定尺须大于端部切除，至少能下料一个所选材料；不同候选不能为同一长度，每个需求件至少有一个候选能容纳完整下料及锯缝。保留原有2至8项、每组200件/全表400件、单位质量一致、禁止重复分组及单项备料互斥门禁。

关闭多定尺移除整个`stock_choices`，恢复0.81单定尺规则，保留原混排组和材料项；再启用为空。修改材料项或切换来源仍清空整个混排，防止沿用失配配置。供应确认不能代替整体材料核定；任一候选或依据变化均撤销整体确认。

## 算法、证明和台账

精确有理数统一为整数容量，先比较多定尺长件优先方案及各可行单一定尺方案，再在最多5000搜索节点内按候选容量和已占长执行对称剪枝搜索。优化次序为购入总长、原材根数，不把“短料更多根”误判为比“长料较少根”更差，也不称为最低采购金额。

根数下界按最大可用长度计算总占长及长度阈值容量下界；购长下界为需求净下料与逐件锯缝之和，加上最低可能根数的端切总长。两者同时达到时为`length_optimal_bound`，搜索穷尽为`length_optimal_search`；预算耗尽为`length_feasible_unproven`，仅称可行并显示购长下界差额，差额为0也可能尚未证明次目标根数最优。证明范围仅限当前候选、固定加工口径及按需供应模型。

结果保留目标、初始及当前购长/根数、下界、节点预算及证明状态；逐根关联S编号、实际购入长度、逐件切割位置，按实际选中规格构建购长及余料公式AST，候选及供应依据全部参与原件字节与审核重建。候选列表包含未选用规格（0根），不隐去比较范围。净下料、锯缝、端切、报废、待留用、总损耗及购入长度质量均独立列示，购入=净下料+损耗+待留用，长度平衡差额0。

规则为`railing-multi-stock-cutting-1.0`，含此功能的材料表为`railing-material-mass-1.15`。没有`stock_choices`时完整旧计算结果保持不变。多组材料表允许单定尺与多定尺组并存，分组各自优化，不跨组交换材料。

## 复核、版本与导出

预览、材料详情和独立复核展示优化次序、候选定尺/选用根数/原件、逐根规格及证明。即使净质量不变，新增或修改候选也须重新独立复核，旧计算书失效；历史对象、旧清单和报价快照保留。角色租户、并发、来源失效和原件五道门禁延续。

JSON保留完整记录。Excel/PDF原六类混排报表兼容多定尺，原材明细标注每根S编号及长度，新增“多定尺候选与选用”。供应详细说明保留在依据宽表，候选表列简明目标和供应原件索引，避免重复长说明造成无必要分页。
