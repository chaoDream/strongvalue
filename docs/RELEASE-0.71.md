# 0.71 固定间距留余跨立柱

继续补齐PRD F05的栏杆计量。材料表新增“固定间距留余跨立柱”，从已审直线栏杆的全部计入区间读取范围，逐区间有据选择从起端或终端布置、固定间距及两端归属，生成根数、常规跨数、余跨位置和逐根端距S，再按独立下料长及每米质量计算材料质量。

## 布置规则

内部柱从选定锚端按固定间距布置，余跨留在另一端；整除时无余跨，终端不重复加柱。两端是否计柱必须分别核定，锚向不代替端部归属。每个区间的锚向、间距、起终端决定及说明都须原件依据，没有默认工程间距，也不能另填手工根数。

例如13m区间、固定间距2m、两端计柱：从起端布置S为0、2、4、6、8、10、12、13m，余跨1m在终端；从终端布置S为0、1、3、5、7、9、11、13m，余跨1m在起端。S始终从来源原段起点增加，反向布置也不倒写S。采用来源已审三维或水平口径，每根实际下料长另据原件，不能把坡段投影或栏杆高度当作下料长。

同材料项内共用源顶点、同原边相接区间的重复端柱阻断，需明确只归属一次。跨边内部交叉、近重合、不同材料项之间的重复不自动合并。未计端柱时，跨区间实际柱距及整体设计合规仍须专业核定。图示只辅助核对S及余跨，不能测量或用于施工定位。

每区间最多1000个跨间，每材料项最多1000根，每表最多5000根自动布置立柱；每表仍为1至50材料项。允许与均分立柱、独立线材和板网片混合，分别保留布置模式、公式及依据。旧最大间距均分模式仍按原规则计算。

## 精度与版本

含新模式的材料表采用`railing-material-mass-1.4`，布置规则为`railing-fixed-step-posts-1.0`。旧材料模式继续使用原规则版本和完整结果。直接载入0.70计算模块，对照30组随机均分布置及材料表，完整记录完全一致；原线材、矩形和异形板网片记录也完全一致。

以原边精确长度平方和有理数确定最小正整数N，使(N−1)²×间距² < 区间长度² ≤ N²×间距²。根数为N−1加两端0/1归属；精确上界相等时常规跨数为N、余跨0，否则常规跨数为N−1、余跨为长度减常规跨数乘固定间距。临界判断不依赖平方根显示或除法修约。

端距及质量采用Decimal 80位；逐根S、余跨和数量均保留可重建表达式，跨数保留精确平方分数校验。单根下料、分项长度及质量不提前修约，合计后只乘一次来源重复数量，仅总质量按有据0至12位HALF_UP修约。

## 界面、审核及导出

编制页逐区间填写锚向、固定间距、端部归属及依据，根数由预览生成。修改字段或切换模式清除旧预览及确认。复核页可选择区间，查看真实S布置及橙色余跨，展开全部逐根端距和精确跨数校验。

沿用独立复核、角色租户、对象哈希、修订并发、完整历史及原件门禁。保存、审核、计算书和导出重新构建布置，不能篡改根数、余跨或表达式通过。来源范围变化使材料及下游失效；恢复时读取当前来源并清空旧材料项、间距、锚向、端部决定、逐项依据和确认。旧清单在重建前保留；历史报价不混入后加材料。无需新依赖或数据库迁移。

JSON包含完整布置；Excel/PDF新增“定距立柱质量汇总”“定距立柱锚向余跨与归属”“定距立柱跨数精确校验”“定距立柱逐根端距”四表。定距与均分两套明细分别保留，总质量汇总全部材料项。
