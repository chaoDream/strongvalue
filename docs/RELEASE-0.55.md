# 0.55 恢复CAD原采用序列与逐项修订

补齐[0.52取段](RELEASE-0.52.md)、[0.53组装](RELEASE-0.53.md)和[0.54来源回查](RELEASE-0.54.md)之后的修订操作。已有单对象、单独取段、完整原对象组装和取段组装均可重新读取原采用序列，保留顺序和方向，逐项调整后提交为同一管线的新修订，避免从原件逐一重选。

## 读取原序列并固定修订目标

在“图纸与算量 → DXF设计坐标读取与单位校核”选择现有CAD管线，点击“读取原采用序列并修订”。系统核对指定修订和来源戳，验证实际原件、解析任务、采用记录、原始坐标、独立依据及保存态计算内容，再恢复本地候选序列。当前有其他候选或弹窗时需先完成或清空，避免覆盖未提交选择。

读取后明确显示当前修订目标与原版本，原文件和登记目标固定。原管线名称、共同WCS说明、计量口径、重复数量、修约和用途依据带入供核对；已知长度、容差、长度依据、修订原因和原图确认清空，旧预览不带入。不能直接沿用原已知距离或勾选状态提交。

读取不创建新构件、不修改原版本、不增加坐标证据、采用记录或工程量。可明确“结束本次修订并清空候选”；关闭调整弹窗或结束候选均不修改业务数据。原来源已失效时拒绝恢复，不通过句柄或近似坐标自动绑定新原件；更换原件仍须从当前CAD来源明确选择原管线修订。

## 逐项调整原始范围

候选序列新增“调整原始范围”。进入时显示完整原对象，恢复此项的原始起止点和方向；范围改变后读取明确范围，再点击“替换当前候选项”。只替换当前本地项，其他项不变。调整模式不显示采用表单，不能误把其中一项直接提交为整条管线。

范围与其他候选项重叠时拒绝替换；相邻范围共用端点允许。顺序、反向、移除及继续加入其他同原件对象沿用既有操作。支持将组装缩减到单独对象或单独取段；单对象反向会明确表示为覆盖全部原始顶点的反向取段，不静默翻转原始坐标。

“检查连接并组装候选”或单项的“检查所选范围并校核”会重新读取实际CAD来源。连接端点须XYZ精确相等，仍不吸附、补段或自动猜测顺序；最多20项、合并后最多101个顶点，原对象几何限制和原始管段防重复继续有效。选择错误可以关闭校核弹窗，继续调整本地序列。

## 重新校核与版本留存

调整后的整条管线重新填写独立已知长度、明确容差及原始依据，核对旧说明是否仍适用，填写修订原因并主动确认。长度校核通过后才可采用。修订提交使用恢复时取得的原构件哈希；期间原构件被其他操作修改或复核时，旧哈希阻断提交，不自动刷新并覆盖新版本。

采用仍更新同一构件ID、递增修订号并回到待复核，受影响计算书失效；重新审定构件、生成并独立复核计算书后，才能重建清单。旧清单在重建前保留原数量，不能当作新修订的当前有效结果。

同时修复CAD修订历史保存时机：在使当前对象及下游失效之前复制旧构件，保存修订前的完整状态，使历史对象哈希与采用记录的`previous_component_hash`一致。旧采用与审核记录继续保留，过去已保存的历史记录和报价不被改写。

## 接口与兼容

新增只读认证接口：

- `GET /api/v1/projects/{pid}/components/{cid}/dxf-revision-candidate`：要求`revision`和`source_stamp`，返回经校验的原序列、固定目标ID/哈希及清空校核与确认后的表单初值。没有CAD来源返回422，旧版本、源变化或不完整来源返回409。
- `POST /api/v1/projects/{pid}/documents/{did}/dxf-route-selection`：严格接收1至20项原对象/取段引用，单项保留单对象或明确取段，多个项沿用组装验证；响应仅为候选，不写业务记录。空序列、缺少明确方向、半截/空范围、额外显示参数、重叠和断接拒绝。

租户与匿名访问受现有项目权限约束。复核角色可只读调用，但页面禁止恢复编制，实际采用仍独立检查编制权限。既有至少两项的组装接口、原候选身份、预览及采用请求哈希保持，无数据库迁移或新依赖，报表结构沿用既有修订台账。

## 验证与范围

2026-10-23：新增31项合成测试，全量1499项通过；TypeScript检查及生产构建通过。覆盖四类来源恢复、项目/审计只读、原序列与身份不变、固定目标及清空校核、单项反向、组装缩减、调整后的V2/历史/下游及清单闭环、缺少新确认、并发复核哈希冲突、原件/任务/依据/映射/预览变化、显式版本、空/超量/不完整范围/断接/重叠、角色和租户及原对象不支持限制。既有计价、报表与历史快照全量回归通过。

隔离浏览器读取已审V1的A原P2至P4、B原P2至P3反向序列，将A扩为原P1至P4，B范围与方向保持。候选调整后核对全部持久化项目字段仍与读取前一致：同一V1构件，计算书和清单均为30.000m。整体检查后原登记目标锁定，旧独立长度、容差、长度证据、采用原因及确认均为空。重新填写13m、零容差、独立依据、修订口径及原因，预览并采用56.000m的同构件V2待复核。

核对旧V1完整状态与哈希留存，旧计算书失效，旧清单在重建前仍为30.000m。独立复核账号无法恢复编制，但可核查V2范围、13m校核和计算明细并审定；后续接口验收重算计算书、计算书独立复核及清单均为56.000m。截图：`docs/qa/v0.55-restored-sequence.png`、`docs/qa/v0.55-fresh-calibration.png`、`docs/qa/v0.55-reviewed-revision.png`。未向实际工程库写入合成测试数据。
