# 0.74 原定距布置中的禁布范围与显式移柱

继续补齐PRD F05的栏杆计量。新增“固定布置及禁布移柱”：按已审来源及有据固定间距、锚向、端部归属建立原布置，再逐根按原内部节点号j和新端距S移柱，并校验指定禁布闭区间。数量、规格及质量保持，移前移后记录独立保留。

## 控制规则

逐区间明确禁布范围和移柱列表，无则为空；本模式至少有一个禁布范围或一根实际移柱。禁布范围须填写名称、原段起终S、单位及构造说明，起距、终距和说明分别关联当前原件。范围须在所选计入区间内，起距小于终距；闭区间包含两端，移后全部计入柱必须在其外。允许不同范围重叠并分别保留原件，但同区间重复名称或等值范围阻断，不按重叠范围扣根数。

移柱按原布置S递增的内部节点号j识别，j为1至N−1，不是材料表总柱号。原起端锚向S=区间起S+j×固定间距；终端锚向S=区间终S−(N−j)×间距。原节点、新S和说明分别有原件。新S仍从来源原段起点、沿已审三维或水平口径增加，局部区间不能改为相对起距。

只移动内部柱，不移动端柱、不删除或增加根数，不自动选取避让位置。新S须严格在本计入区间内部；原位不变、重复移同节点、移到端部或缺口均阻断。多个移柱同时核定，移后按原节点顺序严格递增，重合或交叉换序被拒。端柱仍通过原两端归属决定，不能用移柱绕过共享端点核定。每区间最多20个禁布范围、100根移柱，沿用每材料项1000根、每表5000根单组立柱及1至50材料项上限。

当前适用于原固定间距布置，均分及含构造加柱布置中的禁布移柱尚未扩展。移后实际柱距、专业构造及施工定位须另核，不把原固定间距或余跨当作移后的实际间距，也不自动补柱弥补移柱形成的间隔。

## 精度、记录与兼容

位置比较采用精确有理数及原边长度平方：把原定距坐标表示为a+b×√q，再以符号及平方比较判定顺序、端部和闭区间归属。终端锚向整段斜边不依赖平方根显示值或容差，避免边界误放行。原位置、新位置及各自表达式保留，禁布起终原值和单位换算、原有及移后范围内根数可重建。

新规则`railing-fixed-adjusted-posts-1.0`，含本模式材料表采用`railing-material-mass-1.7`。根数及数量表达式保持原布置，质量仍按独立下料长、单位长度质量和来源重复数量计算；采用Decimal 80位，分项不提前修约，合计后只乘一次来源重复数量，仅总质量按有据0至12位HALF_UP修约。

旧均分、定距和两种构造加柱结果及版本保留。独立载入0.73计算代码，对照100组旧材料结果，完整记录完全一致。允许与其他材料模式同表计量，参数及依据命名空间独立；本模式未定义的额外加柱字段会被拒绝。

## 界面、审核及导出

编制页逐区间增加或移除禁布范围、指定原节点及新S。字段变化清空预览与确认，模式切换清除旧规则和隐藏控制项。复核示意以红色表示禁布闭区间、灰色虚线表示原位置、紫色表示移后柱，原跨数及余跨明确标为原布置；完整逐根表和前后对照可核查依据。示意不能测量。

沿用独立复核、对象哈希、修订并发、精确历史、原件完整性和角色租户门禁。即使只改位置而质量完全相同，也会使旧计算书及审批失效；重建前旧清单保留，重建采用新位置。来源范围变化后材料及下游失效，恢复时读取新来源并清空旧定距规则、禁布、移柱及逐项依据和确认。旧报价不混入新材料。

JSON保留完整前后记录。Excel/PDF保留原定距四表，新增“立柱禁布范围核查”“立柱移前移后端距”，逐根表标明移柱及原S。报告中原跨数和原余跨不表示移后柱距合规。无需新依赖或数据库迁移。
