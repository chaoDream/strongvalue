# 0.69 异形板网片展开轮廓、独立扣孔与材料质量

继续补齐PRD F05的栏杆材料计量。栏杆材料表新增“异形直边板件或网片”，按每片独立展开局部XY的外轮廓和逐孔顶点计算净面积，再乘独立片数及有据面密度。可以与连续线材、独立定长件和矩形板网片混合列项，不能将栏杆安装长度或建筑投影直接当作展开面积。

## 计量与精度

每片包含一个简单直边外轮廓、0至20个独立孔；支持斜边、凹角、顺逆时针及负坐标。按原件顺序输入顶点，末边自动闭合至首点，无需重复首点，也不自动排序。每轮廓3至100点，每片合计最多200点，每表异形板片合计最多1000点；多个外轮廓应分别列项。

每项须核定展开平面、局部原点及XY方向和依据；每个轮廓须有名称、范围说明和原件，每个顶点须有名称、XY、长度单位及逐坐标原件。自交、重复坐标、折返或非相邻接触、零面积及缺依据阻断。每个孔必须严格在外轮廓内，不能接触或越出外边界，孔之间不能接触、重叠或包含。矩形模式继续按开口并集扣重；本异形模式按分离孔逐孔相减，不支持任意孔并集或曲线。

净展开面积乘每组独立片数及kg/m²或g/m²面密度，来源重复数量只在材料合计后乘一次。面密度须匹配净面积口径，网片微孔不得重复扣减。不推断折弯展开、曲面、拼接、损耗、密度或搭接；已审三维或水平投影栏杆均可关联独立展开板片，连续坡段线材仍须三维长度。

含异形板片的新材料表采用`railing-material-mass-1.2`，旧纯线材和矩形板片分别沿用1.0及1.1结果。采用Decimal 80位，直接使用几何核心的未修约面积和未修约AST，不使用其面积显示修约值。即使单片微小面积按显示精度会归零，仍先乘片数、面密度及来源数量，再仅对总质量按明确0至12位HALF_UP修约。内部固定单片数量与来源重复数量采用不同维度名称，轮廓及逐边AST也完整隔离，便于独立重算。

## 编制、复核和报表

界面支持独立展开坐标说明、增删顶点、上移/下移保持顺序、增删孔、逐坐标依据，以及明确将某轮廓原件用于全部XY的操作。模式切换重置原模式参数；任何修改清除旧预览和确认。独立复核显示净面积、片数、面密度及质量，可核对展开轮廓与逐孔示意、原始及标准顶点、有向叉积、孔包含和分离检查、锁定栏杆来源。示意只供定位，不可测量。

沿用当前原件完整性、角色租户/项目权限、独立复核、对象哈希、精确版本历史、来源失效、计算书重建及kg清单映射。来源栏杆修订后，重新读取会清空旧板片模式、坐标说明、轮廓、孔、片数、面密度和逐项依据及确认。旧清单在重建前保留，旧报价不混入后加材料。无新依赖或数据库迁移。

JSON保存完整计算记录；Excel/PDF新增“异形板网片面积与质量”“异形板网片原始顶点”“异形板网片逐边面积”“异形板网片孔边界校验”。混合表同时保留旧线材及矩形片明细，质量汇总包含全部分项。
