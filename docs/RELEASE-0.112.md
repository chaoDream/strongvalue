# 0.112 基础水平模板圆形XY窗口

日期：2026-10-27。前后端与使用手册版本0.112.0。

## 本次完成

整体顶底、台阶平台及内部孔端新增单圆局部窗口。圆心XY、实际直径、共同单位与基准逐项有据，Z与全部基础数量继承已审来源。真实圆参与直线／圆弧全部事件分段及200位解析积分、80位输出；不以外包矩形或多边形逼近代替圆，平台排除上层覆盖，孔端取正确侧层，实际孔只扣共同交集。全部有效分段无剩余才证明严格零接触，仅最终总净量按有据位数修约。

圆圆以圆心距平方及半径和平方比较；圆与旧直边净区以圆心奇偶内外及全部有限边段最短距离平方比较。精确有理数无容差，包含／正重叠拒绝，外切可分项；支持直边内孔残余空区及嵌套岛区防重、跨记录检查。完整输入原件、保存修订、历史并发、来源失效及独立复核门禁复用既有流程。

页面接通圆形选择及原始字段、确认撤销、预览与独立复核；JSON保留全部AST及精确距离见证，Excel/PDF新增圆形参数、分段积分及按需零接触／防重表。详细操作见[使用手册16.12](USER-GUIDE.md#foundations)。
