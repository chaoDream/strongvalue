# 0.119 完整原材领料、投入加工与退回

日期：2026-10-28。前后端及使用手册版本0.119.0。

## 本次完成

项目原材库存新增整单领料、分批完整原材投入加工和未加工完整原材退回单。每单填写实际日期、交接对象、说明和原件，独立复核后由编制人员显式执行；提交及复核本身均不记账，未执行单据可有据取消，已执行单据不能取消或重审。

整单领料继承有效已审预留全部批次及根数，提交、复核、执行均检查当前登记、来源及原件。执行将预留转出库，在库减少、在外未加工增加，可用不因预留解除虚增；同材料表已领料后不能再预留。后续加工／完整退回按已执行领料的逐分配余额防超耗、超退，事务及版本校验阻断并发争用。

完整根账保持“登记=在库+在外未加工+已加工”。投入加工按完整原材退出本台账，不等于净安装量、损耗或余料量。来源或历史原件失效不撤销旧记账；实际后续交接可凭新有效原件记录，历史问题继续提示。库存JSON保留单据、分配、执行事件、独立复核及余额，历史字节不改写；净工程量、排料、清单及报价保持。

操作详见[使用手册15.7](USER-GUIDE.md#stock-operations)。15.6同步更新在库／预留／可用等式及已领预留门禁。
