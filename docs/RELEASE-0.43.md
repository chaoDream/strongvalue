# 0.43 扫描标题栏候选核对与登记

将0.42本机逐页OCR接入F04图纸目录。在“项目与资料 → 读取标题栏候选”中，带明确标签的扫描图号、图名、版次、视图类型可形成机器候选。缺项仍留空，不推断视图；同字段不同识别值全部保留，不按置信度或出现次数裁决。

## 识别来源与原页核对

只接受已完成本地OCR任务所绑定的证据：文件哈希、文档、页码、证据ID及识别器必须对应，逐行文字须与证据全文一致，坐标和置信度须有效。每个字段保留识别原行、行号、显示页归一化位置、机器置信度、识别器和系统算法版本。候选读取不写业务数据，不创建事实、尺寸或构件。

界面明确标记“扫描机器识别·待核对”。编制人须对照原页核对四类字段及人工补填，勾选确认后才可保存。服务器仅接受布尔值true，不能以字符串、数字或缺省绕过；保存后仍为待复核图纸，须另一账号独立审核。缺失字段及人工修正、核对人和时间全部留存。普通文字层和人工标注候选继续沿用原流程。

采用前继续验证候选哈希、原件实际字节及当前版本；识别任务或原行被改变时不能采用旧候选。采用后的独立审核、图纸关联和新报价校核继续检查识别来源，防止原任务依据失配。相同候选不能重复登记；修改已有字段按图纸修订流程保留历史。

## 报价与导出

报价快照保留机器候选、原行、人工补填及核对记录。JSON、Excel、PDF新增“扫描标题栏字段核对”表；历史报价只读取原快照，不混入后续原行或置信度变化。已有“图纸身份候选采用”表保持兼容。显示页位置仅辅助追溯，不代表工程尺寸；机器置信度不等于工程准确率。
