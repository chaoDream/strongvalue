# 0.116 基础水平模板圆形嵌套岛区

日期：2026-10-27。前后端及手册版本0.116.0。

## 本次完成

整体顶底、台阶平台及内部孔端支持2至4个圆形净块，至少一个岛区外圆严格在最近父块的指定W内。每块0至4个W、全部最多8个；各圆尺寸和支模／不支模用途及关系原件独立核定，全部共用基础中心XY及单位。精确有理数严格核对包含与分离，拒绝相切、交叠、错误父关系、自指、成环和跳层；平面层级不代表Z或数量。

各根块及岛区分别取外圆减所属W的真实接触，平台先排上层、孔端取正确侧层、实体孔只扣各块净接触。200位解析积分保留80位后累计，数量继承一次，仅总净量有据修约。全部块候选分段无剩余才证明整体严格零；完整窗口与其他模式逐块对精确防重，父孔未用空区可另项，岛区正重叠阻断，跨记录同样检查。

页面支持逐块／逐W录入、显式最近父选择、删除被引用对象后重选、修改撤销确认及预览、逐块来源和严格拓扑复核；JSON、Excel和PDF保留父子层级、逐圆参数、真实积分、覆盖和防重见证。详见[使用手册16.16](USER-GUIDE.md#foundation-circular-islands)。

- 677项回归通过（446.01秒），涵盖225项新增圆岛、231项旧多内圆、215项旧直边岛区及6项手册检查；另2项块编号及四块八孔补充检查通过，合计679项。180组旧完整计算及水平模板报表与0.115逐字段一致。
- 四层24种排序、18组拆圆毛扣净对照、20组独立数值积分、80组圆窗独立布尔交集、严格父关系及逐圆AST重放、微小正间隙、篡改和原件五道字节门禁通过。前端类型检查、生产构建及手册普通／基线同步检查通过。
- 两份隔离合成工程完成保存、独立复核、计算书、清单及三格式，均7张新表JSON与Excel逐单元格一致；PDF新增41页章节渲染检查。父块加岛区及父孔剩余另项与原外圆未修约差小于1e-70m²；零例7个候选片段分别含B1／B2、全部剩余0。

本机8000已核对为0.116.0。页面验证错误父选择、父孔边界接触拒绝，删除父块／W后重选，修改撤销双确认与预览，放弃修订、独立复核和全部块覆盖通过。
