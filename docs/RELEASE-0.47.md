# 0.47 待询价资源的供应商报价登记与选择

补齐F07“待询价”任务的价格来源处理。在组价审核页，编制人可以为具体待询价资源登记已收到的供应商报价，独立复核人员核查报价依据，编制人再明确选择并补价。该流程不向供应商发送消息，不形成采购承诺，也不自动选择最低单价。

## 登记、条件对照与独立复核

报价绑定当前清单及资源的完整版本，明确资源编码、规格、单位和费用归属；保存供应商、报价单编号或名称、收到日期、完整精度单价、税制、地区、期次、有效期、使用许可、运输/安装/付款条件及核对依据。必须选择已上传原件的证据，保存证据及文档哈希，不能用整包总价直接替代资源单价。

同一资源的多份报价全部保留，可按具体资源筛选和分页查阅。原始单价不提前修约；不同税制和供货条件分别展示，不进行无依据税额换算或最低价排序。登记不改变资源、待询价任务、工程量或当前报价。

报价通过现有独立reviewer流程审定、拒绝或要求补件。复核详情展示原文、原始价格、许可、条件及登记人。过期、地区不适用的报价可以登记留档，但不能通过审定或采用。资源或清单版本变化后，原报价不能直接用于新的目标版本；须重新核对登记。

## 明确选择、补价与重新审核

编制人只能采用已通过复核且来源和适用期间仍有效的报价。采用时必须明确确认规格、单位、税制、供货条件、许可和合同适用性，并填写选择依据。服务器在同一事务内再次核对报价哈希、目标资源和原件实际字节。

操作只补入该资源的价格及价格依据，保留资源消耗量、定额系数、清单数量和编码；原待询价任务随价格补齐关闭，目标清单回到待复核，使当前报价审批失效。原来没有价格，不生成以零为基线的虚假差额。其他报价继续保留，不能重复用于已补价版本；已有价格的资源仍使用现有调价流程。

登记请求和相同采用请求支持幂等重试；重用请求标识更换内容、改写原选择依据或重复采用到其他版本均被拒绝。采用保存原待询价资源、采用后资源、报价及目标版本、理由、人员和时间，可在列表展开查看选择依据。

## 来源失效、历史与成果

已采用报价被拒绝或要求补件时，关联清单失效，阻断新的清单审定和报价计算。采用后再次审核清单、计价时，都会检查报价审批、规格和价格关联、证据哈希、原件实际字节、地区和有效期。未选择的报价撤审不使已选价格失效。

撤审不删除登记和采用记录。若需重新定价，必须核对当前资源和价格依据；本入口不把旧报价直接重新应用到已补价的资源版本。人工重编或现有调价流程可建立新的价格来源，原采用记录留在历史中。

报价快照保存全部登记和采用记录，JSON、Excel、PDF增加“供应商报价登记”和“供应商报价采用”两张台账；审计保留登记、独立复核及采用动作。新增报价、撤审或后续变更不混入旧快照，不修改已生成文件。
