# 0.78 连续来源路径的实际柱距核查

继续补齐PRD F05栏杆计量与复核。本版在八种立柱模式的可选实际柱距核查中增加“沿连续来源路径”，补齐相接区间、跨边转角及闭环首尾的最终计入柱距。按已审来源的三维或水平S口径累计路径长度，不取两柱直线弦长，不改根数、柱位、下料规格和材料质量。

## 选择范围与连接规则

原`spacing_check`结构不变时仍为0.77逐区间模式，历史规则与完整输出保持兼容。只有显式增加`scope: "connected_path"`才启用路径核查，其他scope值（包括显式local、null）拒绝。仍须独立填写上限、单位、范围说明及上限/范围两项原件依据，不自动采用原布置间距。界面切换范围会清空范围说明与该项依据、撤销确认并清除预览；须据图重新核定。

连接采用已审来源原边顺序：同一原边的相接局部区间可以连接；跨原边必须前一区间准确到达原边终点、后一区间从原边S0开始，且两原边在原始轮廓或设计线中相邻。正长度缺口、排除边分别断开；外环和各孔环独立。即使坐标相同、投影重合或内部交叉，也不据此创建额外连接。输入决定及计划列表重排不能改变原始拓扑顺序。

开路径按最终柱序生成N−1对；闭环生成N对，最后一对明确标注“闭环首尾”。跨缺口不补柱距，未计入的路径也不补入长度。中间连续区间若无柱，仍计入两侧相邻柱之间的路径长度。闭环只有一根柱时，核查回到该柱的整圈距离；无柱路径只披露为待另核，开路径边界至最近计入柱距离单列，不当作已经通过的相邻柱距。整个材料项没有可核查相邻对时拒绝启用。

## 计算、复核与输出

每对保留原柱编号及规则/加柱身份、来源区间、两柱原边S、途经范围、各段公式、完整距离公式、精确根式和80位显示。不同原边的长度可能为不同平方根之和：有理数平方根先精确化简，平方比为有理数平方的根式合并；精确零先消去，其余使用逐级收紧的有理数上下界证明符号。等于上限允许、精确超过即拒绝，不按显示小数或几何容差放行；达到比较资源上限仍不能证明时明确拒绝，不猜测通过。

路径核查规则为`railing-connected-path-spacing-1.0`，含该范围的材料表规则为`railing-material-mass-1.11`。旧的未启用核查及0.77区间核查规则保留。核查配置和派生明细均参与保存重建及审核哈希校验；同质量范围变更仍使旧计算书失效，旧构件历史和旧清单完整保留，须重新独立复核、计算和生成清单。原件字节损坏、来源变化、跨项目依据、角色和租户限制继续执行。

界面预览、材料详情与独立复核均展示路径摘要及逐对距离。JSON、Excel、PDF新增三表：立柱连续路径柱距、立柱路径相邻柱距、立柱路径核查依据。局部与路径模式混合材料表可同时导出两类表；旧报价快照不混入新表。PDF逐对行保持完整换页，长S和长名称可换行。
