# 0.35 圆形井底板、盖板及同心通孔

继续补齐PRD F05检查井扩展：从当前已审圆形井筒读取井号及核定井数，独立填写板径、孔径、厚度、板底标高，形成有原始依据的圆形井底板或盖板净实体工程量，接入独立复核、计算书、清单及回填联动。

## 几何与数量口径

- 新增结构化构件`chamber_plate`，m³体积。明确选择`base`井底板或`cover`井盖板；不同用途、层次及材料分别建立构件。仅支持水平等厚圆板及单个同心圆形贯通孔，偏心孔、多孔、凹槽或异形板另建适用模型。
- 每项选择一个已审来源井号，独立填写实际板径、贯通孔径、厚度和板底标高，分别关联原件与范围说明。板径和厚度须为正，孔径大于等于零且严格小于板径；无孔也须显式填零并提供依据，不接受全扣或越界孔。板底标高允许负值，保留标高基准及独立施工依据，板顶为板底加厚度。
- 原始长度支持m、mm、cm、dm、km并保留换算；不由井筒内外径、井高或管线高程推算板尺寸或标高。来源站点只作定位索引，不代表软件完成了位置包含或施工方案验收。
- 每个所选井号本层一块板，数量继承其当前已审井数一次，不从来源已经修约的井筒体积倒算，不再乘管线数量，也不允许客户端另填板数/重复数量。可明确选择部分井号，最多50项，同一构件内板名称和来源井号不能重复。
- `净板体积=Σ[(π/4×实际板径²×厚度−π/4×同心贯通孔径²×厚度)×已审井数]`。记录原体积、孔扣减、单板净量及继承数量。Decimal 80位及固定π常量，各单板和孔不单独修约，仅最终净量按有据选择的0至12位HALF_UP；保留公式树、原始数值及修约差额。
- 材料规格、施工做法/标高基准、计量范围、修约及每项尺寸/标高证据必填，明确核定水平圆板与同心贯通孔口径。不含井盖框、钢筋、收口、流槽、踏步、预埋件或施工附加量，不能认定整井已自动算完。

## 工作流与依赖

算量页新增井号读取、用途、逐板尺寸与标高、同心孔/无孔说明、来源数量、材料施工依据、范围确认、预览、修订及独立复核。修改编制字段清除旧预览并撤销确认。来源井筒版本变化后重新读取会清空旧板孔尺寸、标高和逐板依据，不能沿用旧来源审定。

只读接口`GET /projects/{pid}/chamber-plate-candidates?component_id=...`仅接受当前已审圆形井筒，并继续验证其上游管线与原件。允许已授权复核角色读取，写入仍受角色、成员与租户权限限制。来源完整快照由服务器生成；原件字节、证据、来源版本、并发对象哈希、保存预览及公式在编制、复核、计算书及计价门禁复验。

已审井板可作为关联回填的净实体占位来源，采用既定已审净体积，不回加孔体积、不再次乘井数。实际标高、同域包含及与井筒/其他实体扣减不重复范围仍须单独核定；软件不自动判断空间关系。

井板修订使关联回填及下游审批失效；来源井筒修订会沿“井筒→井板→回填”传递失效。未变化的其他来源审批保留。旧计算书、报价及已保存导出独立保留。
