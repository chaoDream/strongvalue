# 0.2 功能扩展与验收范围

此处保留0.2交付记录；后续审核、调价及企业模板能力见 [0.3功能说明](RELEASE-0.3.md)。

本轮从0.1继续实现可在现有资料下完成的工程能力。以下“实现”指代码、界面及软件测试，不等于真实工程专业验收。

## 本轮新增

| 模块 | 可操作功能 | 关键边界 |
|---|---|---|
| 原始图纸解析 | PDF文字对象及近似定位坐标，ASCII DXF文字、图层、标注测量值及绘图单位；显式尺寸单位转为米；同名构件同参数冲突保留 | 坐标只用于定位文字，不用像素长度生成工程量；DWG、二进制DXF及复杂拓扑仍需专业解析器 |
| 模型辅助解析 | 私有网关协议及OpenAI Responses文件输入/结构化输出路径；逐文件接收方确认、响应大小限制、无工具执行、幂等任务、失败重试、模型/响应哈希记录 | 未配置凭据不调用；本轮未使用真实付费模型，实际调用协议采用模拟HTTP验证；视觉结果仅是待复核证据 |
| 几何与钢筋表 | 九类受控计算：底板/垫层、等厚池壁、直线管段、展开矩形面积、墙梁、核定梯形沟槽、回填、环形构件、钢筋表汇总 | 工法、展开边界、扣减口径须专业审定；钢筋只能按有结构证据的长度、根数及核定每米质量汇总，不是无图配筋推算 |
| 现有清单导入 | XLSX/CSV/TSV预览、列映射、行号、错误与重复提示、确认后入账、导入幂等、原文件证据 | 导入数量和清单分别复核；历史综合单价仅保留为参考，不变成当前授权资源价；不替代原始图纸主流程 |
| 清单拆分与合并 | 单来源等量拆分，同编码/特征/单位/层级/定额组成合并，来源贡献链与重复计量检查 | 不猜测多构件比例分摊；拆并结果重新复核，旧项留存历史 |
| 定额候选 | 把已审且来源完整的组价存为项目授权候选，经独立审定后按地区、规则版本、单位、许可、有效期和文字特征返回Top5 | 当前是项目范围候选库及文字匹配，不是官方定额库、跨企业共享或已完成语义模型召回 |
| 费用与日期 | 项目计价适用日期，价格/规则按该日期校验；0–6位综合单价及三种修约；人工/材料/机械/设备基数；受控加减乘除表达式、已算费用引用 | 费率和适用标准须人工核定；总金额、清单合价、费用仍保留两位。表达式不能运行任意代码或向前引用费用 |
| 变更签证 | 原清单快照、增减量、图纸/签证证据、独立审批、应用后重审、重复应用防护、已撤销签证通过新签证修正 | 不自动撤销已应用数量；已应用签证不能被原设计算量重生成静默覆盖 |
| 专业底稿对账 | 同构件独立底稿CSV/XLSX，逐项数量、单位、差量、绝对/相对容差、覆盖检查及独立复核；数量更新后旧对照失效 | 新建项目默认启用审核门禁。旧0.1项目保留原设置，可在“适用日期与范围”启用。没有真实专业底稿时不能宣称真实算量验收通过 |
| 版本与敏感性 | 两版清单/数量/单价/合价/费用与规则差异；数量、材料、人工、机械假设系数重新计算 | 内部测算单独留存，不改报价或审批，不导出为审核成果，不做多主体联合报价 |
| 成果交付 | 生成实际PDF并通过本地PDF.js渲染/翻页/缩放，原始PDF图纸同样使用该阅读器；切换报价版本清除旧预览；应用变更时增加签证台账；按规则显示单价精度 | 通用报表包已实现，官方历史样板版式及当地电子标格式仍待样本验证 |
| 成员管理 | 当前企业成员创建、角色及启停，变更撤销旧会话，禁止管理员自停用，单独权限审计 | 尚无SSO、专业资质和项目级细分授权；商业多租户运营仍需生产化部署 |

## 如何使用新增功能

- **图纸与算量**：查看尺寸候选，先复核再采用；“模型辅助解析”显示实际接收方，确认后才发文件；形成计算书后可“导入专业底稿对账”。
- **清单编制**：使用工具栏导入、拆并或建立签证；签证审批后由编制账号应用，再审定新清单。
- **组价审核**：保存并复核授权候选，再检索应用；采用候选会使清单回到待复核。
- **取费汇总**：设置适用日期和黄金底稿门禁，配置修约及组合基数；生成两个版本后可对比，也可做内部测算。
- **成果交付**：“生成并预览实际PDF”显示实际存档文件，仍受草稿/审核标识控制。
- **系统配置**：管理员管理成员；模型配置与任务状态、失败重试在同页展示。

底稿列示例（仅表头，不代表专业数据）：

```csv
构件名称,单位,基准工程量,绝对容差,相对容差,计算书ID
```

绝对容差和相对容差由专业人员提供，允许偏差取两者对应数量的较大值。没有唯一匹配或遗漏当前工程量时对照不通过。以中标金额为“基准工程量”无法与同构件计量单位匹配。

## 验证与未完成事项

本轮最终53项自动测试通过，TypeScript检查及生产构建通过。新增软件回归覆盖：九类几何边界、钢筋证据限制、费用表达式与修约、导入预览/错误/幂等、拆并守恒、变更审批/撤回修正、差异对比、测算不改基线、授权候选过滤、跨图冲突/图纸换版、PDF/DXF文字标注、模型授权与原文匹配、Responses协议/拒绝、成员隔离/会话撤销、底稿门禁及变更失效。

合成数据性能脚本为 `scripts/benchmark.py`：500清单、2000定额子目、4000资源行，20次纯确定性引擎重算。本机本轮中位约0.0076秒、P95约0.0078秒；**不包含API/数据库、AI解析、专业软件和报表输出**，不代表生产负载验收。

仍需外部资料或后续工程：真实污水厂全专业图纸与黄金底稿；复杂构件/结构配筋模型和专业工法规则；合法省定额/信息价数据接入；实际模型质量评估；GTJ/GQI/GCCP授权和往返试验；TPL-A/B与当地官方报表样本；电子标交换格式；PostgreSQL/S3/隔离任务队列、SSO、全面恶意文件扫描和商业容量/安全验收。0.2不宣称PRD全量商业版完成。
