# 0.115 基础水平模板多内圆窗口

日期：2026-10-27。前后端及使用手册版本0.115.0。

## 本次完成

整体顶底、台阶平台及内部孔端支持一个圆形外轮廓减2至4个严格内部且两两严格分离的圆形不支模区W。逐圆名称、共同坐标下的圆心XY、实际直径、逐尺寸原件和排除用途原件分别保留；精确有理数严格校验内含及分离。W不创建实体孔或改变混凝土。200位圆弧解析积分保留80位及有序AST，先排全部W再扣净区实际孔H；数量继承一次，仅总净量有据修约。

完整窗口及跨记录防重接通圆形类和直边／带孔／多块／嵌套窗口。一个连通净块须完整在某一个W内，不能拼接不同块或不同W的极值；精确判断不采用容差。零接触按全部外圆候选边界事件排W及H后无剩余证明，显示修约零不替代证明。

页面支持逐圆添加／移除、改动撤销确认与旧预览、逐圆原件及严格拓扑复核。JSON、Excel和PDF保留参数、严格拓扑、真实积分及按需零覆盖、防重和逐边见证。详见[使用手册16.15](USER-GUIDE.md#foundation-circular-holes-window)。
