# 0.72 固定布置中的指定构造加柱

继续补齐PRD F05的栏杆计量。材料表新增“固定间距及指定构造加柱”：在有据核定的固定间距、锚向及端部归属上，按原图逐根指定内部构造柱端距S，保留原柱与余跨，生成全部根数、逐根端距和材料质量。

## 规则与范围

每个来源计入区间都须明确加柱列表，没有加柱的区间为空列表；此模式至少有一根指定加柱。每根填写名称、端距S及单位、构造说明，端距与说明分别关联原始依据。原定距柱不移动、不减少，新增柱不触发重新均分；端距从来源原段起点按已审三维或水平口径增加，与起端或终端定距锚向无关。

加柱必须严格在本区间内部，不能位于端部、排除范围或局部区间缺口。端柱通过既有两端归属核定，避免用加柱绕过共享端点归属。相同区间的重复端距（包括不同单位等值）、重复名称及与原内部定距柱重合均阻断。不会按显示容差合并近邻柱。

新增柱与本材料项原柱使用相同独立核定的下料长及每米质量；不同规格须另行列项并核对范围。系统不推断哪里应加柱，也不从加柱记录认定结构设计合规。当前只支持固定间距来源；最大间距均分布置中的加柱尚未扩展。原独立定长件、均分和纯定距模式及其规则版本保留。

每区间最多100根构造加柱，含原柱的每材料项合计最多1000根，每表最多5000根单组布置立柱、1至50材料项。检查容量后才处理逐根记录，超界须按实际范围拆分。不同材料项、跨边内部相交和近重合不自动去重，跨区间柱距及专业构造仍须另核。

## 精度与溯源

新材料表采用`railing-material-mass-1.5`，布置规则为`railing-fixed-added-posts-1.0`。在原定距计算结果上追加有据立柱，不修改原跨数、余跨或逐根位置。原定距数量与新增列表长度分别保留，数量表达式为原数量加新增根数；逐根S保留原值、单位换算、表达式和原件。

端距及重合判断采用精确有理数。对从终端布置的整段斜边，使用原边长度平方比较端距加固定偏移的平方，不能以修约后的平方根判断相等。加柱后的展示记录按来源S排序并重新编号，原始加柱输入顺序与原件仍保留。

采用Decimal 80位；分项下料及质量不提前修约，材料合计只乘一次来源重复数量，仅总质量按有据0至12位HALF_UP修约。预览、保存、审核、计算书和导出均重建来源、位置、原柱/新增数量及表达式，篡改计算记录会被拒绝。

## 界面与闭环

编制页逐区间新增或移除构造柱。模式切换、参数变动清除旧预览与确认；切回原定距模式不会保留隐藏加柱。复核示意中原柱为绿色、加柱为紫色、原余跨为橙色，可查看每区间原柱数加新增根数及完整端距。跨数校验描述原定距布置，不能替代加柱后的全局柱距校验。

沿用独立复核、对象哈希、修订并发、完整历史、原件及角色租户门禁。来源变更使材料与下游失效；恢复时读取当前来源并清空旧材料、定距规则、加柱及逐项依据和确认。旧清单在重建前保留，旧报价不会混入新加柱。

JSON包含完整位置及来源。Excel/PDF保留原定距四表（逐根表列出所有原柱和加柱），新增“构造加柱数量组成”“构造加柱端距及依据”。无需新依赖或数据库迁移。
