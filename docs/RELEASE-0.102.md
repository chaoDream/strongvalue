# 0.102 基础盲孔孔底、孔顶水平接触模板

## 本次补齐

基础水平模板新增已审竖直圆孔、轴向矩形孔的内部孔底和孔顶整面。孔底取来源起Z，其混凝土侧在下方；孔顶取止Z，其混凝土侧在上方。标高、孔心、截面、层、全部最终基础个数和原件全部只读继承，不接受另填尺寸、Z、面积或重复数量。模板材料、实际接触工法、范围和修约仍须原件并独立复核，不能由盲孔或土面自动推断支模。

每基础毛面积=所选孔截面∩混凝土侧实际层截面，再扣该侧其他孔与所选孔的实际交集。孔底在层界选择满足层底<孔底Z≤层顶的下侧层；孔顶选择层底≤孔顶Z<层顶的上侧层。基础底部孔口没有内部孔底，基础顶部孔口没有内部孔顶，候选明确禁用并保留整体外端面入口。内部孔端与侧层无交集或被相接孔完全贯通时保留零接触，不按全孔代替。边界使用原始十进制比较，没有标高容差、吸附或投影猜测。

对孔底，只扣其他孔起Z<本孔底Z≤其他孔止Z的相交截面；对孔顶，只扣其他孔起Z≤本孔顶Z<其他孔止Z的相交截面。来源已验证该混凝土侧各孔在正高度内互不正面积重叠，且包含于该侧层，因此各实际交集可分别扣减，不重复扣减。若总交集超过毛面积则阻断并要求另核。体积扣孔阈值不填实物理孔，不改变基础计量体积或材料量。

台阶处孔顶可能只覆盖上层的一部分：只取孔与上层的交集；既有平台仅取上层名义截面之外的部分，二者互补而不重复。孔底取下侧层，支持层内及层界内部端面。矩形逐轴精确裁切，圆圆/圆矩形沿用0.101的双弓形/四象限解析计算、200位Decimal工作精度、80位输出及记录固定π；数值界限不能确认时继续阻断。相接孔交集先把两孔原始XY作差形成相对位置AST，不把任意一个孔心当成基础原点。

输入范围使用`face=hole_bottom/hole_top`和整数`hole_index`，不手选层；同基础项同孔同端面、同记录或跨记录均禁止重复。孔底与孔顶、不同孔、整体顶底及平台分别核定。含孔端的计算使用`foundation-horizontal-formwork-1.3`；未选孔端的旧记录、公式、版本和报表保持原样。来源校验、原件字节、独立重建复核、并发校验和完整修订历史沿用原门禁。

页面新增逐孔端候选、上下侧层、全孔与侧层交集、相接孔扣减及可展开解析过程；更换基础项或水平面会清空不再适用的孔/层选择、范围说明和原件，重新要求范围确认。读取修订来源会清空旧范围、材料、依据和修约。JSON保存完整公式及中间数；Excel/PDF按实际孔端新增“基础孔端接触截面”“基础孔端相接孔交集”，存在曲线时再加“基础孔端曲线交集过程”，长数续行、跨页重复表头。无孔端的旧成果不增加新空表。
