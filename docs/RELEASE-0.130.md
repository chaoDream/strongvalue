# 0.130 余料已释放未领余量补料

日期：2026-10-28。前后端及手册版本0.130.0。

余料部分领用并显式释放未领余量后，可在最初材料表及完整需求有效且不变时，重新核定精确定尺的同材质截面、质量合格余料供应。预览冻结上游及释放依据、缩减后的逐需求根数、新余料编号／库位／规格及规范总量；保存另建补料预留立即占用，另一账号复核。核定日期和拟交接对象不代表实际交接，实际领用必须另建独立余料批单、复核及显式执行，不允许从补料预留直接整单领出。

禁止从已领、退回、在外或加工数量恢复额度。未领子单有据整单释放可重做，有领出后只能沿自己的已释放未领额继续，不能向祖先重复取额，最多20级。并发、原件字节、快照、预览、库存版本、项目权限和禁自审门禁保留。祖先释放原件后续失效不回滚数量，既有记录提示，关联加工子余料及后代待核查、禁止新采用。

原预留、实际批单及工程／排料／净量／清单／报价和审批保持；补料及批单随库存JSON独立留档，历史文件原字节保持。使用手册见[15.18](USER-GUIDE.md#offcut-replenishments)。修订或损耗追加、改定尺、原材与余料混配、采购、跨项目及执行冲销仍未完成；全专业图纸提取、授权库及厂商真实往返、真实工程及商用运维验收仍待完成。

1001项相关库存、盘点、加工、排料、权限、报价、手册、交付及PDF历史预览回归通过；新增阻断伪造旧整单事件后，最终39项专项通过，重复用例不重复累加。前端类型及生产构建、普通和基线手册检查通过。合成浏览器核对编辑清预览、核定和实际批单分离、保存／审定只占用、另一账号审实际批单及显式领用；新组和旧组各在外1根。四阶段JSON历史原字节及SHA256、62条审计关联核对通过。截图：[补料预览](qa/v0.130-offcut-replenishment-preview.png)、[独立复核](qa/v0.130-offcut-replenishment-review.png)、[领用后余额](qa/v0.130-offcut-replenishment-issued.png)。这些是隔离合成软件验证，不代表真实仓库、材质鉴别、采购、工程或商用运维验收。
