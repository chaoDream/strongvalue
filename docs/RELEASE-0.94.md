# 0.94 圆柱基础局部圆弧模板

本次继续补齐PRD F05的基础模板：已审圆柱或圆形台阶基础，在原整周外侧模板上新增有据起止角度，按实际圆弧及标高范围计算展开净面积。矩形和原整周记录的计算、规则版本及报表保持；未选范围不计，不由系统推断施工支模范围。

## 角度与共同基准

仅适用于圆柱外侧，可逐层选整周或明确圆弧；矩形面不能填写圆弧。沿用同一基础局部XY圆心，0°为+X，从+Z向原点俯视、从+X向+Y逆时针为正。局部XY如何对应原图方向须填写共同角度基准说明、当前项目原件并确认，不能由孔位、材料数量或界面默认方向推断。

同一来源基础项全部圆弧，包含跨层和跨模板记录，须使用相同的角度基准说明及同一原件（比较时忽略首尾空白）。基准不同直接阻断，不把不同零角方向下的范围当作分离。记录基准哈希用于核对说明与原件的一致性，不代表系统自动完成了图纸旋转坐标校准。

只接受度（°），0≤起角<止角≤360°，支持明确的180°以上大弧。不能用弧度、长度或人工比例代替；不自动求余、倒向、取小弧或补未选角度。跨0°拆成两项，例如270→360°和0→90°，两项须采用同一基准；0°与360°为同一周期边界。全0→360°也可显式填写，但仍须完整角度原件及基准确认。

每项展开宽=π×本层实际直径×（止角−起角）/360；面积乘该项实际接触高及来源全部基础个数。逐弧角度、展开宽及面积不修约，采用Decimal 80位及记录的固定π，仅累计总净面积按核定的位数HALF_UP修约。起止Z仍须在所选层内，底面0向上；跨层分项，不另乘层数、段数或来源重复。

同一基础项内所有基础采用同一角度基准及接触范围，差异做法须先拆分来源。圆柱内部孔及点相切不产生正面积外侧扣减，已有基础孔的实际几何约束继续由当前已审来源保证。矩形侧开口的实际扣面积规则保持，混凝土体积阈值不会恢复不存在的接触面。

## 圆弧与标高重复校验

同一来源基础项、同层、同圆柱外侧，角度与标高两个方向均为正范围交叠才重复。角度分离、角度边界相接、标高分离或标高端面相接可共存；整周也参与检查，不能和同时覆盖的圆弧重复计量。

角度比较同时考虑对比范围平移-360°、0°、360°的周期区间，保存最小角间隔、采用的周期平移、标高间隔、结论和两个间隔的AST。负间隔表示该方向正交叠，零为边界相接，正为分离；0°/360°相接会明确记录，不能误报为离开半圆。记录内逐对计算，跨记录在保存、复核和重算时检查。失效记录仍保留原范围占用，应修订原记录，不能新建一份绕开重复门禁。

## 编制、修订与历史

“基础外侧模板”的圆柱侧面新增“按原件选取局部圆弧”。启用时起角、止角、原件、共同基准及确认均为空，不预填实际角度。切换整周/圆弧清空本项接触说明及其依据；所有编辑撤销整体范围确认。角度、角度原件、基准、标高或单位变更撤销圆弧确认。选择基础项、层或面会移除旧圆弧配置，避免沿用错误方向；读取新来源清空旧接触范围、做法、原件及修约。

同来源修订恢复完整角度、原件、共同基准和原圆弧确认，整体需重新确认；后续编辑再撤销对应圆弧确认。停用圆弧移除角度配置，恢复整周并要求重新核定接触说明；若尚有同域圆弧，仍会被整周重复检查阻断。再次启用为空配置。

保存、独立复核、计算书重算及计算书复核完整重建角度、范围、基准、展开宽、全部数量、周期校验及AST。原件五门禁、角色/租户、异项目依据、篡改、伪造ID及乐观并发保护延续。预览不写项目，修订保留精确历史及旧清单，使旧计算书失效；基础或上游来源变化沿依赖链使模板失效。既有报价及导出字节保留。

## 接口与计算记录

继续使用`kind: foundation_formwork`和既有候选、构件预览/新增/修订接口，顶层为空参数、面积类型。原`contact_ranges`行的基础项、层、外侧面、起止Z及逐参数原件保持。在`face: circumference`行中可选新增：

```json
{
  "arc_range": {
    "parameters": {"angle_start": "0", "angle_end": "90"},
    "unit": "°",
    "evidence": {
      "angle_start": "当前项目起角原件证据ID",
      "angle_end": "当前项目止角原件证据ID"
    },
    "coordinate_basis": "据图核定的局部XY与图纸方向对应说明；所有同源基础项圆弧引用同一基准",
    "coordinate_evidence_id": "当前项目共同角度基准原件证据ID",
    "scope_confirmed": true
  }
}
```

上列角度仅作接口示例，不能作为工程默认值。配置必须完整且不含额外圆弧长度、半径或比例。角度沿用18位有效数字、18位小数及有限值检查，单条配置不允许零弧或反向弧。原单份模板最多200项接触范围的限制保持。

有圆弧的记录使用`foundation-outer-formwork-1.1`，无圆弧仍为原1.0。逐弧新增起角、止角、弧角、角度单位、本层整周长、基准哈希及对应AST；展开宽为实际选弧宽，不是整周长。顶层`arc_checks`保存同项同层的周期角间隔、平移、标高间隔和公式。维度、证据索引、来源快照及原始配置均保留；圆弧不会改变来源基础体积、孔洞、布柱或材料质量。

## 清单与报表

计算书审定后仍生成“基础已选竖直外侧实际接触净面积”m²清单，编码映射不会改变面积。编码、工法、特征及标准适用性仍须独立核定，不提供官方编码或价格默认值。

界面主表直接显示每段角度和标高，并列整周长与选弧展开宽，可展开查看完整长数、原件及周期分离记录。JSON保留完整数据和AST。Excel/PDF在原五张模板表之外，新增“基础模板圆弧角度”“基础模板圆弧基准与原件”“基础模板圆弧分离校验”三表；长数、长说明和原件续行，行高适配。无圆弧的旧模板和历史报价不新增空圆弧表。
