# 0.85 逐规格每件锯缝与实际容量选材

继续补齐PRD F05材料计量和F09可追溯报表。不同候选定尺可分别核定每件锯缝，和已有逐规格端切、余料阈值及有限供应上限组合，按实际规格容量选材、计算切割位置及长度质量台账。

## 输入与确认

`stock_choices`新增可选`kerfs`，严格包含`alternatives`、`scope_confirmed: true`、`measurement_basis`和`evidence_id`。S1沿用本组每件锯缝及原件；S2至全部备选按原顺序逐项填写`kerf_per_piece`及`evidence_id`，不可缺项、多项或夹入其他参数。锯缝非负，可明确填0，单位沿用混排组；每件包含每根最后一件均计一次，不重复计入净下料或端切。

逐规格锯缝口径明确优先于组及端切说明中的通用锯缝，须另填原件和说明并确认，不能直接继承旧通用确认。各候选至少能放下一件所选材料，各需求至少有一种可用规格；有限模式进一步排除零供应规格。不增加材质截面混用能力，每组200件、全表400件、2至5种定尺边界延续。

新启用时S2起锯缝、原件和说明为空，确认未勾选；切换模式清空通用供应说明、原件及按需确认。修改锯缝参数、原件或口径会移除旧供应上限并撤销供应确认，须重新核定。加工和锯缝核定后可重新填写有限供应。修改备选长度/原件、增删候选会移除旧逐规格端切、锯缝及供应配置，防止序号错配。材料项或来源改变沿用整组清除机制。关闭新模式并重新核定供应，可恢复原统一锯缝能力。

## 容量、搜索与台账

每件在规格j中占用“净下料长+规格j每件锯缝”，每根容量为该定尺减去其起终端切除。不同规格的装载量分别记录，不将某规格较小锯缝直接套到另一规格。输入精确整数化后，确定性初始方案与最多5000节点搜索优先最小购入总长，同长度再最少根数。有限供应逐种检查上限。

下界用正供应候选的最小锯缝和最小端切作安全松弛，根数容量下界也使用乐观占长；它不是可直接施工的拼接规格。实际初始方案和搜索扩展逐规格验算容量。达到购长/根数双下界或搜索穷尽才证明最优；预算耗尽且已有方案仅标可行未证明，尚无方案时明确不能据此判供应不足。初始启发式全部失败后仍继续搜索，不把初始失败当作无解。

逐件起点、净切割终点及锯缝终点按所选规格推进；每根最后一件也计入锯缝。余料继续按该规格的核定阈值分类，购入=净下料+锯缝+端切+报废余料+待留用余料精确闭合。参数、单位换算、逐规格/逐根/汇总公式AST和原件均保存。净材料项、原布置、净质量公式、清单与报价不增加损耗。

规则为`railing-stock-kerf-1.0`，材料表为`railing-material-mass-1.18`。没有`kerfs`时旧规则结果及报表保持不变。

## 复核、修订及导出

预览、材料详情和独立复核增加规格/每件锯缝/原件表及范围说明，原通用锯缝依据明确标为S1。保存重建重新计算选材、位置、损耗、公式和原件，拒绝伪造汇总。即使净量相同，锯缝修订仍须重新复核、使旧计算书失效，历史版本、旧清单与报价快照保留；并发、角色租户、原件字节及来源门禁延续。

JSON保存完整数据，Excel/PDF新增“逐规格每件锯缝”和“逐规格锯缝范围依据”，原下料位置及长度质量台账使用实际锯缝，加工范围明确以锯缝表为准。旧报价不加入新表。
