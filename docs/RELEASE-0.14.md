# 0.14 有据定额换算

补齐 PRD F07 的单位换算、人工及机械等分类系数表达。编制人员可在每个定额子目启用换算，填入定额单位、单位换算率、人工/材料/机械/设备四类系数，以及来源、授权、换算说明和本项目当前原始证据。

## 计算与审核

- 单位换算率定义为每一清单单位对应的定额单位数。例如清单 m³、定额 10m³，填 0.1；系统不推断单位关系，不提供默认的官方系数。
- 有效消耗 = 原始定额消耗 × 原通用系数 × 单位换算率 × 资源所属类别系数。资源费用按有效消耗乘价格，再进入原有单价、合价、取费与修约流程。人工等分类取费基数使用换算后的金额。
- 四类系数及单位换算率必须是正的有限十进制数，精度与范围使用既有输入约束。未知字段、缺少任一类别、空说明和无效资源类别均拒绝。改成零消耗应修改原消耗量并复核，不用零系数隐藏费用。
- 保存要求当前本项目证据；复核及计价再次检查原件是否被替代。换算与清单共同签审，编制人员不能替代独立复核。更新使原清单复核及后续报价状态失效，重新核准后才可计价。
- 未启用换算时沿用原来的单位清单消耗与通用系数语义；旧数据无需迁移。启用和停用不会自动改写原消耗量，界面提醒核对口径。

## 追溯与导出

新报价保存原始换算配置、各资源实际合成系数、换算后的消耗和费用，带有 pricing-2.1 标记。旧计价输入仍标记 pricing-2.0，已保存报价不被改写。报价对账显示换算字段变化。

PDF、Excel 和 JSON 的共同报表数据增加“定额换算明细”，列出单位、四类系数、通用系数及证据与说明；长文本分段。没有换算的报价维持原有报表结构。综合单价分析中的“换算系数”为实际合成系数，乘原消耗及价格可核验费用贡献。

## 验收与边界

新增17项合成测试，验证四类计算、取费基数、数字/结构拒绝、跨项目或过期证据、独立复核、报价快照保留、差异字段和三种格式导出；另以隔离工作区在浏览器保存材料系数并核验结果。没有改动实际工程数据。

本版没有引入官方定额数据，也不自动确认系数是否合法适用。材料替换仍通过资源编辑、证据和清单复核完成，尚未提供配合比/替换前后消耗的独立换算规则库；复杂 OCR、完整专业算量、厂商软件授权接口和真实工程黄金底稿验收仍未完成。
