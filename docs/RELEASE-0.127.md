# 0.127 完整原材分批领料与未领余量释放

日期：2026-10-28。前后端及使用手册版本0.127.0。

完整原材可从当前已审预留按原分配序号选择本次实际根数，填写交接人、日期、说明及当前原件，先只读预览，再保存、独立复核和显式执行。每批只结转本次在库及未领占用为该批在外数量，未领继续占用，不因部分出库提前释放。全部领完关闭原需求，完整退回也不重开。旧首次整单领料保留，分批领出后不能用整单入口覆盖历史。

各批独立跟踪加工和完整退回，保留原预留分配序号，包括非首项和跨批次来源；后续加工结果仍按相应投入单验收。部分领出后若确认不再领，可有据显式释放逐项未领余量，在库及已领事实保持；原材料表失效仍保留占用，须人工有据释放。释放和领出并发时重新核对当前余额与版本，不能按旧数重复成功。

输入修改使预览失效，原件在预览／保存／复核／执行检查真实字节。历史交接依据失效不回滚出库或释放剩余占用，实际后续交接另以当前原件核定；原登记／盘点隔离规则保持。记录、来源、累计数量、执行或余量释放顺序异常阻断读账及新导出。原工程、排料、报价及审批保持，库存JSON独立留档且历史字节不改写。

40项分批领料专项与844项既有库存、盘点、加工、排料、权限、报价、手册、交付及PDF历史预览，共884项相关检查通过。前端类型及生产构建、普通及基线手册检查通过。合成浏览器验证编辑清预览、保存／复核不出库、首批领1后在库9／占用2／可用7／在外1、释放未领2后在库9／占用0／可用9／在外1；原工程及预留登记保持，四阶段JSON历史原字节和SHA256及37条审计链关联核对通过。
