# 0.129 完整原材已释放未领余量补料

日期：2026-10-28。前后端及使用手册版本0.129.0。

完整原材部分领出并显式释放未领余量后，可在原材料表及完整排料需求仍有效且不变时，为释放的未领根数重新核定同材质截面、定尺及每米质量的新批次供应。只读预览逐项需求、新批号库位及规范根数／长度／质量；保存另建补料预留立即占用，另一账号独立复核。实际领料仍须另建单、复核及显式执行，原预留、释放事件和已领批单保持。

同一上游额度禁止并发重复占用；未领子单有据整单释放可重做。有领出后不能回祖先取额，须沿该子单自己已释放未领部分继续核定，最多20级。退回、在外或加工数量不恢复未领额度。来源、原件字节、快照、预览、库存版本及独立复核门禁沿用；来源失效不自动释放已存占用或回滚实物。

补料链及本次供应快照随库存JSON独立留档，旧文件原字节保持；工程、排料、净量、清单、报价和审批保持。普通全量预留入口不放开重复领料。

完整操作见[手册15.17](USER-GUIDE.md#stock-replenishments)。不覆盖修订或损耗追加、改定尺、余料改配补料、完整原材／余料混配、采购、跨项目共享及执行冲销。全专业图纸提取、授权库及厂商真实往返、真实工程与商用运维验收仍未完成。
