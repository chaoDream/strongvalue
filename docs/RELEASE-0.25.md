# 0.25 平面区域并集与扣减

继续补齐PRD F05及6.1中的几何布尔计算和可追溯计算书能力。新增受控的平面矩形区域计算：将同一设计坐标平面的多个加项合并，再扣除扣减区域的并集，避免重复计量。结果可选择面积或统一厚度的体积，并沿用独立复核、计算书和清单流程。

## 录入与计算

- 每组1至30个轴向矩形，至少一个加项；逐项录入名称、加扣、起点X/Y、沿X长度、沿Y宽度、原始单位、计量说明和逐参数证据。坐标可为负数，长宽必须为正数。
- 必须明确共同设计原点、X/Y方向及其证据。坐标来自已确认设计标注，不从示意图、图片像素或比例尺推测。区域可分别使用m、mm、cm、dm、km，固定换算关系沿用measurement-units-1.0。
- 支持净面积m²或净面积乘统一厚度得到m³；体积模式须关联厚度原始依据。整组重复数量为1至1000000的整数，须关联来源。面积模式不能携带厚度信息。
- 采用Decimal 80位精度，按X边界分条带，逐条合并Y区间。加项和扣减各自去重，净量为加项并集减扣减并集，再乘厚度及重复数量。允许接边区域及净量为零。
- 扣减必须完全位于加项并集内，包括跨相邻加项的扣减；部分落在外侧或跨越无加项间隙均明确拒绝，不自动裁切。尺寸沿用18位有效数字、18位小数、换算前后范围及工程量上限保护。
- 汇总保留原始累加面积、并集面积、重复面积和净面积。两两相交记录仅用于定位，三重及更多重叠时不能把两两面积相加替代实际并集扣重。

## 来源、复核与输出

保留每个区域的原始参数、原始单位、标准坐标、精确因子、原件证据、共同坐标依据和计量说明。结构化公式AST由原始尺寸及换算节点组成，可独立复算；条带记录提供X区间、加项/扣减Y并集和该段净面积。规则版本为rectilinear-1.0。

保存、构件审定、重新算量、计算书审定和报价门禁均检查来源、原件及计算内容。并发修订须提交当前对象哈希；修改区域、坐标、单位、厚度或依据会要求重新复核，不能通过省略类型降回普通构件或沿用旧计算书审批。历史报价及已留档文件保持原样。

图纸与算量页提供区域编辑、预览、净区域示意图及独立审核明细。绿色区域为扣减后的净区域，虚线标识输入矩形；示意图不能用于测量，极小区域可能无法按比例清晰显示。JSON保留全部过程；Excel/PDF增加“区域并集与扣减”“平面区域与坐标”“区域条带计算过程”“区域相交定位”，原始单位继续进入单位换算表。
