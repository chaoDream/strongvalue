# 0.84 逐规格加工参数与实际可用长选材

继续补齐PRD F05材料计量和F09可追溯报表。多定尺混排可按原件为每种备选定尺分别核定起端切除、终端切除及余料留用下限，按各自实际可用长选材、定位切割并分类余料；支持与0.83有限供应上限组合。

## 参数及原件

`stock_choices`新增可选`processing`，严格包含`alternatives`、`scope_confirmed: true`、`measurement_basis`和`evidence_id`。S1沿用本组原有三项参数及原件；`alternatives`按S2至全部备选逐项填写`trim_start`、`trim_end`、`reusable_min_length`和`evidence`，后者必须包含对应三项原件，不能缺项、多项或增加隐含参数。

长度单位沿用本组，起终端切除非负、留用下限为正，两端切除之和须小于相应定尺。每种候选至少能容纳一件所选材料。统一锯缝按每件一次计入，含最后一件，端切每根各计一次，不能重复扣减。材质截面须相同；每组最多200件、全表400件、候选2至5种的边界延续。

新启用时S2起六项或更多参数、逐项原件、范围说明均为空，确认未勾选。切换加工模式会清空通用供应说明、原件及按需确认；修改加工口径移除旧供应上限并要求重新核定供应。可在加工核定后重新填写有限供应。备选定尺增删、长度或原件变化清除旧加工配置和供应上限，防止序号变化后套用。材料或来源变更沿用已有整组清除机制。关闭后重新据原件确认供应，可恢复统一参数的旧规则。

## 精确下料、证明及净量

各规格容量使用“定尺−起端切除−终端切除”，精确整数化后搜索，目标仍先最小购入总长度、同长度再最少根数。购长下界采用可供候选的最小端切总长作安全松弛，扩展和容量检查使用实际规格参数；有限模式只纳入正供应候选并检查各规格数量。搜索仍最多5000节点，仅双下界达到或穷尽搜索才证明最优；预算耗尽维持可行未证明/尚不能判定无解的区别。

逐件起点采用所选规格的起端切除，单根余料按该规格留用下限判断，等于下限列为待留用。候选参数、可用长及逐根/分组长度质量公式AST、逐参数原件和换算记录完整保留。购入=净下料+锯缝+端切+报废余料+待留用余料，精确平衡。留用余料仅是本次方案台账，不自动入库或回用。

规则为`railing-stock-processing-1.0`，材料表为`railing-material-mass-1.17`。无`processing`时旧结果及旧报表保持不变，净材料、布置、清单和报价口径不增加备料损耗。

## 审核、修订与导出

预览、材料详情和独立复核显示S1至全部候选的端切、可用长、留用下限及逐项原件。原件可按行展开，数值表保持紧凑。原通用参数的三项依据明确标为S1，避免误认为适用于全部备选。保存重建核对参数、选用、位置、余料分类和AST，不信任前端汇总。参数修订即使净量相同也撤销确认、重新复核并使旧计算书失效，历史构件、旧清单和报价快照保留。

JSON保留完整数据，Excel/PDF新增“逐规格加工参数”和“逐规格加工范围依据”，原混排位置及长度质量台账使用新参数，旧报价不增加新表。原件字节校验、角色租户隔离、来源版本和并发门禁延续。
