# 0.83 有限供应选材与上限台账

继续补齐PRD F05材料计量和F09可追溯报表。在0.82多定尺联合选材基础上，可据原件核定本混排组、本次方案各规格可用根数上限，在有限供应约束内优先最小购入总长、同长度再最少根数。上限是方案输入，不办理真实库存占用、采购或入库。

## 输入与供应口径

`stock_choices`新增可选`supply_limits`，严格包含`quantities`、`scope_confirmed: true`、`measurement_basis`、`evidence_id`。`quantities`按S1至全部候选原顺序逐项填写，每项仅含`quantity`和`evidence_id`；不得缺项、多项或增加隐含库存字段。每种须为0至200整数，0表示本次不可用，根数逐项关联原件，供应范围说明另关联原件。有限模式必须显式`supply_confirmed: false`，不能同时确认不限量按需供应。

新启用时上限、原件及范围说明为空，有限供应确认未勾选。切换有限/不限量口径会清空通用供应说明、原件和按需确认，须重新据原件核定。更改备选定尺（含增删或原件变化）会移除旧供应上限，避免候选序号重排后套用旧数量。材料项或来源变更沿用已有整组清除机制。关闭有限供应后仍保留多定尺候选，重新确认不限量口径后可恢复0.82能力；再启用有限上限为空。

同材质同截面、统一锯缝/两端切除/余料阈值、每组200件/全表400件、候选2至5种及原件门禁延续。本组供应上限不与其他组共享，不视为锁定的仓库余额或已采购材料。未选用供应根数与下料产生的待留用余料分别列示。

## 有限约束搜索及错误边界

使用精确整数容量比较，多个确定性初始方案均检查每种使用根数；再以最多5000节点执行有限供应搜索，扩展新原材前检查剩余供应。容量/长度阈值剪枝考虑已开原材空余及未开供应，状态包含原材类型与占长，禁止超供。目标及下界沿用购长优先、根数次之的口径。

初始方案失败不表示无解：搜索仍可找到不同组合，并在结果中明确“初始未找到可行方案”。达到购长与根数双下界或搜索穷尽才证明最优；已有可行方案但预算耗尽，仅标未证明。没有可行方案且预算耗尽时阻断并说明“不能据此判断供应不足”；仅容量约束或穷尽搜索证明不可行时，才提示核定上限无法满足。两类失败都不能保存为成功方案，预览不改持久化项目。

每个候选返回供应上限、选用根数和未选用供应根数，以及上限/差额公式AST和数量原件；保存重建再次核对上限与选用，不信任前端汇总。逐件位置、长度质量组成及购入=净下料+总损耗+待留用余料保持精确平衡。

规则为`railing-limited-stock-cutting-1.0`，含有限供应的材料表为`railing-material-mass-1.16`。没有`supply_limits`时，旧混排及多定尺计算结果保持不变。

## 复核、修订与导出

界面预览、材料详情、独立复核均显示本次上限、选用、计划未选用及原件。任一上限或说明变化撤销整体确认，净量相同也须重新复核、使旧计算书失效；历史构件、旧清单和报价快照完整保留。并发、角色租户、来源失效及原件字节校验延续。

JSON保存全部结果，Excel/PDF新增“有限供应选用台账”，供应范围原件和说明进入混排依据宽表；原多定尺表针对有限口径显示规格/目标依据，不误称不限量供应。初始无可行方案但后续搜索成功的结果也可完整导出，旧报价不增加新台账。
