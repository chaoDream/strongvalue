# 0.9 解析任务执行与重试保护

本版加强 PRD F01/F04 和任务恢复要求中的执行一致性。修复本地解析旧图纸晚到结果可能写入当前候选、重复回调并行执行、恢复后的旧执行覆盖新状态、模型重试未完整核对配置及来源等问题。

## 已实现

- 每次任务领取通过数据库事务检查队列状态，分配独立执行标识；同一任务在排队之外的状态不再次执行。开始、重试及失败事件保留项目审计，本版执行次数和起止时间在系统配置页可见，历史未记录次数不追补。
- 读取原件前核查版本，解析前验证内容SHA256；写入结果前重新检查执行标识、任务状态、原件版本和内容。原件被替代时旧候选不写入当前事实/尺寸，也不改变新版本的解析状态。
- 服务恢复将未完成任务标记失败并保留原件；用户重试会产生新的执行标识。旧执行随后成功或失败都不能覆盖新执行结果，已完成文档不重复生成证据。
- 模型任务在发送前、提交结果前，以及用户重试时核对模型、接收方、协议、抽取契约、提示版本和原始证据指纹；变化时须重新明确确认接收方发起解析，不能沿用过期确认。模型产生的候选仍须人工复核。
- 原件缺失或哈希异常时显示可理解的恢复提示；修复来源后允许显式重试。运行中或已完成任务拒绝重复重试，已替代文档拒绝作为当前数据重试。

## 操作

在系统配置与审计页的“文档与模型任务”中查看状态、原因和时间；失败任务由编制角色点击重试。原件异常应先恢复，历史版本或模型配置变化应重新选择当前文件并确认解析。完成解析不等于工程事实或数量已审定。

## 验证

107项自动测试通过，前端类型检查及生产构建通过。新增用线程和同步事件真实验证重复回调、恢复与重试交错、旧完成/旧失败不覆盖、解析期间图纸替代、损坏原件不进入解析器、原件恢复后重试，以及模型协议/来源变化拒绝复用旧确认、恢复后模型结果不入库。模型使用模拟响应，无真实模型调用。

浏览器在独立合成工作区实际验证原件暂缺失败提示；恢复原件后点击重试，任务完成，记录次数从2到3并显示起止时间，审计保留重试申请。截图 `qa/v0.9-task-recovery.png`。未修改实际工程业务数据。

## 明确限制

仍使用单个应用进程的BackgroundTasks和本地SQLite，没有独立可靠队列、worker进程隔离、租约超时、自动重试、调度或多实例部署支持。服务启动时的恢复适用于单实例；不能把本版称为生产任务队列。挂起任务仍需恢复服务或人工处理，模型外部请求也不能宣称网络层严格只发送一次。
