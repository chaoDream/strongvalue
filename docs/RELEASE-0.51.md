# 0.51 CAD原对象投影、定位与高亮核对

补齐F04中原图对象选择和人工核对的一段交互。读取ASCII DXF后，可在当前批次受支持原对象的XY、XZ、YZ投影中定位，查看句柄、图层及原始XYZ，再明确选择单独采用或加入0.50的多对象管线组装。支持的CAD几何范围继续遵循[0.49](RELEASE-0.49.md)，连接与计量规则继续遵循[0.50](RELEASE-0.50.md)。

## 当前批次原对象视图

“图纸与算量 → DXF设计坐标读取与单位校核”读取原件后，新增“CAD原对象投影与定位”。每个可读原对象形成可点击、可用键盘操作的投影；也可通过“定位原对象”逐项选择重叠对象。橙色表示当前核对，蓝色表示已加入组装序列，绿色表示其他可读对象。支持放大/缩小、四向平移、恢复本批次全貌和居中当前对象。

视图明确显示当前批次起止位置、图层筛选后的总数、绘制数与不可读未绘制数，沿用候选分页上限，默认50、最多200个对象。只绘制本批次可受控读取的LINE与开放3D POLYLINE；纸空间、块、曲线等仍在读取状态中明确说明。当前局部视图不能代表全图、不能将空视图当作无工程量。原件下载入口供核对其他几何、原标注及设计用途。

每次切换投影继续核验源文件与本地解析任务；读取期间保留上次投影并显示状态，禁止使用旧图选择采用或加入组装，完成后更新视图。失败时清除旧视图并显示错误，避免继续展示为当前数据。切换后保留仍属于当前批次的核对对象；更换图层、批次或文件后，无效定位会清除。

## 原始坐标与显示位置分开

后台以80位Decimal、明确声明单位和统一比例计算显示位置，先扣除本批次坐标基点，再映射到显示画布，避免直接将大WCS坐标转为浏览器浮点而丢失微小距离。视图标明所选轴向的WCS米制范围；像素位置修约至6位，仅作显示。

原始CAD坐标字符串、单位、候选ID和对象哈希保持原样。点击对象后可展开逐点原始XYZ、文件哈希和原对象序号，并核对三维长度。后端采用接口拒绝携带显示场景字段，几何证据、长度校核与工程计算继续读取原始坐标；不根据屏幕长度推算施工尺寸。

竖向管段在XY投影中可能成为一点，或微小管段在当前显示精度下重合。页面保留该对象及可选择的标记，显示重合提示，要求切换投影核对XYZ；不能把平面投影零长当作真实三维长度为零。相同投影的不同原对象保留各自身份，可用下拉框分别定位，不自动合并或推断相连。

## 从定位到受控采用

当前核对面板提供“校核当前对象并单独采用”和“将当前对象加入组装序列”。定位、高亮、切换和缩放只改变页面显示，不创建构件、证据、采用记录或工程量。编制人仍须主动确认设计用途、共同WCS及高程基准，填写独立已知长度和容差、重复数量、修约依据及采用原因。独立校核、幂等、防重复采用、源文件变化失效及构件/计算书独立复核门禁继续生效。

复核人员可以读取、切换投影和核对原始坐标，采用及加入组装按钮禁用；服务端的编制权限继续单独验证。显示场景只出现在读取响应和页面中，持久化来源、报价快照及报表继续使用原始坐标与已审计算书。

现有`GET /api/v1/projects/{pid}/documents/{did}/dxf-route-candidates`新增严格的`projection=xy|xz|yz`参数，默认xz，响应增加`scene`：显示规则版本、画布尺寸、米制范围、可绘制与排除数量、逐对象ID/哈希、显示点及重合段索引。候选ID、对象哈希和已有预览/采用请求哈希规则保持，未新增第三方依赖。

## 验证与范围

2026-10-23：新增28项合成测试，全量1342项通过；前端类型检查与生产构建通过。覆盖只读性与对象身份、三个投影的统一比例和轴向、声明单位换算、大坐标下微小距离、竖向投影成点仍按真实三维计量、重叠投影不合并、图层/分页/空结果与排除数量、严格参数、实际源文件和任务变化、角色/租户，以及拒绝将显示数据提交为工程几何。

隔离浏览器读取3个合成CAD对象：2个可读并绘制，纸空间对象未绘制但保留状态。点击A后高亮并核对原坐标；验证放大、平移、居中和全貌恢复；切换XY后保留A，加入组装，再定位投影成点的B，仍显示两点相同XY、Z为17000/12000mm、三维长度5m。切换YZ后保留B，并加入组装。投影、定位和组装候选阶段检查数据库，尚无构件或工程量记录。

明确A原方向接B反向，独立P1至P2校核13m、容差0，采用13m+5m乘重复2的36.000m待复核管线。独立reviewer可定位查看，不能操作采用/组装；核对来源后审定。后续接口验收计算书、计算书独立复核及清单均为36.000m，证据包导出通过，来源未混入投影字段。既有导出格式、历史快照与单对象/组装流程通过全量回归。
