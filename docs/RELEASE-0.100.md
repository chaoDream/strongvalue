# 0.100 基础台阶平台水平接触模板

## 本次补齐

在已审基础水平模板中增加同心紧接台阶的完整中间平台。每项按基础材料项和下层序号选择，平台Z取该下层顶面；尺寸、相邻上层、孔及全部基础个数只读继承当前已审基础。可在一条记录中分别选择多个不同平台，并与整体顶面、底面组合；未选面不计，实际支模及材料做法须原件并独立复核。

平台毛面积=下层截面−紧邻上层完整名义截面，避免将上层覆盖区及上层孔内的孔底误计为平台。孔仅在起Z<平台Z≤止Z时参与，单孔扣减=全孔截面−该孔与上层完整截面的交集；从平台起孔不扣下侧，止于平台的孔只扣外露部分。轴向矩形孔与矩形上层采用共同XY逐轴精确裁切，支持部分相交、角部相交、完全包含、分离及相切。

涉及圆形的孔或层截面，本版仅支持完全包含、分离或相切，使用平方距离精确判定；曲线边界局部相交仍未完成，候选会显示不可计量及原因，预览、保存和复核均阻断，不按整孔或零孔代替。该平台不影响未选它的整体顶底面计算。

单个基础可有2至10层，逐平台毛面积、上下层截面、每孔全面积/覆盖交集/实际扣减、精确分支及可重放公式AST完整保留。沿用Decimal 80位、来源长度换算与固定π；逐孔逐面不修约，继承全部最终基础个数一次，仅总净面积HALF_UP按有据位数修约。体积阈值不改变物理孔存在。

同基础项同下层平台不能在本记录或跨记录重复；不同下层平台、整体顶面和整体底面分别计量。切换平台清空该项接触说明及原件，切换基础项另清空平台选择；任何编辑取消范围确认、清空预览。新来源读取清空旧范围、材料、原件及修约。沿用独立审核、原件字节校验、来源失效、并发保护、完整历史及旧报价隔离。

沿用水平模板面积口径ID及m²单位，编码规则名称扩展到水平接触面，不能将模板面积映射成基础体积。未含平台的旧计算仍沿用`foundation-horizontal-formwork-1.0`，完整结果保持；含平台记录使用1.1。JSON保留精确值和公式；Excel/PDF在原五张顶底模板表后，条件增加“基础台阶平台截面差”和“基础台阶平台孔交集”，没有平台的旧成果不增加空表。
