# 0.4 清单编码映射与企业资源价格库

本版延续0.3的独立专业复核与资源调价流程，补充 PRD 清单编制及企业资源复用能力。所有新增测试均使用独立合成数据，不代表真实工程签审或官方数据授权。

## 新增能力

| 功能 | 操作与约束 |
|---|---|
| 有据编码规则 | 清单页先设置项目标准及版本，再录入编码、特征、专业、地区、有效期、许可和原件依据。完整编码必须出现在原始证据中；规则须由独立复核账号审定。修订只能追加新版本。 |
| 候选预览与采用 | 按已审构件类型、单位、全部名称关键词及规则适用条件匹配。无候选不生成编码，多候选人工选择，唯一候选也须明确采用；提交时检查清单及规则哈希，任何冲突整批回滚。只更新编码与描述，不改变数量或数量来源，清单回到待复核。 |
| 版本失效门禁 | 规则撤审、被新版本替代，或原证据、标准、地区、日期、构件条件发生变化后，关联清单须重新核对；不能用旧映射继续审核成果。 |
| 企业价格发布与复核 | 从已审清单选取来源完整的资源，填写企业内跨项目复用许可范围及原件依据，形成待审企业条目。独立复核账号检查价格、许可及适用条件；保留原项目、原清单、资源版本、证据页码和审核记录。按企业隔离检索，原件访问同样鉴权。 |
| 跨项目采用 | 明确选择名称、类别、单位和规格一致的目标资源，核对合同条件、日期、地区、税制及许可。采用时校验原文件内容哈希，复制来源及授权证据到目标项目，保存已审企业条目的完整快照。形成待审调价单及影响金额，不立即替换当前价。 |
| 审批与历史 | 本项目调价仍须独立审定、应用、清单重审及报价重算；消耗量和定额系数不变。企业价格撤审、原来源变更或失效后阻断关联项目计价及新审核成果导出，旧报价快照和旧导出文件保持原样。已复用的资源不能循环发布为新的原始价格。 |
| 交付追溯 | 使用这些功能的报价快照及导出增加编码映射依据、企业价格复用依据，保留适用版本、来源、授权条件及版本哈希。未使用的项目保持原有表式。 |

## 验证

74项自动测试通过，前端类型检查及生产构建通过。新增覆盖原编码证据、范围/标准/单位校验、多候选、版本替代、批次冲突回滚、租户与角色隔离、目标适用期、原来源变化、采用审批、撤审阻断和历史文件不变。

浏览器在独立合成工作区实际完成编码预览与采用、清单复核、企业价格独立复核和跨项目采用。测试工程量15 m³保持不变；采用单价135.678形成待审调价，影响清单原金额1,575.15、新金额2,136.90、差额561.75，尚未替换目标资源当前单价。截图见 `qa/v0.4-code-mapping.png`、`qa/v0.4-enterprise-price.png`。

## 尚未完成的主要范围

编码映射是有原件约束的确定性规则推荐，不能验证原件是否为现行官方标准，也不能完成专业语义漏项检查。企业价格库依赖人工核查真实授权及工程条件，未接通官方信息价服务，也不提供跨企业共享。历史迁移快照保持0.2原状，启动时兼容新增建表。

可靠扫描识图、复杂几何及全专业配筋、完整官方清单/授权定额库、真实模型质量验收、GTJ/GQI/GCCP授权接口及往返验证、官方报表/电子标、项目级细分授权、独立任务队列、生产存储和商业容量/安全验收仍未完成。尚未完成真实图纸到同工程专业黄金底稿的全链路验收，PRD不能标记全量完成。
