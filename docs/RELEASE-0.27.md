# 0.27 模板与防水逐面计量

继续补齐PRD F05及6.1中的模板接触面、防水展开面与证据要求。在已审空间长方体净实体上提取真实几何边界，消除内部实体接触面，逐面核定是否计量及做法依据，形成独立面积算量书。

## 净实体边界与人工核定

- 来源必须是本项目当前已审定的空间长方体构件；原件、逐尺寸证据和保存的空间计算内容均须有效。沿用最多20个轴向长方体的空间并集与扣减范围。
- 使用原始坐标边界进行精确区间压缩，构造净实体占用区间；仅保留净实体与空区间之间的面。同一实体的内部接触面、重复实体覆盖面不重复计量；洞口和内腔形成的面保留为候选。算法不采样图像像素，不使用浮点数计算面积。
- 同一平面、同一法向的相邻区间合并成确定性的矩形分面。每面保留编号、朝向、平面位置、面内两轴及范围、面积和由原始尺寸及固定单位换算构成的公式AST。分面最多1000项，超限须按专业范围拆分，净实体为空则明确拒绝。
- 总边界面积只是候选。必须为全部分面逐一记录“计入/排除”、计量说明及原图/做法证据；不能遗漏、重复、填写未知面或提交非布尔决定。允许全部排除得到零量。
- 用途可选模板接触面或防水展开面，但系统不推断实际施工接触、材料做法、搭接、翻边及适用计量条款。相同几何可分别建立不同用途的独立表面构件，由专业人员逐面确认。
- 计入面积乘来源空间构件的整组重复数量，不另设无依据倍数。保留单组总边界、计入及排除面积和最终工程量。采用Decimal 80位精度，数量沿用现有范围保护。

## 编辑、复核与来源变更

图纸与算量页新增逐面计量编辑器，可读取已审空间构件，按朝向筛选并批量填写明确的计入或排除依据，仍保留逐面修正。按所在平面查看分面示意：绿色计入、灰色排除、黄色待核定；示意不可测量，极小分面须按精确坐标核查。

每份记录绑定来源空间构件ID、修订号、几何内容哈希和服务端生成的原始几何副本。请求中的自报几何副本不能替代来源。来源改动、撤审、原件替代/缺失/损坏或保存内容异常时，阻断预览、保存、复核、重新算量和当前报价门禁。读取新版来源会清空旧分面决定并要求重新核定，不能静默套用旧分面。

仅修订派生表面决定时保留未变化来源及其他独立派生构件的审批，表面自身回到待复核，下游计算书、清单和报价重新复核。来源空间几何修订仍使相关审批失效。继续保留并发哈希校验、独立编制/复核、类型保护、历史报价和留档文件不变。
