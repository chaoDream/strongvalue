# 0.99 基础整体顶底接触模板

继续补齐PRD F05按实际接触面计算模板面积：矩形、圆柱、同心矩形/圆形台阶基础支持逐项选择整体最顶面或最底面整面，按已审端层真实尺寸及实际贯通该端面的孔截面计量。接通编制、预览、修订、独立复核、计算书、m²清单、有据编码映射和JSON/Excel/PDF导出。

## 端面几何与真实孔扣减

新增`foundation_horizontal_formwork`，只能引用当前已审`post_foundation`，不将基础体积或全部表面积直接当模板。整体底面取最下层底面Z=0，整体顶面取最上层顶面累计Z；上层端面使用上层尺寸，底面使用最下层尺寸，层数不增加基础个数。单体及2至10层同心基础沿用来源限制，中间台阶平台、内部层间面和孔底/孔顶不属于这两个整体端面。

矩形端面毛面积=来源端层实际长×宽，圆形=记录的固定π/4×实际直径²。孔位、截面和竖直范围全部从已审来源读取，兼容旧贯通圆孔、有限标高圆孔及轴向矩形孔/凹槽；没有孔时不增加假扣减。顶面仅扣起Z<顶面Z≤止Z的孔，底面仅扣起Z≤底面Z<止Z的孔，未到该端面的盲孔不扣。精确比较，不按显示精度吸附。

所选端面内有效孔已由来源核定包含及正高度内截面分离/相切，可逐孔相加；不同标高的投影重叠孔不会因投影落在同一区域而错误重复扣减。圆孔使用孔自身实际孔径，矩形孔使用实际长宽，体积扣孔阈值不填实物理孔。底面整个截面被浅凹槽占满时可为零模板接触面积，不产生负面积。

每面净面积=(本端层毛截面−实际贯通本端面孔截面)×本基础项全部最终个数；只继承一次，不另填重复数量。不同来源基础项可分别选同一端面；同来源、同基础项、同整体端面及跨记录不允许重复，存量失效记录也不能绕过范围占用。未选面不计，土面不默认支模，实际整面是否支模必须有当前原件和独立复核。

沿用Decimal 80位及记录的固定π，尺寸和孔单位各自沿用原始单位并保留来源换算；逐面及逐孔不修约，只对总净面积按有据0至12位HALF_UP修约。根数、毛扣净、Z及每孔面积均保留来源公式AST，报表读取已算数值，不另做浮点计算。

## 编制、修订与证据

顶底编辑器只提供整体最顶/最底两个端面，不接受手填面积、标高、尺寸、孔洞、层序号或数量。所取端层、Z、尺寸、每基础毛面积/实际孔扣减及有效孔名只读显示。模板做法、总范围、修约和每个端面实际接触说明分别关联当前原始依据。

新建不预填面、范围、做法或修约；同来源修订恢复原始选面及原件，但整体确认撤销。切换端面清空本面接触说明与原件；切换基础项还清空端面，所有修改撤销整体确认和旧预览。读取新来源清空全部旧选面、做法、依据和修约。预览及放弃不写项目。

保存使用实际记录ID和乐观并发，保留精确旧版本及旧清单，旧计算书失效；已审来源或上游材料变更沿依赖链使顶底模板失效。递归重建来源，校验原件字节、证据索引、快照、公式和计算结果；权限、租户、异项目原件及预览/保存/复核/重算/计算书复核五门禁沿用现有机制。

## 接口、映射与报表

候选接口：`GET /api/v1/projects/{pid}/foundation-horizontal-formwork-candidates?component_id=...`。编制、预览和复核沿用结构化构件接口，顶层`parameters: {}`、`quantity_type: area`，独立的材料/范围/修约原件及确认必填。每项`contact_ranges`严格只接受：

```json
{
  "name": "据原件核定的整端面范围名",
  "material_index": 1,
  "face": "top",
  "measurement_basis": "本整端面实际接触及孔扣减说明",
  "evidence": {"measurement_basis": "当前项目原件ID"}
}
```

`face`仅支持`top`或`bottom`；1至200项，序号必须来自已审基础，布尔值不当整数。结果使用`foundation-horizontal-formwork-1.0`和`horizontal_formwork_summary`，逐面保留实际端层、Z、尺寸、全部个数、毛孔净面积与AST，`apertures`保留真实孔原始尺寸/单位、归一尺寸、底顶Z及未修约孔截面积/AST，按需保存固定π。顶底模板独立提供面积映射口径；编码映射不能改变工程量，也不与竖直外侧或孔壁模板混用。

Excel/PDF新增五表：“基础顶底模板面积汇总”“基础顶底逐面接触净量”“基础顶底实际孔扣减”“基础顶底接触范围原件”“基础顶底模板做法与规则”。长数、原件及规则说明自动续行，跨页保留表头；JSON保留完整来源和精确值。旧记录、旧报价没有顶底模板时不新增空表，旧几何及报表结果保持。
