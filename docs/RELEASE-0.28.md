# 0.28 表面局部分区计量

继续补齐PRD F05及6.1中的模板接触面与防水展开面：在已审空间构件生成的矩形边界面内，按有据设计坐标进行局部分区，分别核定各子面是否计量，支持同一墙面不同高度或不同区段的做法范围。

## 分割坐标及精确计算

- 在原始分面内沿其两条坐标轴分别设置分割线；填写的是共同设计坐标值，不是像素、沿面的相对距离或比例。坐标可为负值，可按m、mm、cm、dm、km录入，逐线绑定原始依据。
- 每轴最多8条分割线，单原面最多形成81个矩形子面；所有原面与子面合计仍不超过1000项，先检查数量上限再构造子面。至少有一条有效分割线；不分区时移除配置。
- 换算后的坐标必须严格位于原面范围内，不能落在边界、越界或重复；不同原始单位换算为同一坐标也会拒绝。沿用18位有效数字、18位小数及换算前后尺寸范围保护。
- 后端按精确坐标排序生成覆盖原面的矩形子面，检查总面积闭合，不允许重叠或空隙。子面保留原始面ID、原面编号、子序号、设计坐标范围、面积及公式AST；子面ID由原面和坐标范围确定，分割线输入顺序不改变子面几何身份。
- Decimal 80位计算；结构化公式从来源原始尺寸、分割原值及固定单位因子构成，可独立复算。重复数量继承来源构件，各子面必须明确计入或排除并关联计量依据。

## 页面、审核及兼容

逐面计量编辑器新增局部分区设置，选择原始面、增删两轴分割线、选择原始单位和证据，再应用分区。分区未应用时禁用预览与送审，避免展示旧分区却保存新坐标。

改变几何范围生成的新子面清空原决定并要求重新核定，几何未变的分面保留决定；移除分区恢复的原面同样需要重新核定。读取已修订空间来源时清空旧分区及决定，保留来源版本保护。后端独立校验全部子面决定，不能用旧整面决定覆盖新子面。

分割线的原件与证据在候选生成、保存、构件审定、重新算量及计算书审定时均检查；原件缺失/损坏、证据跨项目、来源修订或撤审时阻断。继续保留并发哈希、失败原子性、下游审批失效和独立复核。原空间构件未改变时保持其审批，旧报价和留档文件保持原样。

没有分区配置或为空列表的旧记录，仍保持solid-boundary-1.0计算结构与保存预览；有分区记录使用solid-boundary-1.1。JSON保留分割原值、单位、换算、证据和AST；Excel/PDF新增“表面分区坐标”，逐面决定列示原面与子面关联，分割换算也进入原始单位表。

`POST /projects/{pid}/surface-face-candidates/partition`仅为编制角色生成候选，校验来源版本、坐标和原件，不写入项目；保存及审批沿用已有构件接口。

## 验证及边界

新增29项合成测试，全量542项通过，生产构建通过。覆盖30组随机分区与独立矩形面积对照、双轴/负坐标/混合单位、AST复算、重复数量、子面ID稳定、旧版本兼容、坐标和字段拒绝、分割与数量上限、旧决定失配、并发及来源变更、原件和权限门禁、清单传递与三种导出。

隔离浏览器完成第二版分割修订，检查未应用分区时预览/送审禁用、坐标改变后两个子面待核定，再逐子面填写依据并由独立reviewer复核。合成原F5正面8m²，Z=1200mm分为4.8m²下部和3.2m²上部；下部计入，上部及其他边界排除，工程量4.8m²。截图`docs/qa/v0.28-surface-partitions.png`。实际25页草稿PDF已渲染检查，分区坐标、单位换算、原面及子面关联可读，未见重叠或裁切。

本版为轴向矩形面内的坐标网格分区，不支持曲线或斜向裁切，不自动判定防水做法、模板施工接触、搭接或翻边。上述仅为合成数学及软件验收，不代表真实工程专业签审。完整专业算量、授权定额与价格、真实厂商接口、真实图纸/黄金底稿验收及生产上线仍有未完成范围。
