# 0.49 DXF设计坐标读取与单位校核

补齐F04/F05的一段图纸至管线算量流程：在“图纸与算量”读取ASCII DXF原件中的坐标候选，核对独立已知长度、设计中心线用途及坐标基准后，采用为标准`design_route`待复核构件。构件经独立reviewer审定，才可按既有流程生成计算书并进一步生成清单。

## 原始坐标与读取范围

只处理ENTITIES段模型空间中有唯一有效句柄、明确XYZ的`LINE`，以及完整、开放、无拟合的`3D POLYLINE`。逐点保留原始数值字符串和声明单位，记录主对象句柄、图层、原对象序号、文档内容哈希及本地解析任务校验值。候选支持图层筛选、分页和下载原件；只读候选及预览不写入构件、工程量或审批。

本版接受INSUNITS声明的mm、cm、m；未知单位不猜测。纸空间/非Model布局、显式不可见对象、非默认挤出方向、非零厚度、闭合或拟合折线、网格、缺失明确Z坐标、重复/重叠路径，以及二维OCS折线、曲线和块引用，均明确显示不支持或阻止读取。其他实体类型有计数提示，BLOCKS段不展开；不同对象之间仍须人工核定计量边界，不自动去重或连管网。

限制为250000个组码对、20000条ENTITIES记录、每条管线2至101点。超限拒绝，不截断后给出看似完整的工程量。重复关键组码、句柄和不完整文件结构不能静默采用。支持UTF-8及GB18030文本编码，二进制DXF与DWG不进入此解析器。

格式语义依据Autodesk官方说明：[LINE的WCS端点](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/GUID-FCEF5726-53AE-4C43-B4EA-C84EB8686A66.htm)、[POLYLINE类型标记](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/GUID-ABF6B778-BE20-4B49-9B58-A94E64CEFFF3.htm)、[三维VERTEX及WCS坐标](https://help.autodesk.com/cloudhelp/2021/ENU/AutoCAD-DXF/files/GUID-0741E831-599E-4CBF-91E1-8ADBCFD6556D.htm)、[模型/纸空间组码](https://help.autodesk.com/cloudhelp/2015/ENU/AutoCAD-DXF/files/GUID-3610039E-27D1-4E23-B6D3-7E60B22BB5BD.htm)、[INSUNITS定义](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-DXF/files/GUID-A85E8E67-27CD-4C59-BE61-4DC9FADBE74A.htm)。这是上述格式的受控子集，不代表通用CAD兼容认证。

## 独立已知长度校核

用户明确选择原对象两个不同顶点，填写原始依据中的三维直线距离、单位及容差。校核的是两点弦长，不是折线累计长度；按声明单位换算为米，以80位Decimal比较绝对偏差是否小于等于容差，不自动缩放、平移、旋转或推定设计高程。

已知距离须引用独立于当前CAD坐标的原始依据，不能用待校核文件或另一条生成的DXF坐标证据证明自身比例。采用还需明确填写共同WCS原点、XYZ方向和设计高程基准、中心线范围、重复数量、总量修约位数、计量依据及采用原因，并主动确认原CAD设计用途。系统不根据坐标数值猜测专业含义或容差适用性。

校核不通过时保留差异供核查，不能采用。任一输入、原件、任务或依据变化后须重新预览。服务器再次核验实际原件字节、来源证据、候选及预览校验值；同一采用请求可幂等重试，复用标识更换内容被拒绝。继续沿用角色、项目成员和租户门禁。

## 采用、修订与来源追溯

采用后只生成待复核设计管线和专用`dxf_geometry`证据，保留CAD对象、原始XYZ、单位声明、校核输入/结果、独立依据及其哈希、采用人员和时间。构件明细和独立复核页面展示原对象和校核信息；逐点证据可追溯原DXF，提供原件下载核对。

同一候选不能重复生成第二条管线；重新采用时须明确选择原管线并检查当前版本，形成新修订，旧构件与采用记录保留，相关下游待重新复核。普通构件编辑不能新增/伪造DXF绑定或改写原采用记录，也不能静默改变原坐标、共同基准、重复数量或修约来源。需要人工改坐标时，必须明确“转为人工坐标维护”、填写原因并核对当前版本；转出动作及原来源记录留在审计与历史中，人工坐标仍需有效原始依据及重新复核。

源文件被替代、原件字节或解析任务变化、独立依据或采用记录损坏后，旧管线不能继续复核或计算。通用证据验证也检查DXF几何的实际原件与原对象，防止在其他构件中复用已经失效的坐标证据。

JSON、Excel、PDF新增“DXF坐标采用与单位校核”台账，结合现有管线设计坐标、逐段三维长度、总量汇总及审核记录追溯。历史报价快照不混入后续CAD采用记录。

接口：`GET /api/v1/projects/{pid}/documents/{did}/dxf-route-candidates`；`POST .../{candidate_id}/preview`；`POST .../{candidate_id}/adopt`。本次未增加第三方依赖。
