# 0.137 采购分批收货验收入库

“组价审核 → 采购分批收货验收入库”从最新有效已审实际订单登记建立本批验收，精确核对实到＝合格＋不合格、日期、原件、送货单号及库位批号。保存和独立复核均不记账，编辑账号明确执行后合格量按原资源单位进入独立采购库存，不合格单列待处置。

订单家族跨登记修订累计实际到货，合格及不合格都扣额度；全不合格也不自动恢复补货额度。未执行记录可有据取消，实际执行后收货及其来源订单版本不可重审；订单仍可追加信息修订，历史实到不归零。库位批号与完整原材、实物余料双向防重，摘要租约、稳定请求编号及原子执行防止并发超收。原件变化时实际数量保留且提示待核查。每批独立JSON保留生成时状态与原字节。

采购库存尚无领用、退货、移库、原单位转根、加工接入、计价、付款或冲销，不自动进入完整原材／余料排料，不改变工程报价。对外发单及撤单、差异订单量价、追加补料、跨项目供应、真实授权库及商业部署验收等仍待完成。字段、角色、步骤、异常与合成算例见[使用手册19.10](USER-GUIDE.md)。

40项新增收货专项及767项相关回归共807项通过（251.90秒），覆盖最小18位小数精度、本人回避、原件各道门禁、跨修订额度、竞争执行、执行／取消竞争、批号跨台账防重、旧项目与历史文件。前端类型检查及生产构建通过；合成浏览器验证和手册检查见[验证记录](QA.md)。这些仅证明合成软件流程，不代表真实到货、检验、仓库交接、付款或商业工程验收。

隔离合成页面确认首批预览和输入失效、保存及另一账号复核不入库、编制账号显式执行。第二批通过隔离接口执行后页面累计15.75m³实到、15.50m³合格、0.25m³不合格、未到0。原件改变后数量保留并标待核查，恢复后重新有效；9份历史文件和67条审计关联通过，既有工程及完整原材／余料摘要保持。合成截图：[预览](qa/v0.137-receipt-preview.png)、[独立复核](qa/v0.137-receipt-review.png)、[执行库存](qa/v0.137-receipt-executed.png)、[原件异常](qa/v0.137-receipt-proof-changed.png)。普通及基线手册检查通过。
