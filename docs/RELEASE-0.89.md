# 0.89 基础竖直贯通圆孔与毛扣净体积

继续补齐PRD F05几何扣减，并贯通F06清单净量、F09报表及F11独立复核和版本。独立矩形、矩形台阶、圆柱、圆形台阶均可据原件逐孔扣减竖直圆形贯通孔；逐层检查包含关系、逐对检查孔间分离，明确毛体积、扣减和净体积。原无孔记录不变。

## 孔位、范围及原件

每个基础项可选`through_holes`，严格包含`unit`、`coordinate_basis`、`coordinate_evidence_id`、`scope_confirmed: true`、`holes`。每项须1至20孔，无孔时关闭此配置，不用空孔表代替。每孔仅包含`name`、`parameters: {x,y,diameter}`、`measurement_basis`及对应四项`evidence`，孔名须唯一。

孔心以本基础各层共同中心为局部XY原点，须据图核定轴向。实际孔径须为正，不能以半径、公称尺寸或锚栓编号替代；X/Y可为负。孔位和孔径使用独立mm/m/cm/dm/km单位，基础外轮廓单位不必相同。各项同一孔样适用于本项全部保留立柱基础；不同孔位做法须先按实际范围拆分来源项。

仅计同一竖直圆孔从本基础底贯穿全部层。孔高不另填，取已核定单体净高或台阶净层高之和。台阶保持原同心同轴紧接、不外伸约束，孔须位于每一层内，不能只核下层。圆形层用平方距离比较孔心和剩余半径，矩形层逐轴比较实际边界；不采用显示小数容差。圆形孔不能覆盖整个圆层，且每层净体积须大于零。

孔之间逐对精确比较孔心距平方与半径和平方；正面积重叠和相互包含阻断，不将逐孔相加当作孔并集。孔与层边界、孔与孔几何相切允许，但不代表结构净距或承载验收。无需提供孔数量、重复数、累计高度、扣减系数或其他隐藏参数，数量均从列表及来源计算。

## 毛扣净、修订及复核

按原外轮廓计算毛体积，每孔按π/4×实际孔径²×各层净高扣减；同一孔穿过不同台阶，每层仅扣一次。保留每基础及逐层毛/扣/净、单孔体积、贯通高、逐层包含余量、孔间分离余量及公式AST。Decimal 80位沿用既有π常量，各孔各层及分项不修约，累计来源最终立柱根数、重复一次后，仅净总体积HALF_UP修约。

基础个数仍取已审最终立柱，每根一个基础；孔数和层数不乘基础个数。全部孔数=各项每基础孔数×来源单组最终立柱根数×来源重复。来源栏杆长度、材料质量、布柱、柱距及下料不改变。有孔采用`railing-post-foundation-1.3`；关闭配置恢复对应无孔1.0/1.1/1.2规则及原结果。

启停孔扣减清空本项及总体范围说明和依据、撤销确认；启用创建一个空孔，停用移除全部孔位。增删孔也清空范围并撤销贯通及整体确认。修改孔位、孔径、孔单位、孔位原件或基础尺寸撤销对应确认和预览。切换基础形态清空旧尺寸及全部孔位。恢复同来源修订保留孔位、原件和配置，整体确认撤销；读取新来源清空全部旧选择、尺寸、孔位和依据。

预览不改持久化项目。保存、独立复核、重算及计算书复核重建完整来源、逐孔原件、几何校验、数量、毛扣净与AST。来源或祖先修订级联失效；原件字节、并发、角色租户及异项目依据门禁延续。同一来源立柱项不可跨基础记录重复选入，伪造旧ID不能绕过。修订保留精确历史、旧清单和旧报价快照。

## 清单及三格式成果

清单仍用`post_foundation / volume`基础实体体积口径，采用扣孔后净体积；有据编码映射须独立复核，不更改数量。项目特征、材料做法、是否按合同规则扣孔仍须专业核定，不自动生成官方编码或扣减阈值。

JSON保留完整孔样、单位换算、逐层包含/逐对分离、毛扣净和AST。Excel/PDF新增“基础贯通孔毛扣净”“基础贯通孔原始依据”“基础贯通孔校验”“基础贯通孔范围与常量”，原基础汇总及逐层表明确净量，中文标签关联原件。长小数保留完整值，长说明分续行、Excel自动行高。原无孔表和旧报价不增加孔表。
