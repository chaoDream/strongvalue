# 0.123 余料实际再加工与新余料验收入库

日期：2026-10-28。前后端及使用手册版本0.123.0。

## 本次完成

按已执行余料领用单的逐分配未加工且未退回余额，登记本次实际加工原段根数、成品／锯缝／切除／报废总长、新余料逐项实测及验收原件。每项长度精确闭合，实际日期不得早于领用；不按计划生成库存或用容差补差。只读预览、保存和独立复核不记账，显式执行才减少未加工原段、增加已加工根数并验收入库新余料。未执行可有据取消，已执行不可改数、取消或重审。

新余料须更短、独立编号和实际质量验收，继承材质截面及每米质量，保留父代及原领用关联；可按实际定尺另行核定回用、退回未加工原段及登记下一轮实际再加工。加工和退回竞争同一余额，已加工原段不能冒作原段退库。原验收、再加工或祖先依据失效时保留物理数量，关联新余料待核查并阻断新增领用。完整原材、工程净量、排料、报价及最初加工核对额度保持，全部原始输入、复核、事件、逐代去向与余额纳入独立JSON及历史留档。详见[使用手册15.11](USER-GUIDE.md#stock-offcut-processing)。

## 验证范围

714项相关检查通过（含59项再加工专项），前端类型及生产构建、手册普通及基线同步检查通过。浏览器验证1mm差额阻断、编辑清除预览、保存／独立复核不记账、显式加工及新余料入库、原件失效与恢复刷新；原工程摘要、三份历史JSON字节及52条审计链核对通过。相关检查及隔离合成页面见[工程验证记录](QA.md)，不代表真实工程、材质授权或仓库商业验收。

本机8000服务已更新并只读核对为0.123.0，余料再加工预览、保存、执行及取消入口存在。
