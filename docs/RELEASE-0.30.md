# 0.30 管网变断面沟槽

继续补齐PRD F05及6.1的管网土方。以当前已审定设计坐标管线作为路径，逐站核定梯形断面，选择有据断面法，按水平投影长度累计体积。地质场地、开挖施工和工作面依据必填，不从管道高程推算挖深，也不预设放坡系数。

## 数学模型及适用条件

- 新增结构化构件`station_trench`，来源为`design_route`。每个来源转折点必须对应一个断面，完整核定槽底宽、槽顶宽、挖深及断面说明，分别关联原件证据。点序号不能重复、越界或遗漏。
- 断面面积`A=(底宽+顶宽)/2×挖深`。上下宽须大于零，挖深可为零，顶宽不得小于底宽；特殊断面须另建专业模型。m、mm、cm、dm、km可逐站选择并保留原值和固定换算。
- 每段使用来源XY坐标计算的未修约水平投影长，不使用已修约管线总长或三维斜长。来源含竖向段时阻断，要求按实际沟槽范围重新建立路径；重复数量继承来源，不能另行改写。
- 必须明确选择平均端面积法或宽深线性变化棱台法。前者为`L×(A起+A终)/2`，属于所选近似计算；后者在段内底宽、顶宽及挖深分别线性变化的前提下计算中断面，`L×(A起+4A中+A终)/6`。不将一种方法静默替代另一种，不宣称适用于任意地形。
- 保存各站面积、线性中断面参数/面积、计算平均面积、水平长及三维长对照、分段体积。原始XYZ、断面参数、单位因子、平方根、段体积及最终修约均保留AST，可以独立复算。
- Decimal 80位计算，不逐站或逐段修约。先累加体积、再乘来源重复数量，仅总量HALF_UP至明确选择的0至12位，并关联体积修约依据、记录修约前总量与差额。沿用输入、精度和工程量范围保护。

## 工作流与交付

算量页新增变断面沟槽编制、读取已审管线站点、逐站原始单位/参数/依据、断面法和三类总体依据、计算预览及修订。源版本变化后重新读取会清空旧断面，预览与保存须等待成功读取；编辑参数或方法即清除旧预览，请求处理中锁定输入。断面下拉图示、空间/水平长度与逐段体积同时进入独立复核窗口。

保存与复核重验来源当前审批、版本哈希、原件字节、断面及地质/施工依据。来源快照由服务器生成；客户端伪造快照不能覆盖。修改沟槽保留未变化管线的审批，使下游计算书和清单失效；修改管线后旧沟槽必须修订和重新复核。继续使用构件与计算书双重复核、并发哈希、失败原子性、历史构件/计算书及不可变报价留档。

`GET /projects/{pid}/trench-station-candidates?component_id=...`仅返回已审来源点和分段，不落库，允许复核角色查看，按项目权限隔离。预览和编制沿用现有构件接口。

JSON包含完整公式和来源快照；Excel/PDF新增“变断面沟槽汇总”“沟槽站点断面”“沟槽分段体积”“沟槽来源坐标”，逐站参数进入原始单位换算表，原件和审核记录继续可追溯。历史报价按自身快照导出，不混入新增沟槽。

## 验证和边界

新增41项合成测试，全量621项通过，生产构建通过。覆盖坡管水平计量、两种断面法差异、零挖深、混合单位、源重复数量后一次修约、站序无关、多段汇总、30组独立多项式积分对照、AST复算、字段/缺项/单位/精度/超界/竖管拒绝、来源修订撤审、断面独立原件5个门禁、角色与项目隔离、并发原子性、保存与计算书篡改、清单及三种导出、旧报价不变。

隔离浏览器完成V2修订、两法预览切换、旧预览清除、断面切换及独立reviewer审定。合成源坡管空间13m、水平5m；起终面积3与18m²、线性中断面9m²；棱台法47.500m³，平均端面积法52.500m³。截图`docs/qa/v0.30-station-trench.png`。实际22页草稿PDF已渲染检查，新增汇总及续页、原始断面与证据续行、分段体积及来源坐标可读，未见裁切或重叠。

本版是有据路径与核定断面的分段累计，不自动扣除转角、交叉或相邻沟槽交叠，不推断地形、放坡、工作面、支护、土类、回填或运输。测试仅为合成数学及软件验收，不代表真实施工方案或专业签审。全专业自动算量、授权定额/价格、真实厂商接口、真实图纸/黄金底稿验收及生产部署仍待完成。
