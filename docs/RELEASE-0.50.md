# 0.50 CAD多对象设计管线组装

扩展F04/F05的原图至算量流程。0.49支持单条LINE或开放三维折线采用；本版允许将同一ASCII DXF中的2至20个可读原对象，按明确的顺序和方向组成一条开放设计管线，保留每个对象的来源。格式读取范围继续遵循[0.49说明](RELEASE-0.49.md)。

## 选择顺序与精确连接

在“图纸与算量 → DXF设计坐标读取与单位校核”读取原件后，可逐项“加入组装序列”。序列支持上移、下移、明确反向、移除和清空；可在同一文件的不同图层或分页中选取对象。更换文件或项目会清空原选择，不能混合不同来源文件。单对象采用入口保留。

“检查连接并组装候选”只读取原文件和最新本地解析任务，不保存构件或工程量。服务器再次检查每项候选哈希和可读状态，按用户选择的方向连接全部原始顶点。相邻端点的X、Y、Z须以Decimal数值精确相等；平面接触但Z不同、微小缺口、顺序或方向不合均被拒绝，不按容差吸附，不补画连接段，不根据邻近关系或交点自动组成管网。

连接处只保留一个计算顶点，两侧原始坐标字符串分别留存，例如`3000`与`3000.0`数值相同可连接，但原值不改写。支持LINE和已受控读取的开放3D POLYLINE混合连接；采用方向不覆盖CAD原坐标次序。组装后最多101点，超限拒绝，不截断。闭环、回返、共线重叠及重复使用同一对象均由检查阻断，反向重复也不允许。

## 校核、复核与防重复采用

组装候选展示组合后的原始XYZ，以及每个原对象的句柄、类型、图层、方向、组装点范围和原始起止点，可展开连接处两侧原值。候选尚无工程计量效力，须继续填写设计用途、WCS与高程基准、重复数量、修约口径、原始依据和采用说明，并用独立已知两点距离校核声明单位。专业判断和容差依据由编制人及独立复核人员核定。

预览与采用绑定同一原对象序列、方向及各自校验值；任一选择或来源变化后须重新检查和预览。采用仍只生成待复核`design_route`构件，独立reviewer审定后才能生成工程量计算书，计算书再经独立审定后可生成清单。组装本身不增加管件、弯头、接口或施工附加量。

单对象管线与组装管线共享原对象占用检查。原A已被单独采用时，不能另外采用包含A的组装管线；A已在组装管线中时，也不能再单独采用A或在另一组装管线中重复采用。检查限同一来源对象身份，不推断不同句柄、不同原件之间的语义重复或整个工程的计量边界。

若要把已有单对象管线扩展为组装管线，须在采用时明确选择该原管线并校验当前版本。操作追加新修订，保留旧构件和采用历史，相关计算书及下游待重新复核；不能借修订占用其他管线已采用的对象。普通编辑仍不能改写CAD绑定，明确转为人工坐标维护的既有流程继续有效。

## 来源完整性与导出

采用记录及专用几何证据保存组装规则版本、原对象完整快照、顺序和反向选择、每项对应的组合点范围、精确连接处两侧原值、文件和任务哈希，以及原有长度校核和人员依据。后续复核、算量和通用几何证据引用会从实际原件重新构建并比较；篡改选择、范围、连接点或来源快照会阻断，损坏记录返回需重新核对的错误。

继续使用原有CAD采用审计、幂等及来源变更门禁。未使用组装字段的0.49请求保持原请求哈希规则，便于既有操作重试；原单对象记录与历史快照继续可读。

JSON、Excel、PDF增加“DXF多对象组装来源”台账，按原对象列出顺序、方向、句柄和图层、组装点范围、原始端点、单位和文件哈希。结合原有CAD单位校核、管线设计坐标、逐段计算与审核表追溯，后续组装不混入旧报价快照。

新增只读接口：`POST /api/v1/projects/{pid}/documents/{did}/dxf-route-assembly`，请求为严格的`segments`列表，每项须包含候选ID、对象哈希及布尔反向选择。原候选预览/采用接口增加可选`segments`，服务器重建结果须与候选ID及对象哈希一致；仍检查会话、角色、项目成员及租户隔离。未增加第三方依赖。

## 验证与边界

2026-10-23：新增33项合成测试，全量1314项通过，前端类型检查和生产构建通过。覆盖只读组装/预览、反向与混合对象、严格字段与数量上限、精确连接及微小Z缺口、原始字符串保留、闭环/重叠/重复对象、单对象与组装交叉占用、原管线修订、来源及组装元数据变化、权限、旧版请求哈希，以及JSON/Excel/PDF历史快照隔离。

隔离浏览器读取跨图层LINE A和B，先按原方向检查，显示XYZ端点不一致并阻止组装；调整顺序并明确B反向后，组成3点2段候选。独立依据校核P1至P2为13m、容差0；13m与5m两段乘重复2，总量36.000m。编制采用后由独立账号查看逐对象方向、点范围及校核依据并审定；后续接口验收计算书、计算书独立复核及清单生成均为36.000m。
