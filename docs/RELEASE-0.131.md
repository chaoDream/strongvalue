# 0.131 原材与余料按已审定尺联合供应

日期：2026-10-28。前后端及手册版本0.131.0。

同一份已审排料的逐需求可由完整原材与已验收余料共同供应，定尺及每米质量精确相等，两侧合计恰好覆盖原需求，同材质截面及余料质量合格须原件确认。预览冻结完整需求与两侧分配；一次事务保存关联单及两侧预留、分别立即占用，任一侧失败全部不保存。两份预留分别独立复核，两侧均有效通过后才能另办实际领用，核定日期／拟对象不替代真实交接。

原材按实际领料单整单或分批，余料必须另建实际批单；各自复核和显式执行，分别保存在各自实物账。任一侧实际领出后双侧预留均禁止重审，另一侧可按原范围继续领出。拒绝、待补件或来源失效保持双方未领占用，分别有据释放；释放一侧不自动释放另一侧，已领或退回不能重开全量需求。联合计划暂不支持单侧补料。

联合完整需求、规范两侧快照、各预留及实际批单关联随库存JSON留档，旧文件原字节保持。工程、原排料、净量、清单、报价及审批保持。详见[手册15.19](USER-GUIDE.md#stock-mixed-supply)。自动更换定尺优化、联合补料、修订或损耗追加、采购、跨项目及执行冲销未实现；全专业图纸提取、授权库及厂商真实往返、真实工程及商用运维验收仍待完成。

39项联合供应专项及1002项既有相关检查，共1041项库存、盘点、加工、排料、权限、报价、手册、交付与历史PDF预览回归通过。前端类型及生产构建、普通与基线手册检查通过。合成浏览器确认逐需求1＋1＝2、编辑清预览、同次保存双侧占用、单侧已审仍阻断实际领料、双侧审定不出库、两张实际单分别复核及执行，原材先领后余料仍占用，最终两侧各在外1根。六阶段JSON历史原字节及SHA256、69条审计关联核对通过；工程及旧库存记录摘要保持。
