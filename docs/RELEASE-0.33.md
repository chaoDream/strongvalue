# 0.33 管网分段矩形垫层

继续补齐PRD F05管网扩展：从当前已审设计坐标管线读取未修约水平段长，逐段确认垫层宽厚，形成有材料、施工依据、来源版本及独立复核的垫层工程量，并接入关联回填占位。

## 计算与适用范围

- 新增结构化构件`route_bedding`，结果为m³。每个构件只记录同一材料、规格及层次；不同材料层分别编制，以便后续分列清单及组价。材料名称是有原件依据的编制内容，不是系统选材结论。
- 逐段矩形体积为`横向水平宽×竖向厚度×未修约水平投影长`，再累计并乘来源重复数量。明确`length_basis=horizontal`，不接受三维管长替代水平长；存在竖向零水平长段时阻断，要求按实际垫层范围拆分来源。
- 来源每个直段均须填写宽度、厚度、原始单位、各参数证据及本段范围说明/依据；不同段可有不同宽厚和单位。段内尺寸恒定，不对相邻段自动插值。局部无垫层、渐变宽厚或特殊形状须拆分并另建适用模型。
- 宽厚支持m、mm、cm、dm、km原始单位并保留换算。不允许另填重复数量；来源计量数量继承一次。使用未修约水平段长，不使用来源已经修约的长度总量。
- Decimal 80位计算，段长、断面积及逐段体积不单独修约，仅最终总量按有据选择的0至12位HALF_UP；保留未修约量、差额及原始参数公式树。
- 材料规格、材料原件、施工做法及适用条件、计量与交接范围、修约依据必填。编制人员须明确核定同一材料层、水平宽、竖向厚及矩形计量范围；仍须独立专业复核。
- 不从管径、沟槽底宽或管道高程推算垫层尺寸、地面及承载条件。不含管座包角、腋角、包封、交接空间扣重、压实/松方、损耗或材料消耗系数；本版不自动选材或认定施工方案。

## 工作流与来源保护

算量页新增垫层来源读取、逐段尺寸及原件、材料与施工做法、范围确认、预览、修订与独立复核。修改任一编制字段会撤销确认并清除旧预览；重新核定后才可预览或保存。来源版本变化后重新读取会清空旧逐段尺寸与证据。

`GET /projects/{pid}/bedding-section-candidates?component_id=...`只读返回当前已审设计管线的点、段及版本哈希。成员/租户、来源审批与版本、原件字节、证据索引、并发对象哈希、保存预览和公式均沿用现有门禁。来源快照由服务器生成，客户端无法伪造覆盖。旧版本不能仅重新点击审定放行。

当前已审垫层可作为`volume_balance`的占位来源。回填使用既定已审体积及修约，不还原未修约量、不再乘重复数量；实际包含关系、与管道及其他扣减的不重复范围和比例须单独确认。软件不执行空间包含/重叠判断。

垫层修改后，其关联回填及下游审批失效；未变化的设计管线、管道外包及沟槽审批保持有效。历史计算书、历史报价及已保存导出文件保持独立。
