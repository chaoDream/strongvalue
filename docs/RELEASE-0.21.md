# 0.21 工程结算差异复核

继续补齐PRD F12的工程结算差异流程。以人工指定的合同基线报价与最新已审报价进行对照，逐项说明清单和费用差异、关联原始依据与已应用签证，由独立reviewer复核，并单独生成留档文件。

该对象是工程结算差异复核记录，与竣工财务决算、付款审批和真实签章分别建模；不自动认定合同价款权利，不调整报价金额，也不以目标总价反推单价。

## 基线与差异编制

- 成果交付页明确选择两份已审报价。合同基线须早于目标、专业范围一致，且保有未撤回的独立审批；允许其因后续变更成为历史版本，不恢复旧报价的当前审批效力。
- 结算目标须是项目最新、未失效且仍保有成果审批的报价，当前工程须通过原有编制门禁。缺价、未审输入、无效规则和签证等问题不能被结算流程绕过。
- 复用现有快照对账：数量影响按原单价、单价影响按新数量分解，修约余额、新增、移除和口径变化单列；费用依照原计算顺序对照并验证差异总额闭合。该分解是确定性口径，不是专业因果判断。
- 每条清单及费用内容差异均须填写说明和当前原始依据，包括金额为零的内容变化；另填记录名称、合同范围/结算口径及合同原件。无差异记录仍须说明范围和依据。
- 清单差异可关联本次目标报价中新应用的、同清单、已审已应用数量签证；费用差异不得冒用某条数量签证。签证用于追溯，不自动形成签证价款认定。
- 预览绑定所选快照、审批记录、当前清单/规则/日期、专业范围和签证状态。输入或审批改变后不能沿用旧预览。提交幂等、失败无部分写入，版本提交携带上一记录校验值。

## 独立复核与版本

- 新增独立的 `engineering_settlements` 对象与审核类型，沿用编制/复核分离、对象哈希和审核依据要求。
- 记录保存报价差异快照、原审批编号、逐项说明、签证、合同及各差异原件摘录/文件校验值、项目名称、编制人和时间。记录内容有独立校验值，复核时再次检查源输入、审批及原件字节。
- 同项目记录按版本递增，已有更新记录后旧版本仅查阅。新记录须重新独立复核；目标报价、原审批或依据变化后，旧记录不能自动恢复当前可用状态。
- 结算记录的提交、拒绝或通过不改写原工程量、资源价格、规则、报价快照或报价成果审批。结算复核不是对合同价款、付款或财务决算的自动批准。

## 独立成果与历史留档

- 提供JSON、Excel和PDF，包含结算差异封面、差异分解、逐项说明、关联签证、原始依据和复核记录。
- 导出按当前有效性标明“已复核（无签章效力）”或“草稿”。撤审、依据失效或新版本出现后，新导出保留草稿警示；原留档文件字节保持原样，可按现有历史文件接口下载及校验。
- Excel长说明续行、自适应行高、重复表头并防止公式注入；PDF使用现有中文字体及分页引擎。历史导出件明确区分结算差异、版本对账和报价成果；报价PDF预览不会误选结算PDF。
- 结算记录单独留档，报价及其ZIP仍以报价快照为依据，不把后来新增的结算结论反写进旧报价。

## 验证与边界

新增22项合成测试，全量337项通过，生产构建通过。覆盖差异闭合、零差异、量价同时变化、逐项依据与签证归属、角色/租户/项目成员、审批和版本保护、幂等/原子性、原件异常、内容完整性、三种导出与Excel公式安全，以及原报价和历史文件不变。

隔离浏览器完成基线V1与目标V2选择、逐项说明和签证关联、切换独立reviewer复核。合成基线1622.40、目标2163.21，差额540.81，其中数量影响525.05、费用影响15.76。截图 `docs/qa/v0.21-engineering-settlement.png`。实际生成的六页PDF已渲染核对封面、差异分解、说明、签证、原件索引和审核页，未见裁切或重叠。

所有验证均为软件合成数据，不是实际合同结算或专业签审；未操作真实工程资料。正式结算价款仍需真实合同、完整变更及适用计量计价依据和有权人员审定。官方授权数据、完整专业算量、厂商接口、真实工程黄金底稿及生产验收等PRD范围仍未完成。
