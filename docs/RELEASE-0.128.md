# 0.128 余料分批领用与独立批单追溯

日期：2026-10-28。前后端及使用手册版本0.128.0。

已审余料预留现在可按原分配序号登记独立的实际交接批单。逐批预览、保存、另一账号复核及显式执行；保存和复核不出库，执行只结转本次未领占用为该批在外数量，未领继续占用。首次整单领用保留，分批后原预留不能再整单执行或重审。部分领出后可有据释放未领余量，在库和各批已领事实保持，材料表不重开。

原段退回、实际投入、直接完整再加工及投入后结果支持独立批单，按原预留分配序号追溯，即使只选第2项也保持2。不同批单不能借数量，原预留不能冒充已领批单；旧整单历史保持。子余料保留父段及批单关联，本批交接原件失效保留数量并提示，其来源新加工余料采用也须核查本批及投入原件。

全部流程保留原件、独立复核、对象／台账版本及幂等门禁，执行重新核对原分配剩余额度，超量、来源或事件关联异常不记账。JSON独立留档包含原预留进度、批单及事件，旧下载原字节保持；工程、排料、净量、清单、报价及审批保持。

43项新增专项与884项既有库存、盘点、加工、排料、权限、报价、手册、交付及PDF历史预览，共927项相关检查通过。前端类型／生产构建及普通／基线手册检查通过。合成浏览器验证编辑清预览、保存及复核不出库、首批领1后在库1／占用1／在外1／可用0，退回只读预览明确引用实际批单；关闭预览未保存后，有据释放未领1，在库及在外均仍1、占用0／可用1。四阶段JSON历史原字节及SHA256、57条审计链关联核对通过。
