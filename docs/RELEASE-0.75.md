# 0.75 均分布置中的禁布范围与显式移柱

继续补齐PRD F05的栏杆计量。新增“均分布置及禁布移柱”：按已审最大间距建立原均分跨间，再按原件指定禁布闭区间、原内部节点号j及移后端距S。根数、下料规格和质量保持，保留原位、移后位置与完整依据，接通独立复核、清单及三格式报表。

## 控制规则

原跨数N为未修约区间长度L除以核定最大间距后向上取整，原内部节点S=a+L×j/N，j为1至N−1，按原布置S递增编号，不是材料表总柱号。最大间距与实际均分跨间距不可混用，也不能用最大间距乘j代替原节点位置。局部区间沿用原段起点端距，新S不改成相对区间起距。均分模式不填写定距锚向。

每个计入区间明确列出禁布范围及移柱列表，无则为空；本模式至少有一个范围或一根实际移柱。禁布范围须有名称、起终端距、单位、构造说明，分别关联当前原件；范围在所选区间内，起距小于终距。禁布为包含两端的闭区间，移后全部计入柱必须在其外。不同范围允许重叠且分别溯源，同区间重复名称或等值范围阻断，不因范围重叠扣减根数。

只移动原内部柱，原节点、新S和说明分别有原件。不得原位不变、重复移同一节点、移到端部或缺口、重合或交叉换序。多个移柱同时按最终位置判断，最终仍按原节点顺序严格递增；可经过其他柱的原位置，但最终不得碰撞。端柱保持原两端归属，不能借移柱改变共享端点责任。不自动加柱、删柱、寻找避让位置或重新均分。每区间最多20个禁布范围、100根移柱，每材料项1000根、每表5000根单组立柱，材料项1至50项。

原最大间距、跨数和均分跨间距仅描述移前布置，不表示移后柱距合规。移后全局柱距、专业构造和施工定位须另核。

## 精度、记录与兼容

整段原均分位置采用原边精确根式系数j/N，局部区间采用精确有理数a+(b−a)×j/N。以a+b×√q的符号及平方比较判断禁布闭边界、端部、碰撞和顺序，不以平方根显示值或容差放行。原节点、原位置表达式、移后S原值及单位换算、禁布范围内移前和移后根数完整保留。

新规则为`railing-equal-adjusted-posts-1.0`；含本模式材料表采用`railing-material-mass-1.8`。根数及数量表达式保持原布置；按独立下料长、单位长度质量及来源重复数量计算，Decimal 80位，分项不提前修约，合计后只乘一次来源重复数量，总质量按有据0至12位HALF_UP修约。

独立载入0.74计算代码，对25组来源分别核对纯均分、纯定距、两种构造加柱及定距移柱，共125条完整材料记录完全一致。旧模式输出及版本保留；两种移柱可同表使用，依据命名空间独立，均分移柱拒绝定距锚向或未定义加柱字段。无需新依赖或数据库迁移。

## 界面、审核及导出

逐区间编辑禁布范围和原节点、新S；字段变化清空预览及确认，模式切换移除隐藏控制项。示意以红色表示禁布闭区间、灰色虚线表示原位置、紫色表示移后柱，原规则与完整逐根表可供复核。示意不可测量。

沿用独立复核、对象哈希、修订并发、原件完整性、角色及租户门禁。只改位置而质量相同也会使旧计算书及审批失效；历史记录与重建前旧清单保持，重建采用新位置。来源范围改变后材料及下游失效，恢复读取新来源、清空旧材料行及其规则、禁布、移柱和逐项依据；确认必须重做。旧报价不混入新材料。

JSON保留全部记录；Excel/PDF提供原均分四表、“立柱禁布范围核查”“立柱移前移后端距”及“均分移柱规则与范围”共七表，逐根位置明确标注原S。完整规则放入宽表以便阅读，逐根完整端距保持同页。
