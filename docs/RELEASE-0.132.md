# 0.132 联合供应已释放未领补料

日期：2026-10-28。前后端及手册版本0.132.0。

联合单已有实际领出、所有仍未领的范围均分别有据释放后，可合并两侧逐需求未领数量，在最初材料表及完整排料有效且未变化时重新核定供应。仍按原定尺及每米质量精确覆盖，同材质截面及余料质量合格须凭据；可双侧也可仅单侧供应，空侧不造预留、不要求空白审核。预览不占用，保存同一事务建立补料关联单与实际供料侧预留并占用，所有供料侧分别独立复核后才能另办实际批单。

不从已领、退回、在外或加工数量恢复额度；新补料未领前各侧全部整单释放可重做，有领出后只能沿本单自己已释放的剩余继续，不能回祖先分叉或重复取额，最多20级。原核定、释放和各批实际领用保持。原件字节、链路、来源、预览、库存版本、项目角色及禁自审沿用；祖先核定／释放凭据失效保留事实与占用，相关余料批单加工子余料及后代待核查。

完整操作见[手册15.20](USER-GUIDE.md#joint-replenishments)。链路及本次供料随库存JSON留档，历史文件原字节、工程、原排料、净量、清单、报价及审批保持。修改定尺或排料、修订及损耗追加、普通单跨链合并、采购、跨项目、已执行冲销未实现；全专业图纸提取、授权库及厂商真实往返、真实工程及商用运维验收仍待完成。

39项联合补料专项与1041项既有相关检查，共1080项库存、盘点、加工、排料、权限、报价、手册、交付及历史PDF预览回归通过。前端类型及生产构建、普通与基线手册检查通过。合成浏览器核对上游释放未领1根改由新原材单侧供应，预览不占用、编辑清预览、保存及审定仅新侧占用、无空余料预留或空白审核，再另建实际领料单、独立复核并显式执行。新批在库3→2、在外0→1，旧批已领1及原余料在库1保持，累计对应原需求2；四阶段历史JSON原字节及SHA256、73条审计关联核对通过。
