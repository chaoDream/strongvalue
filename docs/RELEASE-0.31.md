# 0.31 已审体积关联回填

继续补齐PRD F05及6.1的回填流程：从当前已审开挖构件读取体积，关联已审实体的核定占位比例，生成带版本、公式和证据的回填平衡。避免手工抄录开挖和占位总量后，来源修订却继续沿用旧值。

## 数量及来源口径

- 新增结构化构件`volume_balance`。开挖可引用已审梯形沟槽、变断面沟槽、空间区域、等厚平面体积或分项体积；占位可引用底板、池壁、墙梁、圆环、空间区域、等厚平面体积或分项体积。实际用途须专业人员核定，不能仅凭几何类型认定。
- 全部来源必须为可复算的m³体积，不接受面积、长度、回填自身或其他回填平衡的递归引用。每项来源须当前已审定、版本一致，预览与重新计算相符；结构化来源继续验证其上游来源及原件。
- 读取来源**已审工程量**，保留其既定单位换算、修约与重复数量，不将其还原为未修约量，也不在回填阶段再乘重复数量。来源完整快照由服务器生成，客户端不能伪造覆盖。
- 最多50项占位，逐项明确大于0且不超过1的扣除比例、范围说明和原始依据；同一构件不能重复扣除，也不能扣开挖自身。不扣的构件应移除；明确无扣减时允许空列表，但仍须填写总体依据并复核。
- `净回填=已审开挖−Σ(已审实体量×核定比例)`。扣减超过开挖时阻断，不静默归零。所有输入及工程量沿用范围保护，Decimal 80位计算，扣减不逐项修约，仅最终净回填按有据选择的0至12位HALF_UP，保存修约前净量和差额。
- 总体范围及计量依据、逐项比例依据、回填修约依据必填。编制人员须明确确认同一计量范围及扣减之间不重复；此确认不等于软件已完成几何包含/交叠检测，也不替代独立专业复核。

## 编制、复核与交付

算量页新增来源选择、读取已审体积、逐项扣除比例及原件、范围确认、计算预览、修订和送审。来源版本改变后重新读取会清除对应旧比例、说明和依据，并撤销范围确认。修改比例或扣减说明也撤销确认、清除旧预览，重新确认后才可预览或保存。来源新增/移除或更换后须重新读取。

候选接口`POST /projects/{pid}/volume-balance-candidates`仅编译所选来源，不落库；允许已授权复核角色查看。实际编制和预览继续使用既有角色门禁，按项目和企业隔离。

接入构件与计算书双重复核、清单、报价门禁和下游失效。原件损坏、跨项目证据、来源修订或撤审、旧哈希、保存记录或计算书被改写均会阻断。回填修订保留未改变来源的审批，使下游重新复核；历史构件、计算书、报价与导出件继续留档。

JSON保存来源完整几何/计算快照、逐项比例、公式AST、参数值、原件及版本。Excel/PDF增加“关联回填平衡”“回填逐项扣减”“回填来源计算索引”“回填范围与修约”。计算索引列示来源版本哈希、已审体积、原公式及去重证据编号；结构化明细见相应来源计算书及JSON。历史报价使用自身快照，不混入新回填。

同时统一后端结构化构件类型登记，避免各审核门禁遗漏新类型；补件任务面板改为按需加载，主入口构建约491KB，浏览器已检查补件任务面板正常加载。

## 验证及边界

新增39项合成测试，全量660项通过，生产构建通过；报表索引调整后重新运行39项回填回归通过。覆盖比例扣减、已有来源修约不逆转、零/全扣、总量修约、30组独立Decimal台账对照、AST复算、重复/自身/未知/递归/非体积来源、字段/比例/精度/超扣/范围确认拒绝、来源撤审及修订、原件5个门禁、角色和项目隔离、并发原子性、伪造预览与保存/计算书篡改、清单及JSON/Excel/PDF、旧报价不变。

隔离浏览器完成V2修订与独立reviewer审定。开挖47.500m³，实体A为4m³按1扣4，实体B为2m³按0.5扣1，回填42.500m³；B比例改1后自动撤销确认并禁用计算，重新确认预览41.500m³；恢复0.5清除旧预览，再算42.500m³。截图`docs/qa/v0.31-volume-balance.png`。实际最终28页草稿PDF已渲染检查，平衡、逐项扣减、来源索引及范围修约表可读，未见裁切重叠。

本版为有据的体积关联台账，不自动判断真实包含关系、相互重叠或多个回填构件间的范围重复，不推算管道外包体积、压实/松方系数、分层材料或运输。上述仅为合成软件验收，无真实工程专业签审效力。全专业自动算量、授权定额/价格、真实厂商接口、真实图纸/黄金底稿验收及生产部署仍待完成。
