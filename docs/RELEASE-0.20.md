# 0.20 企业内跨项目定额组成复用

继续补齐PRD F07/F12：将0.19本项目的有据已审候选，在另行登记并独立复核企业内跨项目许可后，供同企业其他工程检索采用。只复用定额、换算和原始消耗组成；目标资源全部转为待询价，不把源项目或历史单价直接当作目标有效价格。

## 发布、共享范围与独立复核

- 仅企业内共享项目可以发布。须先完成来源清单及本项目候选复核，再填写允许其他项目复用组成及全部相关原件的范围、限制和原始许可依据，并明确确认共享原件。
- 新增企业定额组成库，按企业隔离，支持检索和分页；条目保留源项目、原候选完整版本、组成、来源和许可、原件索引及独立共享复核记录。
- 独立reviewer审定跨项目许可。来源清单、候选、组成、复用许可和原件须有效；通过共享复核核对原件字节，编制账号不能代审。
- 源清单/候选审批或源共享版本改变后，旧条目不能因重新通过审批或恢复共享而自动复活，须重新发布及复核。
- 源项目转为受限后，不再在企业库列表和新检索中显示，阻断新采用及仍保留源依赖的目标后续计价。已授权复制到目标项目的资料、既有导出及下载文件不能追回。
- 企业复用条目和复制原件不能循环发布。来源资源必须有原始编码、规格、单位和费用归属，不能由系统补造这些字段。

## 检索、核对和采用

- 目标明确选择专业与定额年度，严格过滤地区、单位、专业、计价标准/规则版本和候选适用期，返回最多5条候选。
- 解释编码、名称与文字交集匹配；只是文字检索，未经语义模型或专业适用性判定，不按近似单位或不同年度回退。
- 核对页显示构造工法、原始消耗、通用/单位/分类换算、源项目许可、跨项目许可及全部原件入口。目标数量保持不变，整体替换目标的定额组成，保留编码、名称、特征及工程归属。
- 原始价格、期次、价格来源和关联源项目调价/替换标识不作为目标当前价格带入。采用结果价格为空，全部资源生成待询价任务；不生成零价总额或虚构金额差额。
- 采用前明确确认许可、工法、换算与重新询价，填写本项目理由。目标、源清单、候选、共享审批、规则、日期或源共享范围变化时须重新核对。提交幂等，失败不部分复制依据或修改清单。
- 为目标建立独立证据索引，同一源文档只登记一次，原件内容仍按哈希保存。源与目标项目的证据编号不混用。

## 后续补价、审核与历史成果

- 补充本项目当前价格及其原始依据后，保持定额消耗组成不变时继续保留源版本依赖，须独立复核清单并重新生成报价。
- 企业共享许可撤审、原候选/清单变化、依据失效或适用条件变化，阻断关联目标的后续清单/报价审核与计价；不改写历史报价内容。
- 可有据“转为人工编制”，记录原因，保留当前组成、原件与历史采用，解除当前企业条目依赖并重新复核。人工更改组成也解除当前关联并记录审计。受控材料替换改变组成后须重新采用或有据转为人工维护，不能继续冒用原候选组成。
- 报价快照及PDF/Excel/JSON/ZIP新增“企业定额复用台账”，保留来源、专业/年度、许可、采用理由、人员时间、版本校验值和目标原件索引。无价证据包同步保留本项目候选、两类采用台账和相关原件；既有报价与导出件保持原样。

## 验证与边界

新增24项合成测试，全量315项通过，生产构建通过。覆盖发布许可、独立角色、企业/项目访问、源项目限制共享、日期/地区/专业/年度/单位过滤、源修改、撤审、试算版本保护、幂等和事务、多子目与换算保留、原件缺失/篡改、待询价门禁、补价后复核、人工维护、四种导出与旧报价不变。

两个隔离合成项目通过浏览器完成发布、独立共享复核、跨项目筛选与采用。目标保持15m³及1.05原始消耗，价格清空并生成待询价任务。合成补价测试使用本项目120.005资源价格，按既定修约重新计价总额1946.85，与源报价1622.40独立。截图 `docs/qa/v0.20-enterprise-quota-preview.png` 和 `docs/qa/v0.20-enterprise-quota-inquiry.png`。这些仅验证软件数学与工作流，无真实专业定额、商业许可或正式签审效力；未操作实际工程资料。

这仍不是PRD全量验收：官方授权定额/信息价、专业语义召回、复杂图纸和完整专业算量、厂商授权接口、真实工程黄金底稿与生产验收等仍未完成。企业库不跨独立租户，不扩展为跨竞标主体共享报价；源价格的核查展示不表示目标价格已获确认。
