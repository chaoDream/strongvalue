# 0.111 基础水平模板嵌套岛区窗口

日期：2026-10-27。前后端与使用手册版本：0.111.0。

## 本次完成

新增父块窗口内孔中的独立支模岛区模式：2至4块，每轮廓3至12点，每块最多4孔及36点、全部最多8孔及48点。逐块明确根块或最近父块B及内孔W，核定支模与关系说明及原件、逐坐标原件，继承共同单位、基础中心XY、已审Z和全部基础个数。

精确有理数校验岛区严格位于指定父孔，外轮廓不接触或穿越孔边；其他块严格分离，不能交叉、接触或重叠父块净区。核对最近父关系，阻断自指、循环、跳层、错孔及无实际嵌套。支持四块形成的平面层级0至3、同孔多个分离岛区及分离根块；层级不改变基础层号、Z、材料或数量。

复用逐块200位解析积分及80位累计，按每块外轮廓减本块内孔后裁切真实面及实体孔，不填实剩余空区，不创建实体孔或孔壁、不改变混凝土；全部基础个数仅继承一次，总量有据修约。全部有效片段无剩余才形成整体严格零接触证明。完整窗口净区以精确有理数扫描防重，剩余父孔空区可另项，岛区正重叠拒绝，跨记录及混合旧窗口同样检查。

页面接通显式父选择、增删后的引用重选、确认撤销、预览修订及独立复核。JSON保存输入、核定父子层级、逐块净量、包含见证、分段及AST；Excel/PDF新增嵌套顶点、净区、分段积分、拓扑及父子层级表，按需生成整体零接触和防重表。旧模式沿用原规则、操作及结果。详见[使用手册16.11](USER-GUIDE.md#foundations)。
