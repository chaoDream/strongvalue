# 0.41 标题栏候选提取与核对采用

继续补齐PRD F04的图纸身份识别。在0.40人工图纸目录上增加明确标签候选，减少重复录入；保留原候选、人工选定与修正、来源及独立复核。提取结果不自动成为已审图纸，不推算构件或工程量。

## 明确标签提取

从当前PDF/CAD/BIM资料的本地提取文字和人工标注文字中，读取带冒号的图号、图名、图纸版次和视图类型。支持中文标签及`Drawing No.`、`Drawing Title`、`Revision`、`View Type`等明确别名；换行、分号、制表符及同一行相邻标签可分隔字段。没有明确图号或图名时不形成候选，不从文件名、正文描述、图名后缀或比例猜测字段。未采用模型自己的旧输出作为原文。

每份证据形成一组候选，保存原始标签摘录、值、文字偏移位置、文件/证据哈希、页码及`drawing-identity-labels-1.0`规则版本。重复出现的全部原值保留；同字段不同值不按出现次数选取。图号兼容字符、大小写和空白、版次大小写及受控视图别名可确定性比较，但仍保留原值。

- 唯一且明确的字段可预填；歧义图号/版次保持空白，须人工选定。
- 缺失字段保持空白。图名为“剖面图”不会自动推定视图；没有明确视图标签时须人工选择。
- 单字段超过200字或视图不在目录时提示人工核对；不截取超长字段冒充有效值。整组字段间距超过2000字，或单份证据超过100个标签被截断时不能直接采用，须另记标题栏依据或人工登记。
- 扫描PDF没有文字层时不会产生自动OCR结果；可先在原图记录标题栏文字与区域证据，再读取候选。CAD/BIM原件支持现有可读取文字或人工依据，不声明已有DWG/IFC授权解析能力。

## 只读读取与受控采用

`GET /api/v1/projects/{pid}/drawing-candidates`只读当前原文，不写图纸登记、审批、算量或审计，不使已有成果失效。支持`offset`、`limit`（默认50、最大200）及当前项目`document_id`筛选；界面可按批次浏览。项目切换或版本更新后清除旧候选，过期异步结果不会覆盖新项目结果。

`POST /api/v1/projects/{pid}/drawing-candidates/{cid}/adopt`须提交读取时的候选哈希、完整登记字段及核对依据。同一事务内重新核对候选、文件、页码、证据、原文和原件实际字节哈希；不能切换来源或提交过期候选。创建待复核图纸登记，按0.40规则使现有算量与报价需重新复核，并记录候选采用审计事件。失败不会留下登记或采用审计。

登记保留候选快照、规则版本、原候选值、所选值和四类标签的人工补充/修正。独立复核详情同时展示原文标签、全部歧义值及人工修正，编制人不能代审。候选采用后仍需独立复核，读取和采用不会自动调整图纸互参。

同一候选已有当前登记时不能重复采用；手工修订登记后仍受此限制，应继续修订原序列。当前登记被独立复核拒绝后可重新核对采用，旧记录继续保留。人工修订的新R版本按人工登记依据复核，不把旧候选冒充新原文。租户、项目成员及角色限制继续由服务端执行。

## 快照与台账

报价快照中的图纸登记包含候选来源和人工修正。PDF、Excel、JSON增加“图纸身份候选采用”表，逐字段列原候选、登记值、修正说明、规则版本、候选/证据ID及原文摘录。历史报价继续读取原快照，后续图名或版次修订不混入旧成果；已有留档文件不修改。没有候选采用记录的旧图纸不补造提取来源。
