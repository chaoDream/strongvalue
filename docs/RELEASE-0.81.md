# 0.81 不同长度构件混合下料

继续补齐PRD F05材料计量及F09可追溯报表。同一材料表可明确选择兼容的独立定长件及八种立柱模式，按统一原材定尺排入不同下料长度，保存逐根组成、逐件位置、原材需求、锯缝、切除及余料台账。混排独立作为备料附表，净工程量、kg清单、资源消耗和报价保持原口径。

## 输入与边界

可选顶层`mixed_cutting`为1至10个混排组，关闭须移除字段。每组包含唯一`name`、2至8个当前材料名称`members`、`stock_length`、`kerf_per_piece`、`trim_start`、`trim_end`、`reusable_min_length`、统一`length_unit`、`material_basis`、`measurement_basis`、`compatibility_confirmed: true`、`cut_basis_confirmed: true`，五个参数及两项说明分别关联七项`evidence`。新启用时名称、参数、说明和依据为空，成员及确认未勾选。

每组必须据原件确认同材质、同截面允许混排，规范化单位长度质量必须一致；不根据相似名称或相同每米质量推断兼容。单件实际下料长度与每组需求继承材料项，来源重复只乘一次；每组全部重复后最多200件，全表最多400件。同一材料项不得跨组重复，也不得同时启用单项定尺或比例搭接损耗备料。未入组材料可沿用原有附表，分开汇总。连续材料及板网片不参与混排。

每件下料须完整，每件另计一次锯缝，包括每根最后一件；两端切除另计，须核定未重复。原材、留用下限须正数，锯缝和端部切除可有据为0；统一支持m/mm/cm/dm/km。原材用尽、单件加锯缝超出可用长度、单位/原件/确认缺失及重复占用均阻断。

## 排料、证明与台账

先按实际占长从大到小生成确定性可行方案，再执行最多5000节点的对称剪枝搜索，寻找更少原材根数。容量采用精确有理数转整数比较，无浮点容差。根数下界取总占长容量下界与各长度阈值件数容量下界的最大值，分别保留`volume_lower_bound`及`cardinality_lower_bound`。

达到下界标`optimal_bound`；搜索穷尽并排除更少根数标`optimal_search`；预算用尽仅标`feasible_unproven`并显示当前方案与下界差额，不能宣称最优。记录初始/当前根数、访问节点、预算、搜索结论和稳定的逐件来源。最少仅指该组兼容材料、固定单一定尺及锯缝口径内的原材根数；未优化成本或库存。

逐根列示材料项内件号、净下料起终S、锯缝终点、余料及归属。正余料达到核定阈值（含等值）列待留用，小于阈值列报废，零余料不列库存。总损耗=锯缝+两端切除+报废余料；购入=净下料+总损耗+待留用余料，精确长度平衡差额为0。七类长度及质量、需求/逐根/汇总公式AST、原始参数单位换算及原件均可追溯。待留用不代表已经入库或再次使用，覆盖摘要只汇总明确选入项。

## 复核、修订与报表

新附表规则`railing-mixed-length-cutting-1.0`，含混排的材料表规则`railing-material-mass-1.14`。无该可选字段时保持旧结果。保存和审核重建核对原始配置、排料、证明及全部台账，原件字节/来源有效性、角色租户及并发门禁延续。

只改定尺等混排参数，即使净量相同，仍撤销总确认、要求重新独立复核、使旧计算书失效；历史构件及旧清单完整保留。修改任一材料项或切换来源会清空混排分组，须重新选择并补齐原件；关闭后再启用为空。

预览、详情及独立复核支持逐根组成和逐件切割位置；JSON保留完整结果，Excel/PDF新增六表：混合下料汇总、混合下料需求、混合下料原材明细、混合下料逐件位置、混合下料长度质量、混合下料依据与边界。旧报价快照不混入新附表。
