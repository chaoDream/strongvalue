# 0.91 基础矩形孔、矩形凹槽及圆孔混合扣减

补齐PRD F05的轴向矩形孔/凹槽受控算量，并贯通F06净量清单、F09报表及F11版本与独立复核。矩形、圆柱、矩形台阶及圆形台阶基础均可列矩形孔，与既有圆孔混合；可贯通全部基础或明确有限起止标高，逐层只扣实际相交高度。

## 输入和范围

沿用可选`through_holes`，每基础项合计1至20孔，名称唯一。圆孔保持原结构；矩形孔须增加`shape: "rectangular"`，使用`parameters: {x,y,length,width}`及对应`evidence: {x,y,length,width,measurement_basis}`，另填孔名和`measurement_basis`。不接受半径、旋转角、另填孔数或其他隐含参数。圆孔不增加`shape`字段，继续填写实际直径。

矩形孔长沿基础共同局部X轴、宽沿Y轴，不能旋转。XY为孔中心相对基础各层共同中心的坐标；Z=0为基础实体底面、向上为正。坐标原点、轴向、实际长宽或直径以及扣减范围须逐项有原件依据。孔位、截面和标高共用孔表独立单位，支持mm/m/cm/dm/km，基础尺寸单位可不同；输入及换算后均沿用18位小数上限。

可选`vertical_range: {parameters: {z_start,z_end}, evidence: {z_start,z_end}}`，须`0 ≤ z_start < z_end ≤ 基础总高`。不填时贯通全部基础；填写时只在该范围内扣减，包括矩形有限深度凹槽。不能从柱脚、锚栓或名称推定截面与深度。

台阶仍须同心同轴紧接、上层不外伸，各层同一材料，单项全部基础同一孔样；差异做法先拆分来源材料项。孔数和层数不增加基础个数，来源最终立柱和来源重复仅计一次，既有材料质量、栏杆长度、布柱及下料保持。

## 几何和公式

每孔每层取`min(孔终止Z,层顶Z) − max(孔起始Z,层底Z)`；非正值不扣、不检查该层轮廓，正值按实际截面面积乘相交高度扣减。矩形面积为长×宽，圆形面积沿用π/4×实际直径²。每层净体积须大于零；圆孔沿用实际直径严格小于相交圆层直径的约束。

矩形基础层按两轴检查孔边界；圆形基础层对矩形孔检查最远角点：`(|x|+长/2)²+(|y|+宽/2)² ≤ (基础直径/2)²`。不能只检查孔中心或长宽是否小于基础直径。

孔间先核对标高范围。标高相离或仅端面接触可分别扣减；有正高度交叠时逐对检查截面：

- 矩形/矩形：两轴中心距分别减半尺寸和，至少一轴分离余量非负。
- 圆/矩形：圆心至矩形最近点的距离平方减圆孔半径平方须非负，覆盖侧边、角点、包含及四象限。
- 圆/圆：沿用孔心距平方减半径和平方校验。

正面积重叠或包含阻断，不能将逐孔相加作为重叠孔并集。精确相切允许，不设显示小数容差；此类许可仅表示几何关系，不能替代结构净距、承载或施工验收。

完整保留原始参数、单位换算、实际相交层/起止Z/高度/单孔单层体积、逐层包含余量、孔对类型、分离余量及单位、标高分离余量和公式AST。Decimal 80位，逐孔逐层及分项不修约，累计最终立柱和重复后仅净总体积HALF_UP修约。含矩形孔用`railing-post-foundation-1.5`；原纯圆孔仍按1.3/1.4，无孔仍按对应旧规则，旧结果不变。纯矩形基础及矩形孔不附不参与计算的π常量。

## 编制、复核与导出

每孔可选圆形或轴向矩形。切换截面清空该孔坐标、尺寸、原件和说明；保留有限标高模式选择时也清空其起止Z和原件。孔名保留，本项及总体范围依据清空，确认撤销。切换孔深、增删孔、修改尺寸和原件沿用对应确认撤销；切换基础形式清空孔表。同来源修订恢复全部孔样，整体需重确认；来源变化清空旧选择、尺寸、孔位和依据。

预览不写项目。保存、独立复核、重算和计算书复核重建来源、原件字节、几何校验、毛扣净和AST。篡改、原件损坏、异项目依据、角色租户、并发与伪造ID门禁延续。修订保留精确历史和旧清单，旧计算书失效；来源修订使旧基础失效，旧报价及已留档文件保持原字节。

清单采用扣孔后基础净体积，有据编码映射仍需独立复核，不改数量。合同是否扣减、专业扣孔阈值及官方编码须另核。JSON保留完整记录；Excel/PDF在含矩形孔场景输出“基础孔洞毛扣净、原始依据、校验、范围与常量、标高依据、逐层相交”六表，截面类型、矩形轴向、长宽及圆孔实际直径明确区分，校验余量使用正确的m或m²。原圆孔专表及旧报价保持。
