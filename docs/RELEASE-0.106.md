# 0.106 内部孔底与孔顶的XY局部窗口模板

## 本次补齐

基础水平模板新增内部孔底、孔顶的有据XY矩形窗口，圆孔和轴向矩形孔均支持。孔底取已审孔起Z下侧混凝土，孔顶取止Z上侧混凝土，台阶边界按精确不等式选侧层；孔位、标高、层、截面及全部基础个数只读继承。通向基础外部的孔口仍不生成内部端面。窗口使用基础中心XY及来源孔位正向，不能把所选孔圆心当窗口原点，不随俯仰视翻转。

毛面积=所选孔∩混凝土侧层∩窗口。实际孔扣=所选孔∩同侧相接孔∩窗口；同侧相接孔已由来源几何验证完全在该侧层内、互不正重叠，因此不重复加入层裁切，也不把相接孔全截面直接扣除。孔底仅扣相接孔起Z<孔底Z≤止Z，孔顶仅扣起Z≤孔顶Z<止Z，另一侧的投影孔不扣。体积扣孔阈值仍不填实物理孔，未选区域不计。

新增窗口轮廓分段解析：直边与圆弧按窗口、轮廓支撑、圆与水平边交点及两圆交点划分X区间，逐段选最高下边界和最低上边界，以直线或圆弧原函数积分；200位Decimal计算、80位输出和记录固定π，不用网格或几何容差。毛交集和每个相接孔仅保留各自相关轮廓的分段，避免无关事件扩大公式；同Y圆交点直接保存同一X坐标，省去乘零根式。完整可重放AST、端点、有效边界和直接积分面积保留，不能确认面积界限时阻断。

对多个相接孔完整覆盖所选孔端窗口的零接触，另按全部边界事件证明每段交集由同侧孔无重叠完整接续，保留中点、轮廓上下边界、各孔见证上下值、接续间隙及公式。成立时用几何分割恒等式表示最后一个正面积孔扣=窗口毛面积−其他孔扣，净接触严格为零；各孔直接积分面积仍单独存储。有正面积缝隙则不签发完整覆盖证明，不以容差归零。

同来源同基础项所有窗口继续要求相同XY基准说明和原件。同孔同端面整面与窗口、X/Y均正重叠窗口及跨记录重复均拒绝，共享边界可分项；不同孔、孔底与孔顶是不同接触面，不把其XY投影误判为重复。每项继承全部最终基础个数一次，逐面逐孔不修约，仅总净面积按有据位数HALF_UP修约。窗口修改撤销确认，来源修订使旧模板失效，重新读取清空旧范围、材料、原件、修约和确认。

页面接通孔端窗口编制、独立复核、完整精度、直接积分和完整覆盖证明。JSON保留原始输入、来源与完整AST；Excel/PDF按需新增“基础孔端窗口交集”“基础孔端窗口分段积分”“基础孔端窗口覆盖校验”。既有孔端曲线表保留整孔端侧层裁切原值，窗口曲线使用对应直接积分值，实际扣减另列，避免把整孔端面积、窗口毛面积和相接孔全截面混用。无新窗口的旧成果不增加空表。

含孔端窗口的记录使用`foundation-horizontal-formwork-1.7`，旧1.0至1.6计算与报表保持。没有新增运行依赖。
