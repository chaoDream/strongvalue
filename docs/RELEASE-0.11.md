# 0.11 工程量差异归因与复核

本版落实PRD 6.3的计量差异诊断记录，连接F05独立底稿对照和F11版本审核。原因由专业人员依据原图、底稿和计量规则填写，不自动推断专业因果。

## 已实现

- 在图纸与算量页，对独立底稿的超差行、未唯一匹配行，以及未覆盖计算书登记诊断。只允许选择实际未通过或未覆盖的对象，已通过行不能冒充差异对象。
- 支持图纸几何、重复或遗漏、施工工法、计量标准、精度与修约五类。填写系统侧与人工基准的尺寸/参数/条款/精度、原图位置及差异分析、处理建议；各类别显示对应核查提示，均须选择当前原始证据。
- 自动保存当时的系统量、人工基准、差量、允许偏差、底稿行或未覆盖计算书副本。人工分析不能覆盖这些对账记录值；未匹配、未提供基准或不能计算差量时明确显示，不能补造数值。
- 同一底稿同一对象只能追加诊断版本，保留旧分析；提交及审核通过对象哈希检查并发变化，历史版本不能再签署。独立reviewer可通过、拒绝或要求补充资料，批量复核只列出各差异的最新版本。
- 新底稿对账保存完整计算书口径指纹，包括公式、参数和规则版本；这些内容变化时，即使总工程量不变，新对账的审批和黄金底稿门禁仍要求重新对账。计算书审核状态变化不改变该指纹。新诊断必须匹配底稿、当前数量及完整口径。
- 复核诊断前核查底稿和分析依据仍属当前原件，文件存在且SHA256一致。旧输入诊断在界面和新报表中显示历史计算口径提示；历史记录不会因来源变化被抹去。
- 新报价保存当时的全部诊断及审核记录；Excel/PDF增加差异诊断台账，包含自动对账值、系统侧与人工基准说明、类别、版本、状态、分析、处理建议和证据编号。后续修订不改写旧报价。长分析按续行分段并在Excel中自适应行高，避免打印时被固定行高截断；原始完整文本保留在结构化快照中。无价交付证据包同样包含诊断记录。

## 审核边界

诊断复核只核查原因分析，不改变系统工程量、独立底稿、容差或“通过/超差”的定量结论，不会给失败底稿盖上通过状态。修正尺寸、扣减、工法或规则后，应重新算量并导入独立底稿对账。

开启黄金底稿门禁的项目仍须有适用于当前计算口径的已审、通过且完整覆盖的独立底稿；诊断已复核不能解除该门禁。未启用此门禁的兼容流程仍不代表黄金算例验收，诊断记录也不构成新增的全局强制门禁。提交或审核诊断使已有报价审批失效，需要重新生成快照和审阅成果，以纳入最新记录。

## 兼容性

旧底稿记录保留原有数量指纹及审核流程，不静默追补缺失的公式/参数指纹。使用新诊断前需重新上传底稿对账，系统会明确提示。历史记录没有新指纹时不能宣称已通过完整计算口径校验。

## 验证

138项自动测试通过，TypeScript检查和生产构建通过。新增18个用例覆盖五类诊断、定量结论不被诊断审批改变、租户/角色隔离、哈希与版本保护、批量目标过滤、非法输入原子拒绝、未匹配及未覆盖对象、旧底稿兼容提示、计算口径变化、原件缺失/损坏/替代、同量不同规则时的黄金门禁、实际Excel/PDF导出和历史报价不变。

浏览器在独立合成工作区实际提交几何差异分析：系统15m³、底稿14m³、差量1m³、容差0；切换复核账号核对来源并审定，诊断状态更新，底稿仍超差。截图 `qa/v0.11-quantity-diagnosis.png`。没有修改实际工程或进行真实专业签审。

## 仍未完成

本版不自动检查几何交叉覆盖、不自动识别真实工法或法律条款，也不判断人工分析是否专业正确。复杂识图、比例校准、全专业算量、授权定额与价格、专业软件往返、项目细分权限、独立任务队列和生产基础设施，以及真实工程黄金底稿验收仍未完成，PRD不能标记全量完成。
