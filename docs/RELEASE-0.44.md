# 0.44 OCR原行的原图高亮定位

继续补齐F01/F04的原图证据核对。扫描文字识别结果现在逐行展示，每行提供“定位第N行原图”；图纸身份候选的字段原行和独立复核详情也提供同一入口。识别结果按50行分批显示，避免一次展开大量内容。

## 原页核对

定位弹窗显示原件名称、实际页号、机器原文，并在原始PDF显示页上高亮对应归一化区域。复用已有PDF阅读器，支持翻页和缩放；坐标沿用PDF显示裁切区及页面旋转约定，不再额外旋转或换算。此框只辅助定位，不能据此计算工程尺寸或认定机器识别正确。

弹窗独立于登记和复核表单。关闭定位会返回原表单，不切换工作台页面，不清空已填写的图号、版次或核对说明。组件在项目、证据、原行或候选版本变化及卸载后放弃迟到响应，避免旧位置覆盖新上下文。

## 来源保护

`POST /api/v1/projects/{pid}/evidence/{eid}/ocr-lines/{number}/locate`为只读定位操作；机器原文放在请求体内，避免出现在URL和常规访问日志。沿用当前企业及项目成员权限，编制与复核人员均可查看。

服务器确认本地OCR证据对应已完成的来源任务、文档哈希、页码、识别器、原行文字和完整合法位置。所选原行的文字、框及置信度须与界面读取值一致；从图纸候选或复核详情发起时还验证整条证据哈希。返回前验证原件实际字节、PDF实际页数，以及保存时的旋转和裁切信息。

行号越界、文字或位置变化、原件缺失/篡改/替代、来源任务失配、坐标或页几何失配时拒绝定位，提示刷新核对，不使用客户端提供的框绘制。该操作不添加证据、审批或工程量，不改变报价和历史快照。
