# 0.80 定尺自动下料与余料台账

继续补齐PRD F05材料计量及F09可追溯报表。独立定长件及八种立柱模式可按原件启用单一实际下料长度、单一原材定尺的自动排料，计算该口径下最少原材根数，列示整根/尾根方案、损耗与待留用余料。结果独立作为备料附表，不自动增加净工程量、kg清单、资源消耗或报价。

## 输入与支持范围

适用材料项可选`cutting_plan`，完整包含`stock_length`原材定尺、`kerf_per_piece`每件锯缝、`trim_start`/`trim_end`每根起终端切除、`reusable_min_length`可留用余料下限、统一`length_unit`、`cut_basis_confirmed: true`、`measurement_basis`，及五个尺寸和说明分别关联的六项`evidence`。新启用时参数/依据为空，口径确认未勾选，不默认套用任何原材规格或损耗。

单件实际下料长度与每组件数/柱数继承材料项，全部需求只乘一次已审来源重复，须为1至1000000整数。每件下料已完整包含本件专业构造尺寸，不再推断或追加搭接。每件单独计一次锯缝，包括本根最后一件；两端切除另外计，须确认未与锯缝重复。原材和留用下限须大于0，锯缝及两端切除可有据为0。原材不足一件完整下料加锯缝、两端切除用尽原材、单位或原件缺失时拒绝。

本模式仅支持单项同长度、同截面、同定尺，不跨材料项混排，也不自动使用库存余料。连续线材和板网片须采用其他已支持的计量方式。同项与0.79比例搭接损耗备料互斥，接口拒绝同时传入，界面启用一种会清除另一种的参数和依据；不同材料项可分别采用两种方法，分开汇总。

## 精确取整、长度与质量平衡

采用精确有理数运算：可用长度=原材定尺−起端切除−终端切除；每件占长=实际下料长＋每件锯缝；容量为可用长度/每件占长向下取整；原材根数为全部需求/容量向上取整。保留“容量件占长≤可用长＜多一件占长”和“少一根容量＜需求≤当前根数容量”的取整证明。最少根数仅针对上述固定口径，不声称多规格、多定尺全局最优。

最多生成两类压缩方案：装满容量的若干根和剩余件数的一根尾料，保留原材编号范围、原材根数、每根件数及共出件数，不展开百万条记录。容量可能超过JavaScript安全整数，按精确字符串返回，不以浮点数取整。

每根余料=可用长度−实际件数×每件占长。零余料单列为无余料；正余料达到留用下限（含等值）列待留用，低于下限列报废。待留用只是计划台账，不代表已入库或已经再次使用。总损耗=锯缝＋两端切除＋报废余料；购入长度=净下料＋总损耗＋待留用余料，平衡差额精确为0。各项质量采用已核定每米质量换算，分项不额外修约，超过引擎数量范围拒绝。

结果保留需求公式、单根/全部长度公式AST、原始参数与单位换算、容量/原材根数证明、七类长度质量组成、零差额平衡及来源原件。材料表只汇总启用项，明确已编/未编覆盖，不将其视为完整项目采购单。

## 复核、版本与报表

下料规则`railing-uniform-stock-cutting-1.0`，含此附表的材料表规则`railing-material-mass-1.13`。未启用时不增加隐藏下料配置或改变旧结果；原有柱距核查、立柱布置和其他项比例备料可以保留。

配置、取整证明、方案、余料、平衡和汇总均参与保存重建和审核哈希。只改原材定尺等参数，即使净量不变，也须重新独立复核，旧计算书失效，历史构件和旧清单完整保留。角色、租户、并发、原件字节校验和来源变更门禁延续。关闭附表删除配置，再启用为空；来源或材料模式切换不保留不适用的旧配置。

界面预览、材料详情、独立复核和JSON/Excel/PDF均支持四表：定尺下料汇总、定尺下料模式、定尺长度质量台账、定尺取整与原件。旧报价快照不混入新报表。
