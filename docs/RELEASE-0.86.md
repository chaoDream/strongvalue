# 0.86 栏杆立柱独立矩形基础

补齐PRD F05基础构件计量，并贯通F06清单口径、F09报表及F11复核版本。从已审栏杆材料表选择已核定布置的立柱项，按实际基础长宽高独立计算体积，不从栏杆长度或材料质量猜测基础数量。

## 来源、选择及适用范围

新增`post_foundation`结构化构件，`quantity_type: volume`且顶层`parameters: {}`。只允许当前已审`railing_material`来源，服务端重建并校验完整栏杆/坐标或多边形来源链、原件和哈希；只提供有`post_layout`的立柱项。连续材料、板网片和普通独立定长件不能自动推定为立柱。

支持均分、定距及各自构造加柱、禁布移柱、组合加柱移柱八种模式。数量取来源最终保留的单组根数，来源重复只乘一次；共享端点、加柱、禁布移柱及柱距核查仍由已审来源负责。原栏杆长度、原材料质量、布置和下料附表不修改。

`foundation_items`明确选择1至50项，每项严格包含`material_index`、`parameters`、`length_unit`、`measurement_basis`、`evidence`。参数仅长`length`、宽`width`、高`height`，三者须为正；支持mm/m/cm/dm/km，三项尺寸及范围说明分别关联原件。不得另填数量、重复数、扣减或隐含系数。每个选入项全部最终保留立柱每根一个基础、同项同尺寸；不同基础做法须先按实际范围拆分材料项。未选立柱项明确列为未覆盖，不补算。

全表同一基础材料及做法另填说明和原件，总范围/不重复说明及总量修约各自关联原件，须明确确认。一柱一基础仅适用于独立、无交叠的水平矩形等截面基础。本版不定位基础、不做结构承载设计，也不扣柱脚、锚栓孔、预埋件或交叠，不计垫层、土方、钢筋、模板及回填占位；这些须另核。

## 计量、重复拦截及来源门禁

单基础体积=长×宽×高；分项单组体积=单基础体积×来源最终根数；累计后乘来源重复数量，仅总体积按明确0至12位HALF_UP修约。Decimal 80位保留原始尺寸、单位换算、单组/全部根数、分项体积、总量差额及公式AST，根数公式直接引用来源布柱公式。

同一来源材料项不可在其他当前基础记录重复选入；分属不同立柱项的基础记录允许并存，修订也检查交叉占用。重复检查在保存事务中执行，新增请求伪造旧记录ID不能绕过；原记录保留选入项可正常修订。该门禁只识别相同来源表和项号，不自动判断不同材料表/不同几何构件的物理重叠，仍须专业核对现有基础和清单。

来源表修订会使基础失效，原坐标/栏杆变更沿依赖链使材料表及基础失效。旧基础不能直接重审通过，须读取新版本核定。新建、选择立柱项时尺寸和原件为空、未确认；修改任一输入撤销确认和预览。修订同来源保留尺寸原件但撤销确认；来源哈希变化清空选入项、旧尺寸、材料及范围原件、修约选择，显示新最终根数。

## 审核、清单及报表

新建和修订由编制账号完成，独立复核可见来源版本、单组/重复/全部根数、尺寸、单基础及总量，原件按尺寸及范围展开。保存重建检查原始参数、原件、数量、AST及计算记录；角色租户、异项目原件、原件字节、并发门禁延续。基础修订使旧计算书失效，保留精确历史、旧清单和报价快照。

规则为`railing-post-foundation-1.0`。清单新增独立口径“立柱独立矩形基础实体体积（m³）”，不会自动匹配其他同为m³的构件口径；编码和项目特征仍须有据核定。JSON保存全部计算；Excel/PDF新增“立柱基础体积汇总”“立柱基础逐项体积”“立柱基础原始尺寸与依据”“立柱基础材料范围与修约”。旧报价不增加新表。
