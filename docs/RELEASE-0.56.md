# 0.56 CAD修订前后数量与原始管段对照

本版为CAD来源管线补齐修订差异。读取原序列并调整，或从当前CAD明确选择原管线修订后，单位校核预览同时显示固定原版与本次候选的数量、说明和逐段范围变化。对照用于核查变更，不直接生成计算书、清单、签证或金额。

## 数量、口径与原始管段

数量表列出修订前、修订后及增减差额：单组未修约长度、整组重复数量、总量修约位数、乘重复后的未修约总量及修约后工程量。计算及减法均在服务器使用Decimal 80位，浏览器原样显示字符串；不以浮点数或逐段修约重算差额。

逐段对照以原文件、内容哈希、解析任务及任务哈希、原对象ID和原始相邻顶点编号确定身份。对同一原始管段显示保留或反向采用，未再选入显示移除，新选入显示新增；列出前后采用顺序、方向、原始点号及单段长度。扩大前置范围导致其余段序号后移时，它们仍是保留段，并明确显示前后序号。不同文件或解析任务的同句柄、同位置对象不会自动配对。

说明表列出名称、共同WCS及高程基准、中心线计量口径、用途依据、重复数量、修约位数的显式变化；原版状态、修订号、固定哈希及前后文件校验值供追溯。无变化明确显示，不能用总量相等推断几何或计量说明相同。

## 保存与复核

差异纳入服务器预览哈希；采用时重新计算并核对，客户端不能提交或覆盖差异字段。保存至本次CAD来源及采用记录，并记录差异哈希。后续来源检查、复核和算量通过固定原版本哈希寻找历史快照，重建原映射并重新计算对照；差额、范围、口径、原版历史或差异哈希变化时拒绝继续。新版本仍回到待复核，并沿用既有下游失效与重建流程；幂等重试不产生重复修订。

本比较依据固定原构件的历史坐标，不代替原件真实性或旧版有效性检查。原CAD文件已失效时，仍允许从实际有效的新来源明确修订；各原段分别移除、新增，不隐式重绑定。原版历史坐标或映射不完整时显示无法可靠比较、留空数量与段差异并提示人工核对，不编造零差额；有效新候选仍需重新独立长度校核、主动确认和独立复核。

旧版采用记录不补写差异或改写身份；未修订的新建管线维持原请求与来源结构，无数据库迁移或新依赖。

## 导出

JSON、Excel、PDF增加同快照的三张表：`DXF修订数量对照`、`DXF修订口径变化`、`DXF修订原始管段`。包含固定原版哈希、来源文件及逐段身份。原文件完整校验值集中列于口径表，逐段表保留原文件ID、原对象、原段编号和段身份，避免重复长哈希使关键变化跨页。旧报价快照不混入后来新增的修订对照，已保存导出件不改写。
