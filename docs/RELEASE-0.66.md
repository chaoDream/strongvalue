# 0.66 栏杆坡段三维与水平投影计长

继续补齐PRD F05栏杆计量。设计边线栏杆可读取当前已审设计坐标线的原始XYZ，按明确依据选择“三维设计长度”或“水平投影长度”，逐段整段计入、排除或核定局部S区间。已有设计管线只作为坐标几何来源，不能据其管线用途推断真实栏杆安装中心线；须独立填写栏杆材料、安装及计量依据。

## 计量与兼容

三维原段长为√(ΔX²+ΔY²+ΔZ²)，水平投影长为√(ΔX²+ΔY²)。原始XYZ、单位、逐坐标证据及共同高程基准均保留，不能用来源已修约的管线总量反推分段长度。每段同时记录三维长、水平长及当前口径长度，局部S从原段起点按所选口径增加；坡长端距与投影端距不能互换。竖直段可采用三维口径，水平模式遇零投影段明确阻断，要求拆分来源或选择三维，不静默漏计。不同高度段的投影重合不自动推断接触或扣重。

沿用逐边决定、局部区间精确平方上限比较、重叠阻断、每段20区间和合计1000区间上限。每段及每区间不另行修约，单组核定长度累计后只乘一次来源重复数量，总长按有据选择的0至12位HALF_UP修约。新规则为`design-line-railing-1.0`，保留精确长度平方、原始端距、单位换算及AST。

原多边形栏杆继续沿用`polygon-railing-length-1.0`及原水平口径，不新增默认选择或改写旧输入/计算记录；多边形来源不能混带坐标线口径字段。坐标线模式须明确选择并关联口径原始依据。原段身份包含XYZ、顺序及所选口径，不能拿旧模式决定充作新模式输入。没有新依赖或数据库迁移。

## 编制、复核和清单

栏杆面板可选择已审多边形或设计坐标线。坐标线先选择口径再读取；改口径清除旧预览、原段决定/区间、口径依据、来源绑定及确认，重新读取前预览和保存禁用，应用后须重新填写各段说明与原始依据。同版修订可恢复输入但仍须重新确认范围；来源版本变更后清空全部原段决定、说明、依据和区间。即使只改Z而水平段长不变，也须重新核定安装范围。

示意支持XY、XZ、YZ投影，标明原段编号，逐段表同时显示三维/水平长、起终高程和本口径计入量。投影缩成一点不表示漏计，图示不能测量。独立复核可展开原始XYZ、逐坐标依据及共同高程基准；预览、保存、审核、计算书及导出均重建并核对来源、原件、证据和计算记录。

清单映射新增“设计坐标线三维栏杆长度”和“设计坐标线水平投影栏杆长度”，与既有多边形水平长度分开。三者虽同为米，也不能互相套用规则；须分别提供合法编码、适用标准与原始依据。修订保留完整已审旧版，下游旧计算书失效，复核、重算及重建清单后采用新量，旧报价及导出留档不改写。
