# 0.15 未计价资源与待询价任务

补齐 PRD F07、7.1 和 TC-07 中未计价主材的编制与问题清单能力。原来每条资源保存时必须已有数字价格；现在可明确登记为待询价，并保存资源编码、规格、单位、原消耗量、类别、费用归属说明及当前原始依据。

## 已实现

- 资源编辑增加“未计价资源，待询价”选项；缺价用 null 保存，不接受以0或其他数字冒充待询价。名称、编码、规格、单位、消耗、费用归属和原始证据必须完整。价格及其来源、授权、期次和有效期在等待报价时不必虚填。
- 组价页显示待询价和待定额匹配清单，支持直接打开对应清单补充依据。任务从当前清单实时派生，附带清单/资源哈希；缺少定额的清单也进入待办，不生成虚构候选或价格。
- 新录价资源区分官方信息价、供应商报价、询价、历史审核价、人工录入。显式已录价状态须选择来源类型；历史审核价只作参考，不能直接用于当前报价。旧资料未标注来源类型时保留原有数据并明确显示未标注。
- 待询价资源在价格检查和纯计价引擎中均阻断，不返回局部金额或零价总价。清单数量可按原流程复核，但不能据此绕过价格阻断。
- 补价时取消未计价标记，录入当前合法价格和依据后保存；待询价项随之移除，清单回到待复核，独立复核通过后才可报价。费用归属为记录说明，不自动改变资源类别、费用基数或取费规则。
- 编辑表单读取当前清单及哈希，提交校验基线，拒绝覆盖已变化的数据。修改仍保留审计事件，并使下游报价审批失效。

## 无价成果与历史版本

即使项目已有旧报价，成果交付也可选择“当前无价草稿（含待办任务）”，导出当前缺价资源及待匹配任务。PDF、Excel、JSON、ZIP、实际PDF预览及交付完整性检查均支持该选择。API `/exports` 和 `/delivery-check` 增加 `unpriced=true`；与指定 `quote_id` 同时提交会被拒绝。省略参数继续沿用最近报价的兼容行为。

无价草稿不显示总金额，价格表显示“待询价”，增加待询价与匹配任务表并保留显著草稿标记。长任务字段按段排版。历史报价、快照及已留存导出文件不会改变。

## 验收与边界

新增19项合成测试，覆盖缺价非零、字段与数字校验、跨企业和受限项目访问、证据归属、并发编辑基线、补价后复核、历史价格阻断、旧报价不变、PDF/Excel/JSON和ZIP导出及无价版本选择冲突。浏览器在隔离工作区保存待询价资源、显示任务并检查无价草稿证据；没有操作真实工程数据。

待办是随当前清单派生的编制问题清单，尚无供应商收发、指派、截止日期或询价回复管理。未计价资源没有原价，不能生成调价差额，须在定额资源编辑中补价后复核；现有企业库采用和调价流程不用于直接填充缺价。资源编码由原始依据人工录入，不代表系统已验证官方编码。官方定额/价格接入、材料替换和配合比独立规则库、复杂图纸识别、完整专业算量、厂商授权接口及真实工程验收仍未完成。
