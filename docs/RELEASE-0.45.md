# 0.45 扫描原行的人工核对抄录

继续补齐F01/F02/F04的原图证据链。在“项目与资料 → 扫描页文字识别 → 定位第N行原图”中，编制人可以对照高亮原图填写核对文字、说明依据，确认已核对后保存人工抄录。复核账号保留只读原图定位能力，不能编制人工抄录。

## 保留机器原文与不同意见

人工抄录作为新的manual证据追加，保存时保持待复核标记；原OCR文字、原行、置信度、任务及已存人工记录不修改。每条记录保留识别器、系统算法版本、原件与OCR证据哈希、行号、页面裁切旋转及区域、原行快照、核对文字、依据、人员和时间。

同一编制人、来源行、文字及依据完全相同时，重复提交返回已有记录，不重复写入或追加审计；不同文字、依据或人员形成独立记录，界面全部列出，不自动选定最新记录或某位人员的意见。

新增证据不自动改动事实、尺寸、构件、工程量、清单或报价，不替代独立复核。编制人仍须明确选用证据并录入业务对象，再由独立复核人员审定。带明确图号或图名标签的人工抄录可进入已有标题栏候选流程，界面说明来源为人工抄录，并显示原机器文字和人工核对依据。

## 原件与来源检查

`POST /api/v1/projects/{pid}/evidence/{eid}/ocr-lines/{number}/transcriptions`须提交定位时的整条OCR证据哈希及原行快照。服务器在同一事务内核对原件实际字节、当前文档、OCR完成任务、页号、位置及页面几何；来源过期时不留下记录。文字、依据各限2000字，须非空；原页确认仅接受布尔值true。

后续通过通用证据入口选用人工抄录时，会重新验证其机器来源及原件；不能把损坏、换源或被改变的原行当作有效证据。图纸候选读取排除来源失配的抄录；保存和独立审核继续检查实际原件。来源只能直接指向local_ocr原行，禁止循环追溯。现有手工标注不受影响。

## 审核、快照与导出

候选核对和独立审核详情区分机器原文及人工说明。报价快照保留当时的全部记录；JSON、Excel、PDF增加“扫描原行人工抄录”台账，列出机器原文、人工文字、核对依据、人及时间、源行和原图位置。后续抄录不会混入旧版报价或导出。
