# 0.96 基础竖直孔壁模板

本次继续补齐PRD F05的基础模板，新增独立孔壁模板构件。选择已审基础中的矩形孔四侧或圆孔整周，在孔与来源层共同标高内计实际竖直接触面积，扣除与外界或相邻矩形孔贴合的无接触部分。编制、修订、独立复核、计算书、面积清单、编码映射及三格式导出接通。

## 来源及实际接触

孔位、孔尺寸、竖直范围、基础层和全部最终个数来自当前已审`post_foundation`，并递归校验上游及原件。支持已有矩形/圆柱/同心矩形或圆形台阶基础，圆形及轴向矩形贯通孔、有限标高孔/凹槽，包含旧版无显式Z的贯通圆孔。无已审孔洞的基础项不提供孔壁候选，不能在模板编辑器中新增或修改来源孔。

矩形孔分别选择X负、X正、Y负、Y正内壁面，整宽取孔的实际宽或长；圆孔仅选整周，周长=记录的固定π×实际孔径。方向沿基础共同局部XY，不随观察面翻转。Z从基础底0向上，必须在所选层和所选孔共同区间内，起始Z<终止Z；不自动裁切、延伸或跨层计量，跨层应分项。起止Z可独立使用mm、cm、dm、m、km，沿用原始及换算后的18位精度约束。

每项毛面积=孔壁整宽或整周长×实际接触高。矩形孔某侧与本层矩形基础外边界重合时，该侧没有混凝土接触，按选入范围全扣；允许展示零净面积及其扣减原因。与另一矩形孔对向边界相接时，仅扣横向和标高的真实交集，两个方向均为正才扣。多相邻孔逐项扣除，来源已保证孔的实体范围不正交叠；双方选入的贴合面均应扣除。

圆孔及圆形基础外轮廓的点相切不产生正面积扣减。矩形孔位于圆形基础中时仍按矩形孔四壁计，不能用基础直径替代孔壁宽度。体积扣孔阈值不改变物理孔：混凝土可以按规则不扣孔体积，但孔壁仍存在，通外界或孔间贴合也不能恢复成模板接触面。

每面继承对应基础项全部最终个数一次，不再乘来源重复、孔数或层数。未选面不计，不能由孔体积、立柱、锚栓或外表面积推断施工支模。各基础个体须采用相同范围，差异做法应先拆分来源。模板材料、实际接触、修约及不重复计量须有当前项目原件并独立复核。

## 重复、精度及历史

同一来源基础项、同层、同孔、同内壁面的正高度重叠禁止；相邻标高仅端点相接可共存。跨记录保存、复核和重算同样检查，失效记录仍保留原范围占用，须修订原记录。孔壁模板与外侧模板分别记录和映射，不能拿已有外侧模板编码规则自动匹配孔壁。

采用Decimal 80位及记录的固定π。逐面宽、高、毛面积、每项实际扣减、全部基础个数和净面积均保留完整值及AST，不逐孔或逐面修约；只有累计全部净面积按有据0至12位HALF_UP修约。JSON保留原始Z、单位换算、孔位/孔尺寸、层孔共同标高、无接触交集、来源快照、证据索引和修约差额。

新建时名称、材料、范围、原件、修约和接触列表为空。同来源修订恢复完整原始输入，整体需重新确认。改变基础项、孔或层清空旧面、Z及本项依据；改变孔也清空旧层，防止旧孔尺寸或范围串用。切换面或标高单位要求重新核定本项接触说明，所有编辑撤销整体确认。读取新来源清空旧接触范围、做法、原件和修约。

预览及放弃编辑不改项目；修订保存精确历史和旧清单，使旧计算书失效。基础或上游变更沿依赖链使孔壁模板失效。延续角色租户、原件字节五门禁、异项目依据、篡改重算、伪造ID和乐观并发保护；旧报价与旧导出文件保留。

## 接口、清单和报表

新增`kind: foundation_void_formwork`，顶层空`parameters`及`quantity_type: area`，材料/范围/修约字段与基础模板一致。候选接口：`GET /api/v1/projects/{pid}/foundation-void-formwork-candidates?component_id=来源基础ID`，仅返回当前已审来源中有孔的基础项，以及逐孔可选层和共同标高。预览、新增、修订仍使用既有构件接口。

`contact_ranges`每行必须且仅包含以下字段；尺寸仅为合成接口示例，不是实际工程默认值：

```json
{
  "name": "合成孔壁范围",
  "material_index": 1,
  "level_index": 1,
  "hole_index": 1,
  "face": "x_minus",
  "parameters": {"z_start": "0", "z_end": "150"},
  "unit": "mm",
  "evidence": {
    "z_start": "当前项目起始Z原件证据ID",
    "z_end": "当前项目终止Z原件证据ID",
    "measurement_basis": "当前项目实际接触范围原件证据ID"
  },
  "measurement_basis": "据原件核定本孔本侧实际接触及外界/相邻孔贴合扣减范围"
}
```

序号须是来源中存在的整数；圆孔面为`circumference`，矩形为`x_minus/x_plus/y_minus/y_plus`。每份1至200项。不接受重复数量、未审孔、局部横向条带、圆弧角度或人工扣减面积。规则版本`foundation-void-formwork-1.0`；结果新增`void_formwork_summary`，逐面`deductions`区分`exterior_boundary`与`adjacent_void`并记录实际交集及AST。

清单映射新增独立“基础已选竖直孔壁实际接触净面积”m²口径。映射核定编码、工法、特征和标准，不改变数量；不提供官方编码及价格默认值。原外侧模板计量和规则版本保持。

Excel/PDF新增“基础孔壁模板面积汇总”“基础孔壁逐面接触净量”“基础孔壁无接触扣减”“基础孔壁原始范围与依据”“基础孔壁来源孔与原件”“基础孔壁模板做法与规则”六表。长数、长原件和说明续行、行高及分页适配，跨页重复表头；无孔壁模板的旧报表不新增空表。
