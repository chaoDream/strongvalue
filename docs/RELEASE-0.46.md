# 0.46 人工抄录的工程事实候选与采用

继续补齐F02扫描文字进入工程事实的流程。在“项目与资料 → 扫描页文字识别 → 人工抄录”中，编制人可以读取明确事实候选，逐项核对原始数值、单位和换算结果，填写采用依据后保存为待复核事实。复核人员可只读查看候选，通过现有独立复核入口核对、审定或拒绝事实。

## 明确候选与人工选择

复用17类工程事实目录：项目名称、建设单位、设计单位、施工单位、监理单位、建设地点、标段、工程范围、投标截止时间、质量要求、计价要求、合同条款、处理规模、施工工期、施工标金额、监理报价费率、合同金额。文字字段须有明确标签；数值字段使用已有受控识别规则，保留摘录、原始数值和单位。万元/亿元、万立方米等按确定性单位规则换算，施工金额、一般合同金额与监理费率分别记录，不互相替代。

读取候选不修改项目。候选分页展示，每项单独选择并填写核对依据，不批量自动采用；无法识别的文字仍可通过“添加事实”人工记录。长度标注不推断工期、金额或处理规模，监理服务期不误记为施工工期；不从这些候选生成尺寸、构件或工程量。不同值全部保留，不按出现次数或人员决定选值。

## 来源与并发保护

新增只读接口`GET /api/v1/projects/{pid}/evidence/{eid}/transcription-facts`，分页默认50项、最多200项；采用接口为`POST .../transcription-facts/{cid}/adopt`。仅接收人工抄录来源，采用请求仅允许候选哈希和核对依据，不能夹带自由修改的事实值。

候选绑定提取及单位规则版本、整条抄录哈希和序号。读写均重新验证原OCR任务、原行、位置、抄录来源与原件实际字节；过期候选、换源、缺失或损坏原件阻断操作。采用在同一事务内再次核对候选并换算，编制权限、项目成员及租户隔离沿用现有规则。已有有效事实的候选禁止重复采用；原记录被拒绝后可重新核对采用，并保留旧记录。

## 复核、报价与导出

采用结果保持待复核或冲突状态，编制人不能替代独立复核人员。同字段等价单位不制造伪冲突，不同数值进入现有冲突复核流程。事实采用使受影响的当前审核和报价失效，重新复核后才能使用；历史报价快照和已生成文件保持原样。

事实保存候选、哈希、采用依据、采用人及时间，追加审计记录。复核详情同时显示原机器文字、人工抄录依据和事实采用依据。JSON、Excel、PDF的报价快照增加“人工抄录事实采用”台账，便于区分文字核对与业务事实采用。

## 验证与范围

2026-10-23：新增17项合成测试，全量1155项通过；前端类型检查和生产构建通过。覆盖只读候选、原始单位与字段区别、独立复核、重复采用及拒绝后重做、等价与真实冲突、来源及原件损坏、严格输入、权限和分页、下游失效及三种成果格式的历史快照隔离。

另生成无文字层的合成纯图片PDF，实际本机OCR识别出“施工工期45日历天”，保存人工抄录后读取工期候选。隔离浏览器用编制账号填写依据并采用，确认待复核及防重复状态，再用独立复核账号查看两层核对依据并审定为45日历天。截图见`docs/qa/v0.46-transcription-fact-adoption.png`和`docs/qa/v0.46-transcription-fact-review.png`。14页合成草稿PDF第14页新增台账已渲染检查，可读且未见重叠或裁切。
