# 强·报价详细使用手册

适用版本：0.131.0

最后更新：2026-10-28

适用对象：项目负责人、造价编制人员、专业复核人员、企业管理员及本地部署维护人员。

本手册说明当前已经实现的操作。项目定位为受控工程工作台，尚未完成 PRD 全量商业验收。文中的数学示例和截图属于隔离合成数据，不能作为真实工程尺寸、定额、价格或专业判断依据。

后续版本继续维护本文件，不另建一份互相冲突的“最新版手册”。每次新增、修改、停用功能，应同时更新对应章节、适用版本、更新日期和末尾的维护记录。具体要求见[文档维护约定](#maintenance)。

## 1. 先了解工作方式

系统按下列顺序推进：

**原始资料 → 来源证据 → 事实和尺寸 → 构件 → 工程量计算书 → 清单 → 定额及资源价格 → 取费规则 → 报价快照 → 成果审核和交付。**

编制人员录入和修订，独立复核人员核对原件后审定。识别成功、计算成功、保存成功和专业审定是不同的状态；模型或 OCR 的输出只提供候选，不能直接变成已审工程量或报价。

使用中牢记以下规则：

- 每个关键尺寸、材料做法、计量口径、扣减、定额、价格和取费规则，都应关联当前项目的有效原始依据。
- 屏幕示意只用于定位。禁止按示意比例、PDF 像素或 CAD 投影的显示距离填写施工尺寸。
- 工程量单位、原始尺寸单位、重复数量和定额消耗单位必须分别核对；不要重复换算或重复乘数量。
- 原件或上游数据变更后，下游审核可能失效。应从最先变化的环节重新核对，再重新计算、复核和导出。
- 历史报价和历史导出件保留原样。历史文件上的“已审”描述生成当时的状态，不代表当前项目仍可直接采用。
- 缺资料、缺价格或未审数据可以形成有明确标记的草稿，不能靠填零、编造编码或关闭检查代替补齐依据。

## 2. 安装、启动与登录

### 2.1 已安装环境启动

部署要求为 Python 3.12+、Node.js 22+、pnpm 11。以下命令均在项目根目录执行：

```sh
.venv/bin/python scripts/build.py
.venv/bin/python scripts/start.py
```

打开 [工作台](http://127.0.0.1:8000/)。默认只监听本机；关闭启动进程会停止服务。若端口已有服务，先确认现有服务版本和用途，不要反复启动多个进程。

### 2.2 全新环境安装

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock.txt
cd frontend
pnpm install --frozen-lockfile
cd ..
.venv/bin/python scripts/build.py
.venv/bin/python scripts/start.py
```

命令行需要由部署维护人员执行。日常编制人员在服务运行后直接打开浏览器登录即可。

### 2.3 首次登录

首次初始化数据库时，服务终端显示随机初始化密码。初始账号如下：

| 账号 | 身份 | 用途 |
|---|---|---|
| `admin` | 企业管理员 | 建立成员、分配角色及项目访问管理，也可参与编制 |
| `estimator` | 造价编制 | 资料整理、构件算量、清单组价与成果编制 |
| `reviewer` | 专业复核 | 独立核对证据、工程量、规则和成果 |
| `other` | 另一测试企业账号 | 验证企业隔离，不用于当前企业的实际协作 |

本地首次初始化的账号使用同一初始化密码；实际协作前分别设置密码。系统没有公开注册入口。

忘记密码时，由本机维护人员执行，按提示输入至少 12 位的新密码，输入不回显：

```sh
.venv/bin/python scripts/manage.py reset-password admin
.venv/bin/python scripts/manage.py reset-password estimator
.venv/bin/python scripts/manage.py reset-password reviewer
```

重置后该账号旧会话全部注销。不要把实际密码写进手册、项目文件或 Git 仓库。

### 2.4 常用运行配置

程序读取环境变量，**不会自动加载 `.env` 文件**。`.env.example` 是变量清单，复制为 `.env` 并不等于配置生效。

| 配置 | 作用及使用注意 |
|---|---|
| `QIANG_HOST` | 默认 `127.0.0.1`，决定监听地址 |
| `QIANG_PORT` | 默认 `8000`，决定访问端口 |
| `QIANG_DATA_DIR` | 默认 `data`，保存数据库、原件及导出件；建议部署时使用绝对路径 |
| `QIANG_SECURE_COOKIE` | HTTPS 部署设为 `1`；本机普通 HTTP 不要启用 |
| `QIANG_BOOTSTRAP_PASSWORD` | 仅数据库尚无用户时用于首次初始化，后续重启不会重置已有密码 |
| `QIANG_PDF_FONT` | 可指定有合法嵌入许可的中文 TTF/TTC 字体 |

示例仅改变端口：

```sh
export QIANG_PORT=8001
.venv/bin/python scripts/start.py
```

此时访问 `http://127.0.0.1:8001/`。维护命令和工作台必须使用同一个 `QIANG_DATA_DIR`，否则会操作不同的数据目录。

## 3. 账号、角色与项目访问

### 3.1 角色分工

| 角色 | 日常操作 | 审定权限 |
|---|---|---|
| 企业管理员 `admin` | 管理本企业成员、共享范围和编制数据 | 不代替独立专业复核账号 |
| 项目负责人 `manager` | 组织项目编制、维护获授权的受限项目成员、维护企业报表样式 | 不代替独立专业复核账号 |
| 造价编制 `estimator` | 上传资料、编制和修订、应用已审变更、计算及导出 | 提交后由复核人审定 |
| 专业复核 `reviewer` | 查阅资料、展开明细、逐项或批量复核 | 通过、拒绝或要求补充资料；不直接编制业务数据 |

同一浏览器会共享登录会话。需要同时操作编制和复核时，使用不同浏览器配置文件或相互隔离的浏览器会话；不要误以为两个普通标签页就代表两个账号。

### 3.2 添加或调整成员

1. 管理员进入“系统配置与审计 → 企业成员与角色”。
2. 点击“添加成员”，填写账号、至少 12 位初始密码和角色。
3. 现有成员可通过“修改角色 / 启停”调整，填写变更原因。
4. 权限变化会撤销该成员旧会话，成员需重新登录。
5. 在“企业操作审计”核对操作人、对象、原因和时间。

也可由本机维护人员创建编制成员：

```sh
.venv/bin/python scripts/manage.py create-user zhang --tenant local --role estimator
```

管理员页面只处理当前企业成员，不能跨企业管理。界面不允许直接调整当前登录账号自身的角色或启停状态。

### 3.3 项目共享范围

入口：“系统配置与审计 → 项目成员与访问范围 → 维护项目成员”。

- **企业内共享项目**：本企业成员按各自角色访问。
- **受限成员项目**：仅指定成员及本企业管理员访问。加入名单不会自动取得编制或复核角色。
- 企业管理员负责切换共享范围；受限项目负责人可维护授权名单。
- 修改时填写原因，保存后对后续请求生效。
- 收紧范围不会追回已下载文件或此前复制到其他项目的资料；受限项目不继续向企业价格库提供共享来源。

## 4. 页面导航与状态

先在项目选择位置切换到正确项目，再进入左侧业务页面。

| 页面 | 用途 | 主要输出 |
|---|---|---|
| 项目概览 | 查看推进路径、专业覆盖、当前工程状态 | 当前缺口和下一步操作入口 |
| 项目与资料 | 上传、检索、下载原件；扫描识别和图纸登记 | 文件版本、原始证据、图纸目录 |
| 完整性诊断 | 确认专业资料是否充分，跟踪补件 | 覆盖核查、补件任务与关闭复核 |
| 图纸与算量 | 核对证据、构件建模、计算和底稿对账 | 构件、计算书、对账及差异诊断 |
| 清单编制 | 生成或导入清单、编码映射、拆并、调量和签证 | 有来源的清单及数量分配检查 |
| 组价审核 | 定额组成、价格、询价、替换及调价 | 可审核的组价依据和资源明细 |
| 取费汇总 | 日期裁决、工程层级、费用规则和计价 | 报价快照、分级汇总和版本差异 |
| 成果交付 | 选择版本、PDF 审阅、导出及历史文件下载 | Excel、PDF、JSON、ZIP 证据包 |
| 系统配置与审计 | 成员、访问、任务、网关、软件台账及审计 | 配置和可追溯操作记录 |

常见状态解释：

| 状态 | 含义 | 下一步 |
|---|---|---|
| 待复核 | 已保存，尚未完成独立审定 | 复核人查看当前对象和原件 |
| 已审定 | 当前记录通过对应复核 | 继续下游，仍检查来源是否有效 |
| 已失效 | 来源、参数或依赖发生变化 | 重新读取来源、修订、计算及复核 |
| 已拒绝 | 复核人不认可当前记录 | 查看理由，修订有效记录或补资料 |
| 待补件 | 缺少充分依据 | 上传补充原件并重新提交 |
| 存在冲突 | 同字段或图纸身份有不同候选 | 查原文，明确采用及排除理由 |
| 历史来源 | 已被新版本替代的文件或记录 | 只作追溯，不继续支撑当前审批 |
| 等待解析／解析中／已提取／解析失败 | 文件或模型任务执行状态 | 等待完成或检查失败原因并重试 |

项目整体显示“试点范围已审定”，只说明所列范围通过当前门禁，不等于全厂全专业完成，也不具有自动签章效力。

## 5. 第一次完成一个项目

建议先选一个资料充分的真实单体和明确专业范围，完成以下闭环：

1. **管理员准备账号**：至少一名编制人员、一名独立复核人员，确认双方都有项目访问权限。
2. **编制人员新建工程**：填写名称、地区、计价目的和本次专业范围。
3. **上传有效原件**：设计图、技术说明、合同及适用规则、授权定额和价格依据，按专业分类。
4. **整理证据与图纸**：核对原文、页码、图号、版次，处理事实及尺寸冲突。
5. **完成专业覆盖**：提交资料完整性判断，复核人员审定；缺项登记补件任务。
6. **建立构件**：选择合适模型，录入原始单位和尺寸，每项关联证据，填写计量依据。
7. **复核并计算**：先审构件，再由编制人员点击“计算工程量”，再审计算书。
8. **独立底稿对账**：导入同构件底稿，处理差异和遗漏，重新对账并独立复核。
9. **生成清单**：补齐有据编码、项目特征、工程归属，核对数量分配。
10. **配置组价**：录入授权定额、消耗、资源价格、来源、有效期及必要换算，重新复核清单。
11. **配置日期、层级和费用**：核对适用日期，审定规则和工程划分，再生成计价快照。
12. **审阅并交付**：复核报价成果，选择正确版本生成实际 PDF，检查后导出并留档。

遇到阻断项，查看“成果交付 → 交付前检查”，返回对应上游处理。若暂时只有数量没有合法价格，选择“当前无价草稿”，交付工程量、待询价任务及缺项说明。

<a id="project"></a>
## 6. 新建项目、范围与计价日期

### 6.1 新建项目

使用编制角色点击新建工程，填写工程名称、项目地区和计价目的。目的可选择招标控制价草稿、投标报价草稿或工程结算计价草稿。

本次专业范围从建筑、结构、工艺设备、给排水、电气、合同计价中据实选择。范围外专业仍会显示缺项，不会因未勾选而被认定为完成。系统不会自动填入工程规模、图纸、工程量或中标价。

### 6.2 修改适用日期与范围

入口：“取费汇总 → 适用日期与范围”。修改计价日、专业范围或黄金底稿门禁时填写依据。日期用于检查价格及规则包的适用期，修改会影响当前报价有效性。

新建项目默认要求黄金底稿对账。旧项目可在此启用。不要为了让审核通过而随意缩小真实交付范围或关闭底稿要求。

### 6.3 多时间节点裁决

入口：“取费汇总 → 项目时间与计价日期裁决”（系统配置中也可查看对应功能）。

1. 上传含时间及适用约定的原件。
2. 登记实际存在的招标、合同签订、设计版次、施工或结算节点，至少一个；设计节点填写版次。
3. 选择有依据的节点日期，或填写合同另行约定的计价日。
4. 说明日期含义、合同约定、选择理由和冲突裁决依据，关联原文。
5. 独立复核人核查并审定，审定后应用日期。
6. 重新核对规则和资源价格有效期，再生成新报价。

系统不自动选择最早或最晚日期，也不判断合同法律效果。日期审定不会自动替换定额、规则包或价格。

## 7. 上传资料与文件版本

### 7.1 上传步骤

1. 进入“项目与资料”，确认当前工程。
2. 选择实际专业分类。
3. 点击“选择文件”或将文件拖入上传区，支持多文件。
4. 等待解析任务完成，检查文件名称、专业、版本和状态。
5. 打开原件或进入算量页，核对提取内容。

| 文件 | 当前处理能力 |
|---|---|
| PDF | 原件保留、文本提取、页码定位；扫描页可按条件进行本机 OCR |
| DOCX | 文本及证据提取，无可靠固定物理页码 |
| XLSX | 工作表内容及来源位置提取，无可靠固定物理页码 |
| TXT | 文字提取与候选事实 |
| ASCII DXF | 受控标注及支持的模型空间直线／开放三维折线读取，采用前须校核 |
| DWG、IFC | 登记并保留原件；不等于已完成全图解析或 BIM 专业算量 |

一般资料单文件最大 **30 MB**。已有清单导入和模型发送另有上限，见对应章节。

### 7.2 去重及修订

相同内容按哈希去重；同名内容变化保留新版本及旧版本。版本更新后，旧来源仍可追溯，但不能继续支持当前审批。不要通过修改数据库或覆盖原件文件绕过版本流程。

修订图纸后，按顺序检查图纸登记、事实、尺寸、构件、工程量、底稿对账、清单、组价及报价。即使新数值与旧值相同，也应以新的有效来源完成所需复核。

### 7.3 解析失败

进入“系统配置与审计 → 文档与模型任务”查看任务类型、执行次数、状态和消息。修复文件或配置问题后使用“重试”；扫描 OCR 任务也可在扫描识别区域重试。服务中断任务恢复为可重试状态，不应把空结果当作无工程量。

<a id="evidence"></a>
## 8. 证据定位、扫描识别与人工抄录

### 8.1 核对原件证据

在“图纸与算量”选择原始文件及页码，查看原图和证据列表。点击其他页面的来源链接，可回到对应文件、页及证据。PDF 的区域定位用于核对原文；DOCX、XLSX 没有可靠固定页码时显示“无固定页码”，不要自行补造页号。

人工记录时填写文件、真实页码、图号、原文摘录及必要定位信息。尺寸必须来自明确设计标注，不能以屏幕测量代替。后续字段分别选择其对应的原始证据，不能只给整个构件挂一个无关附件。

### 8.2 本机扫描文字识别

入口：“项目与资料 → 扫描页文字识别”。

1. 选择当前 PDF 和真实页码。
2. 检查本机识别能力提示，点击“识别本页文字”。
3. 等待任务完成，展开“核对识别文字”。
4. 点击原行定位，逐行比对原图；识别置信度不能当作工程准确率。
5. 需要修正时追加人工核对抄录，再按候选与独立复核流程采用。

本地适配器依赖 **macOS Vision 和 Swift 工具链**，在本机执行，不向第三方发送资料。Linux／Docker 暂不支持此 OCR 适配器，可使用人工标注或经确认的模型网关。没有文字结果只表示未识别到文字，不能据此判断图纸无内容。

### 8.3 人工抄录与事实采用

对有误的 OCR 原行，保留机器原文，新增人工抄录及核对依据。系统保留原行、框位置、抄录人和来源；不同抄录不会悄悄覆盖机器记录。若形成事实候选，先预览字段、单位及冲突，再明确选择采用，仍需专业复核。

## 9. 事实候选、图纸目录与跨图互参

### 9.1 事实与尺寸候选

提取结果只是候选。同字段不同值会保留并形成冲突，应核对原文、单位、专业及版本。不能按多数候选、模型回答或文件名自动认定最终值。

“图纸与算量 → 图纸尺寸候选与跨图冲突”展示构件、参数、标准值、原始标注和来源。复核人先核查候选；编制人可通过“采用已审尺寸”预填能够明确匹配的字段，再补齐未识别参数、扣减及计量依据。预填后构件本身还要独立复核。

### 9.2 图纸目录登记

入口：“项目与资料 → 图纸目录与平立剖互参”。

1. 点击读取标题栏候选，或手工“登记图纸”。
2. 核对原件位置、图号、图名、图纸版次及视图信息。
3. 同页歧义值全部核查；人工补充或修正填写依据。
4. 保存待复核登记，独立复核人审定。
5. 同图号冲突、未审或失效登记按页面待办处理。

文件上传版本与图纸设计版次是两件事，不能从文件名后缀推断版次。

### 9.3 建立平、立、剖互参

两端图纸先审定，再点击“建立图纸互参”，选择起止图纸、互参类型及实际标记，引用起点图中剖切、立面、详图或跨专业索引原文，必要时关联构件。互参只建立索引，不自动产生尺寸或工程量。

登记和修订会影响下游有效性；旧记录保留。无需采用的当前登记或互参，由复核人按真实理由拒绝，不应删除历史来消除待办。

## 10. 资料完整性与补件任务

### 10.1 完整性核查

“完整性诊断”按专业列出已上传文件、所需资料、本次范围和缺口。**有文件不等于内容充分。**

编制人员提交核查依据，列明已核对图纸、版次、实际覆盖范围和局限，并选择原始证据。独立复核人确认后，该专业才可按有效核查参与下游门禁。

### 10.2 补件闭环

1. 在“补件任务跟踪”点击“登记补件任务”。
2. 填写名称、所属专业、缺项说明、负责人、期限及是否阻断本次范围。
3. 处理人更新任务进度；先上传补充原件，再“提交补充依据”。
4. 复核人打开“关闭复核 / 记录”，核对新原件及任务要求，决定是否关闭。
5. 资料专业覆盖和成果审核仍需各自完成，补件关闭不自动替代这些审定。

历次提交、处理和取消原因保留，不能用“已上传”代替实际专业充分性判断。

## 11. 算量通用流程及九类基础几何

### 11.1 所有构件通用操作

1. 进入“图纸与算量”，选择与实际形状及用途一致的构件工具。
2. 填写名称、原始尺寸、单位、材料和计量依据；每个关键字段分别选择来源。
3. 有重复数量、区域选择或扣减时，核对适用范围及是否重复计入。
4. 有预览入口时先预览，核查毛量、扣减、净量、单位换算、公式和修约差。
5. 保存为待复核构件，独立复核人展开明细并检查原件后审定。
6. 编制人点击“计算工程量”，生成计算书；复核人再次审定计算书。
7. 计算书通过后才进入清单。构件通过与工程量通过不能互相替代。

仅预览通常不会保存业务记录；退出未保存编辑不代表已送审。界面要求的范围确认，须在核对原件后勾选；修改参数会撤销相关确认。

### 11.2 基础几何选择

| 类型 | 录入重点 | 计算口径及限制 |
|---|---|---|
| 矩形底板／垫层 | 长、宽、厚 | 长×宽×厚，扣减另有依据 |
| 等厚矩形池壁 | 外长、外宽、壁厚、壁高 | 外矩形减内矩形后乘高；不是把四段外长直接相加 |
| 确认直线管段／栏杆 | 已确认设计长度 | 单一直线长度；复杂路径使用坐标线工具 |
| 矩形防水／楼地面／模板接触面 | 展开长、宽 | 面积计量，接触或展开范围须人工确认 |
| 净墙体／隔墙／梁 | 净长、高、厚 | 净矩形实体体积 |
| 已核定断面梯形沟槽 | 槽底宽、槽顶宽、深、长 | 上下底宽均已核定的恒定梯形断面，不自动推断放坡 |
| 已审开挖扣实体积回填 | 开挖量、占用量 | 开挖减占位；建议可关联时使用专门回填工具 |
| 圆形井壁／环形构筑物 | 外径、内径、高 | 环形净实体体积，外径须大于内径 |
| 钢筋表逐规格汇总 | 单根下料长、根数、每米质量 | 按已有钢筋表汇总质量，须有结构证据，不从混凝土体积推配筋 |

以页面字段标注为准区分原始单位与标准单位；不要把毫米直接当米。支持原始单位的编辑器会保留换算过程。扣减量应与输出同单位，不能用面积直接扣体积。

### 11.3 一个数量自查示例

以下仅为数学核对：矩形底板长 10m、宽 5m、厚 0.2m，无扣减，则体积为 10m³。若原图以毫米给出，应在支持原始单位的输入中录入 10000、5000、200mm，核对换算后仍为 10m³。示例不含定额、税率或实际工程含义。

## 12. 分项、区域、多边形与逐面计量

### 12.1 分项合计与逐项扣减

点击“建立分项构件”，逐项选择加项或扣减，填写形状、尺寸、重复数量及原始依据。同一记录内各项结果必须同单位。预览核对每项贡献和净量；系统不会替您判断空间相交、规范扣减阈值或是否应重复计算。

### 12.2 平面区域并集与扣减

适合共同设计坐标下的轴向矩形，可计算净面积或统一厚度的体积。

1. 确认共同原点和 X/Y 正向，按设计坐标录入各加项矩形。
2. 录入扣减矩形，扣减必须完全位于加项并集内。
3. 预览条带分解、重复覆盖和净区域；重叠加项及重叠扣减按并集处理。
4. 体积模式另核定统一厚度、材料和依据。

允许负坐标。旋转矩形、曲线或不同厚度不能套用本模型。不能把两两相交面积相加当作完整并集扣重。

### 12.3 空间长方体并集与扣减

使用共同 X/Y/Z 基准录入轴向长方体加项及扣减，预览空间净实体体积。不要将任意旋转、斜面或曲面实体转换成外包长方体后声称精确净量。后续逐面计量从已审净实体读取边界，不从手填总表面积直接生成。

### 12.4 水平设计多边形

按设计顺序录入外轮廓顶点，可处理受支持的凹形及独立孔轮廓；先说明坐标基准，逐点绑定依据，再选择面积或等厚体积。预览核对轮廓、孔、叉积过程及净量。非法自交、越界或不满足当前孔关系约束的输入会阻断，应修正模型，不能靠放大容差跳过。

### 12.5 模板与防水逐面计量

前提：先审定空间长方体或等厚多边形构件。

1. 点击建立逐面计量，选择模板接触面积或防水展开面积。
2. 读取当前已审来源边界。多边形包括上下净面、外侧及贯通孔内侧。
3. 对每个候选面明确计入或排除，填写实际做法、计量理由和原件；未核定面不能当作完成。
4. 局部侧面按原边 S/Z 分区；上下净面可使用共同设计 XY 窗口或两点斜线分区。
5. 两点斜线按无限延伸的裁剪线处理，不能当有限折线。可按支持模式对分离净块独立核定；点接触不等于内部连通。
6. 预览每面、每分区及总量后送审。读取新来源会清空旧分面决定，需重新核定。

实体外表面或内腔面只提供几何候选，不自动判断现场是否支模、是否防水或是否满足搭接要求。局部底面 Z=0 也不自动等于实际工程绝对高程。

## 13. 设计管线与 DXF 坐标采用

### 13.1 手工设计坐标线

在“设计坐标管线长度”建立管线，按实际设计顺序录入 XYZ 点、共同基准、重复数量和用途依据。预览逐段三维长度及水平投影长度，审定后供沟槽、垫层、外包和井筒等关联读取。

三维中心线长度不等于沟槽水平长度；高程不等于井深；坐标线本身不自动证明它就是实际安装中心线。

### 13.2 从 ASCII DXF 读取

入口：“DXF设计坐标读取与单位校核”。

1. 上传当前 ASCII DXF，在读取工具中选择原件及图层、批次。
2. 点击“读取CAD对象”，查看模型空间直线和开放三维折线。
3. 利用投影、对象高亮及原始 XYZ 表定位，核对句柄、图层和点编号。
4. 选择一个完整对象，或选择已有原始顶点之间的连续取段范围。
5. 填写有依据的独立已知两点距离、容差和来源，执行单位校核。
6. 明确坐标正向、高程、中心线用途和原图核对，预览后“采用为待复核设计管线”。

校核不会自动缩放 CAD 使其符合输入距离。BLOCKS 不展开，不从 PDF 测像素，不补高程或识别整张管网。不可读对象仍需下载原件核对。

### 13.3 多对象组装与取段

可将同一原件内的完整对象或指定顶点范围加入组装序列，最多 20 项，明确顺序及采用方向。相邻连接点必须 XYZ 精确相同；相邻范围可共享端点，不可重复同一原始管段。不自动吸附、补段、插值或推断支路。

更改范围或方向后重新读取并校核。形成组装候选不等于已经保存构件；仍需整体独立长度校核、用途确认和独立复核。

### 13.4 回查与修订

已采用来源可“读取原CAD范围回查”，检查原对象投影、完整顶点及实际采用范围。回查是只读核对。需要修订时，恢复原采用序列，逐项调整并重新填写校核、依据、确认和修订原因。

保存新版本后核对前后长度、增加／移除／反向管段及保留管段。旧版本保留，下游引用需按当前版本重新读取及复核。

## 14. 沟槽、垫层、井筒、井板与回填

这些工具应在已有对应已审来源后使用；按钮没有可选来源时，先完成来源构件审定。

| 工具 | 操作要点 | 容易混淆的口径 |
|---|---|---|
| 管网变断面沟槽 | 读取已审管线，逐站核定实际断面、宽深及依据，预览逐段体积 | 用水平投影段长；不能从管径自动推槽宽或由管线高程猜挖深 |
| 管网分段矩形垫层 | 读取水平段长，逐段填本层宽和竖向厚度，核定同一材料层 | 段内宽厚恒定；不同材料层分别建立；不把坡管三维长当水平长 |
| 管道外包占位体积 | 引用已审管线并核定实际外径等参数，检查逐段及总量 | 含管内空腔的外包占位，不是管壁材料体积 |
| 圆形检查井井筒 | 选关联站点，逐井填写内外径、高、实际井数及原件，选择材料或外包用途 | 井数独立核定，不继承管线重复数；站点只作定位，不能代替井深 |
| 圆形井底板与盖板 | 读取已审井号及数量，核定板径、厚、板底高程及孔 | 每井本层一块；不同层另建；数量来自已审井筒 |
| 已审体积关联回填 | 选择有效开挖和占位来源，逐项确认本次范围内实际占位及不重复 | 不能拿井筒材料体积代替整井外包；不得重复扣管道、垫层或板体积 |

井筒当前适用于竖直等径圆筒井段，井底、盖板、收口和洞口需要另核。井板新建支持水平等厚圆板及 0～20 个完全在板内、互不重叠的圆形贯通孔；逐孔填写相对板中心的 XY 和直径，孔相切允许，越界、重叠或相互包含阻断。无孔时保持空孔表并提供范围说明。

回填还可关联受支持的已审多边形净体积等来源，必须核对用途、范围和实体位置。体积平衡只说明列入的量可对账，不自动证明实体在现场空间中确实不重叠或完全位于开挖内。

### 14.1 变断面沟槽的计算方式

点击“建立变断面沟槽”，选择并读取已审设计管线，逐站填写原始单位、槽底宽、槽顶宽和挖深，分别绑定原件；填写总体范围、方法及修约依据。

必须明确选择以下一种方法，不由系统自动判断：

- **平均端面积法**：水平段长×（起断面面积＋终断面面积）÷2，属于选定的近似方法。
- **宽深线性变化棱台法**：假定段内底宽、顶宽及深分别线性变化，按水平段长×（起面积＋4×中面积＋终面积）÷6 计算。

预览核对各站面积、中断面参数、水平长／三维长及逐段体积。方法必须符合本次原始计量依据，不适用于任意地形。来源变化后重新读取并核定断面，不沿用旧预览。

### 14.2 分段垫层与管道外包

分段垫层点击“建立分段垫层”，读取已审管线分段，逐段填写本层矩形宽度、竖向厚度及依据，再填写材料做法和总量修约依据。核对重复数量只继承一次。竖管、包角、变截面及不同材料层不合并为一个恒定矩形模型。

管道外包点击“建立管道外包体积”，读取已审管线和当前分段，按原图核定外径、计量用途及依据，预览逐段和汇总。它计算用于占位的管道外包体积，不能直接代替管壁材料、接头、支墩或未列附属物工程量。

两者均经过“预览 → 保存并送审 → 构件独立复核 → 计算工程量 → 计算书复核”，再用于清单或回填。

### 14.3 井筒及井板的继承关系

“建立圆形井筒”后读取关联管线站点，逐项选择实际井号、定位、内外径、井段高度、独立井数和原件，再选择材料体积或外包占位用途。管线重复数仅供核对，不参与井数计算。

“建立井底盖板”后读取已审井号，逐板核定底板或盖板用途、直径、厚度、底标高和开孔，数量继承所选井号的已审井数。孔 XY 相对于本板中心，孔直径和位置均须独立依据。每井不同层板分别建构件，不从管线站点 Z 自动推板底标高。

先看预览是否分别列出毛体积、各孔扣减及净量，再保存送审。材料量与外包量即使来自同一井号，也须在清单和回填中明确区分用途。

### 14.4 关联回填的完整操作

1. 点击“建立关联回填”，选择已审开挖体积来源。
2. 按实际范围逐项增加占位扣减，选择有效已审体积构件。
3. 为每项填写核定扣除比例、比例及范围原件，以及不重复说明；比例表示本次扣减采用该来源已审量的份额。
4. 点击“读取已审来源体积”，核对开挖、各占位的版本及数量。
5. 填写总体范围、计量说明、修约位数及原件，确认同范围且不重复。
6. 预览“开挖－各来源量×核定比例”的体积平衡，检查扣减合计不超过开挖。
7. 保存并独立复核，再计算工程量。来源变化时重新读取，重填被清除的扣减比例和确认。

此处采用来源已有重复数量和修约后的已审量，不再乘组数或重复扣孔；不自动推算压实、松方系数，也不把扣减超量自动归零。

## 15. 栏杆、立柱、材料及备料下料

### 15.1 设计边线栏杆计长

1. 先审定水平多边形或 XYZ 设计坐标线。
2. 在“设计边线栏杆计长”读取来源，选择适用的三维或水平投影口径。
3. 按原边逐段确定整段、局部区间或排除，填写安装范围及依据。
4. S 从来源原段起点沿核定口径递增；核对孔边和多边形末边的闭合关系。
5. 预览计入长度，保存并独立复核。

竖直段不能用于水平计长口径；XY 投影缩成一点不代表三维长度为零。原边只是候选位置，不自动确认为安装中心线，也不会自动生成高度、立柱、多道扶手或质量。

### 15.2 栏杆材料表

从已审栏杆范围建立材料表，逐项选择线材、独立定长件、立柱或板网片。每项核定材料、实际下料尺寸、单位质量或面密度、数量、用途及证据。

- 连续线材：核定每道是否覆盖全部计入范围；坡段使用三维来源。
- 独立定长件：根数及每根下料长据图填写，不自动推断接头或构造长度。
- 矩形板网片：填写独立展开长宽、片数和开口，重叠矩形开口只扣一次。
- 异形板网片：按展开直边轮廓及受支持的独立孔计净面积，孔关系须满足当前限制。
- 面密度须与净面积口径一致，网片自带微孔不能既在面密度中体现又重复扣面积。

水平投影栏杆来源不能直接用来算坡段连续线材；应改用已审三维栏杆来源。板网片数量不从栏杆长度或间距自动推算。

### 15.3 立柱布置与显式移柱

按页面支持模式选择最大间距均分或固定间距留余跨，逐区间核定间距、起算方向、两端归属和每根下料长。可明确增加构造柱，设置禁布范围，并逐根填写实际移柱位置及依据。

系统保留原布置、加柱、移前移后及最终柱数，不自动避障。加柱不会重排原规则柱；端点归属需避免相邻区间重复计数。完成后核查区间内及连续来源路径的实际柱距，实际柱距检查不代替结构设计或专业构造核定。

### 15.4 比例备料附表

符合条件的线材可按有据搭接、损耗等参数形成备料附表。净工程量与备料量分开，备料附表不会自动修改 kg 清单、资源消耗或报价。

### 15.5 定尺与混合下料

按实际需要选择单一定尺、不同长度构件混排或多定尺联合选材，并核定原材规格、可供根数、两端切除、每件锯缝和可留用余料下限等字段。

操作顺序：确认实际下料长度及需求 → 选择同组规格和原材 → 核定加工及供应参数 → 预览方案、容量和长度／质量平衡 → 独立复核。

核对以下含义：

- 每件锯缝按当前工具口径逐件计入，包括一根原材中的最后一件；两端切除另计，不能重复。
- 供应上限是本次选材约束，不表示已锁定实物库存。需要占用已登记批次时另走15.6库存预留，不能将供应上限直接当作登记根数。
- 待留用余料是计划台账，不表示已经入库或自动参与下一批下料。实际加工和余料验收入库须按15.8另行核对，不能直接采用计划余料数量。
- 当前受控算法的目标、分组和输入边界以预览说明为准，不承诺任意多规格场景全局采购成本最优。
- 同项比例备料与定尺下料按页面互斥规则选择，切换后重新核对参数及依据。

<a id="stock-inventory"></a>
### 15.6 项目原材库存与预留

入口：“图纸与算量 → 原材库存与预留”。编制人员、负责人、管理员可登记、预留、释放及停用；独立复核人员查看全部内容并复核登记和预留。即使原编制人员之后改任复核角色，也不能审定自己提交的记录。所有操作仅在当前有权访问的项目内生效，不共享其他项目库存。

**准备资料与计量口径**

先取得本项目实物批号、仓库／存放位置、材质和截面规格、完整原材定尺、每米质量、实物根数及核查说明的原始凭据。每项分别选择当前原件，不能用排料采购计划替代实物根数。相同仓库、相同实物批号只能有一份未停用登记；不同项目的实物归属须人工核定，系统不自动识别同一外部仓库实物是否重复登记到其他项目。

| 字段 | 单位及填写要求 |
|---|---|
| 实物批号、仓库／存放位置 | 按凭据逐字填写；同仓库同批号防重复，首尾空格不形成新批号 |
| 材质及截面规格 | 明确材质、截面及必要质量标准，不能只填近似品名 |
| 每根原材定尺 | 正数，支持m、mm、cm、dm、km；后台统一m，不是总长或净件长 |
| 单位长度质量 | 正数，支持kg/m、g/m、kg/mm、g/mm；后台统一kg/m，不接受单根质量或体积密度 |
| 实物登记根数 | 1至1000000正整数；不按长度比例折算根数 |
| 实物登记范围及核查说明 | 说明本项目实物归属及盘点／交接范围，逐项关联原件 |

**登记及独立复核**

1. 编制人员点击“登记实物原材”，完整填写上述字段和每项原件。提交后状态“待复核”，可查看登记、占用、可用根数及“逐项登记与原件”，此时可用根数为0。
2. 独立复核账号点击“独立复核登记”，检查实物批号是否重复、原件当前版本及真实字节、定尺及单位换算、每米质量、根数和归属说明，再填写复核依据。复核不会代替真实仓库的实物验收。
3. 当前有效已审登记才可新增预留。原件缺失、被替换、篡改、复核被撤回或待补件时，可用根数变为0；已有占用保留。
4. 登记需修正时，先核查并释放全部相关预留，由编制人员点击“停用登记”，填原因及当前原件。停用不删除历史，也不能恢复原登记；之后才可按同实物批号重新登记正确内容并送独立复核。仍有占用时禁止停用。

**按已审排料预留**

1. 前置材料表、上游来源和全部原件须当前有效且已审定，并已有单项定尺或混排计算。连续材料、板网片、比例备料、未排料项不生成完整原材需求。
2. 点击“按已审排料预留”，选择材料表，读取每种实际选用定尺、每米质量及所需根数。支持单项定尺、单定尺混排、多定尺联合选材及有限供应方案；未选用的零根候选不形成需求。数量已经包含来源全部重复次数，不再倍乘。
3. 为每项需求选择已审可用批次及分配根数，可“增加批次分配”把同一需求拆给多个批次。同需求同批次不得重复列；全表各需求合计必须恰好完整满足，不能少留、超留或遗漏。每一批次的定尺、每米质量必须与相应需求精确相等；不能用不同长度原材按总长代换，也不重新优化排料。
4. 填“材质截面兼容性与预留范围说明”及原件，确认对应实物批次与需求材质、截面、定尺和每米质量一致且未重复占用。相同每米质量不能证明相同截面，软件数值检查不能替代这一步。
5. 核对全部需求和分配后点击“提交并占用根数”。所有批次在同一事务内核对并占用，任何一项不满足整单不保存；库存或复核已变化会要求刷新，不会按旧可用数超占。同一材料表仅允许一份未释放预留，即使材料表已修订也不能再占一份。已执行任一批领料后该材料表不能再次预留，完整退回也不自动重开需求；仅已释放未领余量可按15.17另建补料预留；修订和其他追加范围未提供。
6. 提交后预留“待复核”但根数已经占用，其他方案看见的可用数相应减少。独立复核账号核查来源版本、需求、批次分配、兼容说明及原件，再点击“独立复核预留”。只有复核当前有效的记录显示“已审定”。

普通原材预留与15.9普通余料回用申请互斥；已有未释放余料申请或已领用余料时，不能在本入口再次全量预留完整原材。原材与余料共同供应须在符合前置范围时走15.19独立联合核定入口，不能拼接两份普通申请绕过完整需求。

**失效、释放及台账**

“登记／在库／预留／可用”单位均为根。在库=原登记＋累计盘盈－累计盘亏−累计领料+累计完整退回；预留占用为尚未释放的原分配根数减累计已领根数，分批领出后只保留未领余量；有效已审登记的可用=在库−预留，待审、无效或停用登记的可用为0。另显示在外未加工、已投入加工及累计退回，完整根库存账须满足原登记＋累计盘盈－累计盘亏=在库+在外未加工+已投入加工。尚未执行领料时仍沿用原预留规则。预留待补件、被拒、材料表修订或原件失效，都会显示原因并继续占用，不静默释放，也不代表已领料。编制人员核查实物及计划后点击“释放整单预留”，填写原因与当前原件；即使原材料表失效，也能有据释放，不能把释放当作实物退库。释放后保留整单、分配及复核历史；已释放记录不能再审定，需要时重新预留。

已领料预留不能再整单释放或重审；原材分批领料及有据释放未领余量见15.15。完整原材实物退回使用15.7退回单；不能用释放把已出库原材虚增为库存。登记仍有预留、在外或加工后未能完整退回的根数时不能停用。完整原材在库盘点见15.14，原登记不被盘点覆盖，累计盘盈／盘亏另列；历史盘点依据失效同样使本批及来源余料待核查，禁止新增采用。

“库存事件记录”显示释放、停用、领用执行或未执行单据取消的人员、时间、原因及原件／已审单据关联。“下载库存台账 JSON”保存当时全部登记、规范单位、分配、在库／预留／可用／在外／加工／退回数、领用单据与状态、失效提示、执行／释放／停用／取消事件、复核与内容哈希，并在“成果交付 → 历史导出件”以“库存台账／独立业务记录”留档。导出不是整体工程报价审定；原件失效时台账保留问题，不能据此新增预留。历史文件可原样下载及校验，新操作不改写旧文件。

**合成示例及边界**

仅软件合成示例：登记某批6000mm原材10根、3000g/m，规范为6m及3kg/m；已审材料表的全部重复后定尺排料需求3根，预留提交后登记10、占用3、可用7，独立复核后仍为这三个数。材料表修订使预留待核查，但仍占3根；整单有据释放后恢复可用10。登记停用后可用0，历史仍保存。此示例不代表真实采购或仓库验收。

合成页面示例：[已审批次及3根预留](qa/v0.118-stock-inventory-review.png)、[整单释放后余额](qa/v0.118-stock-inventory-release.png)。截图均来自临时隔离合成库，不包含真实仓库或工程资料。

本版支持本项目完整原材登记、预留、15.7有据领用记账、15.8实际加工验收与余料入库及15.14完整原材在库盘点；不自动领料、按计划入库、回用、跨项目共享、采购计价或对接外部仓库。库存操作与独立复核不改变几何、原排料方案、净kg工程量、清单数量、资源价格、报价或既有工程成果审批；库存台账须单独留档，未合并到原报价PDF／Excel。

<a id="stock-operations"></a>
### 15.7 完整原材领料、投入加工与退回

入口：“图纸与算量 → 原材库存与预留 → 领料、加工与退回”。编制人员、负责人和管理员建立单据并在独立复核后执行；复核账号审核其他人员提交的单据。执行者仍须核对真实凭据，软件按钮不代替仓库实物交接。

**前置资料及边界**

新领料须有当前有效已审材料表、原材登记及未释放／未领料预留，其逐项原件必须可读取且哈希一致。本版整单领出预留的全部完整原材，不支持只领部分预留或按净件长度代换根数。后续“投入加工”和“完整原材退回”按已执行领料记录的逐项余额，可分批填写完整根数；加工后余料不是原长完整根，不能用此入口退回。

每份单据填写实际业务日期（YYYY-MM-DD，不晚于当日）、领用／交接对象、实际交接或加工说明、当前原件，并确认这是实际完整原材范围。领用对象是凭据中的班组、人员或交接方文字，不会发送通知或自动创建账号。禁止仅凭计划、预留或审批就声称实物已交接。

**整单领料**

1. 点击“建立整单领料单”，选择当前已审未领料预留，逐项核对继承的材料表版本、需求、批次及全部根数。不能在领料单修改定尺、材质、原件中的根数或分配，需改变时先按15.6核查预留。
2. 填写上述实际日期、交接对象、说明及原件，点击“提交领用单据待复核”。此时仅存单据，原材仍按预留占用，在库数不变。
3. 独立复核账号点击“独立复核领用单”，核查实际凭据、批次、定尺、每米质量、完整根数、规范总长／总质量及来源有效性，再签署意见。审定后显示“已审待执行”，仍不记账。
4. 编制人员点击“执行库存记账”，核对弹窗中的已审单据及影响，点击“确认执行库存记账”。后台在同一事务内再核对单据、审核、原件、预留及当前来源；过期或争用时整单不执行。
5. 执行后预留标“已全部领料”，预留根数转为领出，在库减少，在外未加工增加；可用数不会因预留解除而虚增。已领料预留不可整单释放或重审；分批领出后的未领余量见15.15，已释放未领额补料见15.17，同材料表不能重新全量预留，即使后续全部完整退回也不自动重开该材料表需求。

**分批投入加工及完整退回**

1. 在“已执行领料的未加工余额”选择对应领料记录，核对各需求和批次的原领、已加工、已退及未加工根数。
2. 按实际情况点击“记录投入加工”或“记录完整原材退回”。逐分配填本次完整根数，0表示本次不涉及，至少一项为正整数；本次根数不能超过该项未加工且未退回余额，不得挪用另一批次或另一分配余额。
3. 填实际日期、交接对象、说明、当前原件并确认后提交。提交和独立复核均不改变实物台账；已审后仍由编制人员执行，按相同程序重查最新余额。
4. 投入加工执行后减少在外未加工并增加已投入加工；在库不变。该数表示完整原材退出完整根台账，不等于净安装kg工程量，不证明所有原材都成为成品或损耗。
5. 完整退回执行后减少在外未加工、增加在库；登记仍有效时增加可用数。已经投入加工的根数不能再按完整原材退回，切剩余料不能直接记作原长完整根。累计退回是历史交接量，不能再次加到当前在库数。

**余额、失效及纠正**

| 台账项 | 实际计算口径 |
|---|---|
| 在库完整根 | 原登记根数＋累计盘盈－累计盘亏−累计领料+累计完整原材退回 |
| 在外未加工 | 累计领料−累计完整退回−累计投入加工 |
| 预留 | 未释放的各原预留分配根数减累计已领根数，分批后仍含未领余量 |
| 可用 | 有效已审登记的在库−预留；登记失效或停用则为0 |
| 根数闭合 | 原登记＋累计盘盈－累计盘亏=在库+在外未加工+已投入加工 |
| 本次长度／质量 | 按各分配规范定尺×本次根数，以及该长度×原登记每米质量精确累计；不是价格、净安装量或余料质量 |

两份已审单据争用同一余额时，执行先到者按当前余额记账，另一份必须刷新并重新核查，不能因为已审就超量。提交但未执行的单据不会额外锁定在外余额，因此复核通过不保证未来一定能执行。

未执行单据可点击“取消未执行单据”，填当前原因及原件后留痕取消，不改变库存或预留，也不能再审定；需要时重新建立。已执行单据不可取消、重审或直接改数；实际未加工完整原材退回另建退回单，不虚构退回以纠正资料错误。完整原材分批领料见15.15；对已加工数量的盘点调整、账务冲销和同材料表二次领料暂未提供，须保留问题并另行核定，不能改数据库伪造闭合。

来源修订、旧原件缺失或历史凭据被替换，不会把已经领出或加工的原材自动还库存。新领料必须当前有效；已执行领料后的真实加工及未加工完整退回以已执行领料快照和新的有效交接凭据记录，不重新采信旧排料为当前工程量。历史原件问题仍显示，登记依据失效时即使已完成完整退回，可用数仍为0，需先核查登记。所有库存行为均不改变净工程量、原排料、清单、报价及工程成果审批。

仅软件合成案例：某批登记10根、6m及3kg/m；已审排料预留3根。领料单待审及已审未执行时在库10、预留3、可用7；执行领料3根（18m、54kg）后在库7、预留0、在外未加工3、可用7。执行投入加工1根后在外2、已加工1；执行未加工完整退回1根后在库8、在外1、已加工1、可用8，10=8+1+1。每个1根单据为6m／18kg，不等于相应立柱净安装质量。本例不代表真实工程或仓库验收。

升级旧项目时，原库存和预留保留，领用单据列表默认为空，不自动领料或记账。既有JSON留档不补写新字段，需当前余额时重新导出并核对时间。

<a id="stock-processing-results"></a>
### 15.8 实际加工结果与实物余料验收入库

入口：“图纸与算量 → 原材库存与预留 → 实际加工结果与余料入库”。编制人员、负责人及管理员登记并执行已审结果；独立复核人员审核其他人员提交的结果。首次使用前须完成15.7“完整原材投入加工”的实际执行；只有排料计划、预留或已审但未执行加工单时不能登记实际结果。

**实际口径与前置资料**

准备来源投入加工单、实际加工根数、成品实测总长、锯缝总长、切除总长、报废总长、每组余料的编号／每段实测长度／根数／库位及可留用验收凭据。分别关联原件，说明实际加工范围及与计划的偏差，即使一致也须说明实际核对情况。系统不从预计余料、原材消耗根数或固定损耗率推测实物余料。

- 逐来源分配填写本次实际加工原材根数，正整数，不能超过该加工单尚未核对的根数；同一已投入加工根数只可执行验收一次，可分批核对。
- 成品、锯缝、切除、报废均填本次所选原材的实际**总长**，可为0，不能把每根数值当作全批总长。成品总长不等于已安装工程量。
- 每段余料长度须正数且小于原材原长，根数须正整数。相同长度、库位和验收口径可按一组填根数；该编号是组别编号，不代表逐根原材序列号。无余料时不添加余料组，仍须把全部长度去向核对闭合。
- 每个加工分配选择m、mm、cm、dm或km，实测及该项全部余料共用此单位；切换单位不自动改写数值。后台统一m及kg，材质、截面及每米质量继承已执行加工快照，不能手改密度或用成品重量倒算。
- 每份1至20个不同加工分配，每项0至20组余料，全单最多100组且合计1000000段余料；根数均为1至1000000整数。超限按真实加工范围拆单。

**登记、预览和保存**

1. 点击“登记实际加工结果”，选择仍有未核对根数的已执行投入加工单。选择加工分配，核查来源名称、原材批次、原长、材质截面、每米质量及剩余核对额度。切换来源分配会清空该项旧实测及余料，须重新核定。
2. 填实际验收日期（YYYY-MM-DD，不晚于当天）、验收人、整批实际范围和与计划偏差说明及原件。验收人是凭据上的文字，不发送通知或自动建立账号。
3. 按本次原材根数填写四类去向总长、逐项原件、本项实际说明及原件；需要时“增加来源加工分配”，不得重复选择同一分配。
4. 有可留用实物时“增加实际余料组”，填实物余料编号、每段实测长度、根数、库位、材质质量及可留用验收说明，并为每项选择原件。编号须区分完整原材批号；同库位同余料编号不得重复，即使旧余料已停用也不能重用编号。
5. 确认本次真实加工及余料验收，点击“预览实际长度及余料”。后台按原始单位精确换算，以有理数核对每项：**原材原长×本次根数＝成品＋锯缝＋切除＋报废＋实物余料总长**。不能用容差归零、自动补差或手填总面积／金额代替。
6. 核对规范长度、质量、每组实物及来源原件。质量逐项按继承的每米质量计算，既不增加净kg清单，也不作为报价成本；不同分配按各自每米质量分别累计。
7. 预览通过后点击“保存验收单待复核”。任意实测、根数、单位、原件或说明变更均清除旧预览，须重新预览；保存时还会核对库存版本、来源及预览哈希。预览不写项目，保存不入库，也不抢占尚未核对额度。

**独立复核与执行**

独立复核账号点击“独立复核加工结果”，核查实际加工快照、每项投入根数、四类实测及余料原件、单位、偏差说明、材质及可留用验收、逐项长度及质量闭合，再填写意见。编制人之后改任复核角色也不能自审。复核通过显示“已审待执行”，仍不入库。

编制人员点击“执行余料验收入库”，核对执行窗口，确认执行后才占用本次来源加工根数的核对额度，并登记独立余料批次。两份已审结果争用同一加工额度或同编号时，执行先到者成功，另一份刷新后须重新核查，不能因已审而重复入库。

执行后在“余料实物库存”核对编号、库位、材质截面、来源原材批次、每段实测长、在库根数、总长和质量。该台账独立于完整原材：原来的“已投入加工根数”保持，不把回收余料当原长完整根加回完整原材在库数。相同余料编号也不能另在15.6再次登记为完整原材。

**失效、取消和停用**

未执行验收可填写原因和当前原件后“取消未执行验收”，不改加工额度及库存；已取消记录不能再审定。已执行结果不可取消、改数或重审，当前暂不支持其账务冲销。

已执行结果的原件后续缺失、替换或损坏时，已核对加工根数和余料验收数量保持，余料显示“依据待核查”，不能通过丢失原件或撤回状态重新取得加工额度。原上游图纸或排料修订不改写已执行加工快照；实际结果仍须凭新的有效实测及验收原件，不代表旧图重新获审。

需停止采用某组余料登记时，点击“停用余料登记”，填写核查原因及当前原件。该组仍有回用预留、在外未加工、在加工待验收或已验收加工原段数量时不能停用，须先核查15.9台账。停用后该组当前可用根数为0，当前在库及原验收数量保留，实物去向须另行核查；这不是实物报废、处置、消耗或冲销。停用不退回加工核对额度，不允许重用原编号重新入库。错误执行应保留问题并另行核定，不能改数据库或虚构实物来补平。

**合成示例及能力边界**

仅软件合成示例：已实际投入加工1根6000mm原材，3kg/m。实测成品2400mm、锯缝6mm、切除20mm、报废0mm、可留用余料3574mm×1根，6000＝2400＋6＋20＋0＋3574。规范原材6m／18kg，余料3.574m／10.722kg；核对依据及独立复核后执行，才出现1根实物余料。若余料误填3573mm，差1mm也阻断，不自动补到报废；恢复3574mm后须重新预览。此例不代表真实工程或仓库验收。

合成页面示例：[实测长度闭合预览](qa/v0.120-processing-preview.png)、[逐项原件独立复核](qa/v0.120-processing-review.png)、[实际余料入库](qa/v0.120-offcut-stock.png)、[停用后保留原数量](qa/v0.120-offcut-stopped.png)。均为临时隔离合成库，不含真实业务资料。

### 15.9 实物余料按核定定尺回用

入口：“图纸与算量 → 原材库存与预留 → 余料按定尺回用”。编制人员、负责人及管理员申请、释放及执行已审整单领用；独立复核账号审核其他人员申请。前置为15.8实际验收并执行入库的余料、当前有效验收原件、已按该实物长度核定且审定的排料材料表，以及实际交接和同材质截面、质量合格的凭据。

本节保留普通预留首次整单领用；独立分批领用及未领余量释放见15.16。15.18补料预留只走独立实际批单，不使用本节整单执行。分批后原预留只保留未领占用，任何一批领出后不再整单执行或重审，完整退回或余量释放不重开全量需求；仅已释放未领额可走15.18余料补料入口。

**范围与数量口径**

余料与完整原材分账。每段实测长度须与目标已审排料的原材定尺**精确相等**，每米质量也须相等；仅名称相同、每米质量相同、所有余料总长足够或相差很小都不能替代材质截面和定尺确认。不拼接短料、不用长料直接替代另一种定尺，不自动修改原排料或减少完整原材需求。请先按实际用途在材料表核定该定尺、锯缝、切除等参数并独立复核；旧方案修订及重复材料范围须由专业人员核对，不能把回用表再次计入已计净量。

一份申请须恰好覆盖一个材料表**全部已审定尺排料需求**，已经包含来源重复数量，不再倍乘；连续材料等未排料项不在该预留需求内。允许1至100条需求／余料组分配，同一需求同余料组不得重复，根数为1至1000000正整数。普通回用与15.6普通完整原材预留互斥；按已审定尺原材与余料共同供应须走15.19联合核定，不能把两份普通预留拼在一起；已有未释放完整原材预留或已领料记录时不能申请余料。同材料表余料已领用后不能重新做全量预留；原需求不变且已显式释放的未领额可走15.18。排料修订或退回不能重开额度。

**申请、预览、保存**

1. 在“余料实物库存”核对余料编号、库位、材质截面、实测每段长度、每米质量、原验收数量和当前余额。已停用或原件失效的余料保留账面数量，但当前可用为0。
2. 点击“申请余料回用”，选择已审材料表，读取全部定尺需求。为每项选择实际余料批次及根数，必要时增加分配从不同余料组供同一需求；逐段规格须一致且合计恰好覆盖各需求。不能把完整原材批次选作余料。
3. 填实际交接日期（YYYY-MM-DD，不晚于当天）、实际领用人、同材质截面／质量合格／不重复占用及交接说明，关联当前原件并确认。领用人是交接凭据上的文字，不自动创建账号或发送消息。未发生交接时不要虚构日期或确认，应在实际业务具备凭据后登记。
4. 点击“核对回用预览”，核对来源版本、余料编号及库位、规格、各根数、规范总长m和质量kg。预览只读，不占用。修改任何输入清除旧预览，须重新核对。
5. 点击“保存并预留余料”。后台重查需求、原件、预览及库存版本，成功后立即占用本次余料；此时仍在库，不等于已领用。并发争用时仅足额的申请可保存，失败者刷新再核定，不因预览曾通过而超占。

**独立复核、领用与释放**

独立复核人员点击“独立复核回用”，核对排料来源、全部需求、实物长度及每米质量、材质截面和质量凭据、实际交接日期、领用人及原件，再填写审核意见。编制人之后改任复核角色也不能自审。拒绝、待补件、排料变化或原件失效均**保留预留**，不自动放回可用数量；独立复核通过也不扣在库。

编制人员在已审定且无来源问题的申请点击“执行整单余料领用”，再次核对交接明细并确认，才减少余料在库并增加“在外待加工”。同申请重复执行不会重复扣减，库存版本或来源变化会阻断。整单领用后记录只读，不可重审或通过释放增加库存；未加工且验收合格的原段退回使用15.10专门入口，不表示已加工完成、已安装或成品净工程量。

未领用申请可点击“释放余料预留”，填实际核查原因及当前原件后显式释放，包括已拒绝、待补件或来源失效的申请。释放不表示实物退回、报废或加工；已释放不可重审，重新核定须建立新申请。余料仍有预留、在外未加工、在加工待验收或已验收加工原段数量时，15.8停用按钮禁用，后台也会阻断。

**余额、历史和异常处理**

- 当前余料账满足：**本组原验收根数＋累计盘盈－累计盘亏＝当前在库＋在外未加工＋在加工待验收＋本组已验收加工原段根数**，**在外未加工＝累计领用－累计原段退回－在加工待验收－本组已验收加工原段根数**，**在库＝原验收＋累计盘盈－累计盘亏－累计领用＋累计原段退回**。退回原段仍在原余料账，累计领用可包含后续其他材料表的再次领用，不应当成当前在外数；未加工原段退回见15.10，实际再加工和新余料验收入库见15.11。在库包含预留，**待核查前的剩余＝在库－未释放预留**；依据有效且未停用时“当前可用”等于该剩余，否则为0。15.10已执行退回验收原件失效时也会整组待核查并禁止新增领用，数量不回滚。再加工成品、损耗及新余料属于后续独立长度去向，不可把父组和子组的历史验收长度相加当作当前库存。
- 来源或交接原件后续失效，已领用数量保持并在回用记录提示待核查。余料验收原件失效也不恢复完整原材在库、不退回15.8加工核对额度；未领用申请须先有据释放，再重新核定。
- “可用不足”须核查其他申请、历史已领用及停用；不能通过反复提交、修订来源或删除原件取得库存。“定尺不一致”须重新核定实际适用排料，不能用总长凑数；“材料表已有预留”须核查旧预留，已领用的当前不能撤销。
- 下载库存台账JSON包含回用原始申请、预览摘要、规范分配、独立复核、领用／释放及15.10原段退回事件、逐领用分配在外余额及当时库存；在历史导出件可下载原字节，后来领用不会改写原文件。回用台账独立于工程报价PDF／Excel，工程净量、原排料、清单、报价和工程成果审批不随回用记账改变。

仅软件合成示例：余料SYN-V121-O1实际入库3.574m×1根、3kg/m。另经核定的同规格材料表采用定尺3574mm，每件1200mm、每件锯缝3mm、两端各切除10mm，总需求2件，对应1根余料。申请预览为1根／3.574m／10.722kg；保存后在库1、预留1、可用0；独立复核后仍相同；整单领用后在库0、预留0、在外待加工1，原验收1及完整原材台账保持。此例和页面均为隔离合成库，不代表真实工程、材质授权或仓库验收。

合成页面示例：[回用申请与交接原件](qa/v0.121-offcut-reuse-form.png)、[独立复核](qa/v0.121-offcut-reuse-review.png)、[领用后在库与在外余额](qa/v0.121-offcut-reuse-issued.png)。均来自临时隔离合成库。

当前不支持余料自动排料替换、改变原定尺的跨账替换和联合计划补料、同材料表领后重新全量预留再领、设备／工时／细化工序跟踪、在外／在加工盘点调整、账务冲销、采购或跨项目共享。错误领用须保留异常另行核查，不能改数据库或伪造释放。旧项目升级时新增空回用列表，不自动迁移或领用，旧JSON字节保持。

### 15.10 未加工余料原段退回

来源现在包括旧已执行整单和15.16已执行余料批单，须选择实际单号，按本批原分配序号和余额操作，原预留不能冒充已领批单。

入口：“图纸与算量 → 原材库存与预留 → 未加工余料原段退回”。编制人员、负责人及管理员登记、取消未执行单及执行已审退回；独立复核人员签署其他账号的退回。前置为15.9**已经执行**的余料领用单、该单各分配尚在外的原段，以及本次实物交接与未加工原段质量验收凭据。预留、仅已审待领用或计划余料都不能登记退回。

**什么可以退回**

只能退回保持原实测每段长度、同材质截面、未加工且验收合格的余料原段。切短、已加工、损坏或遗失不能当作原段填回；原段编号、原库位、材质截面、每米质量和长度从已执行领用快照继承，表单不允许另改编号、尺寸、质量或移到新库位。实际加工及新余料须按15.11另行实测验收入库；此原段退回流程不覆盖再加工回收、报废、盘点或冲销。

实际数量按来源领用单**逐分配**核对，而不是按同规格全项目总长抵扣。每单1至100个不同来源分配，根数为1至1000000正整数，每项不超过该领用分配尚未加工且未退回根数；可以分批退回。15.12已执行投入加工及15.11直接模式已执行再加工会扣减这一未加工余额，投入后不能再按未加工退回；引用投入单的结果仅结转待验收数量，不能再把已加工原段退回；待审或已审未执行的加工与退回竞争同一余额，执行时重新核对。保存及复核不占用退回额度，多份待执行单可以引用同一余额，执行时重新核对，不能据“曾审通过”重复退库。

**操作、预览和保存**

1. 先在“已领用余料逐项在外余额”核对来源材料表、原领用单号、分配序号、余料编号／原库位、每段原长、每米质量、原领用／在加工待验收／已验收／已退回／未加工根数。历史来源问题保留显示，不自动撤销已发生领用。
2. 点击“登记余料原段退回”，选择尚有在外余额的已执行余料领用单。选择原领用分配，填写本次**实际原段退回根数**；根数初始留空，不能默认等于全部在外数量。需要时增加其他分配，同一分配不能重复。
3. 填实际退回日期（YYYY-MM-DD，不早于原领用交接日期且不晚于当天）、实际接收人、未加工／保持原长／同材质截面／质量合格／回原库位的实物验收说明，关联当前原件并确认。接收人是交接凭据上的文字，不创建账号或发送消息。未收到实物、无原件或质量待核查时不要虚构退回。
4. 点击“核对原段退回预览”，逐项核对来源单号和分配、原编号及库位、规范m与kg、根数、总长及质量。长度和质量按原段快照精确计算，不增加已安装工程净量。预览只读，尚未增加库存或占用额度。
5. 点击“保存退回单待复核”。输入、原件、接收人、数量、日期或确认变化都会清除旧预览，须重新预览；保存还会检查台账版本及预览摘要。成功后是草稿，**在库及在外数量均不变**。

**独立复核与显式记账**

复核人员点击“独立复核余料退回”，核查原领用单号和分配、实际交接日期及接收人、实物原长和质量验收、原编号原库位、当前原件及本次根数，再填写意见。编制人之后转为复核角色仍不能自审。拒绝和待补件不记账；复核通过显示“已审待执行”，仍不增加在库。

编制人员点击“执行余料原段退回”，再次核对后“确认原段已接收并记账”。执行才在原余料组增加实际退回根数，并减少对应原领用分配的在外余额。多单竞争余额时，先执行者成功，另一单显示超余额待核查，不自动改成0或补足；须核查后有据取消错误待执行单。

执行后在“余料实物库存”核对**当前在库、预留、当前可用、在外待加工、累计领用、累计原段退回**，以及退回区的逐分配在外余额。退回不加回完整原材台账，不退回15.8已经使用的加工核对额度，也不释放原领用材料表的二次预留门禁；经核定的其他材料表可申请当前有效可用的已退原段，仍须完整需求分配及独立复核。已有预留仍占用在库，不能把累计退回数直接当可用数。

**来源失效、取消和异常**

旧排料、图纸或旧领用交接依据失效，不阻止凭本次新的有效验收原件记录真实原段退回；原领用单及其历史问题保持。原余料验收依据无效时，退回仍增加实际在库，但当前可用仍为0；不能借退回使原资料重新获审。

本次退回原件在预览、保存、复核及执行时均须有效；原字节缺失、损坏或来源变化阻断。**已执行退回原件后来失效时，已退回和在库根数保持**，退回记录提示问题，涉及的整个余料组待核查、当前可用0并禁止新增领用。当前按同长度同库位组记账、没有逐段序列号，因此保守暂停整组；即使部分原段后来再次领用，也不回滚已发生的出库。点击页面“刷新项目”会重新读取库存台账和原件状态，包括项目内容版本未变化的情况。恢复经核对的原始依据后再次刷新核查；不能用新建无关原件、改数据库或虚构新批次绕过。

未执行单可“取消未执行退回”，填实际核查原因和当前原件后留档取消，不改实物数量。已取消不可重审；已执行不可取消、修改或重审，暂不支持其冲销。实际已收到短料或问题料时应另行核查，不能通过此入口冒充原段。

库存JSON保存退回原始输入、预览摘要、原段规范分配、独立复核、执行／取消事件、累计退回和各领用在外余额；在“成果交付 → 历史导出件”按“库存台账／独立业务记录”下载当时原字节。后续退回不改写旧文件，不等于报价审批。旧项目升级默认空退回列表，不自动退库或补写旧JSON。

仅软件合成示例：SYN-V122-O1为原验收3.574m×1根、3kg/m，已领用后在库0、在外1。实际未加工原段退回1根，预览为3.574m／10.722kg；保存和独立复核后仍在库0／在外1，显式执行后在库1／在外0／累计领用1／累计退回1，有效依据下可用1。再有据停用时在库和原验收1保持、可用0。所有示例均为隔离合成软件资料，不代表真实仓库或工程验收。

合成页面示例：[原段退回只读预览](qa/v0.122-offcut-return-preview.png)、[独立复核](qa/v0.122-offcut-return-review.png)、[执行后在库及累计退回](qa/v0.122-offcut-return-stock.png)、[退回原件失效整组待核查](qa/v0.122-offcut-return-quarantine.png)。均为隔离合成库；失效原件已在验证结束后按原字节恢复，不含真实业务资料。

加工后新余料回收见15.11；本入口当前不支持未加工原段退到新库位、同材料表退后全量再次领用、在同一退回单混记两账、在外／在加工盘点调整、执行冲销、跨项目调拨及采购闭环；这些不能用原段退回代替。

### 15.11 余料实际再加工与新余料验收入库

来源现在包括旧已执行整单和15.16已执行余料批单，须选择实际单号，按本批原分配序号和余额操作，原预留不能冒充已领批单。

入口：“图纸与算量 → 原材库存与预留 → 余料实际再加工与新余料入库”。编制人员、负责人及管理员登记、取消未执行结果及执行已审结果；独立复核人员审核其他账号的实际结果。前置为15.9**已执行余料领用单**、该单逐分配尚未加工且未退回的原段，以及本次实际加工去向、实测、偏差和新余料质量验收原件。仅预留、仅已审待领用、排料预计余料均不能作为来源。

**实物与计量口径**

本入口保留未单独登记投入、但已掌握完整实测结果时的一步记账方式。无完整结果时先用15.12登记实际投入；已执行投入单后，须到“已投入加工余料结果验收”引用本单待验收数量，不能再用本入口直接扣未加工余额。工程上发生加工后不能再虚构未加工退回；系统中的待执行单还未记账，须及时核查实际业务并显式执行正确结果。

每份1至20个不同领用分配，可分批核对，实际原段根数为1至1000000正整数，不能超过对应分配未加工且未退回余额。按本次实际加工原段填写成品、锯缝、切除、报废**总长**，可为0；不是每根数量，也不是已安装净量。每项选择m、mm、cm、dm或km，该项全部实测及新余料共用单位，换单位不会自动改写数值。后台按精确有理数换算，逐项检查：

**来源原段每根长度×本次加工根数＝成品总长＋锯缝总长＋切除总长＋报废总长＋新余料总长**。

没有容差补差，不自动把差额填到报废。材质截面及每米质量继承已执行领用快照；长度去向乘继承每米质量得到kg去向，不增加工程量、清单或报价。实际结果与计划可不同，但必须填写实际范围及偏差说明，不能按计划自动回收。

每项可填0至20组新余料，全单最多100组、合计最多1000000段；每段须正长且**严格短于来源原段**。相同长度、库位和验收口径可以合并根数，该编号仍是组别编号，不代表逐段序列号。新余料须独立实物编号、每段实测长、根数、实际库位、材质质量及可留用验收说明，逐项关联当前原件。新编号不能与本项目任何代余料或完整原材在同库位重复，即使旧组已停用也不能复用编号。没有可留用新余料时不添加组，仍须精确核对全部长度去向。

**登记与预览**

1. 在15.10“已领用余料逐项在外余额”核对来源材料表、原领用单号、原余料组、原长、规格、原领用／在加工待验收／已验收／已退回／未加工余额。旧来源失效会提示，不能自动退回或撤销历史实物。
2. 点击“登记余料实际再加工”，选择仍有未加工且未退回原段的已执行余料领用单，选择来源分配。新模式的本次加工根数初始留空，按实际填写；不要再次乘材料表重复数量。
3. 填实际验收日期（不晚于当天且不早于原领用交接日期）、实际验收人、实际加工范围及与计划偏差说明、整批原件。逐项填根数及原件、四类实测总长及原件、本项实际范围／去向／偏差说明及原件。
4. 有新余料时点击“增加实际余料组”，逐项填编号、每段实测长度、根数、库位、材质质量及可留用验收说明与原件；不同长度或库位分组。有多个来源分配时“增加来源加工分配”，不能重复选择同一分配。
5. 据实测及原件确认，点击“预览实际长度及余料”。核查“余料再加工长度及新余料预览”中的原领用单号、父余料标识、来源组编号、规范原段投入、各去向长度／质量、新余料及差额0。
6. 任意输入、单位、根数、验收人、说明、原件或确认变化都清除旧预览，须重新核对。点击“保存再加工结果待复核”后为草稿，**未加工余额、已加工根数和新余料库存均不变**；保存也不抢占加工额度。

**独立复核、显式执行与余额竞争**

独立复核账号点击“独立复核再加工结果”，逐项展开“实测输入及逐项原件”，核查原领用及父余料、实际加工根数、日期、四类实测、单位、偏差及全部新余料的尺寸／编号／库位／质量验收，再填写意见。编制人转为复核角色后也不能自审。拒绝或待补件不记账；通过后“已审待执行”，仍不增加新库存。

编制人员点击“执行再加工及新余料入库”，核对确认窗口并显式执行。后台重查当前实测原件、独立复核、对象及库存版本、逐分配余额、新编号和闭合；成功后把本次原段转为“已加工”，减少对应领用的未加工余额，并登记独立新余料组。原段不能再按15.10未加工退回。待执行加工与原段退回竞争同一余额，先执行的正确单成功，另一单刷新后显示超余额问题，不能因为曾审通过而重复记账。

在“余料实物库存”可查看新余料的“再加工入库／父余料”标记，明细保留父余料完整标识及原领用单号。新余料实际验收执行后，在依据有效时才有可用数量；后续按其实际定尺另行核定材料表，按15.9独立申请回用，可再按15.10退回未加工原段或再次使用本入口登记下一代实测。每代新余料均须更短、独立编号及实际凭据，不自动递归生成预计库存。

每组独立满足：**本组原验收根数＋累计盘盈－累计盘亏＝当前在库＋在外未加工＋在加工待验收＋本组已验收加工原段**；**在外未加工＝累计领用－累计原段退回－在加工待验收－本组已验收加工原段**；**在库＝本组原验收＋累计盘盈－累计盘亏－累计领用＋累计原段退回**。新子组是加工后另一次实际验收，不能将父组历史长度和子组长度重复相加当作当前在库；库存根数更不能跨不同长度的代际相加当成原材根数。已有预留继续占用在库，当前可用仍须扣预留并通过全部依据门禁。

**失效、取消、停用和历史**

原图、排料、旧领用或父余料原件失效不撤销已发生领用；实际再加工可凭本次新的有效实测及验收原件记录。既有已加工根数和新余料验收数量保持，不退回完整原材库存或15.8最初加工核对额度，也不重开原材料表再次领用额度。

新余料的有效采用同时检查本次再加工验收、父余料至最初余料的验收依据，以及涉及原段退回的验收依据。任一失效时保留历史实物数量，关联新余料显示待核查并禁止新增领用；已经领用或再次加工的不回滚，须另行核查。点击“刷新项目”重查原件状态，恢复经核对的原始依据后重新读取，不能用新建无关资料或新编号洗去历史问题。

未执行结果可“取消未执行再加工”，填核查原因及当前原件，不改实物数量或余额；已取消不可重审。已执行不可取消、改数或重审，暂不支持冲销。仍有预留、在外原段或已加工原段的余料组不能停用；新余料尚无这些占用时可按15.8有据停用，原验收和在库记录保持、可用0，不退回父代加工余额或重用编号。

下载库存JSON可核对再加工原始输入、预览摘要、规范去向、逐代父余料及原领用关联、独立复核、执行／取消／停用事件、各组在库／已加工及逐领用未加工余额。历史下载保持原字节；该业务台账独立于报价PDF／Excel，几何、工程净量、排料、清单、报价和原工程成果审批保持。旧项目新增空再加工列表，不推测历史加工或生成新余料，不改旧JSON字节。

仅软件合成示例：已领用原段3.574m×1根、3kg/m。实测成品2.4m、锯缝0.006m、切除0.02m、报废0、新余料1.148m×1，3.574＝2.4＋0.006＋0.02＋0＋1.148，投入10.722kg，新余料3.444kg。预览／保存／复核均不变更余额；执行后父组在库0／在外0／已加工1，新组在库1／可用1。新组另经已审定尺1148mm、2件400mm下料核定回用后，可实测0.8m成品＋0.006m锯缝＋0.02m切除＋0.322m新余料，下一代0.966kg；均须各自实物和原件，不代表真实工程、材质授权或仓库验收。

合成页面示例：[再加工精确闭合预览](qa/v0.123-offcut-processing-preview.png)、[独立复核](qa/v0.123-offcut-processing-review.png)、[父余料已加工与新余料入库](qa/v0.123-offcut-processing-stock.png)、[再加工原件失效待核查](qa/v0.123-offcut-processing-quarantine.png)。均为临时隔离合成库，失效原件在验证结束后按原字节恢复，不含真实业务资料。

无完整结果时的实际投入与按数量跟踪见15.12；当前仍不支持设备、工时、细化工序或自动进度百分比、自动优化替换原排料、在同一再加工单混记两账、同材料表全量再次领用、在外／在加工盘点调整、执行冲销、跨项目调拨或采购闭环；实物遗失等无法取得完整去向时不能伪造长度闭合。

### 15.12 余料实际投入加工、在加工跟踪与分批结果验收

来源现在包括旧已执行整单和15.16已执行余料批单，须选择实际单号，按本批原分配序号和余额操作，原预留不能冒充已领批单。

入口：“图纸与算量 → 原材库存与预留 → 余料实际投入加工与在加工跟踪”，后续为同页“已投入加工余料结果验收”。编制人员、负责人及管理员登记、取消未执行单及执行已审单据；另一独立复核账号签署。前置为15.9**已执行的余料领用单**、逐分配尚未加工且未退回原段，以及实际投入日期、地点／工位、接收人／班组和交接原件。实际仅计划投入时不要确认已投入。

此流程适合已发生投入但尚无完整实测结果的情况。按**投入及结果验收数量**跟踪“在加工待验收 → 已部分验收 → 已验收完毕”，不跟踪设备运行、工时、细化工序或自动进度百分比。“尚未验收”不是剩余完好原长实物的保证，不能将其当未加工原段退回。

**实际投入登记与预览**

1. 在“已领用余料逐项在外余额”核查原领用／在加工待验收／已验收／已退回／未加工数量。只有已执行领用且仍有未加工原段的分配可选；已退回、已投入及已直接验收加工的数量不能重复投入。
2. 点击“登记余料实际投入加工”，选来源领用单和原分配，填本次实际投入根数。根数初始留空，须为1至1000000整数；每单1至100条不同分配，可按实际分批登记，不能把其他分配余额借来凑数。
3. 填实际投入日期（YYYY-MM-DD，不早于原领用交接日期且不晚于当天）、实际加工地点或工位、加工接收人或班组、实际投入范围及交接说明、当前原件，确认原段已经实际投入。地点和班组是原件上的文字，不自动建立仓库、设备或账号，不发送通知。
4. 点击“核对实际投入预览”，核查来源单号、分配、原编号／库位、规格、每段原长、实际根数、规范总长m及质量kg。此处长度及质量按投入原段快照计算，不是成品、损耗或新余料估算，不增加工程净量。
5. 修改任何输入、原件或确认都会清除旧预览，须重新核对。点击“保存投入单待复核”后为草稿，尚不扣未加工余额，不增加在加工数量，也不抢占投入额度。

**独立复核与执行投入**

独立复核人员点击“独立复核投入加工”，核对实际交接凭据、日期、工位、班组及逐分配实际投入量，再填写意见。编制人以后转为复核角色也不能自审。拒绝或待补件不记账，复核通过仍不改变数量。

编制人员点击“执行实际投入加工”，再次核对后“确认已实际投入并记账”。执行时重查当前原件、独立复核、对象版本及未加工余额，成功才把本次数量从“在外未加工”转为“在加工待验收”。**原段在库仍保持先前领用后的数值，不再扣一次在库；没有任何成品、损耗或新余料自动入库**。

投入单与其他投入单、15.10原段退回、15.11直接模式完整结果竞争同一未加工余额。保存或曾复核通过不保证后来仍足额，执行先到者成功，其余显示超余额待核查。核查实际业务后有据取消未执行错误单，不能改数量或自动填0绕过。

已执行投入不能取消、改数、重审或按未加工原段退回，也不能通过释放回用申请增加库存。仍有在加工待验收原段的余料组不能停用。未执行投入可“取消未执行投入”，填实际原因和当前原件后留档，不改数量；已取消不可重审。

**引用投入单分批验收结果**

1. 取得实际结果及逐项原件后，在“已投入加工余料结果验收”点击“登记投入单加工结果”，选择尚有待验收数量的**已执行余料投入加工单**。不是选择原领用单；预留、仅已审待执行、已取消或已全部验收投入单均不能采用。
2. 表单按投入单保留原领用分配序号，只能选本投入单实际包含的分配；例如该投入单只投分配2，不能改选原领用的分配1。填本次实际验收原段根数，不超过本单该分配待验收量，可分多次、每次1至20个不同分配。
3. 按15.11填写实际验收日期、验收人、实际范围与偏差、成品／锯缝／切除／报废总长和新余料逐项实测及原件。验收日期还须不早于本投入日期。逐项原长×本次根数与全部去向精确闭合，既不能按计划生成新余料，也不能用容差补差。新余料编号、质量、库位、各代关联和后续回用规则保持15.11。
4. 预览显示原领用单号及**本次引用的实际投入单号**，明确“仅结转本单待验收数量，不重复扣减未加工余额”。修改输入清除旧预览，保存及独立复核不记账；逐字段原件均可在复核中展开核对。
5. 另一账号“独立复核再加工结果”后，编制人员点击“执行投入单结果验收”并确认。执行只减少该投入单尚未验收数量、相应“在加工待验收”数量，增加已验收加工数量及实物新余料，不再次扣未加工余额、在库或最初加工核对额度。
6. 在投入跟踪表核查“投入／已验收／待验收”及逐分配余额。已投入2根，本次验收1根显示2／1／1和“已部分验收”；另验收1根后2／2／0和“已验收完毕”。已完成单不再提供新结果来源。两份结果争用同一待验收数量时执行重查，不能超验收或把另一投入单剩余量借来覆盖。

每份结果仍可按15.11有据取消未执行记录，已执行不可重审或冲销。尚有待验收量时即使已出现部分新余料，也不能认为整单完成；系统不补齐未知长度或自动关闭剩余数量。未单独投入且已掌握完整结果时仍可用15.11一步登记，但已执行15.12占用的数量不能再被直接模式重复扣减。

**余额、原件失效及历史**

逐余料组满足：**本组原验收根数＋累计盘盈－累计盘亏＝当前在库＋在外未加工＋在加工待验收＋已验收加工原段**；**在库＝本组原验收＋累计盘盈－累计盘亏－累计领用＋累计原段退回**；**在外未加工＝累计领用－累计原段退回－在加工待验收－已验收加工原段**。投入执行把未加工转入在加工，结果执行把在加工转入已验收，均不自动把未知去向当成当前库存，也不把父子代历史长度相加当库存。

旧图纸、排料或旧领用原件失效不回滚实际领用和投入；本次投入须自己的当前有效交接凭据。已执行投入原件后来丢失、损坏或失效时，实际在加工及已验收数量保留，投入单显示待核查；不因原件问题重新取得未加工余额。取得新的有效实测凭据后仍可记录真实后续结果，但关联新余料采用同时检查投入原件，投入依据仍无效时新余料在库保留、可用0，不能通过新结果洗去历史问题。按原字节恢复经核对的原始依据并点击“刷新项目”重查；不能伪造回退或新编号绕过。

下载库存JSON包含实际投入原始输入、预览摘要、独立复核、执行／取消、工位及班组、逐投入分配验收余额，以及结果中的投入单号和原领用关联。历史下载保持当时原字节，不代表报价审批；工程净量、排料、报价、完整原材台账和15.8最初加工核对额度保持。升级旧项目默认空投入列表，不把旧15.11一步记账结果改写成投入单，也不补写旧JSON。

仅软件合成示例：已领用同组3.574m原段2根、3kg/m，原在库0／未加工2。实际投入2根，预览7.148m／21.444kg；保存与复核不变，执行后未加工0／在加工待验收2，不生成新余料。随后每批验收1根，逐根实测2.4m成品＋0.006m锯缝＋0.02m切除＋1.148m新余料，第一批后待验收1／已验收1，第二批后待验收0／已验收2；每批新余料须独立编号及实际验收，各3.444kg。示例均为隔离合成软件资料，不代表真实仓库、人员或工程验收。

合成页面示例：[实际投入预览](qa/v0.124-offcut-start-preview.png)、[投入后待验收2根](qa/v0.124-offcut-started.png)、[结果引用本投入单](qa/v0.124-job-result-preview.png)、[已部分验收2／1／1](qa/v0.124-offcut-partial.png)、[已验收完毕2／2／0](qa/v0.124-offcut-complete.png)。均为隔离合成库，不包含真实业务资料、人员或设备。

当前不支持设备、工时、细化工序或自动进度百分比、投入后未加工撤回、执行冲销、在外／在加工盘点调整、同材料表全量再次领用、在同一投入单混记两账、自动替换排料、跨项目调拨或采购闭环。实际已投却没有结果的记录应保留待验收并核查，不能虚构完整去向来关闭。

### 15.13 已验收余料在库盘点与差异调整（v0.125）

**入口和角色。** 在“图纸与算量 → 原材库存与预留 → 余料在库盘点与差异调整”点击“登记余料实物盘点”。编制人／管理员登记及显式执行；另一 reviewer 账号独立复核，提交人改角色后也不能自审。每单盘点一个本项目已验收的现有余料组，包括再加工后代组；当前在库为0的既有组仍可有据盘点。停用或历史原件待核查的组不能借新盘点恢复可用。

**前置资料。** 现场核对原余料编号、存放位置、材质截面、每段实测长度、每米质量和同组在库原段根数，上传本次盘点及差异核查原件。两项可选同一文件，但该文件必须确实包含两项内容。新上传原件可能按既有规则使工程来源待复核，盘点不会代审工程。实盘输入留空，不自动照抄账面。

| 字段 | 填写及口径 |
| --- | --- |
| 现场实盘在库根数 | 0～1000000整数，单位根。0表示现场确无在库原段；只数此编号、库位、同规格原段，不含在外、在加工、已加工或其他组，不按总长折算。 |
| 当日盘点日期 | 中国标准时间当天YYYY-MM-DD，预览、保存、独立复核、执行均须同日。过日须取消未执行单并重新现场核对，不能改日期复用旧数。 |
| 现场盘点人 | 实际清点人，最长200字；不替代系统账号和独立复核签署。 |
| 差异原因、范围及核查说明 | 最长2000字，说明识别范围、差异成因及核查过程；无差异也须说明核对结果。 |
| 现场盘点原件／差异核查原件 | 分别选择当前有效且原始字节可核验的证据。盘盈须核查同组原段及漏记原因，不能把采购、新规格、拼接、未知来源或计划余料充作盘盈。 |
| 实物确认 | 确认按编号、位置、材质截面、段长和质量核对在库原段，差异有据，不以计划找平。 |

**操作步骤。**

1. 现场清点并准备原件，选择余料组，核对页面账面在库、预留、在外未加工、在加工和已加工数量，填写实际信息并勾选确认。
2. 点击“核对盘点差异预览”，查看账面→实盘、盘盈／盘亏／无差异根数、带正负号的长度差异m及质量差异kg。长度差异＝每段长度×根数差异，质量差异＝长度差异×每米质量，均精确换算，不推定成品或损耗。
3. 点击“保存盘点待复核”，只存草稿，不占用或调整库存。修改任何输入、原件或确认后预览清除，须重新预览。
4. reviewer 在该行点击“独立复核盘点”，核对组别、范围、差异成因及两项原件，填写依据签署。通过、拒绝、待补件均不调整；拒绝不使原工程量、报价或其他库存失效。
5. 编制账号刷新后点击“执行盘点差异调整”，确认原件与现场一致。执行追加冻结前后值、差异、单据关联及审计事件；不覆盖原验收、领用、退回、投入或结果记录。
6. 状态显示“已执行盘点”，库存显示累计盘盈／盘亏、调整后总根数及在库／可用。无差异也追加确认事件并更新快照。已执行不能重审、取消或冲销；新差异另行现场盘点。

**余额与下游。** 每组满足：**原验收＋累计盘盈－累计盘亏＝在库＋在外未加工＋在加工待验收＋已验收加工原段**；**在库＝原验收＋累计盘盈－累计盘亏－累计领用＋累计原段退回**。仅调整在库，保持在外、在加工、已加工及原验收历史。原验收长度／质量仍按原数显示，不用新总根数覆盖；不同长度、父子组历史量不能重复相加当成当前库存。依据有效且未停用时，可用＝在库－未释放预留。实盘少于当前预留将拦截，先据实核查并有据释放未领预留，必要时按既有规则重新分配，不自动减占用或改配。

该组领用、退回、投入、加工结果或另一次盘点后，旧快照不能执行，即使当前在库恰好恢复原数。不同组流转不改变本组实盘，但保存和执行仍检查整体台账版本。盘盈后的有效在库可按15.9供其他当前已审材料表精确定尺回用，不重开已领用材料表，不自动替换排料、净工程量、清单或报价。

**错误与恢复。** 未执行可点击“取消未执行盘点”，填写当前取消原因及原件，不改数量。过日、快照变化、缺原件、预留超实盘、对象／台账过期或缺独立复核须处理后重新核定。盘点原件在预览、保存、复核、执行均检查真实字节；已执行后失效保留差异及当前数量，同时该组及所有后代余料可用为0并提示待核查，恢复原字节后再检查。新盘点不能清除旧依据异常。记录、事件、来源或执行顺序无法核验时阻断读账及新导出。

**留档与边界。** 库存JSON保存盘点输入、快照、冻结前后值、差异、原件摘要、独立复核和执行／取消事件；旧下载原字节不变，当前余额需重新导出（23.5）。完整原材在库盘点见15.14；本入口尚不支持在外或在加工盘点、跨库位迁移、新规格采购入库、报废处置、财务损益入账、执行冲销、仓库自动扫描。无差异确认不代表整库验收。

合成示例：既有同组3574mm余料1根、3kg/m，现场同规格在库2根，有据核查漏记。预览1→2根、盘盈1根、＋3.574m、＋10.722kg；保存及复核仍在库1，显式执行才在库2、原验收仍1、累计盘盈1。若后来实盘1，另单盘亏1，累计盈1／亏1均保留。这是隔离合成软件验证，不代表真实仓库、材质鉴别或工程验收。[合成预览](qa/v0.125-count-preview.png)、[合成执行结果](qa/v0.125-count-executed.png)。

### 15.14 完整原材在库盘点与差异调整（v0.126）

**入口、角色和前提。** 在“图纸与算量 → 原材库存与预留 → 完整原材在库盘点与差异调整”点击“登记完整原材实物盘点”。编制人／管理员登记及显式执行，另一 reviewer 账号独立复核；提交人改角色后也不能自审。每单仅盘一个本项目已有效独立审定且未停用的原材登记批次，包括当前在库为0的既有批次。待审、被拒、待补件、登记原件或历史盘点依据失效、停用批次不可采用。先在15.6完成登记及复核，余料组仍走15.13，不能把切短余料并回完整根。

**现场准备与字段。** 核对原批号、库位、材质截面、完整定尺和每米质量，清点现场在库完整根。上传盘点及差异核查原件；两项可指同一文件，但必须包含相应内容。新增资料可能按既有规则使工程来源待复核，盘点不代审工程。界面显示当前在库、未释放预留、在外未加工及已投入加工，实盘输入留空，不自动照抄账面。

| 字段 | 填写要求与单位 |
| --- | --- |
| 完整原材批次 | 选原登记批号及库位；继承原材质截面、规范定尺m和每米质量kg/m，不能在盘点中改规格、库位或长度。 |
| 现场实盘在库根数 | 0～1000000整数，单位根；0表示现场确无在库完整根。排除在外、已投入加工及余料，不按零散总长折成完整根。 |
| 当日盘点日期 | 中国标准时间当天YYYY-MM-DD。预览、保存、复核、执行须同日；过日取消未执行单后重新现场核查，不能仅修改日期照用旧数。 |
| 现场盘点人 | 实际清点人，最长200字；不替代系统签署账号及独立复核。 |
| 差异原因、范围及核查说明 | 最长2000字；写明辨识范围、盘盈／盘亏成因及核查依据，无差异也需说明核对过程。 |
| 现场盘点原件／差异核查原件 | 分别选择当前有效证据，并核查真实原始文件。盘盈须证实本批同规格完整根漏记，采购、新规格、未知来源或计划量不能充作盘盈。 |
| 实物确认 | 据实核对原批号库位、材质截面、定尺及每米质量，仅盘在库完整根，差异有据，不以计划找平。 |

**完整操作。**

1. 现场清点并准备资料，选择“完整原材批次”，逐项填写实际数量、日期、盘点人、核查说明及两项原件，勾选确认。
2. 点击“核对盘点差异预览”，检查账面→实盘、盘盈／盘亏／无差异根数和带正负号的长度m、质量kg差异。长度差异＝规范定尺×根数差异，质量差异＝长度差异×每米质量，精确换算，不计算财务损益或净安装量。
3. 点击“保存盘点待复核”，只保存草稿，不占用、调整或释放库存。修改任一输入、证据或确认后保存禁用，须重新预览。
4. reviewer 在该行点击“独立复核原材盘点”，核对本批规格、实盘范围、两项原件及成因，填写审核依据签署。通过、拒绝、待补件均不调整实物，也不使原工程量或报价失效。
5. 编制账号刷新，点击“执行原材盘点差异调整”，复核冻结明细后“确认实盘并追加差异事件”。后台再次检查批次有效审定、原件字节、当日、当前预留、实物流转快照、对象及整体台账版本。任何一项失效整单不执行。
6. 状态变为“已执行盘点”；“实物原材批次”仍显示原登记根数，同时显示累计盘盈／盘亏、调整后总根数和当前在库、预留、可用。原登记、领用、退回、投入加工及加工结果不改写。无差异也追加确认事件并更新盘点快照；已执行不可取消、重审或冲销。

**守恒及下游。** 完整根满足：**原登记＋累计盘盈－累计盘亏＝在库＋在外未加工＋已投入加工**；**在库＝原登记＋累计盘盈－累计盘亏－累计领料＋累计完整退回**。实际投入加工已退出完整根库存，不能用盘亏抹掉其数量或15.8的加工核对额度。盘点也不制造成品、余料、报废或完整退回。有效已审且依据有效时可用＝在库－预留。实盘小于未释放预留将拦截，先核查并有据释放未领预留，必要时重新分配，不自动减占用。待审、被拒、待补件或来源失效的预留继续占用。

该批领料、投入加工、完整退回或另一次盘点后旧快照失效，即使在库最终恢复原数，也须取消后重新现场核对；仅其他批次变动不改变本批实盘快照，但保存／执行仍须刷新整体台账版本。盘盈后的有效在库可按15.6用于新的当前已审材料表预留，完整覆盖需求；不重开已经领料的材料表，不自动替换排料、工程量、清单或报价。无盘点的旧批次累计盈亏为0，沿用原口径。

**错误、取消与历史依据。** 未执行可点“取消未执行原材盘点”，填原因及当前原件，不改数量，过日和来源失效的未执行单也可有据取消。保存／复核／执行遇到过日、过期快照、缺原件、预留超实盘或缺独立复核时，须核对后重做，不能绕过门禁。盘点原件在预览、保存、复核、执行均检查实际字节；已执行后失效保留差异及实物历史，本批可用0并阻断新增预留／领料／盘点；由本批加工产生的余料及所有后代也可用0。这是整批保守隔离，不按无法证明的单根身份分摊异常。既有在外原材可凭新的有效交接／实测原件继续登记实际完整退回或加工，数量不回滚，依据问题持续提示。恢复历史原件后重新检查，不用新盘点清除旧异常。记录、事件、批次关联、独立复核或执行顺序无法核验则阻断读账及新导出；出库不能用发生在后的盘盈追补。

**导出和能力边界。** 库存JSON增加完整原材盘点输入、冻结前后值、差异、快照、证据摘要、复核及执行／取消事件；历史下载原字节不变，当前余额需重新导出（23.5）。不支持在外或已加工物料盘点、执行冲销、跨库位迁移、采购／新规格入库、财务损益入账、同材料表再次领用、跨项目共享或仓库自动扫描。批次为分组台账，非逐根身份追踪。盘点单审定不代表整库、真实材质或商业工程验收。

合成例：原登记6m、3kg/m、10根，已领3根且其中1根投入加工，账面在库7、在外2、已加工1；现场同批在库8根，有据核查盘盈1根。预览＋6m／＋18kg，保存及独立复核仍在库7，显式执行后在库8、原登记仍10、累计盈1、在外2／加工1保持，11＝8＋2＋1。此为隔离合成软件验证，不代表真实仓库验收。

隔离浏览器合成例另核对盘亏：原登记仍10根，在库7→6、累计盘亏1，调整后总根数9＝在库6＋在外2＋已加工1，既有余料原验收保持。[合成原材盘亏预览](qa/v0.126-stock-count-preview.png)、[合成显式执行结果](qa/v0.126-stock-count-executed.png)。截图仅为软件验证。

### 15.15 完整原材分批领料与未领余量释放（v0.127）

**入口和角色。** 在“图纸与算量 → 原材库存与预留 → 领料、加工与退回”点击“建立分批领料单”。编制人／负责人／管理员建立并显式执行，另一 reviewer 独立复核；改角色不能自审。先完成15.6完整原材登记、当前排料及预留独立复核。仅从本项目当前有效已审且仍有未领数量的原预留按原分配序号选择，不另建预留、不改变批次、需求、定尺或规格。首次仍可用旧“建立整单领料单”；任何一批领出后续领须继续用分批入口，整单入口不覆盖已领记录。余料独立分批领用见15.16，旧首次整单入口保留。

**资料、字段与单位。** 每批须有实际完整原材交接原件。选择“当前已审未领完预留”后逐项显示原预留分配序号、批号、原预留／累计已领／未领根数，序号始终沿用原预留，选择第2项不会变为第1项。

| 字段 | 填写口径 |
| --- | --- |
| 原预留逐分配本次根数 | 单位根，空白或0表示本次不涉及；至少一项为正整数。每项1～1000000且不超过该原分配未领根数，最多100个不同原序号。不能挪用另一批次、需求或分配余额，不能改原定尺或按总长替换。可一次领完全部剩余。 |
| 实际业务日期 | 不晚于今天的实际交接日期YYYY-MM-DD；页面初值为当天，必须按真实凭据核对，不以保存时间替代实际日期。 |
| 领用／交接对象 | 本批实际接收人或班组，最长200字；各批可以不同，不自动沿用上一批。 |
| 实际交接或加工说明及原件 | 最长2000字，说明本次完整根交接范围、批次和凭据，选择当前有效证据；真实原件字节须可核验。 |
| 实物确认 | 确认本次交接实际发生，不把计划／预留当实物，不把切短余料当原长完整根退回。 |

**预览、保存、复核和执行。**

1. 选择原预留，核对逐项未领余额，填本次根数、日期、接收人、说明及原件并勾选确认。
2. 点击“核对分批领料预览”，检查本次分配、规范定尺m、每米质量kg/m、合计根数／长度m／质量kg。每项长度＝定尺×本次根数，质量＝该长度×原登记每米质量，精确累计；不是净安装量、损耗、采购价格或余料重量。
3. 点击“保存分批领料待复核”，只存草稿，原在库及未领占用不变。修改输入、来源、原件或确认后预览清除，重新预览才能保存。保存／复核不额外占用，仍由原预留保护，不能因多张草稿重复扣占用。
4. reviewer 在“领用单据及记账状态”点本批“独立复核领用单”，核对本批对象、原分配、实物凭据及未领余额后签署。通过、拒绝、待补件均不出库、不释放原预留；未执行可有据“取消未执行单据”，也不改变预留。
5. 编制账号在本批点击“执行库存记账”，再次核对实际交接并确认。后台重新检查来源、独立复核、原件字节、原预留未领逐项余额及对象／整体台账版本，任何失败整批不记账；不自动缩小已审本次数量。
6. 执行后只将本批根数从在库及预留未领占用转为本批在外未加工。原预留显示“已部分领料 · 未领继续占用”，列原预留／累计已领／未领／占用。各批单独保存，全部领完显示“已全部领料”，占用为0。

**余额和后续加工。** 每个原分配的未领＝原预留根数－累计已执行整单或分批领出根数；未释放时占用＝未领，释放后占用0。每批执行在库减少q、占用减少q，所以有效来源的可用数不会凭空增加。不同预留仍不能超占。两张草稿／已审单争用同一余额，执行先到者按当前余额记账，另一份须刷新核对；通过审定不保证未来可执行。任何一批领出后原预留不能再审、改配或整单释放，同材料表不能重新全量预留；仅已释放未领额可走15.17补料入口。

“已执行领料的未加工余额”分别显示每批及实际接收人。15.7投入加工／完整退回须引用对应已执行批单及原分配序号，只能用该批未加工未退余额；不能借另一批的数量。各批加工结果仍按15.8引用相应已执行投入单验收，核对额度不重复。完整退回增加在库，但不回补原预留未领额，也不重开原材料表需求。盘点15.14只保护当前未领占用，已领在外及加工数量保持；分批实际出库也会使旧盘点快照失效。

**释放未领余量。** 若部分领出后确认剩余不再领，在“排料预留记录”该行点击“释放未领余量”，核对弹窗“本次仅释放未领余量”的原预留／累计已领／仍占用根数及逐原分配、批号、释放根数，再填写当前原因及原件，点击“确认并记录原因”。仅编制角色可操作；原材料表失效或被修订也须按事实有据显式释放，不会自动释放。该操作不另做独立复核，沿用15.6释放操作的有据留痕规则，不替代已领批单审核。后台核对原对象、当前台账及逐项余量并冻结释放分配，追加事件。状态“未领余量已释放”，保留原预留、累计已领和未领历史，未领占用变0；在库、已领、加工及退回保持，未领部分不能再领。尚未领出任何一批用旧“释放整单预留”；已经全领完没有余量可释放。释放与剩余领料并发时按同一事务及版本门禁处理，不能两边都按旧数成功。

释放不是实物退回，不能用于冲销已领数量；已领原材仍可凭实际有效原件继续加工或完整退回，原已领数量不恢复为未领需求。原需求不变时已释放未领余量可按15.17另建补料预留，旧预留不重开。同材料表修订后补料、损耗追加、改定尺及领后跨账补料仍未实现；初次按已审定尺联合供应见15.19。

**失效、错误及留档。** 来源尺寸、材料表、原材审定或原件失效时，已领事实及未领占用保持，新分批领料阻断；可用新有效原件有据释放未领余量。历史某批交接原件失效保留该批在外／加工／退回及剩余占用，提示待核查；不把交接文件缺失当作退料。后续真实加工／完整退回可用新有效原件记录；原登记或盘点依据失效造成的整批隔离仍按原规则持续。字段错误、超量、旧预览、旧对象、台账过期或缺独立复核均不出库。库存JSON保存原预留及进度、各批输入和原件摘要、独立复核、执行／取消及未领余量释放事件；历史文件原字节不变（23.5）。原工程几何、排料、净量、清单、报价及审批不因领料改变。

### 15.16 余料分批领用、批单追溯及未领余量释放（v0.128）

**入口、角色与前提。** 在“图纸与算量 → 原材库存与预留 → 余料分批领用”点击“登记余料分批领用”。编制角色建立和显式执行，另一 reviewer 独立复核，提交人改角色也不能自审。来源包括15.9普通余料回用预留、15.18补料预留及15.19联合供应的余料侧预留。先建立并审定按实物定尺核定的余料预留，完整覆盖当前已审材料表需求；保存原申请即占用。原预留是供应及交接范围核定，不能仅凭原申请中的日期、领用人或确认推定全部原段已经领出，实际各批以独立执行事实为准。首次仍可在原预留执行旧“整单余料领用”，或使用本节分批入口；任何一批领出后原预留不能再整单执行、整单释放或重审。

**本次原件与字段。** 每批现场核对原余料编号／库位、材质截面、每段实测长度、每米质量及质量合格依据，准备实际交接原件。

| 字段 | 填写要求 |
| --- | --- |
| 当前已审未领完余料预留 | 明确选择本项目原预留单号，核对材料表版本。原申请须有效独立审定，排料来源及依据有效，未领余料组未停用且验收及盘点依据有效。 |
| 原预留分配及本次实际交接根数 | 沿用原分配序号，每项1～1000000正整数且不超过本项未领数；每单1～100条不同分配，可增加／移除。初值留空，不从原根数推定实际交接。不能借其他分配、改长、拼接或按总长替代。可一次领完全部剩余。 |
| 实际交接日期 | 不晚于今天的YYYY-MM-DD，且不早于原预留核定日期；初值留空，按本批原件填写。 |
| 本批接收人或班组 | 最长200字，每批单独填写，不默认原预留接收人就是本批接收人。 |
| 本批实际交接说明及原件 | 最长2000字，说明本批根数及实际交接范围，选当前有效证据。原文件字节在预览、保存、复核、执行均须可核验。 |
| 实物确认 | 确认完整余料原段本批确已交接，不把计划当实物，未领部分继续占用。 |

**从预览到执行。**

1. 选择原预留，逐项核对分配序号、余料编号、定尺和未领余额，填写本次实际根数、交接日期、接收人、说明与原件，勾选确认。
2. 点击“核对余料分批预览”，核对原预留单号、本批各原分配、编号／库位、材质截面、段长m／每米质量kg/m、根数、长度m及质量kg。长度＝段长×本批根数，质量＝长度×每米质量，精确累计，不是安装净量或损耗。
3. 点击“保存余料批单待复核”，只存本批草稿，不新增预留，也不改变在库、未领占用或在外数量。任何字段、来源、证据或确认修改后预览清除，须重新预览。多份草稿和已审未执行批单竞争原预留未领额，不额外锁定一份。
4. reviewer 在独立批单行点击“独立复核余料批单”，核对原预留、逐分配数量及原件并签署。通过、拒绝、待补件均不出库；未执行可填新原因／原件“取消未执行余料批单”，不释放原预留。
5. 编制账号刷新后点击“执行余料分批领用”，核对本批明细再“确认本批已交接并记账”。后台再次核对来源、审核、预览绑定、原件、原分配未领余额、对象及整体台账版本；任何失败整批不执行，不自动缩小已审数量。
6. 原预留显示“已部分领用 · 未领继续占用”，列原预留／累计已领／未领／占用；本批显示“本批已领出”及独立单号。本次在库减少q、未领占用减少q、该批在外增加q，有效可用不会凭空增加。全部领完原预留显示“已全部领用”，未领及占用0。该状态不是一张额外领用单。

**批单与后续关联。** 原预留只管理需求和占用，独立批单才是本次实际领用来源。15.10原段退回、15.12实际投入、15.11直接完整再加工均明确选择对应已执行批单，按其原分配序号及未加工未退余额操作；下拉项包含单号以区分同材料表、同日、同接收人的不同批次。选原分配2不会重编号为1；不能从另一批借根数。部分或全部分批领出后，原预留本身不可冒充旧整单来源。已实际投入后结果须引用本批关联投入单，不能绕回直接模式；本批1根不能因为原预留有2根就退2、投2或验收2。旧已执行整单领用仍可作为来源，旧单号、字段和历史不重写。

原段退回仍回原编号／原库位，完整退回不回补原预留未领额度，不重开已领材料表。再加工子余料仍按实测独立验收入库，追溯父余料、原领用批单及对应投入；新旧来源可以在各自流程使用，不互借数量。库存守恒沿用15.13：原验收＋累计盘盈－累计盘亏＝在库＋在外未加工＋在加工待验收＋已验收加工原段；新批单只改变本次在库和在外，不制造余料。未释放时占用＝各原分配原预留根数－累计已领根数，原段退回不加回此占用。盘点只保护当前未领占用，实际分批出库使旧盘点快照失效。

**释放未领余量。** 部分领出后确认剩余不再领，在原“余料按定尺回用”预留行点击“释放余料未领余量”。核对“仅释放尚未领出的余料”中原预留／累计已领／未领占用及逐分配、编号、库位、释放根数，填当前原因和原件，再“确认仅释放未领余料”。仅沿用原有有据释放的权限及留痕规则，不另做独立复核，不替代已领批单审核。执行冻结逐项余量并追加事件，原预留显示“未领余量已释放”，占用0，保留累计已领及未领历史；在库、各批已领／加工／退回事实不变。未领任何一批用原整单“释放余料预留”，已全部领出没有未领可释放。余量释放与领用竞争同一版本和余额，不能按旧数两边都成功。

已经领出后，即使余量已释放、原段全部退回或原材料表修订，也不能重新全量预留同材料表，不能借整单释放或第二份普通回用申请绕过已领历史。原需求不变且已显式释放的未领额可走15.18另建余料补料预留；修订及损耗追加、改定尺、执行冲销和跨项目调拨仍未提供；初次按已审定尺联合供应见15.19。

**失效、常见错误和留档。** 排料或原预留证据失效，已领事实及未领占用保持，新批单预览／审定／执行阻断；可凭当前有效原件有据释放未领余量。已领批单交接原件失效不回滚数量，提示待核查，实际退回或加工仍可凭新有效实测／交接原件记录；新加工子余料的采用还检查本批交接、投入及实测原件，依据失效保留数量但可用0，恢复原字节后再核验。原验收、原段退回、盘点及祖先依据失效造成的隔离沿用原规则，不用新批单清除异常。超量、空白根数、重复或错误原分配、未来／早于原预留日期、原单对象或台账过期、缺原件或独立复核均不出库。累计超领、批单／原预留关联、原件封存内容、取消或余量释放顺序无法核验时阻断读账与新导出。

库存JSON增加原预留进度、独立余料批单输入／冻结分配／原件摘要／审核及执行／取消／余量释放事件；旧下载原字节不改写（23.5）。预览、复核及实物记账不修改工程几何、原排料、净工程量、清单、报价或既有工程成果审批。原预留和批单仍为分组数量台账，不代表逐段身份、仓库扫描或采购系统。

合成例：原余料3574mm×2、3kg/m，有效预留2根。在库2／占用2／可用0；首批领1后在库1／占用1／可用0／在外1。可继续第二批领1；若首批后有据释放未领1，则在库仍1／占用0／可用1／在外仍1，绝不是退回首批。[合成独立批单预览](qa/v0.128-offcut-batch-preview.png)、[首批领出未领继续占用](qa/v0.128-offcut-batch-issued.png)、[退回预览引用实际批单](qa/v0.128-batch-return-preview.png)、[未领释放而批单保持已领](qa/v0.128-offcut-remainder-released.png)。退回截图仅预览，未保存或执行，不表示实际退回。所有示例和截图仅验证软件，不代表真实仓库、材质鉴别或工程验收。

### 15.17 完整原材已释放未领余量补料（v0.129）

**入口、角色和前提。** “图纸与算量 → 原材库存与预留 → 原材未领余量补料”，点击“核定原材余量补料”。编制人、负责人或管理员建立新预留，另一 reviewer 独立复核；之后实际领料仍按15.7或15.15另建、复核和显式执行。原预留须已经部分领出，并按15.15有据释放全部未领余量。原材料表、来源及完整排料需求须仍有效且与最初预留一致，上游释放原件仍有效且原字节可核验。未释放、已全部领完、仅完整退回、仅未领整单释放或余料预留均不是本入口来源。

这是原需求额度内重新核定供应，旧预留不修改、不恢复占用。只取所选上游释放事件冻结的逐需求未领根数；已经领出、在外、退回或加工的数量均不补额度。可换同材质截面、同定尺和同每米质量的当前已审完整原材批次，也可重新核查后仍用原批次；系统不凭编号或总长自动判断材质合格。每项本次需求已包含最初来源重复数量，不再倍乘。

**原件、字段和单位。** 准备原余量不再从旧分配领用的释放凭据、本次替代供应兼容性凭据及新批次实物登记原件。

| 字段 | 填写口径 |
| --- | --- |
| 已释放未领余量的原材预留 | 下拉只列当前可核定者，按单号辨认；后台绑定原预留、释放事件及其快照。台账表保留不可用来源并显示原因和已有补料单号。 |
| 本次未领需求 | 只读名称、规范定尺m、每米质量kg/m及根数；不能改成原全量或借用另一需求额度。 |
| 新的实物批次及根数 | 每项1～1000000正整数，共1～100条分配。按需求逐项恰好覆盖未领数量，可拆到多批，但同需求同批次不得重复；定尺和每米质量精确相等，库存须足额且当前有效已审。 |
| 补料兼容性与核查说明 | 最长2000字，说明上游已领和释放范围、本次未领额度、供应变更及同材质截面核查。关联当前原件。 |
| 兼容性确认 | 据原件确认同材质截面、定尺和每米质量且未重复占用；该确认不代替专业检查。 |

**预览、保存和独立复核。**

1. 选择上游预留，核对仅本次未领需求及释放依据。选择实际新批次，填写各根数；必要时“增加补料批次分配”，逐项合计精确覆盖。
2. 填说明、原件并确认，点击“核对补料预览”。核对上游预留和释放单号、释放原件、各需求、本次新批号／库位／材质截面、定尺m／每米质量kg/m、根数／长度m／质量kg，以及新兼容性原件。长度＝定尺×根数，质量＝长度×每米质量，精确累计；不是净安装量、损耗或采购金额。
3. 预览不占用。修改任何输入或选择来源会清除预览，须重新核对。点击“保存补料预留并占用”，后台重查原件、当前需求、来源链、足额库存、预览及整体台账版本，在一次事务建立独立草稿预留并立即占用新批次；旧已领与释放事件保持。保存后在“排料预留记录”查看，展开“未领余量补料及上游释放依据”。
4. reviewer 在新预留行点击“独立复核预留”，核对弹窗里的上游／释放依据、本次需求、规范新供应分配及说明原件后签署。作者改角色也不能自审。拒绝、待补件、来源失效仍保留新占用，须另填当前原因和原件显式释放。
5. 审定后按新预留建立整单或分批领料单，核对实际交接日期、接收人、原件，再由另一账号复核并显式执行。独立复核预留本身不出库。后续加工或完整退回引用对应新实际领料批单，不能引用已释放旧预留或挪用旧批余额。

**重复、链路和余额。** 同一上游已释放未领额同一时点只能有一份补料预留。未发生任何领出前，可有据整单释放该新预留，再从同一上游重新核定；旧新预留及释放历史都保留。一旦新预留有领出，即使全部原长退回，也不能回上级取同一额度。若新预留又部分领出并释放自己的未领余量，只能选这份最近预留继续补料，最多20级；不能从祖先分叉取额。界面会保留祖先不可用原因和子单关联。

合成例：原需求3根、6m／3kg/m，旧批领1后释放未领2；旧批在库9／占用0／在外1。新批登记10根，补料预览2根／12m／36kg，预览仍可用10；保存后新批在库10／占用2／可用8，审定仍相同，执行新领料2后新批在库8／占用0／在外2，两批累计已领恰为3。若新补料只领1再释放未领1，下一级最多补1；退回其中任何已领根都不恢复原需求额度。示例仅为合成软件核查，不代表真实仓库交接、材质、采购或工程验收。

**错误、失效和留档。** “已有补料预留或后续领用”先核查已有子单，不能反复保存；“原材料表或完整排料需求已变化”须另行核定业务范围，本功能不支持修订后额度；“可用不足”核查新批其他占用和流转；文件缺失／替换、来源不匹配、旧预览或台账过期须刷新及核查。任何失败不新增占用或出库。原件后来失效保留既有已领事实与新未领占用，禁止新的补料和领料；可凭新的当前原件显式释放未领占用，不能靠删除资料回滚数量。历史链快照被破坏时，读取／导出也会阻断，须保留异常核查，不改数据库伪造关系。

库存JSON（23.5）追加每份补料原始输入、上游预留及释放快照、缩减后的本次需求、新供应规范分配与精确总量、原件摘要和预览关联；复核及后续实际领料沿用独立记录与事件。历史导出保持原字节，当前余额重新导出。工程几何、最初排料、净量、清单、报价及审批均不因补料改写。旧项目无补料时不补造历史记录。

本入口不覆盖联合供应计划补料、修订后补料、损耗追加、已加工／退回数量重新取额、改定尺、采购、跨项目共享或已执行冲销；也不自动优化原排料或计采购成本。

### 15.18 余料已释放未领余量补料（v0.130）

**入口、角色与前提。** “图纸与算量 → 原材库存与预留 → 余料未领余量补料”，点击“核定余料余量补料”。编制人／负责人／管理员建立和释放新预留，另一 reviewer 独立复核；实际领用另走15.16独立批单。上游须是本项目已部分领用且按15.16显式释放全部未领余量的余料预留。最初材料表及完整排料需求须仍有效且不变，释放链全部原件有效且原字节可核验。尚未领、未释放、全领完、仅原段退回或仅未领整单释放均不产生本入口额度。

只按释放事件冻结的逐需求未领根数重新核定余料供应，原预留不改配、不重开占用，已领、在外、原段退回和加工数量不恢复额度。新供应可使用另一组或重新核查后仍用原组当前有效可用的已验收余料；每段实测长度和每米质量须与原需求精确相等，材质截面及质量合格须据原件确认。不能用总长拼接或换定尺。各需求已含最初来源重复数量，不再倍乘。

**资料与字段。** 准备上游释放凭据、当前余料验收与盘点资料，以及本次兼容性核查原件。

| 字段 | 填写口径 |
| --- | --- |
| 已释放未领余量的余料预留 | 下拉只列可核定者，按单号辨认。表中同时保留不可用原因、释放事件号和已有补料子单号。后台绑定上游、释放及未领需求快照。 |
| 本次未领需求 | 只读名称、段长m、每米质量kg/m和根数，只覆盖已冻结的未领额。 |
| 新的实物批次及补料根数 | 选择本项目已实测验收、未停用且来源及盘点有效的余料组。每项1～1000000正整数，共1～100条，逐需求恰好覆盖，可拆到多组；同需求同组不得重复。不可选完整原材、借其他需求、改长度或质量。 |
| 余料补料核定日期 | YYYY-MM-DD，不晚于今天，不早于上游预留核定日期；初值留空，按核查凭据填写。**不是实际交接日期。** |
| 余料补料拟交接对象 | 最长200字，说明拟供应对象；不创建账号或推定实物已交给此人。实际各批仍须按交接凭据单独填接收人。 |
| 兼容性与核查说明、原件和确认 | 最长2000字，说明上游已领／释放、本次剩余、余料编号及库位、同材质截面及质量合格、实测段长和每米质量一致，确认未重复占用。凭据须当前有效且原字节可核验。 |

**操作、预览、保存与复核。**

1. 选择上游预留，核对释放依据及仅本次未领需求，选择新余料组，填各根数；必要时“增加补料批次分配”，逐需求合计恰好覆盖。
2. 填核定日期、拟交接对象、说明及原件，勾选兼容性确认。点击“核对补料预览”，核对上游／释放单号及释放原件、需求、新余料编号／库位／材质截面、规范段长m、每米质量kg/m、根数、长度m和质量kg。长度＝段长×根数，质量＝长度×每米质量，精确累计；不是安装净量、损耗或采购金额。
3. 预览不占用。修改任何输入清除预览并禁用保存，须重新核对。点击“保存补料预留并占用”，后台重查整条释放链、原需求、全部原件、规范分配、足额可用、预览和整体台账版本，在同一事务新增独立草稿预留并立即占用；不出库，原预留和各批历史保持。
4. 在“余料按定尺回用”表查看新预留，展开“回用明细与原件”可看上游释放及新供应。reviewer 点击“独立复核回用”，核查补料核定日期／拟交接对象与全部来源和新分配后签署。通过不出库；拒绝、待补件或来源失效继续占用。作者改角色也不能自审。
5. 实际交接时，必须点击15.16“登记余料分批领用”，选新补料预留，按其分配序号填写本批真实根数、日期、接收人和原件，预览、保存、另一账号独立复核，最后显式执行。可在一个批单领完全部本次量。补料记录没有旧“执行整单余料领用”按钮，后台也阻断直接整单执行；核定日期／拟交接对象不能代替实物交接确认。
6. 执行只把本批未领占用转为该批在外数量。后续原段退回、投入或再加工及结果引用这张实际批单，不能拿补料预留本身作已领来源，不能借上游旧批的余额。原段退回仍回原编号及库位，不恢复未领额度。

**重做、逐级补料与失效。** 同一上游额度同一时点只允许一份补料预留。新预留尚未领出时可填当前原因及原件整单释放，再从同一上游重新核定，历史保留。有领出后不能回祖先重复取额；只有本子单部分领出并有据释放自己的未领额时，才可选此子单继续，最多20级。拒绝或文件缺失不会自动放回占用。来源修订、原需求变化、释放原件失效、旧预览或台账过期阻断新增；原件失效仍保留已领、在外、加工和未领占用，可凭新当前原件有据释放未领部分。历史链快照被破坏时读账及新导出也会阻断，须保留异常核查。

祖先释放原件后续缺失时，既有补料已领记录提示待核查，数量保持；对应批单加工生成的新余料及后代待核查、可用0，不能以新的结果凭据绕过缺失的补料额度依据。原实物余料组若自身验收及盘点仍有效，不因另一张释放文件丢失而回滚数量；恢复原字节后按当前状态重新核查。原工程、最初排料、净量、清单、报价和审批不随补料改写。

合成例：上游预留原段3574mm×2、3kg/m，旧组已领1，释放未领1。另一组独立验收同规格1根，补料预览1根／3.574m／10.722kg，保存及审定仅新组占用1；另建实际批单执行后新组在库0／占用0／在外1，旧组仍在外1，累计恰为原需求2。若另一例原需求3，先领1释放2，新补料又领1释放1，下一级最多补1，不能回祖先再补2。仅合成软件验证，不代表真实仓库、材质、采购或工程验收。

**常见错误及留档。** “已有余料补料或后续领用”先查子单，不能反复提交；“原材料表或完整需求已变化”不支持沿旧额补料，须核定范围；“新余料可用不足”查其他预留、在外及停用；“实际交接日期早于原预留核定”应核对两张凭据，不虚构日期；“须另建余料分批领用单”使用实际批单入口。任何失败不占用或出库。库存JSON（23.5）保存原始补料输入、上游及释放快照、本次缩减需求、新余料规范分配、精确总量、预览与原件摘要、独立复核及后续批单和事件；旧导出原字节保持，当前余额需重新导出。旧项目没有补料时不补造历史。

本补料入口不支持联合计划补料、修订或损耗追加、改定尺、跨账补料、采购、跨项目、已执行冲销或自动优化排料；初次按已审定尺的联合供应见15.19。本次为在原额度内核定供应，不是采购入库或真实验收证明。

### 15.19 原材与余料按已审定尺联合供应（v0.131）

**入口、角色和适用范围。** “图纸与算量 → 原材库存与预留 → 原材与余料联合供应”，点击“核定原材与余料联合供应”。编制人／负责人／管理员建立预留；另一 reviewer **分别签署两侧预留**。两侧均有效审定后，原材按15.7／15.15独立实际领料单整单或分批，余料按15.16独立实际批单领用；实际单据仍各自独立复核并显式执行，不能凭联合核定即出库。

适用于原材料表已经按实际可用定尺编排且审定，完整原材及余料分别符合相应定尺、每米质量，同材质截面且余料质量合格的情况。两侧均须有供应，可以共同覆盖同一项，也可分别供不同需求；逐需求“原材侧根数＋余料侧根数＝原完整需求”。不是把长料按总长抵短料，不更改原排料、不自动择优替换、不拼接或追加原需求。只有单类供应时使用原普通入口。

**前置资料、字段及单位。** 本项目须有当前有效已审完整原材登记和已实测验收的余料，来源、验收及盘点原件有效，库存足额。原材料表不能已有其他未整单释放的普通／联合预留或任何已领历史；已领后完整退回不重开需求。先核查旧范围，不通过新建联合单绕过。

| 字段 | 填写口径 |
| --- | --- |
| 联合供应排料材料表 | 当前已审材料表，读取完整需求及来源版本；仅已启用排料的项，已含来源重复数量，不再倍乘。 |
| 原材侧分配 | 本次原需求、完整原材登记批次、正整数根数。定尺m／每米质量kg/m精确匹配该需求；仅已审有效可用批次。 |
| 余料侧分配 | 本次原需求、已验收余料组、正整数根数。实测每段长m／每米质量kg/m精确匹配；不得选完整原材、计划余料、停用或待核查余料。 |
| 两侧数量 | 每条1～1000000正整数，两侧均至少一条，合计最多100条；同需求同侧同批次不可重复。逐需求合计恰好覆盖，不能借另一需求根数补差，可增加／移除本侧分配。 |
| 联合供应核定日期 | YYYY-MM-DD，不晚于今天，初值留空，按核定凭据填写；不是实际交接日期。实际两侧单据日期不得早于核定日期。 |
| 联合供应拟交接对象 | 最长200字，仅核定拟供应对象；不创建账号，不代替两侧实际批单的接收人。 |
| 兼容性核查说明、原件及确认 | 最长2000字，说明完整原需求、两侧分配范围及未重复占用，关联当前核定原件；据原件确认同材质截面、余料质量合格、定尺和每米质量相等。确认不代替专业鉴别。 |

**预览与同次保存。**

1. 选择材料表，核对只读原完整需求。分别选择原材和余料需求／批次，按实际核定填写根数，必要时“增加原材侧分配”／“增加余料侧分配”。原材批次与余料组分别选择，不串账。
2. 填核定日期、拟交接对象、说明及原件，确认后点击“核对联合供应预览”。逐需求核对原需根数＝两侧根数之和，再看两侧每项批号／库位／规格／定尺／每米质量、根数、规范总长m及质量kg。长度＝定尺×根数，质量＝长度×每米质量，精确累计；两账总量仅为本次供应量，不是安装净量、加工完成量或采购金额。
3. 预览不占用。修改任何输入清除旧预览并禁用保存，重新核对。点击“同次保存并分别占用两侧”，后台重查完整需求、原件字节、两侧库存、预览和整体台账版本，在**一个事务**保存联合关联单及两侧预留并立即分别占用；任一项不足或失败都不保存，不留下只占原材的半份申请。
4. 联合表列联合单号、两侧预留单号及状态、累计实际领出／未领占用。展开“联合供应完整需求与两侧明细”查看完整需求和两侧快照；两份预留也分别在原有“排料预留记录”和“余料按定尺回用”表显示。联合关联单是不可改写的范围和分配记录，本身不等于专业审定。

**分别复核与实际领用。** reviewer 在联合表点击“独立复核联合原材侧”和“独立复核联合余料侧”，分别核查完整需求、两侧分工、对应实物及兼容凭据，并签署本侧；原表的独立复核入口也保留同一联合明细。作者即使改角色也不能自审。仅一侧通过时两侧均不能办理实际领用；拒绝、待补件或资料失效保留双方未领占用，不自动释放另一侧。两侧审定不出库。

两侧均审定后，编制账号在原材实际领料入口选择原材侧预留，或在“登记余料分批领用”选择余料侧预留，分别填本次真实日期、接收人、根数和原件，按原分配序号预览（分批入口）、保存、另一账号复核及显式执行。余料侧没有直接“执行整单余料领用”按钮，后台也禁止用核定日期或拟对象冒充实际交接；一张独立批单可领完余料侧全部根数。

执行只改变本侧在库、未领占用及对应实际批单在外数量，另一侧保持原余额。任一侧首次实际领出后，**双方预留均不可重审或撤销原审批**，保持历史关联；另一侧仍可在来源及双侧原审定有效时按原分配继续领出。后续退回、投入和结果分别引用本账实际批单，不以联合单或另一侧批单替代，原分配序号按本侧原预留。原材和余料的原段规格、退回及加工结果沿用各自规则，不相互借数量。

**释放、失效、重做与留档。** 未领或不再领的范围分别在原材预留／余料预留对应行有据释放：未发生本侧领出用整单释放，本侧已部分领出用未领余量释放。释放只解除本侧尚未领出的占用，不自动解除另一侧，也不表示退回已领。即使单侧被拒或来源失效也须分别核查并显式释放。仅两侧都从未领出且均整单释放后，可按当前完整需求重新建立联合或普通预留，旧记录保留；任一侧已领过，后续全部退回也不能重新全量核定。部分领出后释放未领范围不制造补料额度，联合计划暂不支持15.17／15.18单侧补料。

原完整来源或兼容原件变化、任一侧未领实物停用／验收或盘点失效，均阻断新的实际领用，既有数量及占用保持；可凭当前有效新原件分别释放。联合核定依据后续丢失时，已领及已加工事实不回滚，关联余料批单加工子余料和后代待核查、可用0；恢复原字节后按当前状态重查。原材批次或原余料组自身失效的隔离仍沿用15.6～15.18，不能借另一账绕过。

“合计须恰好覆盖”核查每个需求的两侧根数，不能只看总长；“已有普通或联合预留”核查旧单及是否曾领出；“两侧须分别有效独立复核”完成另一侧审核，不能代签；“原件／需求变化”先核查，不能通过重复保存解除旧占用。结构性联合关联、子单、分区、需求或预览快照破坏会阻断读账与新导出，保留异常，不改数据库凑数。

## 16. 立柱基础、孔洞与模板

### 16.1 独立基础来源与数量

前提：已审栏杆材料表中有最终立柱项。

1. 在“栏杆立柱独立基础”选择已审材料表并读取最终立柱。
2. 明确本次选入哪些立柱项，填写矩形、实心圆柱或同心台阶基础尺寸、材料和依据。
3. 每根选入立柱对应一个独立基础，继承加柱和移柱后的最终数量，重复只乘一次。
4. 台阶逐层核定净高，层间同心、同轴、紧接且不外伸。
5. 预览每基础毛体积、扣减、净体积及全部数量，再送审。

单项全部基础应使用同一做法和尺寸；存在差异先拆分来源。同一来源立柱项不能被多个基础记录重复选入。定位承载、钢筋、土方及基础间交叠另核。

### 16.2 竖直孔洞与计量阈值

按真实原件逐孔录入圆孔或轴向矩形孔／凹槽，填写相对基础中心的 XY、孔尺寸、起止 Z 及依据。Z 从基础底面 0 向上；可按支持条件贯通或限定标高。

预览分别核对：基础毛量、实际孔洞体积、计量扣减及净量。有据单孔阈值目前按单指标“大于／大于等于”判断，符合全扣、不符合不扣。**计量上不扣孔，不等于物理孔被填实**；模板仍根据真实孔洞计算。

不支持的旋转／斜孔、异形或变截面孔、孔洞重叠并集，应另建适用专业模型，不能用近似输入冒充已完成。

### 16.3 基础外侧模板

选择已审基础，读取真实竖直侧面，按基础项、层、侧向及 Z 范围选择接触范围。

- 矩形基础：X 沿基础长、Y 沿基础宽，逐侧选择整宽或有据横向条带。
- 圆柱基础：选择本层整周或有据局部圆弧，核对角度方向及范围。
- 范围应在选定层内，跨层分别列项；扣除实际侧开口。
- 未选面不计，不默认贴土面支模。同面重复范围会被拒绝。

填写材料做法、每个接触范围依据及总体说明，确认后预览并保存。外侧模板不包含孔壁、孔底、顶底和台阶水平面。

### 16.4 基础孔壁模板

先读取已审基础孔洞。矩形孔逐侧选整宽或横向条带；圆孔选整周或局部圆弧。圆孔角度以该孔圆心为原点，零角沿基础 +X，从 +Z 俯视逆时针；Z 和 XY 正向继续沿来源基础。

范围必须位于当前层和孔的共同标高内，跨层分项。按实际边界扣除与外侧或相邻孔贴合的无接触面。体积阈值不影响真实孔壁。此工具不计孔底、孔顶或其他水平面。

### 16.5 基础水平模板：完整操作

入口：“图纸与算量 → 基础水平模板 → 建立水平模板”。

1. 选择已审基础，点击“读取已审水平接触候选”。
2. 填写模板名称、材料及施工做法、实际水平接触与不重复计量说明，分别选择原件。
3. 按依据选择总净面积修约位数，并关联修约依据。
4. 点击“增加水平接触端面”，选择来源基础项及具体端面。
5. 核对页面只读显示的来源版本、层尺寸、Z、孔和继承基础个数。
6. 需要局部范围时，勾选“按原件选取XY矩形局部窗口”，按下一节填写。
7. 填写每项接触范围名称、实际接触及孔扣减说明、来源。
8. 核对后勾选总体接触范围确认，点击“预览水平模板”。
9. 核查逐项毛面积、孔扣、净面积、全部个数、总量及修约，再“保存并送审”。
10. 独立复核人点击“水平明细与独立复核”，展开接触原件、孔交集及解析过程。
11. 构件通过后重新计算工程量、复核计算书，再生成或核对清单及成果。

| 端面 | 当前计量口径 |
|---|---|
| 整体顶部 | 最上层顶面，扣在该面实际开口的孔 |
| 整体底部 | 最下层底面，扣在该面实际开口的孔 |
| 台阶平台 | 下层截面减紧邻上层覆盖，孔仅扣外露平台内部分 |
| 内部孔底 | 取孔起 Z 下侧混凝土层与所选孔的交集，再扣同侧相接孔 |
| 内部孔顶 | 取孔止 Z 上侧混凝土层与所选孔的交集，再扣同侧相接孔 |

通向外部的孔口不生成内部孔端。没有实际接触的面不应因几何存在就计模板。

### 16.6 XY 矩形局部窗口（含 v0.106 孔端窗口）

整体顶部、底部、矩形及圆形台阶平台、内部孔底与孔顶均可按支持条件使用轴向 XY 矩形窗口。

填写窗口单位、X 起／止、Y 起／止，并为四个坐标分别选择原始依据；另填共用 XY 基准说明及原件，完成窗口坐标确认。

**窗口原点始终是基础中心，不是所选孔中心；与来源孔位共用正向，不随俯视或仰视翻转。**

- 顶底窗口：只计窗口与真实端面的交集，并扣窗口内实际孔。
- 平台窗口：先扣窗口中上层覆盖，再扣外露平台内实际孔，不能直接扣完整孔截面。
- 孔端窗口：毛量为“所选孔 ∩ 混凝土侧层 ∩ 窗口”；孔扣为“所选孔 ∩ 同侧相接孔 ∩ 窗口”。另一侧投影孔不扣。
- 孔底相接孔标高条件为“起 Z＜孔底 Z≤止 Z”；孔顶为“起 Z≤孔顶 Z＜止 Z”，边界不可随意互换。
- 同来源、同基础项所有窗口使用一致的 XY 基准说明和证据。
- 同孔同端面的整面与窗口不能重复并计；X/Y 都有正重叠的窗口会被拒绝。只共享边界可分项，不同孔或不同端面分别核对。
- 每个范围继承全部基础个数一次，逐项不先行修约，仅总净面积按依据修约。

圆弧交集会显示分段积分及完整精度。多孔完全覆盖孔端窗口时，系统保留完整覆盖证明和各孔直接积分，不靠容差将小正面积改成零。复核人应展开原件及证明核查，不能只看最终三位小数。

更改窗口会撤销确认。来源修订后，旧模板失效；重新读取会清空旧范围、材料、原件、修约和确认，需重新填写。

### 16.7 凸多边形、旋转矩形与斜边窗口（v0.107）

适用角色：编制人员创建／修订，独立复核人员核对并审定。前提为当前已审立柱基础及其尺寸、孔位、标高和最终数量；还须有窗口各顶点设计坐标、共同XY基准、实际支模范围、材料做法和总面积修约的原始依据。

入口：“图纸与算量 → 基础水平模板 → 建立水平模板”，读取已审来源后选择整体顶／底面、矩形或圆形台阶平台、内部孔底／孔顶。勾选“按原件选取XY局部窗口”，将“窗口轮廓”改为“凸多边形（含旋转矩形、斜边）”。

1. 选择独立的窗口坐标单位（mm、cm、dm、m或km）。单位不必与基础尺寸相同，X和Y均使用该单位。
2. 沿实际边界顺时针或逆时针依次输入3～12个顶点的XY坐标，逐坐标选择原件。默认4点，可增加或移除末尾顶点；末点到首点自动闭合，勿重复填写首点。
3. 旋转矩形输入四个角的真实坐标。系统按所填轮廓计量，不自动从旋转角、屏幕图形或估计长宽生成角点，也不宣称所填四边形已经过直角核定。
4. 填写与来源孔位共用的基础中心、X/Y正向和依据，核对后确认窗口，再填写接触说明、材料和修约依据并确认总体范围。
5. 点击“预览水平模板”。复查按边界顺序的规范米制顶点、轮廓面积、实际毛交集、孔扣、净量及全部基础数量；显示的X/Y起止只是外包边界，不是实际裁切矩形。
6. 展开“曲线交集解析过程”核查窗口实际毛交集和直接净接触分段。核对真实孔Z条件，平台排除紧邻上层完整名义截面，内部孔端沿用孔底下侧／孔顶上侧规则。
7. 保存并送审。独立复核人员在“水平明细与独立复核”查看逐顶点依据、共同基准、解析分段和孔扣，不只看最终显示小数。通过后重新计算工程量、复核计算书，再核对清单并重新计价／导出。

**合成示例，仅用于软件说明：**窗口单位mm，顶点P1(-100,0)、P2(0,-100)、P3(100,0)、P4(0,100)，为绕基础中心的旋转正方形，轮廓面积0.020m²。这个面积不是最终模板工程量；仍须与所选真实截面、平台或孔端相交，再扣实际孔并继承基础个数。

同端面凸窗口与另一凸窗口或旧XY矩形窗口按边的法向分离轴检查。即使外包矩形重叠，只要实际窗口分离或仅共享边界，仍可分项；任何极小正面积重叠、包含或整面与窗口并计均阻断。检查使用整个窗口轮廓，实体以外或孔内的窗口重叠也不允许借此重复登记。跨记录使用同样检查，同来源基础项各端面继续要求相同XY基准及原件。

独立积分会保留未修约的直接净接触面积。若所有边界分段扣除上层及实际孔后确无剩余接触，保存零接触分段见证，以“毛面积减其他孔扣”分割恒等式核定最后一孔实际扣减；各孔直接积分仍保留，不按容差将小正面积抹成零。

出现完整覆盖时，在预览或复核明细展开“凸窗口零接触分段覆盖校验”，逐段核对X起止、中点、毛接触上下边界、各覆盖轮廓及其上下值，确认每段扣除后剩余为0段。中点用于检查已按全部边界交点分段后的边界次序，不是用抽样估算面积；完整公式依赖仍由JSON保存。零接触计算结论不能代替原件和真实支模核查。

JSON保留输入、尺寸、原件、逐段AST、净接触分段见证及有序的`window_expression_definitions`。独立重放时先从原始维度按序重算200位中间定义，再计算分段和总量，不能只信任存储的中间值；Excel／PDF按需新增“基础凸窗口顶点”“基础凸窗口分段积分”，存在完整覆盖时另有“基础凸窗口零接触校验”。新数据沿用现有版本、来源失效及留档流程。修改坐标、单位、轮廓或顶点数量会撤销确认并清除旧预览；来源修订后重新读取会清空旧范围及依据。旧整面及旧矩形窗口无需转成新轮廓。

### 16.8 简单多边形与凹窗口（v0.108）

适用角色：编制人员创建和修订，独立复核人员检查原件及计算明细。前提与16.7相同：已审基础、明确的全部基础个数和孔洞、真实窗口顶点坐标、共同XY基准、支模做法及修约依据。

入口：“图纸与算量 → 基础水平模板 → 建立水平模板”。读取已审来源，选取顶面、底面、台阶平台或内部孔端，勾选“按原件选取XY局部窗口”，将轮廓选择为“简单多边形（含凹形、L形、U形）”。本模式也接受满足条件的凸轮廓，原凸窗口模式保留。

1. 选择坐标单位，按实际边界顺序录入3～12个顶点，顺时针或逆时针均可；首尾自动闭合，不重复录入首点。
2. 用“增加末尾顶点”及“移除末尾顶点”调整点数，分别关联每个X/Y坐标的当前原始依据。
3. 明确基础中心和XY正向，填写共同基准及依据。凹口是窗口外部，不能把外包矩形作为实际范围。
4. 核定真实接触、材料、修约及逐范围说明，确认窗口和总体范围，点击“预览水平模板”。
5. 核查顶点、轮廓面积、毛接触、各孔扣减和总净量。凹窗口在同一X区间可以有多个内部纵向片段，系统分别裁切并积分，片段之间的空区不计入。片段号只用于当前X分段及当前计算对象的上下次序核对，不代表独立构件或施工分区。
6. 展开解析明细；若出现严格零接触，展开“凹窗口零接触分段覆盖校验”，检查每个片段的上下边界和覆盖后剩余段数。任何一片段有正面积缝隙都不能形成完整覆盖证明。
7. 保存并送审，由独立复核人员检查原件、共同基准、凹口、多片段及孔洞标高口径。通过后按既有流程计算工程量、复核计算书、核对清单并重新计价及导出。

**合成说明示例：**单位mm，依次输入(-100,-100)、(100,-100)、(100,-40)、(-40,-40)、(-40,40)、(100,40)、(100,100)、(-100,100)，为开口向右的C形窗口。轮廓面积0.0288m²；当X在-40～100mm之间时，下、上两个内部片段之间的凹口不计面积。最终模板量还须与真实截面、平台或所选孔端相交、扣实际孔，并继承全部基础个数，不能直接拿0.0288乘数量交付。

防重复计量采用精确有理数的竖向扫描，检查完整窗口轮廓，而非仅检查外包矩形。另一窗口完全落在凹口空区可以分项；只共边或点接触可以分项；正面积重叠或包含仍会拒绝，跨记录同样检查。凹窗口与旧矩形、凸窗口混用时也适用。所有窗口继续使用相同基础中心和共用XY原件，不能借不同坐标基准规避防重。

新增JSON保留原始输入、有序表达式、多个纵向片段、覆盖见证和防重分段；Excel/PDF按需增加“基础凹窗口顶点”“基础凹窗口分段积分”“基础凹窗口零接触校验”，存在相关窗口对时另有“基础凹窗口防重分段”。防重表左右内部片段分别对应表中窗口对的第一个、第二个C编号；分数为精确米制有理数，不是显示修约值。旧整面、矩形及凸窗口的计算规则和历史文件保持各自版本。

常见错误：自交、非相邻边或顶点接触、重叠边、重复点、相邻三点共线、非法单位、缺原件或未确认会阻断。系统不自动排序、修形或填补凹口。修改轮廓、坐标、单位或点数会撤销确认及旧预览；来源变化后需重新读取和填写。

### 16.9 带内孔的多边形窗口（v0.109）

适用角色：编制人员建立和修订，独立专业复核人员核查内孔排除依据及下游计量。前置资料同16.8，另须提供每个内部不支模范围的边界坐标、排除原因及当前原件。

入口：“图纸与算量 → 基础水平模板 → 建立水平模板／修订水平模板”。读取当前已审基础，选择顶底、平台或内部孔端，勾选XY局部窗口，将轮廓选为“带内孔多边形（排除内部不支模范围）”。

**窗口内孔W与基础实体孔H分别处理：**W仅从本项窗口支模范围排除，不改变混凝土、材料表或来源基础，不新增实体孔、孔壁或孔端。实际孔H由已审基础提供，按真实Z和侧层裁切。毛接触已按外轮廓减W后与真实截面相交；H只扣余下范围内的交集，不能把W再次当成H扣减。

1. 核定共同坐标单位、基础中心和XY正向，按边界顺序填写外轮廓3～12点及逐坐标依据，可为凸或凹轮廓。
2. 在“窗口内孔（本窗口不支模范围）”录入1～4个内孔。每孔填写不重复的名称、3～12个有序XY顶点、逐坐标原件、“本内孔不支模范围及依据”及其原件。外轮廓与全部内孔合计最多36点。
3. 内孔继承窗口单位和共同XY基准，不能单独填写单位、Z或重复数量。首尾自动闭合，无须重复首点，各轮廓可分别顺时针或逆时针。通过“增加内孔顶点”“移除内孔末点”调整顶点，通过“增加窗口内孔”“移除本窗口内孔”调整内孔；至少保留一个，否则切换无内孔模式重新录入。
4. 每孔须严格在外轮廓内；内孔之间不接触、相交、重叠或包含。边与边或点接触也会阻断，不自动合并、排序或修形。凹外轮廓中，即使孔的各顶点看似在内，孔边穿越凹口也不能采用。
5. 核定材料、实际接触、范围说明及总量修约依据，重新确认窗口和总体范围，再预览。修改内孔名称、坐标、依据、说明、个数或外轮廓／单位都会清除旧预览并撤销相关确认。
6. 展开“窗口外轮廓、排除内孔及净区校验”，核查外轮廓面积、各W面积、窗口净区、全部原件、严格在内及相互分离校验。窗口净区仍是设计范围，不能直接当作真实接触面积乘数量。
7. 检查毛交集、平台上层覆盖、真实H扣减、多个有效纵向片段及全部基础数量。零接触时展开“带孔窗口零接触分段覆盖校验”，逐片检查剩余0段；微小正面积缝隙不能归零。
8. 保存后交独立复核人员检查当前原件、W不支模用途、坐标单位及方向、H真实Z和数量。审定后重新计算工程量、复核计算书、核对／重建清单，再计价及导出。来源变化后旧模板失效，重新读取会清空旧范围及确认；旧计算书、报价和留档文件保留原版本。

**合成说明示例：**外轮廓单位mm依次(-100,-100)、(100,-100)、(100,100)、(-100,100)，内孔W1依次(-20,-20)、(20,-20)、(20,20)、(-20,20)。外轮廓0.0400m²，W1为0.0016m²，窗口净区0.0384m²。最终仍与真实端层、平台或孔端相交并扣物理孔；不能直接把0.0384作为每基础模板量。

同端面防重检查扣W后的完整窗口净区。另一窗口完全在W空区内可另项，边界相接可分项；越过内孔边界形成微小正重叠则阻断。可混用矩形、凸或凹窗口，跨记录同样检查；不能更换XY基准规避防重。这里检查设计范围，不按实体外部或实体孔内的投影豁免重复登记。

JSON保留外轮廓和各W输入、规范坐标、逐环面积及公式、净区、拓扑校验、完整分段积分／覆盖证明、有理数防重见证与有序AST。Excel/PDF增加“基础带孔窗口顶点”“基础带孔窗口分段积分”“基础带孔窗口净区与校验”；有零接触证明或相关窗口对时，另有“基础带孔窗口零接触校验”“基础带孔窗口防重分段”。防重表左右栏目按窗口对第一个、第二个C编号对应，精确分数为米制有理数。

合成软件验收截图：[窗口净区与内孔原件](qa/v0.109-inner-window-review.png)、[内孔边界的零接触分段](qa/v0.109-inner-window-zero.png)、[PDF精确防重](qa/v0.109-inner-window-export.png)。截图均为合成资料，不代表真实项目或专业验收。

本单轮廓模式只支持一个简单直边外轮廓与严格分离内孔；多块分离窗口见16.10。父块内孔中的岛区请使用16.11专门模式；曲边、任意水平分区、斜面或个体不同做法仍待补齐。几何或台账审定不能代替真实工程、工法、专业规则或独立顾问底稿验收。

### 16.10 多块分离窗口（v0.110）

适用角色：编制人员建立和修订，独立复核人员按原件核查全部净块。前置资料同16.9，另须提供各块实际支模范围说明及原件；同一条C范围中的各块采用同一材料做法、同一来源基础项、同一端面／平台／孔端和全部基础个数。

入口：“图纸与算量 → 基础水平模板 → 建立／修订水平模板”。读取已审来源并选择水平端面，勾选XY局部窗口，将“窗口轮廓”选为“多块分离窗口（每块可带内孔）”。

1. 核定共同窗口单位及基础中心XY方向。模式初始两块，通过“增加窗口净块”“移除本窗口净块”调整为2～4块；至少保留两块，只有一块时请切换单轮廓模式重新录入。切换模式会清空旧轮廓坐标及原件选择，重新确认。
2. 按B1、B2等逐块填写不重复的名称、“本净块实际支模范围及依据”及其原件。每块外轮廓沿实际边界顺序录入3～12个XY顶点，逐坐标关联当前原件，不重复末点；可为凸或凹轮廓，顺时针或逆时针均可。
3. 需要排除内部不支模区域时，点击“增加B1内孔”等按钮，按B1 W1等编号填写内孔名称、3～12个有序顶点、逐坐标原件、不支模排除说明及原件。无孔保留空列表，并在本块支模说明中核对无排除内孔。每块最多4孔及36点，全部最多8孔及48点。
4. 各块的外轮廓须严格分离，不能共边、点接触、交叠或包含；孔须严格在所属外轮廓内，相互不接触、重叠或包含。另一块即使落在某块的内孔空区，本分离模式也会拒绝；请改用16.11嵌套岛区模式并明确父块内孔关系。不能用外包矩形代替各块边界，也不自动合并相接外轮廓。
5. 各块和各孔继承窗口单位与共同XY基准，不能另填单位、Z或重复数量。不同端面、基础项或材料做法请建不同C范围或构件；不从块名推断施工分区。
6. 核定总体实际接触、材料做法及总量修约依据，确认窗口和总体范围后预览。修改任一块／内孔的名称、坐标、原件、范围说明、增删或单位，会撤销确认并清除旧预览。
7. 展开“逐水平面真实孔扣减及接触原件 → 多块分离XY窗口”，核对整体外包边界、外轮廓／内孔／窗口净区累计值。外包边界只供定位，块间空区不计。先在逐块汇总表对照窗口净区与真实毛／孔扣／净接触，再按B编号展开各块，查看本块原件、窗口顶点、排除内孔、每基础真实毛／实际孔扣／净接触及解析过程。
8. 每块独立按200位解析积分并保留80位过程，用80位累计块结果，再继承全部基础个数一次；不按显示位数逐块修约，只对总净面积按已确认位数HALF_UP修约。窗口内孔W仅排除本块支模，基础实际孔H只扣余下接触交集，不新建实体孔、不扣混凝土、不生成孔壁或孔端。
9. 实际孔完整覆盖后若生成整体严格零接触证明，展开“多块窗口零接触分段覆盖校验”，按B编号、X区间和片段号检查。全部净块的全部有效片段无剩余才形成整体严格零接触证明；某一块为零不能代替全部块为零。小正面积可能在总量显示修约后成为0.000，但不产生严格零接触证明，需检查未修约值。
10. 保存后由独立复核人员核查每块原件、拓扑、支模做法、窗口内孔与实体孔区别、实际孔Z和全部数量。通过后重新计算并复核计算书、核对／重建清单、重新计价及导出。来源变化后旧模板失效，重新读取会清空全部旧块和确认；历史计算书、报价及留档文件仍按原版本保留。

**合成说明示例：**单位mm，B1外轮廓(-100,-100)、(-5,-100)、(-5,100)、(-100,100)，B2外轮廓(5,-100)、(100,-100)、(100,100)、(5,100)。两块外轮廓合计0.038m²，中间X负5至5mm的空带不计。B1内孔W1为(-60,-15)、(-30,-15)、(-30,15)、(-60,15)，面积0.0009m²，窗口净区合计0.0371m²。最终仍须逐块裁切真实截面及孔，不能直接将净区面积乘数量交付。

同端面及跨记录防重使用全部净块减所属内孔后的完整净区，支持与矩形、凸、凹和带孔旧窗口混用。另一窗口完全落在块间空区或窗口内孔空区可另项，共边或点接触可分项；越界形成微小正重叠则阻断。此处“窗口之间允许边界接触”不放宽同一多块窗口内部“各外轮廓严格分离”的要求。所有记录共用相同XY基准及原件；不按实体外部或实体孔内的投影豁免重复登记。

JSON保留全部块与内孔输入、逐块原件、块与整体净量、独立公式、B编号分段／覆盖见证及完整AST。Excel/PDF增加“基础多块窗口顶点”“基础多块窗口净区”“基础多块窗口分段积分”“基础多块窗口拓扑校验”；有严格零接触或相关窗口对时另有“基础多块窗口零接触校验”“基础多块窗口防重分段”。防重表左右栏目按窗口对第一个、第二个C编号对应，分数为精确米制有理数。

窗口与真实面完全无交集时保留零量及空积分，未必生成孔覆盖证明，需同时核对逐块的实际毛接触与净量。

常见错误：块数／点数／孔数超限、缺本块原件或逐点依据、自交／重复／共线、外轮廓接触或嵌套、孔越界、混用单位与基准均阻断。系统不自动排序、修形、合并或填补块间空隙。嵌套岛区见16.11；曲边、接触或交叠外轮廓合并、任意水平分区、斜面及个体不同做法仍待补齐。数学或台账审定不能代替真实工程、工法、顾问底稿或商业部署验收。

### 16.11 父块内孔中的嵌套岛区（v0.111）

适用角色：编制人员建立和修订，独立复核人员核查父子关系及真实支模范围。前置资料同16.10，另须有各岛区位于哪个父块内孔、实际支模做法及完整边界的原始依据。父块内孔W只是从父块支模窗口排除，岛区以另一块的净区单独计入；不创建基础实体孔H、不扣混凝土、不生成孔壁或孔端。

入口：“图纸与算量 → 基础水平模板 → 建立／修订水平模板”。读取已审基础、选择同一水平端面，勾选XY局部窗口，轮廓选择“嵌套岛区窗口（父块内孔中另计支模）”。初始B1为根块并带一个待填内孔，B2默认指向B1 W1；这些只是待填结构，不能代替按原件核定关系和坐标。

1. 选择共同单位，核对基础中心XY及正向。所有块采用同一来源基础项、同一顶底／平台／孔端及同一材料做法，Z和全部基础个数只读继承；不同端面或做法另列C范围或构件。
2. 逐块填写名称、外轮廓3～12个有序XY顶点及逐坐标依据。在本块支模范围说明及其原件中，同时说明实际支模边界、所属父块内孔或作为根块的依据。
3. 在“最近父块内孔与平面嵌套关系”明确选择“根块（不在其他块内孔中）”，或选当前其他块的具体内孔，如“B1…W1…”。岛区必须选择最近父块，不能跳过中间岛区直接选择祖先；系统核对几何关系，不会自动改写选择来放行。
4. 每块可带0～4个排除内孔，各孔3～12点、逐坐标原件及不支模说明原件。每块最多36点，全部2～4块、最多8孔及48点；至少存在一项真实嵌套关系。纯分离窗口用16.10，无需为其编造父关系。
5. 岛区外轮廓必须严格位于所选父块内孔中，不能接触或穿越孔边；不能落入父块实际支模净区。即使岛区各顶点在凹孔内部，边穿过凹口也会拒绝。其他根块或兄弟岛区外轮廓须严格分离，不接触、交叠或相互包含；各孔仍须严格在所属外轮廓内且相互分离。
6. 支持在岛区自己的内孔中再放岛区，最多四块形成平面层级0～3，也可有分离根块和同孔内多个分离岛区。父关系不能自指或成环。“平面层级”只表示包含深度，不是基础层号、Z标高、施工层或重复数量。
7. 修改父关系、块／孔坐标、原件、范围说明、名称或单位，以及增删块／孔，都会撤销窗口及总体确认并清除旧预览。删除被引用的父块或内孔后，相应父选择清空，必须重新选择；其余引用随编号调整保持原对象对应。修改孔边界后即使父选择仍显示，仍须重新确认并通过真实包含校验。

### 16.12 圆形XY局部窗口（v0.112）

适用角色：编制人员建立／修订，独立复核人员审查原件、实际支模和计量口径。先准备已审基础、圆窗实际圆心与直径、与基础孔位共用的XY基准及原件、支模做法和总量修约依据；圆窗是选取支模的范围，不是基础实体孔，不改混凝土体积、不生成孔壁或内部孔端。

入口：“图纸与算量 → 基础水平模板 → 建立／修订水平模板”。读取已审来源，选择基础项和整体顶／底面、台阶平台或内部孔底／孔顶，勾选“按原件选取XY局部窗口”，轮廓选“圆形（圆心XY与实际直径）”。

2. 填共同XY基准说明及原件，确认圆心、直径及方向。Z、基础截面、所选孔位和全部最终基础个数只读继承。不同端面、材料或做法分别列C范围或构件；不能附加数量或对同一范围重复计量。
3. 填本端面真实接触说明、模板材料做法及其原件，选择总量修约位数及原件；确认窗口与总体范围后预览。修改圆心、直径、单位、原件、轮廓或范围均撤销确认并清除旧预览，须重新核对确认。切换轮廓会清空原轮廓参数，不自动将矩形或多边形拟合成圆。

5. 整体顶底取真实端层截面；平台先与下层相交并扣紧邻上层完整覆盖，再扣外露平台内的实体孔；内部孔端取所选孔与正确混凝土侧层，再扣同侧相接孔在圆窗内的实际交集。体积扣孔阈值不填实物理孔。逐面、逐孔和全部数量核对后，仅总净面积按有据位数HALF_UP修约。
6. 展开圆弧解析过程核对各X事件分段、有效上下界和面积；工作200位、保留80位及有序AST。展开“圆形窗口零接触分段覆盖校验”（如有），核对全部有效分段无剩余才认定严格零接触。显示0.000可能只是修约，不能替代未修约净值与证明；窗口完全在实体外时保留空积分和零量，不一定生成孔覆盖证明。
7. 保存送审后，独立复核人员核对圆心、实际直径、逐参数原件、共同坐标、Z侧层、接触工法、材料、全部基础个数及修约；审定后重新计算并审定计算书、核对／重建清单、重新组价和导出。来源修订后旧模板失效，重新读取会清空旧范围及确认；旧计算、报价及导出仍按原版本留存。

### 16.13 同心圆环XY局部窗口（v0.113）

适用角色：编制人员建立或修订，独立复核人员核查真实支模、内圆排除和原件。先准备已审基础、一个共同圆心及实际内外径、与孔位共用的XY正向、内圆不支模说明及原件、模板材料做法和总量修约依据。圆环只是水平接触的选取范围；内圆W不创建基础实体孔H，不改混凝土体积、不生成孔壁或内部孔端。

3. 填“内圆W不支模范围及依据”，说明中间圆盘为什么不属于本次支模，并选择原件。内径原件与内圆排除原件分别核对：有直径尺寸不等于已证明不用支模。内圆W只从本圆环窗口排除，不自动排除其他另列窗口。

### 16.14 外圆减可偏心内圆XY窗口（v0.114）

适用角色：编制人员建立／修订，独立复核人员核查两圆心、内圆排除和真实接触。先准备已审基础、外圆心与外径、内圆心与内径的明确设计坐标和原件、内圆不支模说明及原件、共同XY正向、模板材料做法和修约依据。一个外圆减一个严格内部的内圆W；W不是基础实体孔H，不扣混凝土、不生成孔壁或孔端。

入口：“图纸与算量 → 基础水平模板 → 建立／修订水平模板”。读取已审来源，选择基础项及整体顶／底面、台阶平台或内部孔底／孔顶，勾选“按原件选取XY局部窗口”，轮廓选“外圆减可偏心内圆（分别填写两圆心）”。同心也可用本模式，原16.13同心模式仍保留。

1. 选择共同长度单位（mm、cm、dm、m或km），填写外圆心X、外圆心Y、实际外径、内圆心X、内圆心Y、实际内径，六项分别关联原始依据。两个圆心均相对来源基础中心这个共同原点；内圆心不是相对外圆心的偏移量。允许负坐标，不接受面积、比例、半径、公称尺寸或额外重复数量。
2. 按原件确认XY与来源基础孔位共用正向，不随俯仰视翻转，填写共同基准及原件。系统严格检查0＜内径＜外径，且两圆心距严格小于两半径之差；采用精确有理数平方比较，不用显示位数或容差放行。内圆接触外圆边界或越界均拒绝；本功能不合并相接圆边界。
3. 填“内圆W不支模范围及依据”，明确中间偏心圆盘为什么不属本次支模，并关联原件。圆心尺寸原件与排除用途原件分别核查，不能仅凭一个圆被画出就推定其不支模。内圆只从本窗口排除，不能自动排除其他有据另项。
4. 核定本端面实际接触说明、模板材料与做法及原件、总净量修约位数及原件。Z、真实截面、所选孔位及全部最终基础个数只读继承；不同端面或做法另列C范围或构件。确认窗口与总体范围后预览。改变任一圆心／直径、排除说明或原件、单位、范围、轮廓均撤销确认、清除旧预览；切换轮廓清空旧参数与排除字段，不能把其他图形拟合成圆。
5. 预览“可偏心内圆XY窗口”，核对两圆心和内外径的米制数值、外圆／W／窗口净区、严格包含的圆心距平方与半径差平方，以及实际毛／实体孔扣／净接触。严格包含值单位m²、可为精确分数。外包XY仅定位；实际按外圆减W裁切，不能用外包矩形、多边形近似或面积比例替代。
6. 整体顶底与真实端层相交；平台先排紧邻上层完整覆盖，再扣外露平台内实体孔；孔端取正确混凝土侧层并扣同侧相接孔。W先从窗口排除，实体孔H只扣剩余净区内实际交集，不重复扣W；体积阈值不填实物理孔。全部基础个数只继承一次，仅最终总净量按有据位数HALF_UP修约。
7. 展开解析过程核对两个圆心对应的真实圆弧、全部边界事件分段和有效上下界；工作200位、输出80位及有序AST。若出现“偏心内圆窗口零接触分段覆盖校验”，“外圆候选接触”尚未扣W，覆盖行分别列W、上层及H；全部有效片段无剩余才证明严格零接触，W不记作实体孔扣。显示0.000不能替代未修约值或证明；极薄正净区仍保留正值。实际接触全部落入W时毛量为零，不一定有孔覆盖证明。
8. 保存送审，独立复核人员核查两个圆心的共同原点及六项原件、严格包含、内圆用途、Z侧层、实际支模／材料、数量和修约。审定后重新计算并审定计算书、核对／重建清单、重新组价和导出。来源变更后旧模板失效，重新读取清空旧范围和确认；历史计算、报价及导出保留原版本。

同端面及跨记录防重仍检查完整净区，并要求同来源同基础项所有窗口使用相同XY说明与基准原件，不按实体外或物理孔投影豁免。与圆、同心圆环或另一可偏心内圆窗口比较时，检查两外圆是否分离，或一个完整外圆是否落在另一窗口的内圆内。两外圆交叉且未被另一内圆完整排除时存在正重叠；每个内圆都严格在自己的外圆内，不能把两个内圆的面积简单相加来抵消交叉区。正重叠拒绝，边界接触或共享可分项，内圆未用空区可有据另项。

与矩形、凸／凹、带孔、多块及嵌套岛区比较时，按每个连通净块分别检查：到外圆心的最小距离平方小于外半径平方，且到内圆心的最大距离平方大于内半径平方，才与本净区正重叠。外圆心在净块内时最小距为0，否则取全部外／内有限边段最短距离；到内圆心最大距取该净块外轮廓顶点。两项使用不同圆心，不能套用同心公式或拼接不同块的极值。所有比较均为精确有理数，边参数0至1定位有限边段最近点，不用无限直线距离替代。

JSON保留六项输入原件、内圆排除依据、规范几何、严格包含精确见证及AST、解析分段及全部防重距离。Excel/PDF新增“基础偏心内圆窗口参数”“基础偏心内圆严格包含”“基础偏心内圆分段积分”；有完整覆盖时增加“基础偏心内圆零接触校验”，有相关窗口对时增加“基础偏心内圆防重校验”，涉及直边净块时另有“基础偏心内圆逐边距离”。防重表标明左右C编号、本窗口所在侧、比较的是哪两个圆心及平方界，单位m²。

**合成算例（非真实工程）：**无孔矩形底面400×500mm，外圆心(0,0)、外径200mm；内圆心(20,10)、内径100mm。圆心距平方500mm²＜半径差平方2500mm²，内圆严格在外圆内。整个净区均在实体内，每基础净接触π×(0.1²−0.05²)=0.0075πm²；22个同做法基础总未修约0.165πm²，三位小数0.518m²。此例仅因整个净区均在实体内才可直接相减；窗口越过实体或有实际孔时，内圆位置会影响真实接触，必须按实际交集计算。

常见错误：把内圆偏移量当共同坐标、混用两原点或单位、内圆相切／越界、内外径倒置、缺内圆坐标或用途原件、正重叠、把两个圆心用于同一距离计算均须修正。只支持一个外圆减一个严格内部圆，多个内圆请用16.15专门模式，本单内圆模式不支持扇形、椭圆、多圆并集、相接曲边合并、曲边嵌套或任意水平分区。工程坐标转换、任意空间／斜面、个体不同做法及专业例外仍待补齐。合成测试和台账审定不能替代真实工程、工法、专业标准、独立顾问底稿或商业部署验收。

### 16.15 圆形外轮廓内的多个不支模圆区（v0.115）

适用角色：编制人员建立／修订，独立复核人员核查逐圆位置、排除用途及真实支模。前置资料：已审来源基础、外圆及各内圆的明确设计坐标和实际直径原件、每个内圆不支模说明及原件、共同XY基准、材料做法和修约依据。一个圆形外轮廓减2至4个窗口内圆W；各W严格在外圆内且两两严格分离。只有一个W时使用16.13或16.14。

入口：“图纸与算量 → 基础水平模板 → 建立／修订水平模板”。读取已审来源，选择基础项、整体顶／底、台阶平台或内部孔底／孔顶，勾选“按原件选取XY局部窗口”，轮廓选“圆形多内圆（2至4个不支模圆区）”。

1. 选择共同长度单位mm、cm、dm、m或km，填写外圆心X、Y及实际外径，三项分别关联原件。圆心允许负坐标。不能填半径、面积、比例或额外数量。
2. 在“窗口内圆W”中逐圆填写不重复名称、圆心X、Y、实际直径及各尺寸原件；另外填写本圆不支模说明及其原件。W1、W2分别保留资料，不能用一个内圆的用途替代另一个。全部圆心均相对来源基础中心同一原点，不是相对外圆的偏移；每圆继承上方单位和下方共同XY正向，不另设单位、原点或数量。
3. 可“增加窗口内圆”至最多4个；“移除C… W…”至少保留2个。修改、添加、移除、换单位、换轮廓或修改任何原件均撤销窗口及总体确认并清除旧预览。切换轮廓清空旧参数及内圆，不自动拟合图形。
4. 填写与来源孔位共用的XY基准及原件，确认窗口；核定实际水平接触说明、材料做法、修约位数及相应原件，再确认总体范围并预览。Z、真实截面及全部基础个数只读继承来源一次；不同端面或做法另列范围或构件。
5. 系统以精确有理数检查每个内圆半径小于外圆半径，且两圆心距平方严格小于半径差平方；再逐对检查内圆心距平方严格大于半径和平方。相切、交叠、包含、越界、重名、缺原件或超过数量限制拒绝，微小正间隙不按容差抹去。距离平方单位m²，可能以分数保留。
6. 预览“多内圆XY窗口”：核对外圆和每个W的米制圆心、直径、面积及严格包含，查看两两分离关系，展开“W…不支模说明及逐项原件”。外圆面积减全部W仅是设计窗口净区；实际毛接触还须与真实截面相交。外包XY仅定位，不能以外包矩形、网格、多边形逼近或面积比例计量。
7. 整体端面取真实端层；平台先排上层完整截面，孔端取正确混凝土侧层。先排全部W，再扣剩余净区中的实体孔H交集，不重复扣W与H。W不创建实体孔H、不扣混凝土、不生成孔壁或孔端，不自动排除另项支模。全部基础数量只乘一次，逐圆／逐孔不修约，仅最终总净量按原件位数HALF_UP修约。
8. 展开曲线解析查看全部圆弧边界事件、上下界及分段积分；工作200位、保留80位及有序公式AST。有“多内圆窗口零接触分段覆盖校验”时，“外圆候选接触”尚未扣W，覆盖行分别列W1、W2等及实体孔H／上层；全部有效片段扣除后无剩余才证明严格零接触。W不记入实体孔扣。显示0.000不等于严格零；实际接触整个落在某W内时毛量为零，未必有实体孔覆盖证明。
9. 保存送审；独立复核逐圆核对共同原点、原件字节、用途、严格拓扑、所选端面及Z侧层、真实支模、材料、数量和修约。审定后重新计算、审定计算书、核对／重建清单并重新组价导出。来源修订后旧模板失效，须重新读取来源并重建范围；历史记录保留当时版本。预览只读，未保存修订可放弃。

**完整窗口防重：**同来源同基础项全部窗口共用XY说明及同一基准原件；同端面及跨记录均检查，实体外或物理孔投影不豁免。与圆、圆环、可偏心内圆及多内圆窗口比较，只有两外圆分离／外切，或一个完整外圆落在对方某一个W内时才无正重叠。不能拼接不同W抵消交叉区。与矩形、凸／凹、带孔、多块、嵌套岛区比较，逐个连通净块检查：到外圆心最小距离平方不小于外半径平方，或本块全部外顶点到某一个W圆心最大距离平方不大于该W半径平方，才无正重叠；不同块可分别落在不同W内，但一块不能拼用多个孔的极值。外圆心在净块内最小值为0，否则取全部外／内有限边段最近点。正重叠拒绝，窗口之间共享边界可分项；W未用空区可有据另项。本窗内部的W之间仍必须严格分离。

**导出与复核：**JSON保留逐圆原始尺寸／用途及原件、规范几何、严格包含与两两分离AST、真实积分、覆盖和防重见证。Excel/PDF新增“基础多内圆窗口参数”“基础多内圆严格拓扑”“基础多内圆分段积分”；有完整覆盖时增加“基础多内圆零接触校验”，有窗口对时增加“基础多内圆防重校验”，涉及直边净块时增加“基础多内圆逐边距离”。防重表标明左右窗口及多内圆所在侧、采用哪个W、逐孔最大距和逐边最短距，距离平方m²，圆心和半径m。导出不回写计算，也不能代替独立复核。

**合成算例（非真实工程）：**无孔矩形底面400×500mm，外圆心(0,0)、外径200mm；W1圆心(-30,0)、W2圆心(30,0)，各实际直径30mm，分别有不支模依据。每圆心距平方900mm²＜半径差平方7225mm²；两内圆距平方3600mm²＞半径和平方900mm²。全净区位于实体内，每基础净接触π×(0.1²−2×0.015²)=0.00955πm²；22个同做法基础总未修约0.2101πm²，三位小数0.660m²。越过实体或有实际孔时须计算真实交集，不能直接套该面积。

常见错误：把内圆坐标填成偏移、混用单位／原点、内圆相切／相交／包含或越界、重名、缺某个W的用途原件、把W作为实体孔重复扣、用不同块或不同W极值拼证明均须修正。圆形嵌套岛区另见16.16；本模式不包含超过4个W、接触／交叠内圆并集、扇形、椭圆、多外圆并集、任意曲边组合及任意水平分区仍待补齐；空间斜面、工程坐标转换、个体不同做法及专业例外另核。软件合成验证不代表真实工程、专业标准、独立顾问底稿或商业部署验收。

### 16.16 圆形内圆中的嵌套支模岛区（v0.116）

适用角色：编制人员建立／修订；独立复核人员核查每块的实际支模、最近父内圆及逐尺寸原件。前置资料：已审基础、各根块和岛区的设计圆心XY／实际直径及原件、每块支模与父关系说明及原件、各内圆不支模说明及原件、共同XY正向、材料做法及修约依据。此处“岛区”是父块内圆W中独立另计的一块支模，不是基础实体孔H或标高层。

入口：“图纸与算量 → 基础水平模板 → 建立／修订水平模板”。读取已审来源，选择基础项及整体顶／底、台阶平台、内部孔底／孔顶，勾选XY局部窗口，轮廓选“圆形嵌套岛区（父内圆中另计支模）”。直边岛区继续用16.11；单圆、单内圆或多内圆模式继续用16.12～16.15。

1. 选择共同长度单位mm、cm、dm、m或km。系统先给两块：根块B1含待填写W1，B2预选B1 W1为父关系；这只是空表单，不是自动核准几何。逐块填不重复名称、外圆心X、Y及实际外径，三项分别关联原件。全部圆心相对来源基础中心同一原点，不是相对父块／父内圆的偏移，不随俯仰视翻转。
2. 在“最近父块内圆”中明确选择“根块”或另一块的指定W。每块填写实际支模及父关系说明和原件：岛区为什么在该W中另行支模、其余W内空区是否排除。平面层级只说明嵌套深度，不改变所选Z、基础层、材料或数量。至少一块须真实嵌套；仅分离圆窗可另列C范围。
3. 每块可有0至4个不支模内圆W，全部最多8个。逐W填写不重复名称、圆心XY、实际直径及三项原件、独立不支模说明及原件。W只从所属块排除，岛区以独立块计回；不填实未选空区，不创建实体孔、不扣混凝土或生成孔壁／孔端。无W块的整个外圆参与裁切。每圆共用上方单位及XY基准，不增设重复数量。
4. 可增加净块至最多4块、移除至至少2块；每块可移除全部W。删除被其他块引用的净块或W后，受影响的父关系清空，须重新选择；后续编号自动调整，不能静默指向其他孔。任一新增、修改、删除、原件、父选择或单位变化均撤销窗口与总体确认、清除旧预览。切换轮廓清空旧块及参数，不自动拟合。

### 16.17 圆形与直边混合嵌套岛区（v0.117）

适用角色：编制人员建立／修订，独立复核人员逐块核查尺寸、支模／不支模用途及最近父关系。前置资料：已审基础、每个圆的圆心XY／实际直径及原件、每条直边轮廓沿边界顺序的设计顶点XY及原件、所属内孔W不支模说明、每块实际支模及父关系说明、共同XY基准、模板材料做法与总量修约依据。2至4块，至少一个圆形块、一个直边块及一项真实嵌套。每块外轮廓和所属W同类；不支持在同一圆形块中直接填直边W或在同一直边块中直接填圆W。

1. 选择共同单位mm、cm、dm、m或km。各块圆心及顶点均相对来源基础中心同一原点，XY与已审孔位共用正向，不是相对父块／父孔的偏移，也不随俯仰视翻转。初始表单给圆形根块B1含待填W1、直边岛B2预选父B1 W1；这只是空输入，不是自动认可几何。

## 17. 黄金底稿对账与差异诊断

### 17.1 准备底稿

由独立专业人员提供**同项目、同构件、同计量范围**的算量底稿。不能使用其他项目报告、中标总价或系统自身结果作为独立真值。

入口：“图纸与算量 → 导入专业底稿对账”。支持 CSV 或 XLSX 第一张表，列名如下：

| 列名 | 含义 |
|---|---|
| 构件名称 | 与当前构件对应的明确名称 |
| 单位 | 与对应工程量一致 |
| 基准工程量 | 独立专业底稿数值 |
| 绝对容差 | 按计量依据核定的允许差量 |
| 相对容差 | 小数形式，例如 `0.001` 表示 0.1%；只作格式举例，不是推荐容差 |
| 计算书ID | 可选，用于明确匹配计算书 |

填写底稿提供人、范围及计量依据，执行逐构件对账。核对实际量、差量、允许偏差、未匹配项和未覆盖的当前工程量。对照通过后仍需独立复核。

### 17.2 差异诊断

在“工程量差异归因”对超差、未匹配及未覆盖项登记原因、专业说明和证据，修正相应来源或构件后重新计算及对账。

诊断通过只表示原因分析被认可，不会改写数量、底稿、容差或对账结论。不要仅通过扩大容差掩盖实际建模或单位错误。新增工程量及来源变化后，原对账可能失效，应重新覆盖全部当前计算书。

<a id="boq"></a>
## 18. 清单编制、导入、拆并和编码映射

### 18.1 从工程量生成

计算书审定后，在“清单编制”点击“从工程量生成”，形成候选清单。逐项完善真实编码、名称、项目特征和工程归属，核查单位及数量。系统不内置虚构官方清单编码。

查看“清单数量分配检查”：每份计算书的已分配、未分配或超量必须解释并处理。生成、拆并或调整后重新检查来源贡献是否闭合。

### 18.2 导入已有清单

点击“导入已有清单”，选择 XLSX／CSV／TSV，最大 **10 MB**。

- 必需列：`清单编码`、`项目名称`、`单位`、`工程量`。
- 可选列：`项目特征`、`工程层级`、`综合单价`。
- 公式单元格先核实并转换为值。

先解析预览，处理所有错误，逐项确认重复编码是否为合理分项，再确认导入。保留原文件及行位置，仍需复核。导入历史综合单价仅作参考，不会自动成为当前资源价格；导入也不证明已完成原图算量。

### 18.3 清单编码映射

1. 在“有据清单编码映射”设置实际适用清单标准及版本。
2. 新增规则，填写构件类型、计量口径、单位、条件、编码、名称、特征、来源及许可。
3. 上传原始依据，关联包含实际编码的原文，提交独立复核。
4. 对待映射清单执行匹配预览，无匹配继续待补，多候选人工明确选择。
5. 采用后核对编码、名称及特征；数量保持，清单回到待复核。

同为 m³ 不表示用途相同：井筒材料／外包、底板／盖板、模板／防水要分别匹配。合并多来源清单时，各来源都须满足规则条件。

### 18.4 拆分与合并

“拆分清单”要求拆分量之和与原量完全相等；多来源项不能未经明确分摊直接拆分。“合并清单”要求编码、特征、单位、工程层级和定额组成等条件兼容，保留各构件贡献并重新送审。

拆并后检查数量分配、映射、工程归属和组价，不要直接沿用旧审核结论。

<a id="pricing"></a>
## 19. 定额、资源、供应商报价与调价

### 19.1 编辑定额组成

在“组价审核”选中清单，点击“编辑定额与资源”。一项清单可增加多个定额子目。

每个子目填写定额编码、年度／版本、通用系数、来源、授权依据和原始证据。每个资源填写名称、类别、单位、消耗、单价、规格、资源编码、费用归属以及来源、许可、地区、期次、税制、有效期和原件等适用字段。

未启用换算时，消耗按**每一清单单位**填写。来源类别可据实选择官方信息价、供应商报价、询价、历史审核价或人工录入；人工录入同样需要真实依据，不能免除适用性检查。

修改定额、消耗、换算或价格后，应重新复核清单再计价。

### 19.2 有据单位与分类换算

启用“有依据的定额单位与分类换算”后，填写定额单位、单位换算率、人工／材料／机械／设备分类系数及换算说明和原件。

有效消耗＝原始消耗×通用系数×单位换算率×对应类别系数。

例如清单单位 m³、定额单位 10m³，则每一清单单位对应 0.1 个定额单位，换算率填 `0.1`；此时消耗填写原始定额口径。启用或停用不会自动改写消耗，切换时必须重新核对，不能既把消耗除以 10 又填 0.1。

### 19.3 未计价资源与待询价

暂缺合法价格时勾选“未计价资源，待询价”，保留名称、编码、单位、消耗、规格、费用归属及其依据。价格为空，不按零元处理，也不能生成完整计价成果。

“待询价与定额匹配”按当前数据生成任务。补价后取消未计价状态，补齐价格来源、日期、税制及原件，再重新复核。可在成果交付选择无价草稿导出待办。

### 19.4 供应商报价登记、选择和重新询价

1. 在“供应商报价登记与选择”选择当前待询价资源，录入供应商及真实报价条件、价格和依据。
2. 核对单位、规格、地区、税制、有效期和采购条件等差异。
3. 提交独立复核；通过后由编制人员明确选择并应用。
4. 应用后重新审定受影响清单并计价；不会自动选择最低价。
5. 需要更新报价时追加修订版本；需要撤出现价时按页面操作恢复待询价，再登记新报价。

报价修订或重新询价保留旧版本与历史快照。登记报价不等于下采购单，也不表示已经收货入库。

### 19.5 定额候选及企业复用

“本项目授权定额候选”可保存和检索有据组成，先预览适用条件、资源及差异，再明确采用。“企业定额组成库”支持按授权共享范围复用，原件及来源一并核查。

候选检索只是建议，不是官方定额授权。跨项目复用后仍需核定当前工程适用性、补齐当前有效资源价格并重新复核，不能将旧项目价格直接视作现价。

“企业资源价格库”同样只复用有权访问的已审来源；核对地区、期次、有效期、单位和税制后采用。项目访问范围变化会影响共享来源可用性。

### 19.6 材料替换与资源调价

材料替换：建立替换单，选择原资源，填写替换材料、系数及配合材料等实际内容、原因和原件，先预览影响再独立复核，应用后重新审定清单。

资源调价：点击“建立资源调价单”，明确勾选需调整的资源，录入新价及来源、许可、期次、地区、税制、有效期和原件。先生成影响试算及待审调价单，复核后再应用。影响金额只覆盖列示清单，不应当作完整含费总价。

历史审核价不能未经当前依据直接成为现价。任何替换或调价都不能通过修改旧报价快照实现。

<a id="fees"></a>
## 20. 工程层级、取费与报价快照

### 20.1 工程层级与归属

在“取费汇总 → 工程层级与清单归属”编制建设项目下的单项、单位工程层级，为每条清单明确归属。核对完整性后送独立复核。工程层级影响分级汇总和节点费用，不是只改显示分组。

结构调整后应检查费用规则引用的节点和清单归属，重新复核。查看报价时以该快照保存的结构版本为准。

### 20.2 配置计价规则包

点击“配置规则”，填写名称、版本、地区、适用标准、来源、许可、起止有效期和原件；设置综合单价保留位数及修约方式，再添加按顺序执行的费用。

| 项目 | 填写方式 |
|---|---|
| 费率 | 填小数，例如 `0.01` 表示 1%，不是填 `1`；示例不代表实际适用费率 |
| 项目级／节点费用 | 按实际计价规则选择层级，逐项写来源；不能上下级重复取费 |
| 费用基数 | 分部分项、下级含费、下级费用、当前累计或人工／材料／机械／设备原始合计等支持项 |
| 组合基数 | 使用受控加减乘除及已计算费用引用；不能引用尚未计算的后续费用 |
| 单价修约 | 0～6 位，四舍五入、半数取偶或截位，按项目规则选择 |
| 合价及费用 | 清单合价及各项费用按引擎规定保留两位，按规则顺序计算 |

不要默认套用历史税率或其他项目费用。未配置的费用不会自动补齐。规则包需独立复核，日期不在有效范围时仍会阻断。

### 20.3 生成报价快照

上游有效且满足计价门禁后，编制人点击“生成计价快照”，查看分部分项、逐级费用、总价和输入哈希。快照保存当时的数据及依赖，不随后续编辑改写。

数值使用十进制确定性计算。输入超限应核对单位和原始精度，不要截掉关键位数以强行通过。Excel 是展示和编辑成果，修改导出单元格不会回写系统或重新生成合法计价结果。

### 20.4 内部敏感性测算

以已有报价选择数量、材料、人工、机械系数，填写测算名称后执行。`1` 保持基准，`1.05` 表示增加 5%。测算单独保存，不改变原始价格、正式报价或审批，不能当作已审报价交付。

<a id="review"></a>
## 21. 独立复核、批量复核与失效处理

### 21.1 单项复核

1. 复核人登录，确认工程及对象版本。
2. 点击“专业复核”“复核 / 记录”或相应明细入口。
3. 展开对象数据、计算、原始证据和依赖，不只检查汇总数。
4. 选择通过、拒绝或要求补充资料，填写专业依据及理由。
5. 提交后核查状态及下游提示。

系统用对象校验值防止审核已被他人修改的数据。若提示对象已变化，刷新并重新打开核查，不要反复提交旧窗口。

### 21.2 批量复核

在支持页面点击“批量专业复核”，选择对象类型，逐项展开核查后勾选，填写共同决定及依据后提交。页面每次最多展示 200 个待处理对象；批量仍保留逐项审核记录，任一对象变化或校验失败则整批不提交。

批量工具用于减少重复点击，不减少专业核查责任。不同原因或证据的对象应分别处理。

### 21.3 上游变更后的处理

| 变更 | 通常需要重新处理的环节 |
|---|---|
| 原图、图纸身份或证据修订 | 相关事实、尺寸、构件及其所有下游 |
| 构件尺寸、孔、范围或数量变化 | 构件复核、计算书、底稿对账、清单和报价 |
| 来源构件变化 | 依赖工具重新读取来源，重填被清空的范围及证据 |
| 编码、特征、定额、资源或价格变化 | 清单复核、报价快照、成果审核 |
| 日期、范围、工程层级或费用变化 | 适用性检查、相应复核、重新报价及成果审核 |
| 独立复核拒绝或要求补件 | 查看具体阻断；补齐后重新提交，不沿用旧结论 |

按当前页面阻断清单确定具体依赖。处理顺序为上游到下游，不应只在最后重新点一次成果审核。

## 22. 变更签证、版本对账与结算差异

### 22.1 单项签证与批量调量

“清单编制 → 建立变更签证”：选择已审原清单，填写**变更后总工程量**、原因和变更原件，系统保留原量并计算增减。不是在总工程量框里填写增量。

独立复核通过后由编制人应用，清单重新送审并生成新报价。当前不支持自动撤销已应用签证，后续更正要按有据新变更处理。

“批量调量单”逐条选择清单、填写调整后的总量、原件和说明，核对条件性试算，整批复核后整批应用。0 表示取消该数量，不可填负值。同一清单在一批中只出现一次。不能按目标总价反推数量。

### 22.2 报价版本差异

在“取费汇总 → 报价版本差异”选择基准和对比报价，核对工程层级、清单数量、单价、定额、消耗、价格、费用及来源变化。可下载并留档 JSON 对账单。相同总价也可能有内容变化，不应只看总差额。

### 22.3 工程结算差异复核

入口：“成果交付 → 工程结算差异复核”。

1. 确认合同基线报价与最新有效已审目标报价均已独立审核。
2. 建立结算差异记录，填写合同范围、结算口径和合同原件。
3. 对各清单及费用内容差异逐项说明并关联当前证据；适用时关联目标报价中已审已应用的同清单签证。
4. 预览量、价和费用影响，提交独立复核。
5. 单独导出 JSON、Excel 或 PDF，并查看其历史留档状态。

结算记录解释同范围报价差异，不改写原数量、价格、费用或报价。复核不等于自动认定合同价款权利、付款批准、真实签章或竣工财务决算。

## 23. 成果预览、导出、留档及校验

### 23.1 选择正确版本

在“成果交付”顶部选择具体报价版本，或“当前无价草稿（含待办任务）”。当前数据草稿与历史报价是不同对象；不要一边查看旧快照，一边按当前构件预期解释其中数值。

先阅读审核状态、阻断项和来源失效提示。门禁未通过时，导出仍有显著草稿标记，不能当作已审成果。

### 23.2 企业报表样式

管理员或项目负责人可在“企业报表样式”新建或基于最新版本修订模板，填写编制单位、封面内部说明、页脚和配色。每次保存新版本，旧模板保留。

选择模板后应用到实际 PDF、Excel、JSON 和 ZIP 导出；页面封面摘要只是导航，应以实际文件为准。模板不能移除金额、证据和审核标记，也不等于官方表式认可。

### 23.3 实际 PDF 分页审阅

在“PDF分页审阅”生成并查看实际文件，按章节跳转，检查页数、长表续页、表头、公式、来源、数量、总价及审核标记。预览绑定本次生成的留档文件，不是封面模拟图。

新增复杂模板或材料表可能生成大量页，重点检查对应章节及前后续页。截图或封面摘要不能代替检查完整导出。

### 23.4 导出选择

| 格式 | 适用场景 | 注意 |
|---|---|---|
| Excel 工作簿 | 编辑核对清单、计算书、资源分析和费用表 | 本地改动不回写系统，重新计价走工作台 |
| PDF 审阅件 | 固定版式审阅和归档 | 只有签章预留位，不自动生成签名或印章 |
| JSON 结构化快照 | 精确追溯数量、参数、来源、公式和规则版本 | 高精度数值按十进制字符串保留，避免转成浮点丢失精度 |
| ZIP 完整交付证据包 | 将指定版本原件、报表、快照、审计和校验工具一起交付 | 原件去重后上限 100MB，包含敏感业务资料，应按授权范围交付 |

三种主要成果来自同一选定快照，但显示精度不同。检查精确计算时读取完整明细和 JSON，不用 PDF 显示的小数位倒推中间过程。

### 23.5 历史文件与校验

v0.131联合供应完整需求、两侧分配与预留关联及实际分账记录、v0.130余料未领余量补料及其独立实际批单、v0.129原材未领余量补料的上游／释放快照、有效剩余需求、新批次规范分配及预览、v0.128余料独立批单及未领余量释放、v0.127完整原材分批领料及未领余量释放、v0.126完整原材盘点及v0.125余料盘点输入、冻结账面／实盘／差异、独立复核及执行／取消事件随库存JSON独立留档；旧文件保持原字节，当前余额需重新导出。

导出后在“历史导出件”按格式、报价版本、状态、时间和文件哈希找到原文件。后续来源变化不会改写该文件；需要当前结果时重新计算、审核并生成新文件。

库存台账JSON作为独立业务文件留存，包含完整原材领用单据、加工验收、余料实物及回用申请／独立复核／释放与领用事件、未加工原段退回单／复核／执行与取消、余料再加工实测去向／新余料及父代关联、独立实际投入及逐单待验收数量、当时在库／预留／可用／在外待加工余额及失效状态，不等同于已审报价。

“交付证据完整性”可检查当前证据或历史文件。离线 ZIP 也可使用项目工具：

```sh
.venv/bin/python scripts/verify_delivery.py /绝对路径/交付证据包.zip
```

`valid: true` 表示包内文件、清单、快照和审计链通过相应一致性检查。哈希不是数字签名，不证明资料真实或专业结论正确。校验失败时保存问题说明并联系维护人员，不修改包内文件伪造通过结果。

## 24. 模型与独立密钥服务配置

### 24.1 日常用户操作

在“图纸与算量 → 模型辅助解析”选择当前文件，核对页面显示的接收方、模型和文件范围，确认允许发送后再发起。单次文件上限 **8 MB**。未配置时不能调用，仍可使用本地解析、人工证据及受支持的本机 OCR。

结果是带来源的事实和尺寸候选，不接收模型生成金额，也不自动审定。失败可查看任务消息后重试；接收方或模型变化需重新确认。

### 24.2 维护人员配置

当前提供企业网关及 OpenAI Responses 两条可选路径。按实际已授权服务配置 `QIANG_AI_PROTOCOL`、`QIANG_AI_GATEWAY_URL` 和 `QIANG_AI_MODEL`，凭据仅在服务端注入。远程端点使用 HTTPS，本机允许 HTTP。

详细协议、Schema 和调用边界见[模型接入文档](MODEL-GATEWAY.md)。该文档中的模型名、地址和凭据均为占位说明；应使用企业真实可用且获准的服务。

### 24.3 专用密钥接口

仓库提供独立 `backend.key_service:app`，认证接口为 `GET /v1/secrets/ai-gateway`。部署系统准备仅服务账号可读的模型密钥文件及服务令牌文件，真实值不写入仓库。

密钥服务独立进程配置示例：

```sh
export QIANG_AI_GATEWAY_TOKEN_FILE=/run/secrets/qiang-model-key
export QIANG_SECRET_SERVICE_TOKEN_FILE=/run/secrets/qiang-service-token
.venv/bin/python -m uvicorn backend.key_service:app --host 127.0.0.1 --port 8101
```

工作台进程增加以下配置，再设置实际网关和模型：

```sh
export QIANG_SECRET_ENDPOINT=http://127.0.0.1:8101/v1/secrets/ai-gateway
export QIANG_SECRET_SERVICE_TOKEN_FILE=/run/secrets/qiang-service-token
```

文件路径是部署约定，需由维护人员实际创建和授权。服务令牌必须由部署系统注入，不能从无认证接口领取。此密钥服务不挂载到工作台，不应直接公开到公网。

工作台每次模型调用前获取密钥，不通过浏览器返回、不持久化缓存；接口失败时终止本次调用，不回退其他密钥。轮换供应商密钥时更新服务端文件，服务不会自动向供应商申请轮换。完整配置及恢复说明见[迁移及密钥文档](TRANSFER-AND-SECRETS.md)。接口实现及模拟验证不等于实际服务已经配置或启用。

## 25. 专业软件往返验证台账

入口：“系统配置与审计 → 专业软件往返验证台账”。它用于登记和比较**实际执行过的**试验，不是自动连接广联达的按钮。

1. 下载字段对照模板，基准及回导文件均用 XLSX 中的“字段对照”工作表。
2. 在合法授权的软件及明确版本内实际完成导出、整理及回导，保留源文件、执行日志和许可依据。
3. 按真实输出填写两份字段表，在台账登记产品、软件及工具版本、格式、执行依据、保真及失败恢复说明。
4. 运行字段比较，核对丢失、变化或不支持内容，再独立复核。
5. 按需单独留档试验记录。

字段表严格使用 `对象类型、对象标识、字段、值、单位、比较方式、绝对容差` 七列，每表最多 5000 条。前三列组成唯一键；数值按基准表指定的非负绝对容差比较，无容差填 0，单位不同不隐式换算。拒绝公式和重复标识，返回表不能自行放宽基准容差。台账可分别导出 JSON 和 Excel。

实际回导失败或字段对照存在差异的事实记录仍可由复核人核对，但“记录已复核”不会将失败比较变成通过。覆盖率只表示列示基准字段的同标识匹配情况，不代表软件全部功能兼容率。

台账通过不代表厂商接口已启用、原生模型无损或全部费用对象保真，不替代报价成果审核。当前 DWG／BIM 全专业解析及 GTJ／GQI／GCCP 真实授权往返仍需要补齐和验收。

## 26. 备份、恢复、迁移与日常维护

### 26.1 数据位置与备份

默认运行目录为项目根目录的 `data/`，数据库为 `qiangquote.db`。配置 `QIANG_DATA_DIR` 后，以实际目录为准。

由维护人员先停止工作台，整体备份同一时点的数据目录，包括数据库、存在的 WAL／SHM 文件、上传原件和历史导出件。确认备份可读后再启动。不要只复制数据库或仅下载 Excel 代替完整备份。

恢复时停止目标服务，将同一备份整体恢复到新的独立目录，配置 `QIANG_DATA_DIR` 后启动核查项目、原件、历史报价和导出下载。确认恢复正确后再安排切换，不覆盖唯一现有数据副本。

### 26.2 仓库迁移快照

`transfer/local-snapshot/` 是特定时点快照，不随日常使用自动更新，也不代表当前全部业务数据。快照移除了可登录的认证凭据，恢复后需重设密码。

恢复示例，目标目录必须不存在：

```sh
.venv/bin/python scripts/restore_transfer.py transfer/local-snapshot --data-dir restored-data
export QIANG_DATA_DIR=restored-data
.venv/bin/python scripts/manage.py reset-password admin
.venv/bin/python scripts/manage.py reset-password estimator
.venv/bin/python scripts/manage.py reset-password reviewer
.venv/bin/python scripts/start.py
```

原生离线依赖适用于快照记录的平台，不保证换目录或跨系统直接运行。跨平台优先按锁定依赖重新安装。重新生成迁移包、依赖分卷合并及校验步骤见[迁移及密钥文档](TRANSFER-AND-SECRETS.md)。打包工具清理认证信息，不自动审查业务资料的公开范围。

### 26.3 更新程序

1. 阅读新版本说明及本手册更新记录，确认新增功能的前置资料和兼容边界。
2. 停止服务并整体备份运行数据。
3. 更新代码，按锁定文件安装确有变化的依赖，重新构建前端。
4. 以同一数据目录启动，核对版本、登录、原件、代表性项目和历史导出。
5. 新功能先在独立演练工程验证，不在真实业务库批量制造测试数据。

切换数据目录时，维护命令、密钥服务配置和工作台服务分别核对。遇到新版本数据变更，不假设任意旧代码都能直接回退；保留升级前备份用于恢复。

### 26.4 中文 PDF 和部署边界

macOS 自动选取系统中文字体；Linux 需安装 `fonts-wqy-microhei`，或配置有嵌入许可的 `QIANG_PDF_FONT`。字体缺失应由维护人员修复后重新生成，不用乱码成果交付。

Dockerfile 已提供，但当前记录尚未完成镜像构建和容器运行验收。本地 SQLite 工作台不等同于已通过企业生产部署验收；企业 SSO、隔离任务队列、集中监控、恶意文件扫描、生产容量与运维方案仍需后续建设和验收。

## 27. 常见问题

| 问题 | 检查与处理 |
|---|---|
| 打不开页面 | 确认服务进程仍运行、地址及端口正确；若未构建先构建；端口占用先确认已有服务 |
| 密码无效或忘记 | 检查实际数据目录，由本机维护人员重置；初始化变量不会重置已有账号 |
| 登录后项目不见了 | 核对账号所属企业、受限成员名单、成员启停和数据目录，不要新建同名工程覆盖问题 |
| 按钮灰色或没有来源 | 核对角色、项目访问、来源是否已审、范围确认及必填字段；复核账号不能编制 |
| 上传后文字为空 | 可能是扫描图、格式不支持或解析失败；核对原件，按条件 OCR 或人工记录 |
| 本机 OCR 不可用 | 检查 macOS 及 Swift 条件；Linux／Docker 使用人工证据或经确认的网关 |
| 原文没有对应候选 | 候选识别受字段和单位限制，人工记录原文并按审核流程采用，不从空候选推断无数据 |
| 尺寸或数量突然大很多 | 核对 mm／m、面积／体积、重复数量是否乘两次、定额单位是否换算两次 |
| 来源替代后不能审核 | 使用当前有效原件，修订来源和下游，重新计算及复核；不能只改回旧值 |
| XY 窗口结果不符合预期 | 检查原点为基础中心、正向共用、所选孔及混凝土侧层、Z 边界、窗口单位和交集范围 |
| 窗口重叠被拒绝 | 核对同来源同基础同端面是否整面与窗口重复，或 X/Y 均正重叠；共享边界才可相邻分项 |
| 模板面积没有扣某孔 | 核对孔是否在所选端面或同侧层实际相接，实际交集是否正面积；体积阈值不决定模板物理孔扣 |
| 无法生成计价快照 | 看具体阻断：未审输入、编码、定额、价格、适用期、规则、图纸登记或其他依赖，逐项补齐 |
| 缺价格能否填 0 | 缺价应标记待询价；有据真实零价与缺价是不同情况 |
| 对账通过仍无法成果审核 | 检查是否独立审定、是否覆盖全部当前工程量、对账后是否又改了来源；其他门禁也须通过 |
| 提示对象已变化 | 刷新并重新打开当前对象，重新核对后提交，不覆盖他人新版本 |
| 导出仍有草稿字样 | 选择的报价未有效审定、上游失效或尚有阻断；以交付前检查逐项处理 |
| PDF 与页面封面不同 | 页面封面是摘要；选择正确报价和模板，以实际 PDF 为准 |
| Excel 修改后系统不变 | 导出文件不回写；在工作台有据修订、复核并生成新报价 |
| 历史 PDF 还是旧数据 | 历史文件按哈希原样留档是预期行为；当前结果需重新计算、审核并导出 |
| 模型调用失败 | 检查配置、文件 8MB 上限、接收方确认、密钥接口和任务消息；不在日志或截图暴露密钥 |
| 备料余料没有出现在库存 | 待留用余料仍是计划台账；15.8须有实测加工去向闭合、当前原件和独立复核并执行，才登记实物余料；不自动回用或形成采购入库闭环 |
| 软件往返台账通过但不能自动回导 | 台账记录不启用厂商接口；真实授权适配及往返仍待开发和验收 |

问题反馈时提供软件版本、页面、项目及对象版本、操作步骤、错误文字和脱敏截图。不要附登录密码、服务令牌或未经授权的完整工程资料。
