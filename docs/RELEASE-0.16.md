# 0.16 有据材料替换与配合材料

补齐 PRD F07 中材料替换的独立编制、复核和应用能力。一项原材料可替换为1至20项材料，各自记录原始消耗和价格；配合材料的比例、单位对应和性能适用性由专业原始依据确认，系统不推断或硬编码配合比。

## 流程与计算

- 组价页建立替换单，绑定当前材料、清单及资源哈希，填写替换原因、规则来源、授权和当前原始证据。替换后材料须逐项填写编码、规格、单位、原始消耗及费用归属。
- 支持有价材料及待询价材料。有价材料须明确来源类型、地区、期次、税制、有效起止及证据；历史审核价不能冒充当前价。待询价材料保持空价，应用后自动进入已有待询价任务。
- 提交仅保存提案，不改当前清单。独立复核账号核准后，编制人员才能原子应用；未审、拒绝、补件中的提案不能应用。
- 应用只替换选定材料，保留清单工程量、其他资源及原定额单位换算和分类系数。每项新消耗沿用该定额的录入口径；单位变化必须在依据中明确。费用归属只是说明，不改资源分类或费用规则。
- 输入和输出均价源完整、原清单及规则审定且适用时，使用全部当前清单、同一费用与修约规则生成条件性试算；缺价时只记录替换、不虚构差额。试算不等于专业适用性核准或正式报价。
- 应用保留旧清单、替换前资源、审核日志和新资源来源标记，使受影响清单回到待复核及旧报价审批失效。重新核准清单后才可生成新报价，历史报价字节与哈希不被改写。

## 失效与追溯

创建、复核及应用均检查当前本项目证据和原件内容。清单、规则、地区、适用日期或日期裁决变化后，旧替换单不能继续应用，须按新基线重新提交。重复提交相同请求和重复应用返回既有结果，重复标识对应不同内容会被拒绝。

应用后的材料关联替换单及子项序号；伪造、复制或更改材料身份/消耗标记会阻断清单复核与正式计价。后续正常补价和审定调价仍可保留替换来源；材料本身继续变化需重新建立替换单。撤回已应用替换的审批，会使相关清单和报价失效；不能直接重新核准旧应用记录。

报价输入及当前无价JSON、ZIP保留替换记录和应用标识。PDF/Excel/JSON增加材料替换台账，列出替换前后消耗、价格/费用归属、原因与许可、证据、状态及提交时试算；长文本分段。已审组价存入本项目授权候选时保留原清单的替换来源。

## 验收与边界

新增22项合成测试，覆盖一对多替换、试算与新报价一致、原换算只执行一次、独立角色、先审后应用、重新复核清单、缺价与补价、旧报价不变、审批撤回、基线变化、原件替代/丢失、非法输入、重复请求、引用篡改及候选库兼容。浏览器在隔离工作区完成编制提交、独立账号复核、编制账号应用，未操作真实工程数据。

本版是项目内的有据替换流程，不是官方配合比设计器或跨项目可复用的专业换算规则库。尚未提供批量多原料替换、质量性能或物料平衡自动校核、供应商询价收发、完整官方定额/价格接入、复杂图纸识别及完整专业算量。专业软件授权接口和真实工程黄金底稿验收仍待完成。
