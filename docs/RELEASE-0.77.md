# 0.77 区间内实际柱距上限核查

继续补齐PRD F05的栏杆计量和复核。八种立柱模式均可单独启用“区间内实际柱距上限核查”，按最终实际计入柱位置计算逐对距离，并与独立原件核定的上限精确比较。上限等值允许，超限阻断预览及送审；不以原均分或定距规则代替移后柱距，也不改变根数、柱位、下料规格或材料质量。

## 核查范围与输入

每个材料项可选填`spacing_check`，完整包含`max_spacing`、`spacing_unit`、`measurement_basis`及分别关联上限和范围说明的`evidence`。启用时不自动复制原间距，不默认选择依据；必须明确填写同一材料项全部计入区间共同采用的上限及其专业范围。不同上限可按实际做法拆分材料项。未启用时不写该字段，不能以空对象、null、隐藏旧值或无依据的上限表示启用。

核查仅限同一材料项、同一已审来源计入区间内，按最终S排序的相邻两根实际计入柱之间的沿S距离。定距、均分、指定加柱、禁布移柱及含加柱移柱全部参与，沿用来源明确的三维或水平口径；距离不是柱净空或两点间直线距离。不跨越局部计入缺口，不连接不同区间或原边，不补转角或闭环首尾。

每个区间列出计入柱数、相邻对数、最大实际柱距及对应相邻对，逐对保留两柱总编号、原规则节点或构造加柱身份、起终S、距离、精确表达式及差值AST。未归属端柱时，边界到最近计入柱的距离单列，不当作已通过的实际柱间距；0表示该边界已有计入柱。无柱区间明确“整区间无计入柱”，只有一根柱的区间明确“无相邻对”，两者均不称为通过。整个材料项没有任何区间内相邻对时阻断启用，不能形成空核查。

超限错误明确来源区间、相邻柱号及核定上限，须有据修订布置或上限，系统不自动移柱、加柱或放宽上限。跨区间、缺口、转角、跨边、闭环首尾及专业构造仍须另核，本版不能认定全局柱距合规。

## 精度、记录与兼容

实际位置采用精确有理数与原边根式a+b×√q建立，按精确S排序；相邻距离同样保存有理常量、根式系数和原边长度平方，比较与上限的符号和平方关系，不按显示小数或容差放行。距离显示采用扩展工作精度避免大端距相减时吞掉微小正差，再保留80位有效数字；判定仍由精确数完成。差值AST保留两根原位置公式，JSON保留精确结构；界面及报表把结构显示为可读分数和根式。

核查规则为`railing-local-post-spacing-1.0`，含核查项的材料表采用`railing-material-mass-1.10`。材料数量、质量及质量公式不变，新增依据和单位换算进入完整性校验、来源哈希及审核记录。字段变化清空预览和确认；关闭核查删除上限及其依据，重开为空，模式切换清除隐藏核查配置。来源变化后沿用材料行整体清空，须重核范围。

仅修改上限或关闭核查，即使质量相同，也须重新送审并使旧计算书与审批失效；历史记录及重建前旧清单保持。沿用原件损坏门禁、角色租户隔离、并发修订及独立复核。不新增依赖或数据库迁移。独立载入0.76代码，25组来源×8种旧模式共200条未启用核查的完整计算记录完全一致，原版本保持。

## 界面与报表

编制页独立开关及上限/范围依据；预览和独立复核页提供区间摘要、未归属端部距离、逐对距离及精确表达式，明确已核范围和未核范围。长小数在窄列换行，避免复核窗口越列。

新增“立柱区间实际柱距”“立柱相邻柱距明细”“立柱柱距核查依据”三类Excel/PDF表；每对完整起终端距和距离保持同页，范围说明放宽表。原有数量、禁布、移柱及原布置表保留，旧报价不混入新核查项。
