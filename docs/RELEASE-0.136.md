# 0.136 已下单采购订单登记、独立复核及追加修订

“组价审核 → 已下单采购订单登记”凭当前有效已审内部申请和实际下单原件登记已发生订单。供应商、规格、数量、单价、税制和费用沿用冻结申请，不在登记中改量价。保存即锁定申请取消及任何重审；登记拒绝、补件、原计划后续失效或追加修订均不解除锁定。

独立账号核查实际原件。上游测算、报价及计划后来失效时保留已发生登记，单列计划核查提示；冻结申请及原复核关联保持、最新实际原件有效时仍可核查已发生事实，不等于旧计划可再次下单。登记信息错误只从最新版本追加修订，旧版本和审核、JSON保留；当前同供应商订单号防重，过期摘要或并发分叉拒绝。成果历史明确标为独立订单登记。

本次不向供应商发单、不签合同、付款、推定收货或入库；不支持差异订单改量价、换申请／供应商、外部撤单、撤销误报下单事实、解除锁定或冲销。首次当前性门禁不满足的历史补登须另核，不修改旧数据伪造通过。详细操作、字段和边界见[使用手册19.9](USER-GUIDE.md)。

42项新增订单专项与317项既有相关回归，共359项检查通过（80.30秒）。覆盖来源、日期、本人回避、首次当前性门禁、保存即锁定、登记／取消并发、同供应商当前订单号防重、最新修订及摘要租约、原计划失效不抹除已发生登记、独立实际原件、整批失败回滚、旧项目及历史文件。前端类型及生产构建、普通与本次基线手册检查通过。

隔离合成浏览器：已审A申请15.75m³／1396.15元登记SYN-ORDER-001，预览不锁申请，改号清确认及预览，恢复后保存R1即锁定；另一账号独立复核。随后明确撤审上游合成测算，原订单事实、审核和金额保持并提示原计划待核查；按单独合成修订原件改正漏录后缀为SYN-ORDER-001-C，追加R2并再次独立复核，复核窗口包含计划提示，R1历史保留。最新原件字节变化使R2当前复核无效但不撤销下单或解除锁定，恢复原件后登记重新有效，原计划撤审提示继续保留。工程、消耗、资源价、原申请及供应商、工程报价和库存摘要保持；六阶段JSON原字节与SHA256及58条审计链通过。成果历史明确标识独立订单登记；页面无警告或错误。
