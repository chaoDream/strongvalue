# 0.108 基础水平模板简单多边形与凹窗口

日期：2026-10-27。前后端与使用手册版本：0.108.0。

## 本次完成

基础顶底、台阶平台、内部孔底／孔顶增加3至12顶点的简单直边窗口，可含凹角、L形、U形及C形。沿真实边界顺序填写原始XY及逐坐标依据，不自动排序、修形或填补凹口；重复、共线、自交、非相邻接触及重叠边阻断。共同基础中心、XY正向、Z和最终个数继承既有原件与复核约束。

新窗口沿所有顶点、直线与圆弧交点划分X区间，以奇偶规则配对各内部纵向片段，分别裁切混凝土侧层、上层覆盖和实际孔，再用直线／圆弧原函数积分。不以最上、最下边界之间的全部区域代替凹窗口。全部有效片段无剩余时才形成零接触证明，微小正缝隙不归零。200位Decimal工作、80位输出、有序公式依赖及独立重放沿用；新增规则为`foundation-horizontal-formwork-1.9`。

完整窗口防重采用精确有理数竖向扫描，可处理凹口、混合矩形／凸窗口、包含及极小正重叠。仅共边或点接触可分项，窗口落入凹口空区可分项；不按实体外或孔内投影豁免重复登记，跨记录同样校验。

页面接通轮廓选择、顶点录入、确认撤销、预览／修订及独立复核。JSON保留全部输入、多个纵向片段、AST依赖和有理数防重见证；Excel／PDF新增“基础凹窗口顶点”“基础凹窗口分段积分”，完整覆盖时新增“基础凹窗口零接触校验”，相关窗口对另有“基础凹窗口防重分段”。原整面、矩形和凸窗口保留原路径、规则及历史数据。

详细操作见[使用手册16.8](USER-GUIDE.md#foundations)。
