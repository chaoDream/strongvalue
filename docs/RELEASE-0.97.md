# 0.97 矩形孔壁局部横向条带模板

继续补齐PRD F05的实际接触模板面积，矩形基础孔壁从逐侧整宽扩展至有据局部横向条带。条带沿来源基础局部XY，按偏心孔真实界限及层孔共同标高校验，扣除与外界或相邻矩形孔的真实无接触交集，接通编制、修订、独立复核、计算书、m²清单、映射和三格式导出。

## 几何与接触范围

沿用`foundation_void_formwork`及当前已审`post_foundation`。来源可为矩形、圆柱及同心矩形/圆形台阶基础，选入孔须为已审轴向矩形竖直孔或有限标高凹槽；不能在模板中新增孔或改变孔位。圆孔仍仅整周，不接受条带或局部圆弧。

矩形孔X正/负侧横向沿基础局部Y，Y正/负侧沿局部X，原点为基础中心0，不以孔中心0，也不随观察面翻转。孔心偏移必须带入真实边界：例如孔心X150mm、长100mm，Y正侧的横向界限为X100至200mm；不能直接使用±50mm。起坐标须小于止坐标并完全在该孔该侧界限内，不自动裁切、调向、吸附或坐标变换。候选返回只读`lateral_bounds`，分别标明各孔侧实际起止坐标及横向轴。

横向可独立用mm、cm、dm、m、km，与Z单位无须相同；沿用原始和换算后18位精度约束。须逐坐标关联当前项目原件，核定基础局部XY与图纸对应的共同基准并确认。同一来源基础项全部孔、层、孔侧及跨记录条带须使用相同基准说明和同一原件；不同基础项可各自有据核定。

所选毛面积=(横向止−横向起)×(终止Z−起始Z)。Z继续受孔与层共同标高约束，跨层分项。与本层矩形基础外边界重合的选入条带全部没有混凝土接触，毛面积全扣、净0；与相邻矩形孔对向壁贴合时，只扣所选横向与该邻孔的交集再乘所选Z与邻孔Z的交集。两个方向均须为正，端点/边界相接不产生正面积；多邻孔按实际各交集扣除，来源实体几何校验继续阻止孔重叠。体积阈值不改变物理孔壁或实际无接触面。

各范围继承对应基础项全部最终个数一次，不重复乘孔数、层数或来源重复。全部基础个体须相同条带做法；差异做法应先拆来源。所有宽、高、界限、毛扣净、单位换算及分离间隔保留Decimal 80位和AST，不逐带修约，只有总净面积按有据0至12位HALF_UP修约。

## 重复、修订与独立复核

同来源、同基础项、同层、同孔、同内壁面，只有横向及Z均为正范围交叠才重复。相邻条带共边、标高相接或任一方向分离可共存；整宽与局部带也参与，不能通过整宽/条带切换重复计量。净量为0也保留范围占用。跨记录保存、预览、复核及重算均校验，失效记录不能靠新建覆盖，须修订原记录。

新建或启用条带时坐标、原件、基准及确认均空；同来源修订恢复原始单位和全部参数，整体须重新确认。切换孔壁面、孔、层、基础项删除旧条带；切换整宽/条带或修改条带撤销本面接触说明与依据及整体确认，条带内部修改撤销基准确认。切换圆孔不再提供条带。读取新来源清空旧范围、做法、原件和修约。

预览和放弃不改项目。整面修订成条带保留精确历史和旧清单、使旧计算书失效；来源几何或上游变更使内外模板沿依赖链失效。继续使用原件字节五门禁、当前已审来源递归校验、角色租户、异项目原件阻断、实际ID、乐观并发、证据索引/快照/AST重算篡改阻断。

## 接口、报表与兼容

矩形`contact_ranges`行可额外携带`lateral_range`；不填沿用原整宽规则。以下仅为合成接口结构，尺寸不是工程默认值：

```json
{
  "lateral_range": {
    "parameters": {"lateral_start": "120", "lateral_end": "180"},
    "unit": "mm",
    "evidence": {"lateral_start": "当前起坐标原件ID", "lateral_end": "当前止坐标原件ID"},
    "coordinate_basis": "据当前原件核定基础中心及局部XY与图纸对应，孔位沿此基准",
    "coordinate_evidence_id": "当前共同坐标原件ID",
    "scope_confirmed": true
  }
}
```

根字段、Z及原有逐参数原件结构、1至200项上限不变。带条带结果使用`foundation-void-formwork-1.1`，逐项新增`lateral_start/end/axis`、`face_lateral_start/end`、`full_face_width`、`lateral_frame_hash`及对应数值AST，保留原始`lateral_range`；`void_lateral_checks`记录同孔同层同侧的横向/Z间隔、状态及AST。旧整面和圆孔整周结果继续使用1.0且保持逐字段一致；原外侧模板规则保持。

沿用独立孔壁m²清单口径和有据编码映射，映射不改变面积、不自动套外侧模板编码。Excel/PDF在六张孔壁专表之外，按需新增“基础孔壁横向条带”“基础孔壁条带基准与原件”“基础孔壁条带分离校验”三表；无条带旧报表不新增空表。全部结果来自存储的高精度计算，不在报表二次算量；长原件/基准续行、Excel行高与PDF跨页表头适配。JSON保留完整原始值、换算、来源、证据和AST。
