# 0.88 实心圆柱与同心圆形台阶立柱基础

继续补齐PRD F05基础计量，并贯通F06清单、F09报表及F11独立复核和版本。立柱独立基础新增实心圆柱与2至10层同心圆形台阶，数量引用已审最终立柱，不从材料质量或栏杆长度倒算。旧矩形和矩形台阶沿用原规则与计算结果。

## 直径、净高及台阶范围

选择“实心圆柱基础”时，行`shape: circular`仅包含来源`material_index`、`parameters: {diameter,height}`、`length_unit`、适用说明及三项原件（实际直径、净高、范围）。必须填写原件中的实际直径，半径或公称尺寸不能替代。仅计竖直、实心、等径圆柱，无内径和孔洞扣减。

选择“同心圆形台阶基础”时，行`shape: stepped_circular`使用`levels`，每层仅有实际直径、本层净高及两项原件；另有本项范围原件和`stacking_confirmed: true`。必须2至10层，自下而上同心同轴垂直紧接无空隙，上层直径不得大于下层；精确等径允许，微小外伸也会阻断。高度为该层净高，不是累计高度。局部Z从本基础底面0起累计，不代表工程绝对标高。

支持mm/m/cm/dm/km。单个来源立柱项内全部基础同一尺寸及做法，各项各层同一材料；各层共用本项单位。不同做法须先拆分来源立柱项。矩形、矩形台阶、圆柱、圆形台阶可分属不同立柱项共同核定，未选项不补算。不得额外填写半径、根数、层数乘数、累计高程、内径、扣减或隐藏系数。

## 计算、编辑及审核

单圆柱体积=π/4×实际直径²×净高，台阶为逐层圆柱体积之和。每根最终保留立柱对应一个基础，层数不增加基础个数，来源重复仅乘一次。逐层及分项不修约，累计全部体积后仅按明确位数HALF_UP修约。Decimal 80位沿用工程现有π常量，保留常量、原尺寸、单位换算、逐层相对底顶Z、单层/单基础/单组/全部体积及公式AST。

含圆形项采用`railing-post-foundation-1.2`；纯旧矩形仍1.0、纯矩形台阶仍1.1。来源材料质量、布柱、柱距及下料记录不修改。界面长小数可展开查看完整未修约值，带省略号仅为显示截取，不参与计算；展开完整值会自动换行。

切换形态清空本项尺寸、原件及本项/总体范围，撤销确认和预览；新增层为空，增删层须重核范围与原件。修改圆台阶尺寸、单位或本项依据撤销叠置确认，所有编辑撤销整体确认。圆柱不附带台阶确认字段。恢复同来源修订保留对应形态输入和原件，整体确认撤销；来源变更后旧选择、尺寸、原件及范围清空。

预览不改持久化项目。保存、独立复核、重算及计算书复核重建来源、原件、逐层尺寸、常量、数量与AST。相同来源立柱项不能被其他基础记录重复选入，伪造旧ID不能绕过；来源或祖先修订级联失效，并发、角色租户及原件字节门禁延续。修订保留精确历史、旧清单和报价快照。

## 清单及三格式成果

清单继续使用`post_foundation / volume`基础实体体积口径，显示名称补充圆柱；有原件的编码映射仍须独立复核，不更改数量。材料、做法和项目特征须人工核定，不自动生成官方编码。

JSON保留完整计算，Excel/PDF新增“圆形基础圆周率与口径”，基础逐项尺寸以Φ明确直径；圆台阶沿用“台阶基础逐层体积”“台阶基础逐层原件”，逐层原件分别列直径及净高。圆形报表长范围分续行，Excel自动行高完整显示长小数；矩形及矩形台阶原表内容保持。旧报价不增加新表。
