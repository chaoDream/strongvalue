# 0.120 实际加工结果与实物余料验收入库

日期：2026-10-28。前后端及使用手册版本0.120.0。

## 本次完成

库存新增“实际加工结果与余料入库”，仅引用已执行完整原材投入加工单。逐项实测原材根数、成品／锯缝／切除／报废总长，以及余料编号、每段实测长、根数、库位和可留用验收。逐字段原件、单位与实际偏差说明必填，原材总长与全部实际去向须精确闭合；不按排料计划生成余料、不用容差补差。

预览只读，修改即清除旧预览；保存、独立复核均不入库，显式执行后才占用该加工根数的核对额度并登记独立余料。并发、重复请求、超额度及重复余料编号阻断；已执行结果不可取消或重审，未执行可有据取消。余料可有据停用，但不退回加工额度、不复用编号，也不等同于实物报废。历史依据失效保留数量并提示待核查。

余料与完整原材分账，不能用完整原材入口重复登记；修复领料后新增预留须按实际在库数而非最初登记数核对的门禁。净工程量、原排料及报价保持。详见[使用手册15.8](USER-GUIDE.md#stock-processing-results)。

## 验证范围

58项加工验收专项、462项既有库存／领用／排料／权限及报价、44项手册／交付／历史PDF预览，共564个不同相关检查通过。停用语义修正后专项重跑通过，前端类型检查及生产构建通过。浏览器核查1mm差额阻断、编辑清除旧预览、独立复核及显式入库；1根余料3.574m／10.722kg，停用后原在库及验收数量保留、有效采用归零，加工额度不回退。工程数据摘要、三份留档字节与哈希及39条审计链核对通过。相关数量、页面与截图见[工程验证记录](QA.md)。合成数据不代表真实工程或仓库验收。

本机8000服务已更新并只读核对为0.120.0，加工实测预览、执行入库及余料停用入口存在。
