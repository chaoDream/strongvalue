# 0.68 栏杆板网片净展开面积与材料质量

继续补齐PRD F05的栏杆材料计量。现有栏杆材料表新增“矩形板件或网片”模式，可与连续线材、独立定长件混合列项；板网片采用独立核定的展开长宽、每组片数、矩形开口及单位面积质量，不从栏杆长度或间距推断片数，也不从建筑投影推算展开面积。

## 计算范围

每片为一个展开矩形，局部原点固定在左下角，长沿X、宽沿Y，与栏杆来源XYZ独立。每项可明确0至20个轴向矩形开口；开口坐标、长宽、单位、说明和逐参数原件均须填写。开口完全位于外矩形内，可接触外边界；重叠、嵌套开口取并集，仅扣一次。越界、全片扣尽、零负尺寸及缺依据阻断。无开口必须显式空列表，不能省略。

单片净展开面积乘每组独立片数及有依据的面密度，支持kg/m²、g/m²。面密度依据必须匹配该净面积口径；网片微孔不自动推算或再次扣除，不能混用已含微孔的面密度与重复扣孔。密度、厚度、含钢率、损耗、搭接和接头均不自动补入。水平投影栏杆来源允许列独立展开板网片，仍禁止将水平投影用于坡段连续线材下料。

每表仍限1至50项，片数为1至1000000整数。含板网片的新记录采用`railing-material-mass-1.1`；旧纯线材继续原1.0计算结果及精度规则。Decimal 80位计算，开口并集、净面积和分项质量不单独修约；材料合计后只乘一次来源重复数量，仅总质量按有据选择的0至12位HALF_UP修约。完整保存原始尺寸、换算、开口并集、分条闭合、逐参数依据和可重算AST；板片内部的固定单片数量维度与来源重复数量分开命名，防止相互覆盖。

## 编制、复核及导出

“图纸与算量”的栏杆材料表支持选择板网片模式、录入展开尺寸、增删开口、独立片数和面密度、逐参数依据及预览送审。模式切换清除其他模式参数，任一参数变化清除旧预览及范围确认。复核页显示单片净面积、单组质量、总量及展开开口示意，可展开原始尺寸、依据、分条面积闭合和锁定栏杆来源。示意图只用于定位，不可测量。

沿用现有审核、对象哈希、精确历史、原件校验、计算书重建和kg清单映射。来源栏杆修订使材料表及下游失效；读取新来源清空旧材料项的模式、片数、面密度、尺寸、开口、说明、逐项依据及确认，需重新核定。原几何变动亦沿既有依赖链失效。没有新依赖或数据库迁移。

JSON保存完整板片计算记录；Excel/PDF新增“板网片净面积与质量”“板网片原始尺寸与开口”“板网片面积分条闭合”，材料质量汇总继续包含线材及板片合计。旧报价快照不会混入后加的板网片。
