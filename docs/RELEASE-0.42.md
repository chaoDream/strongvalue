# 0.42 本机扫描页文字识别

补齐PRD F01/F04的一部分：在“项目与资料”新增扫描页文字识别。选择当前PDF及页码后，后台在本机用macOS Vision读取页面图像，不把工程资料发送给第三方。PDFKit按显示裁切区域和页面旋转渲染，每边不超过2400像素。需macOS及Swift工具链；Linux/Docker暂不支持此本地适配器，界面明确显示不可用，仍可人工标注或使用已有模型网关。

识别结果保存为`local_ocr`待复核证据，保留原件哈希、页号、识别器/系统算法版本、渲染大小、逐行原始文字、置信度及显示页归一化位置。置信度不是工程准确率，像素和识别框不可换算工程尺寸。机器文字不直接生成事实、尺寸、构件或工程量，也不冒充PDF原始文字层进入标题栏自动候选；编制人可对照原页人工记录信息，再走独立复核。

## 原件与任务保护

- 识别前后校验原件字节、当前文件版本、页号及任务执行标记。源文件被替代或篡改时不提交旧结果。
- 同一引擎、文件哈希及页面只保留一个任务；完成后重复点击不重复写证据，失败使用原任务重试。
- 独立线程锁将单进程的本地识别串行化，识别期间不持有数据库写事务。单次执行限90秒；临时原件和编译缓存结束后删除，不记录原件路径或识别器错误输出。
- 最多2000行、单行2000字、总计100000字；异常文字、位置和置信度拒绝写入，不截断后冒充完整结果。
- 无文字时明确提示人工标注，不能据此判定图纸没有内容。失败、重试、完成均审计；服务中断后可重试，不覆盖已有文字层解析状态。
- 沿用企业、项目成员和编制角色权限；复核账号不能发起识别，越权访问拒绝。
