# 0.60 多边形侧面局部分区与逐子面核定

继续补齐PRD F05、6.1中模板及防水的局部范围核定。已审等厚多边形实体的外轮廓侧面、贯通孔内侧面可按原边展开进行两轴矩形分区，不必把整条侧面全部计入。带孔或凹形的上下净面仍整体核定，不能套用轴向矩形分区。

## 原边局部坐标

S为从原边起点、沿输入P起→P终方向量取的距离；Z为从局部底面0起算的高度。范围分别为0至该原边80位边长、0至来源厚度，均不是共同XY或绝对高程。反向原边会改变S原点，须按新来源重新核定，系统不猜测施工方向。

每原面每轴最多8条分割线，保留原始值、长度单位及独立原件依据；换算后须严格在原面内部，重复、落边和越界均阻断。非空分区必须至少有一条线，原面不能重复或过期，最多1000个最终计量面。多边形上下净面在界面中不可选作分区原面，服务器也拒绝夹带请求。

## 数量、精度与身份

分割按S/Z坐标排序，完整铺满原展开矩形；子面面积为沿边区间长度乘局部高度区间，计入子面合计后仅乘一次来源重复数量。保存原轮廓/边/起终点、原面和子面编号、局部区间及公式AST。子面身份由原面及换算后区间决定，同坐标改单位或调整分割输入顺序不改变几何身份，不把子面局部S冒充设计X/Y。

新增分区规则`polygon-boundary-1.1`。Decimal 80位计算每个子面及工程量，不另行修约；非有理边长沿用来源80位平方根。另用200位中间运算验证这些有限十进制区间恰好铺满原边展开范围，保存子面面积合计与原面80位面积的精度差，不通过调整某个子面调平。这是计算精度记录，不声称非有理几何在有限位数下绝对精确。未分区的旧多边形仍按1.0原结果重建，原长方体分区算法及版本保持。

## 编辑和复核

局部分区设置只列出原外侧/孔内侧，明确S/Z口径；设置变更立即清除旧预览，并在应用前禁用预览及保存。应用后变化子面的决定、说明和依据清空，未变化面按几何身份保留决定；移除分区恢复的原面也需重新核定。已有分区可恢复原始值、单位和依据，再明确修订。

展开图保留原边尺寸和全部同原面的子面位置，绿色计入、灰色排除、黄色待核定，粗框定位当前子面。全部最终候选面仍须明确计入或排除，并记录做法和原件依据。独立复核可核查换算、原面/子面映射、闭合与精度差、原始来源及逐面决定。

沿用原件实际字节、文档/证据、来源版本哈希、保存预览及下游重算校验。分割值、依据或保存校验记录被改动，审核/计算书复核阻断；来源修订后旧哈希及原面身份失效，不能继续沿用旧分区。分区修订保留旧已审对象精确历史，使旧计算书与清单审核失效，重新核定、复核和重建后形成新数量。
