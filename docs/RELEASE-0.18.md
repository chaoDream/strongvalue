# 0.18 单位、单项与项目独立取费

继续补齐 PRD F08/F09：在0.17已复核工程结构基础上，支持单位工程、单项工程各自登记费用，再向建设项目汇总并执行项目费用。未配置下级费用时保留原计价行为，旧报价仍使用自己的不可变快照。

## 编制与复核

- 规则编辑器可为已复核的单位或单项工程增加费用组，每组独立维护费用顺序、费率、计算基数、来源说明和本项目原始依据。规则包仍须记录地区、专业、标准、有效期、许可及修约方式。
- 分级规则绑定工程结构的完整校验值。修订结构后必须重新绑定、提交和独立复核；不自动把旧费率迁移到新节点。
- 保存、复核和生成报价校验节点、依据当前版本与原件；页面提交携带规则校验值，防止覆盖他人的新修改。失效依据、未审结构、错误归属或超期规则阻断后续计价。
- 每个节点最多50项费用，总费用上限500项；禁止重复节点组、未知节点、缺失依据、非法数字、跨范围引用和向后引用。

## 确定性计算

按“单位工程 → 单项工程 → 建设项目”计算。每个范围独立使用有序费用表达式，费用标识可在不同范围复用，不能引用另一范围的费用标识。

| 基数 | 含义 |
| --- | --- |
| 本范围清单合计 `subtotal` | 该范围全部原始清单合价，不含任何费用 |
| 下级含费合计 `children_total` | 直接下级节点含费合计；单位工程为本单位清单合计 |
| 下级费用合计 `lower_fees` | 全部后代节点费用之和 |
| 当前累计 `running` | 下级含费合计加本级已执行费用 |
| 人工、材料、机械、设备 | 本范围按数量累加的对应原始费用基数，不含下级附加费用 |
| 前序费用 `fee:<key>` | 本范围内已计算的指定费用 |

每项费用按既有 Decimal 精度与规则修约，验证“清单合计 + 全部各级费用 = 报价总价”，并检查每个节点闭合。下级费用只汇总一次；不自动分摊上级费用，不自动生成专业费率或税费。

## 联通流程与成果

- 汇总页分别显示清单合价、下级费用、本级费用和含费合计；费用明细标明单位/单项/项目范围。
- 批量调量、材料替换的金额试算使用同一分级计价，并绑定工程结构上下文。内部敏感性测算使用所选报价的历史结构和规则。资源价格局部差额仍明确为不含取费的差额。
- 版本对账保留费用范围；PDF/Excel/JSON/ZIP保留规则、各级金额、基数、来源和依据。新增分级取费规则表；旧快照继续按旧结构输出。

## 验证与剩余范围

新增22项合成测试，全量269项通过，生产构建通过。覆盖逐级金额、局部费用引用、非法结构/规则、独立复核、并发提交保护、依据失效、结构重绑、四种导出、旧报价不变，以及调量/替换/敏感性测算的一致性。

隔离浏览器完成规则编制、独立账号复核与新报价生成：清单1575.15，单位费73.51，单项费40.43，项目费50.67，总价1739.76。截图见 `docs/qa/v0.18-scoped-fees.png`。费率仅为合成数学测试，无真实专业签审效力。

这仍不是PRD全量验收。尚需授权的地区/专业标准规则包、官方定额及信息价、复杂图纸与完整专业算量、厂商授权接口、真实工程黄金底稿及生产环境验收。该版本提供人工有据配置与确定性执行，不代表内置的合成费率符合任何真实项目规范。
