# 0.126 完整原材在库盘点与差异调整

日期：2026-10-28。前后端与使用手册版本0.126.0。

已审且未停用的原材批次现在可登记现场在库完整根盘点，包括实盘0、盘盈、盘亏及无差异。先核对原批号、库位、材质截面、定尺和每米质量，填写当日日期、盘点人、盘点及差异核查原件，预览根数及精确长度／质量差异，保存后由另一账号独立复核，再显式执行。保存和复核不调整；执行追加事件，原登记、领用、退回、投入加工及结果保留。详见[使用手册15.14](USER-GUIDE.md#stock-counts)。

实盘不能低于未释放预留，不自动减占用或改配。本批领用、完整退回、加工或另一次盘点后，旧快照失效，即使在库恢复原数也须重新现场核对；其他批次变动仍需刷新整体台账版本。须同一中国标准时间日期完成，过日有据取消未执行单后重新盘点；已执行不可取消、重审或冲销。

原件四阶段字节门禁；历史盘点依据失效保留实物数量，整批及来源余料、所有后代可用0，禁止新预留／领料／盘点，不能用新盘点绕过。既有领出原材可凭新有效原件记录实际加工或完整退回，历史异常继续提示。出库按事件发生时在库校验，不能用后来的盘盈追补。JSON独立留档包含盘点、复核及事件，旧导出原字节保持。余料盘点入口保留。
