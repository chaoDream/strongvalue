# 0.105 圆形台阶平台的XY局部窗口模板

## 本次补齐

基础水平模板新增圆形台阶平台的有据XY矩形窗口。下层与紧邻上层的直径、平台标高、实际孔位及全部最终基础个数只读继承已审基础；窗口继续要求四坐标、单位、逐坐标原件、与来源孔位共用的基础中心XY正向和范围确认。平台毛面积=(下层圆∩窗口)−(上层完整名义圆∩窗口)，孔扣=(孔∩窗口)−(孔∩上层圆∩窗口)。只扣起Z<平台Z≤止Z的物理孔，体积扣孔阈值不填实孔，不把上层孔底并入外露平台。

上下层圆分别与窗口作解析裁切。轴向矩形孔先与窗口相交，再求该矩形与上层圆交集。圆孔共同覆盖为两圆与矩形窗口的三重交集：按各圆支撑、圆与窗口水平边交点及两圆边界交点的X分段，逐段选择最低上边界和最高下边界，用圆弧原函数积分后累加。工作精度200位Decimal、保留80位和既有固定π；保留分段端点、有效边界、面积及可重放AST，不使用网格或几何容差。完整包含和分离有独立分支；分段还证明共同交集是否等于某一完整裁切圆，成立时复用同一表达式，避免等价式相减的末位误差。不能确认严格面积界限时阻断。

新增外露平台全孔覆盖的几何证明。把下层、上层、孔与窗口的所有边界事件分段，逐段核对下层减上层后的外露带完全位于该孔内；保留端点、中点、上下边界、孔内余量及对应公式。证明成立时实际孔扣复用同一平台毛面积及AST，净接触严格为零；直接算得的共同覆盖解析值仍单独保留，不作容差归零。有未覆盖正面积时不签发证明。该分支支持圆孔及轴向矩形孔。

同一平台的整面与窗口、X/Y均正重叠的窗口及跨记录重复仍拒绝，即使重叠只在上层覆盖、孔或轮廓外；共享边界可分项。不同下层序号对应不同平台，可共用XY窗口。同来源同基础项的全部窗口须相同坐标说明和原件。数量继承全部最终基础个数一次，逐孔逐面不修约，仅总净面积按明确位数HALF_UP修约。窗口修订撤销确认，来源修订使旧模板失效，重新读取来源清空旧范围、做法、原件、修约及确认。

页面接通圆平台窗口编制、独立复核、上下层裁切、孔与窗口交集、共同覆盖分段及全孔覆盖证明。JSON保留完整输入、来源、曲线细节及AST。Excel/PDF按需新增“基础圆平台窗口分段积分”“基础圆平台窗口全覆校验”；旧平台曲线表及窗口曲线表按实际曲线类型标注，不把三重交集误写为四象限过程，也不把窗口内下层面积误写成平台差面积。没有新对象的成果不增加空表。

圆平台窗口使用`foundation-horizontal-formwork-1.6`，旧矩形平台窗口保留1.5、整体端面窗口保留1.4，其他旧整面保留1.0至1.3及原结果。没有新增运行依赖。
