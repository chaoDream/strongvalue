# 0.57 水平设计多边形、凹形与逐孔净量

补齐PRD F05与6.1中非矩形轮廓、开孔和原始坐标算量的一部分。图纸与算量页新增“水平设计多边形与扣孔”，按有据XY坐标计算斜边或凹形区域净面积，也可乘统一竖向厚度得到净体积。无需将每个斜边或凹角拆成轴向矩形，不从图片测量或自动推断设计边界。

## 输入与边界

- 一个简单直边外轮廓，可明确无孔，或增加最多20个直边贯通孔。每个轮廓3至100点，全部轮廓合计最多200点。末边从末点连回首点，无需重复首点；顺时针、逆时针及前向共线中间点均支持，不自动排序。
- 每个点独立填写XY、原始长度单位和逐坐标证据，支持m、mm、cm、dm、km、负坐标及既有18位精度约束。每个轮廓独立记录名称、范围与扣孔说明及原始依据；可明确将本轮廓所选依据应用到全部XY，之后仍可逐点修改。
- 共同水平设计平面、原点、XY方向及高程口径、总计量/扣孔条件、重复数量与修约均须有据。水平性及高程口径由人员依据原图确认，系统不以二维坐标证明真实水平面。体积模式须另填统一竖向厚度、单位及依据，面积模式不得夹带厚度。
- 重复数量1至1000000整数，总量修约0至12位。采用前须主动确认平面、顺序、首尾闭合及逐孔计量边界；任一表单字段变化会清除旧预览及确认，须重新核对、预览后送审。

## 确定性计算与错误阻断

服务器先统一长度单位，使用Decimal 80位进行叉积、精确线段相交和绕数包含判定，不使用屏幕坐标或浮点几何容差。轮廓重复顶点、零长/折返/重叠边、非相邻接触、自交和零面积拒绝；相同位置使用不同单位录入也按实际坐标拒绝重复。

每个孔必须严格位于外轮廓内部。孔顶点越界、孔边跨越凹角、接触外边、孔之间相切/相交/重叠或相互包含均拒绝，不裁剪、不自动合并，也不重复扣孔。此处选择严格分离模型；接触孔或复杂连通洞口需另行核定真实轮廓。

相对本轮廓首点，逐边计算有向叉积，合计取绝对值除以2得到面积；凹形的负贡献保留。外面积扣除各孔面积后，再乘统一厚度（体积模式）和整组重复数量，仅总量HALF_UP修约。原始尺寸、单位因子、逐边及逐轮廓公式AST、正负贡献、净量和修约差额完整保存；浏览器只显示服务器返回的精确字符串。大原点下极小几何若无法可靠画成浏览器示意，会提示查看精确数值，不改变算量。

## 编辑、审核与清单

支持逐点增删、上下调整顺序及逐孔增删，示意显示净区域、孔与选定轮廓的点号，不能拖图改尺寸。预览不写入构件或工程量；错误轮廓不能保存，保存产生待复核构件，独立复核账号可核查轮廓、各点证据、逐边叉积和扣孔包含/分离结果。

原件实际字节、文档及逐坐标证据、保存预览与来源校验值在构件复核、重算及计算书复核时重新验证。修订沿用对象哈希并发保护及下游失效规则；旧计算书、旧清单及旧报价保留，须重新审定新构件、计算书后重建清单。并修复通用构件修订的历史复制时机：先复制旧构件完整状态，再使当前对象和下游失效，避免将已审旧版在历史中保存成失效状态；不回写既有历史。

新增`polygon_region`结构化类型，接入既有预览/保存、复核、算量、底稿对账和清单流程。清单映射新增“多边形扣孔后净面积”和“多边形等厚净实体体积”两个独立口径，不能混用单位。新类型不进入原始简单几何表单，现有轴向矩形、长方体、CAD管线和旧计算内容不改写。未新增依赖或数据库迁移。
