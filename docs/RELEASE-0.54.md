# 0.54 已采用CAD范围回查与原对象投影核对

在[0.51原对象投影](RELEASE-0.51.md)、[0.52取段](RELEASE-0.52.md)和[0.53取段组装](RELEASE-0.53.md)基础上，补齐采用之后的原CAD范围回查。编制人和独立复核人员可在完整关联原对象中查看实际采用范围及方向，对照已采用和本项未选顶点，减少仅看裁出折线时遗漏原对象上下文的问题。

## 在管线详情和复核中回查

“图纸与算量 → 设计坐标管线长度”每条有CAD来源的管线新增“回查已采用范围的原CAD投影”。独立复核弹窗提供相同入口。主动点击“读取原CAD范围回查”后，系统检查当前版本、实际原件、解析任务、坐标及独立依据，再显示校验结果。仅有人工坐标或已明确转为人工维护的管线不提供此入口。

视图只显示本条管线关联的完整原对象：灰色作为原对象背景，紫色表示其他已采用范围，橙色及箭头表示当前定位范围和采用方向。逐项定位下拉框标明原对象句柄、原始顶点范围和方向，支持同一原对象中的多个相邻取段。原始对象按身份去重绘制，每一采用项分别保留。

支持XY、XZ、YZ切换、放大缩小、四向平移、关联原对象全貌和居中当前采用范围。切换投影后保持当前范围，并重新核验来源；读取期间清除旧回查图，失败后显示具体原因，不能继续将旧投影当作当前数据。原始点在当前投影中重合或小于显示精度时明确提示切换投影及核对XYZ，不认定真实三维长度为零。点号和标记在缩放时保持可读大小。

## 原始顶点与采用范围对照

当前范围显示原类型、句柄、图层、原始起止点、方向和单组长度。完整原对象顶点表保留全部原始XYZ字符串及单位，逐点标明“本项已采用”或“本项未选”，并给出对应的整条管线点编号；“本项未选”不表示其他组装项没有采用该点。

反向取段和反向完整对象均按实际采用顺序映射。组装共享点可以同时对应前一对象的原末点及后一对象的原起点，各对象的原始数值独立保留。图上使用CAD原始点号，管线点对应关系在表格中核查；不根据投影像素计算工程量。

关联原对象米制范围使用既有Decimal投影规则，采用高亮直接引用同一原对象显示点的位置，不从浏览器大WCS浮点数重算几何。原件、构件和原对象哈希可展开查看。图形只作定位，原始坐标、独立长度校核和确定性三维计算仍是数量依据。

## 只读接口与版本门禁

新增认证接口 `GET /api/v1/projects/{pid}/components/{cid}/dxf-source-view`，要求明确的`revision`和`source_stamp`，并接受`projection=xy|xz|yz`，默认xz。只允许当前租户可访问的现有CAD设计管线；版本或来源戳不符返回409，没有CAD来源返回422，越权或不存在对象返回404。

每次读取执行保存态管线验证：重建CAD来源，比对原对象、取段和组装元数据、采用记录、原件及本地任务，核验独立证据、计算书预览和来源戳。响应包含当前构件哈希、当前状态、原件、去重的完整原对象、显示场景，以及逐采用项的原始点/管线点编号和同场景高亮。读取可以核对待复核或其他当前状态，但不会把状态改为已审定；实际签审继续受独立权限、对象哈希及原有业务门禁约束。

接口不写项目、证据、采用记录、审核记录、工程量或审计日志。未改变已有采用请求、来源版本、报表或历史报价结构，无数据库迁移或新依赖。历史报价保持原快照；本入口面向当前构件，不承诺回查已经替换原件的旧版本为有效当前图。

## 验证与范围

2026-10-23：新增38项合成测试，全量1468项通过；前端类型检查及生产构建通过。覆盖单对象、单独取段、旧版整对象组装、取段组装的三个投影，原始上下文、反向编号及共享点、同原对象去重、投影重合段、严格参数及显式版本、旧版本/来源戳阻断、原件/任务/替代状态/独立依据/映射/预览变化、当前审核状态、租户/匿名/无CAD对象、项目及审计只读，以及显示响应不能作为CAD采用输入。原有计量、组价、导出与历史快照回归通过。

隔离浏览器以独立复核账号读取A原P2至P4和B原P2至P3反向的30.000m合成管线。核查灰色原对象背景、紫色其他范围、橙色当前范围与方向箭头；切换XY/XZ保持B范围，居中及全貌恢复通过，B完整顶点表中原P1/P4为本项未选，原P2对应管线P4、原P3对应管线P3。回查前后数据库项目完全一致，仍为一条待复核构件、零工程量、一条原采用记录。

隔离环境中将来源任务设为失败后，切换YZ返回来源变化错误，旧图及旧顶点表清除；恢复原任务后主动读取恢复，并保持所选B范围。独立复核弹窗可再次回查来源，填写核查意见后审定；审定后回查显示当前“已审定”状态及同一范围。截图：`docs/qa/v0.54-adopted-source-view.png`、`docs/qa/v0.54-reverse-range.png`、`docs/qa/v0.54-source-vertex-map.png`、`docs/qa/v0.54-source-view-blocked.png`。未在实际工程库写入合成测试数据。

此功能不是全图CAD渲染或自动范围识别，不能凭未绘制内容判断不存在工程量。仍限既有ASCII DXF显式WCS直线与开放三维折线；块、曲线、跨原件变换、DWG/BIM授权解析、全专业自动识图算量、授权定额/信息价、厂商真实往返、真实黄金底稿及生产化验收仍未完成，PRD尚未全部完成。
