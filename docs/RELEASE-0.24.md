# 0.24 算量原始单位与换算追溯

继续补齐PRD F05“参数、规则、单位换算和系数来源”的计算书要求。在分项合计与逐项扣减编辑器中，参数可以按原始图纸的单位录入，保留原值、单位、精确换算倍数和标准值，再执行原有几何计算、加扣汇总与独立复核。

## 录入和确定性计算

- 每个分项可带完整的`parameter_units`，键须与该几何类型的参数完全一致。长度支持m、mm、cm、dm、km；已审开挖/占用体积支持m³、cm³、mm³；钢筋每米质量支持kg/m、g/m、kg/mm、g/mm；根数只接受无量纲1。
- 换算因子是版本化的固定物理关系，不能由请求自定义。先将参数统一为m、m³或kg/m，再调用原有九类几何引擎。面积和体积通过各长度参数的换算后乘积形成，不能把线性换算倍数直接当面积或体积倍数。
- 保留原始参数和单位，新增`normalized_parameters`、逐参数`unit_conversions`、`measurement-units-1.0`规则版本。结构化公式AST显式包含换算乘法，维度索引仍引用原值，可以从原始输入复算最终工程量。
- 继续使用Decimal 80位计算精度。原值与换算后的参数都须满足已有18位有效数字/18位小数及尺寸范围约束；换算后超限则明确拒绝，不静默修约。工程量沿用现有范围校验。
- `GET /takeoff-unit-types`提供经过认证的逐几何/逐参数可用单位、标准单位与固定因子；界面按参数维度限制单位选择，不推断像素单位或施工图中未明确的单位。

## 复核与兼容

- 原始单位与原值共用该尺寸的原图证据，须由专业人员核对原文；不能用历史含钢率或任意材料密度补全钢筋量。
- 保存、构件审定、重新算量、工程量审定和报价门禁继续执行原件及计算内容校验。修订单个单位也会变更构件内容哈希，使下游重新复核；不能沿用旧计算书审批。
- 未提供`parameter_units`的旧分项仍按原标准单位计算，保持`compound-geometry-1.0`计算结构与已保存预览。提供原始单位的记录使用`compound-geometry-1.1`；新旧分项可共存，只要最终工程量单位一致。
- 修订旧分项时界面会明确显示其已有标准单位，保存后形成新版本并重新复核。原单体编辑器仍使用原有明确标准单位，不改变旧单体参数含义。
- 数值和单位的修改均不反写历史报价快照或已留档文件；仍保留并发修改保护、来源失效、签证应用后的重算限制和独立编制/复核权限。

## 计算书与验证

界面逐参数展示“原始值 原始单位 × 因子 → 标准值 标准单位”，与分项量、加扣汇总和原始证据一同复核。JSON保留全部原值、换算和AST；Excel/PDF新增“算量原始单位换算”表，列示参数、原值/单位、因子、标准值/单位、规则版本和证据编号。分项及换算表增加长文本续行与自适应行高，Excel参数值继续按文本保存，防止公式注入和精度损失。

新增23项合成测试，全量420项通过，生产构建通过。覆盖混合长度单位、面积/体积维度、回填体积、钢筋单位质量、圆环π精度、原值AST复算、非法/缺少/跨维单位、换算后精度及范围、旧版本兼容、认证单位配置、独立复核与清单传递、三种导出及历史报价保护。

隔离浏览器完成原始单位核对、分项修订、预览和reviewer独立复核：10000mm=10m、500cm=5m、300mm=0.3m；主底板15m³，加厚0.8、扣洞0.6，净量15.2m³。截图`docs/qa/v0.24-measurement-units.png`。实际14页草稿PDF已渲染核对，单位表与计算书可读，未见裁切或重叠。
