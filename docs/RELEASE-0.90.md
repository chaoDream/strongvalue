# 0.90 基础有限标高圆孔与盲孔扣减

继续补齐PRD F05的有据几何扣减，并贯通F06清单净量、F09报表和F11修订及独立复核。矩形、圆柱、矩形台阶及圆形台阶基础，均可逐孔明确竖直圆形空腔的起止标高，支持有限深度圆孔和圆形盲孔。逐层只扣实际正相交高度，不再把所有孔都当作全高贯通孔。

## 输入、坐标和适用范围

沿用可选`through_holes`孔表，每基础项1至20孔；每孔仍须唯一名称、实际直径、局部XY、扣减范围说明及逐参数原件。孔位/孔径/标高共用孔表独立单位，支持mm/m/cm/dm/km；基础尺寸单位可不同。共同中心为XY原点，Z=0为本基础实体底面、向上为正，原点和方向必须有原件依据，不能由柱脚或锚栓推断。

每孔可选以下严格结构：

```json
{
  "vertical_range": {
    "parameters": {"z_start": "0", "z_end": "150"},
    "evidence": {"z_start": "当前项目原件证据ID", "z_end": "当前项目原件证据ID"}
  }
}
```

起止Z须满足`0 ≤ z_start < z_end ≤ 基础总高`。不接受空配置、只填深度、累计层高替代标高、负值、反向、零高或超高。输入和换算后的尺寸都沿用18位小数上限，超限阻断。孔不填`vertical_range`时，仍按原有全部基础高度贯通；可在同一孔表混合贯通和有限标高孔。

台阶仍须同心同轴紧接、上层不外伸，各层同一材料。单项所有基础使用相同孔样；差异做法须先拆分来源材料项。圆孔须位于每个实际正相交层内；圆层仍要求孔径严格小于该层实际直径，不接受整层轮廓被覆盖。与孔的标高范围无正高度相交的层不做轮廓包含检查，也不扣减。

## 逐层扣减及三维孔间校验

对每个孔及每一层，实际扣减高度为`min(孔终止Z, 层顶Z) − max(孔起始Z, 层底Z)`；非正值不计。正值按`π/4 × 实际直径² × 相交高度`扣减，保留实际相交层号、起止Z、高度、单孔单层体积及可回溯公式AST。每层毛/扣/净量、全部基础毛/扣/净量和原件索引均保留。

孔间逐对核对标高范围与圆截面：标高相离或仅端面接触可分别扣减；存在正相交高度时，圆截面正面积重叠或相互包含即阻断，不能重复相加代替并集。截面几何相切允许。明细同时保留孔心距平方减半径和平方、标高分离余量及对应公式，标高分离余量为负表示有正相交高度。此类相切或接触只作几何判断，不能代表结构净距、承载或施工验收。

Decimal 80位及既有π常量保持；逐孔、逐层、分项不修约，来源最终立柱根数和重复数量仅计一次，最后仅净总体积按HALF_UP修约。层数及孔数不增加基础个数，来源材料质量、栏杆长度、布柱和下料保持。含有限标高采用`railing-post-foundation-1.4`，全部为贯通孔仍为1.3，无孔仍按对应1.0/1.1/1.2规则。

## 编制、复核和成果

孔深方式可选“贯通全部基础”或“有限起止标高（含盲孔）”。切换方式清空该孔起止标高、相应原件和扣减说明，并清空本项及总体范围依据、撤销确认，不自动带入旧深度。增删孔、切换基础形式、编辑尺寸和依据沿用对应清空及确认撤销；同来源修订恢复完整孔样及原件，整体需重新确认；读取新来源则清空旧选择、尺寸、孔位、标高和依据。

预览不写项目。保存、独立复核、重算及计算书复核重建完整来源、原件字节、逐层及孔间校验、数量和AST；篡改、异项目原件、角色租户、并发及伪造ID门禁延续。修订保留精确历史和旧清单，旧计算书失效；来源修订使旧基础失效。旧报价及导出字节不随新参数变化。

清单使用扣孔后的基础净实体体积，编码映射仍需有据复核，不更改数量；专业扣孔阈值及是否按合同口径扣减须另核。JSON保留完整参数、逐层相交、标高原件及AST；Excel/PDF在有限标高场景提供六表：基础圆孔毛扣净、原始依据、校验、范围与常量、标高依据、逐层相交。原基础汇总及逐层表明确净量，长数和说明完整保留、分续行及自动行高。旧贯通孔报表保持原四个专表。
