# 0.67 栏杆线材材料表与多道构件质量

继续补齐PRD F05的栏杆材料计量。可从当前已审栏杆范围建立独立材料表，按有据填写的多道连续构件或独立定长件计算等截面线材质量；安装栏杆长度和材料质量分别建模、复核及映射，不将二者默认等同。

## 计量范围与计算

连续构件采用来源单组未修约计入长度，乘适用于全部已计入范围的道数和单位长度质量。不同局部做法应拆分栏杆来源再建材料表。定长构件按每组件数、每件实际下料长度和单位长度质量计算，例如独立列明立柱根数和下料长；不从总长度或间距自动推算立柱。

支持kg/m、g/m、kg/mm、g/mm单位换算，定长下料沿用明确长度单位。每项须有名称、模式、整数道数或件数、单位长度质量、计量说明及逐参数原件依据；定长项另有下料长和依据。每表1至50项，名称不得重复，道数/件数为1至1000000整数，长度和每米质量必须为正。不以密度、含钢率或来源显示总量补齐缺失参数。

坡段连续材料须采用已审三维栏杆范围，坐标线水平投影来源不能作为连续构件的下料长度；其下仍可独立列实际定长件。多边形来源须确认原边就是实际水平直线下料范围，不自动推断安装位置。来源计入范围为空时拒绝。

规则为`railing-material-mass-1.0`。采用Decimal 80位，从原栏杆决定和原始几何重建单组未修约长度；各道/件长度、单位换算和分项质量不单独修约。分项合计后只乘一次来源重复数量，最终按有据选择的0至12位HALF_UP修约。保存逐项及总量AST、原始参数、标准量、完整栏杆范围和来源快照，不使用已经乘数量并修约的栏杆安装总量再次计长。

不自动增加损耗、接头、搭接、立柱端部、基础、网片或板材质量。本版是等截面线材材料表，不能替代完整栏杆专业建模或实际材料验收。

## 编制、复核及失效

“图纸与算量”新增“栏杆线材材料表”，可读取已审来源、添加/移除材料项、选择模式、填写数量、原始质量/长度单位及依据，预览和保存送审。任一参数改变清除旧预览及范围确认。水平投影来源明确提示仅可列独立定长件，连续材料须改用三维来源。

独立复核页显示单组分项质量、来源重复数量及总质量，可展开原始参数、逐项依据和锁定的栏杆范围、原始XYZ/轮廓及计量口径。候选只读取已审来源，尚未选择的材料依据在预览及之后的门禁核验；预览、保存、审核、计算书、清单映射和导出均重建当前来源并核对原件、证据、输入和计算快照。

同版修订恢复材料项但须重新确认范围；栏杆来源修订后旧材料表和下游失效，重新读取将旧材料表参数全部清空为待填写新项，不沿用道数、件数、下料长、质量或逐项依据。原几何变更也沿依赖链使栏杆和材料表失效。修订需当前对象哈希，保留完整已审旧版；复核、重算及重建清单后使用新量。新增“栏杆线材材料表质量”kg清单映射，仍需合法编码、标准及原始依据。旧类型和报价快照沿用原规则；无新依赖或数据库迁移。
