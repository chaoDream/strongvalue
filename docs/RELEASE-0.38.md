# 0.38 PDF章节导航与历史留档审阅

完善PRD F09成果审阅与交付。原版本已有实际PDF生成、翻页和缩放；本版解决生成后按导出列表查找文件的竞争问题，补齐实际排版章节导航、历史PDF内嵌预览、生成时状态与当前报价状态区分。封面摘要继续保留，并明确实际版式以上方PDF为准。

## 精确绑定本次生成文件

`POST /api/v1/projects/{pid}/report-previews`必须明确选择一个`quote_id`或`unpriced=true`，可指定有权访问的企业模板。不允许同时选择、留空、伪造租户或请求其他格式。服务端沿用实际导出事务，返回刚生成的文件ID、哈希、模板副本和分页信息，不从“最新文件列表”猜测目标文件。

原`GET /exports`继续兼容，在响应中增加`X-Artifact-ID`。两条路径复用同一留档逻辑；选择报价时复验报价及输入快照哈希，损坏快照不能生成新成果。排版失败时不提交文件登记或导出审计事件，不修改报价、工程量或审批。

## 实际排版章节与分页校验

PDF每个报表章节完成排版后记录真实起始页，形成PDF书签及`report-pagination-v1`清单。记录总页数、章节名称、起止页，长表的续页属于同一章节；不通过文字搜索或预估行数推算页码。PDF、Excel、JSON及ZIP原有金额和业务规则不变。

`GET /api/v1/projects/{pid}/artifacts/{aid}/preview`只读已留档PDF，先验证文件实际字节SHA256，再核对PDF总页数、真实书签和章节页段的完整覆盖。文件丢失、内容变化、索引损坏或跨项目/租户请求被阻断。旧文件没有分页清单时仍可按页码审阅，不伪造章节索引。其他格式仍由下载入口审阅。

## 审阅与状态边界

- 新“PDF分页审阅”卡片支持本次生成、章节跳转、页码、前后页、缩放、新窗口及下载同一文件。历史PDF可直接选择，读取历史文件不会重新生成或签署审核。
- 显示文件生成时的报价版本、审核标识、模板版本、时间、总页数和哈希。另行显示当前报价复核记录是否有效、来源是否已失效。历史审核件保持原字节和原审核标识，不能据此认定当前项目已审定。
- 切换工程、报价或模板清除旧预览；项目版本刷新后也须重新选择文件，避免沿用旧的当前状态提示。异步请求返回时核对组件请求序号，过期结果不会覆盖新选择。
- 原项目成员、租户和会话权限继续生效，reviewer可像原有导出流程一样生成审阅文件；预览本身不修改业务审批。独立业务的历史PDF按文件内审核范围展示，不当作整个项目成果审批。
