# 0.122 未加工余料原段退回

日期：2026-10-28。前后端及使用手册版本0.122.0。

## 本次完成

已执行余料领用新增逐分配原领用／已退回／在外余额，可登记未加工、保持原长、同材质截面且质量合格的原段退回。继承原编号原库位及规格，实际日期不得早于领用，接收人、验收说明、当前原件及确认必填。只读预览后保存草稿，独立复核后显式执行才增加原余料在库并减少对应领用在外数量；可分批、不可超退，并发重查余额。未执行单可有据取消，已执行不可取消或重审。

来源图纸或旧交接依据失效不撤销实物领用，实际退回可凭新的有效原件记录；原验收或已执行退回验收原件失效时保留物理数量，整组待核查并禁止新增领用。退回不恢复原材料表的再次领用额度，其他经核定材料表可复用当前有效可用原段。完整原材、工程净量、排料、报价及原加工核对额度保持；退回单、复核、事件及余额进入独立JSON和历史留档。手动刷新项目时，即使项目版本未变化也重查库存原件状态。详见[使用手册15.10](USER-GUIDE.md#stock-offcut-returns)。
