# 0.70 最大间距均分立柱、端部归属与质量

继续补齐PRD F05的栏杆计量。栏杆材料表新增“按最大间距均分立柱”：从当前已审栏杆的整段或局部计入区间读取范围，逐区间核定最大间距、起终端是否计柱及原件，生成单组根数和逐根端距S，再按独立核定的实际下料长、每米质量计算材料质量。旧独立定长件仍由原件填写根数，新模式不接受另填数量。

## 规则与范围

每个直线区间分别均分跨间，跨间数N为区间未修约长度除以核定最大间距向上取整的最小正整数；内部立柱为N−1根，再加明确归属本区间的两端。每个区间的最大间距、两端决定、计量说明均须逐参数依据，不能遗漏任何已审计入范围。间距不预填工程数值，支持明确长度单位；两端必须是明确布尔决定，不能留空或用字符串假冒。

S从所列原边或设计线段起点增加，沿来源已审三维或水平投影口径。坡段两种口径不能混用；立柱每根实际下料长另据原件，不从栏杆高度推断。均分规则不是从起点每隔固定距离、末跨留余长。本区间最大间距约束的是均分跨间；未计端柱时，跨区间实际柱距、端部构造和整体设计合规仍须专业核定。

同一材料项内，相同源顶点和同原边相接局部区间的重复端柱阻断，须明确只归属一次。源顶点按精确XY或XYZ比较，不以投影重合或显示容差合并。闭合多边形可采用每边计起端、不计终端的明确归属；分离孔边与局部缺口分别核定。跨边内部相交、近重合、额外构造柱、重复的不同材料项不自动去重或补柱。输出沿来源S的布置，不推断施工定位坐标、基础或柱脚偏移。

每区间最多1000个跨间，每材料项最多1000根单组立柱，每表最多5000根单组自动布置立柱。空布置、过密、重复/过期区间、缺依据、非法单位或负零间距阻断，需按真实范围拆分。仍限每材料表1至50项，允许与线材、矩形和异形板网片混合。

## 精度与溯源

含均分立柱的新表采用`railing-material-mass-1.3`，布置规则`railing-equal-bay-posts-1.0`；未含此模式的旧线材及板网片沿用原1.0至1.2结果。

跨间数使用原边精确长度平方和有理数比较，确定(N−1)²×间距² < 区间长度² ≤ N²×间距²，避免平方根显示值或除法修约影响临界向上取整。逐区间保存三项精确分数及N作为可重建计算记录；数量AST保留由该规则重建的离散跨间数及两端0/1决定，不将生成根数冒充人工输入。间距和端部决定均有维度、换算及原件，逐根S保留位置类型、节点号和表达式。

采用Decimal 80位表示均分端距及间距，分项下料长和质量不单独修约，材料合计后只乘一次来源重复数量，仅总质量按有据0至12位HALF_UP修约。根数、布置、精确边界、公式及来源均在预览、保存、独立审核、计算书和导出时重新构建，不能靠修改显示根数或公式通过审核。

## 界面及导出

读取已审栏杆后可选择均分立柱模式，填写每米质量、下料长，并逐区间选择最大间距、起终归属及依据。数量由预览计算，不提供手工根数框。模式切换、字段改变均清除旧预览及确认。复核页可切换区间查看S示意、根数、端部归属，展开完整均分跨间数值、逐根S和精确跨间数校验；示意不可测量。

沿用权限、独立复核、对象哈希、完整历史、来源失效、计算书重建及kg清单映射。修订来源栏杆后旧材料和下游失效，重新读取清空材料模式、下料长、每米质量、旧区间间距、两端决定、说明、逐项依据和确认。旧清单在重建前保留，旧报价不会混入后加立柱。没有新依赖或数据库迁移。

JSON包含完整布置；Excel/PDF新增“立柱均分布置质量”“立柱逐区间间距与归属”“立柱跨间数精确校验”“立柱逐根端距”，栏杆材料总质量仍汇总全部材料项。
