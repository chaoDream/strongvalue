# 0.138 合格采购库存按原单位分批领用

“组价审核 → 采购库存按原单位领用”从已执行验收入库的合格采购批次登记实际领用，固定原资源单位，记录数量、去向、接收人及交接原件。保存及独立复核均不扣库、不预留数量，明确执行后扣减尚在库并累计已领；多个待审单不能增加供料数量。两处采购库存视图显示一致的合格入库／累计已领／尚在库。

独立账号复核、当前余额及原件门禁、单号防重、摘要校验、幂等和原子执行防止超领或重复扣库。未执行单可有据取消，保留原输入及审核；已执行单不能重审、取消或冲销。历史领用原件失效时实际数量保留，整批库存待核查并阻止新领用。每单JSON独立留存，历史字节不重写；旧版收货说明文字不会使原已存记录失效。

领用仅表示实物交接，不代表安装、消耗或加工，不改订单实到／未到额度、工程报价、完整原材或余料台账。采购领后退回、退供应商、移库、原单位转根、加工接入、成本结转、付款及冲销仍待建设；不将合成软件验证当作真实检验、交接或商业验收。字段、角色、步骤、异常和合成算例见[使用手册19.11](USER-GUIDE.md)。

验证结果及合成页面记录见[QA记录](QA.md)。

849项相关回归通过（266.52秒），最终45项领用专项通过（其中42项已包含，去重852项），前端类型及生产构建、普通与基线手册检查通过。合成页面验证预览输入失效、保存及独立复核不扣库、首批明确执行2.125m³后在库2.875、原件异常隔离及恢复、第二批领尽后在库0；订单实到及未到保持，7份历史文件及71条审计关联核对通过。
