# 0.17 工程层级与逐级汇总

补齐 PRD F08/F09 中建设项目、单项工程、单位工程的结构化归属与汇总基础能力。原有清单文字分组继续兼容；启用新结构后，必须完整登记、复核工程划分及每条当前清单的唯一归属。

## 工程结构与复核

- 取费汇总页支持建立/修订“建设项目 → 单项工程 → 单位工程”结构，最多200个下级节点。建设项目为当前项目；单项直属项目，单位直属单项，每个单项至少有一个单位。
- 禁止重复节点编号、同上级下重复名称、孤立单位、循环、额外层级；每条当前清单必须且只能归属一个单位工程，不能遗漏、引用历史清单或直接归属上层。
- 每次提交保存版本、工程划分与归属说明、本项目当前原始依据及清单身份指纹。编制/独立复核继续分开，旧结构只能查阅，复核不能覆盖旧版本。
- 提交新结构或撤回审批使旧报价审批失效；结构未审、拒绝、补件、归属失效或依据失效时，阻断生成新报价及正式成果复核。复核和报价时还核对原件字节。
- 清单名称、编码、单位、特征、原文字分组或清单增删发生变化时，要求修订并重新复核。数量、资源价格及其复核状态变化不自动改变声明的工程归属，仍由原有算量/清单/价格审核门禁控制金额。
- 提交携带结构与清单校验值，拒绝覆盖新变化；同一请求重复提交返回既有记录，不同内容复用请求标识会被拒绝。

## 金额计算与费用边界

新报价保存不可变的结构版本、逐条清单归属和工程汇总：清单合价进入单位工程，单位工程合计进入单项工程，再汇总项目分部分项金额。项目级费用另行单列，验证“全部单位工程 = 全部单项工程 = 分部分项合计；分部分项 + 项目级费用 = 报价总价”。全部使用原报价的 Decimal 金额，不重新分摊或改变单价修约。

当前规则包费用为项目级费用，**不按比例摊入单项或单位工程**。本版没有实现单位/单项各自独立的取费规则或地区专用分摊规则。空单位工程显示0与清单项数0，不代表通过漏项核查。

## 报表与版本

- 取费页显示所选报价对应的结构及逐级金额，已失效报价明确作为历史版本展示。
- PDF/Excel/JSON将原“分级汇总”升级为真实三级节点、清单项数、分部分项金额、项目级费用和总金额，新增“工程结构与归属”表及依据；长字段分段。
- 当前无价JSON和ZIP保留结构版本，缺少归属或结构失效时保留草稿警示。旧报价仍使用旧快照，不能把当前结构反写进旧成果。
- 报价对账增加结构版本及逐项归属变化。单纯改变归属不产生金额差额，也不被误归因为量价变化。

## 验收与边界

新增21项合成测试，覆盖合法多节点汇总、逐级与费用闭合、独立复核、旧版本保护、结构修订/归属变化、非法树和分配、清单变化失效、价格变化兼容、证据和原件失效、提交幂等，以及PDF/Excel/JSON/ZIP导出。全量247项测试通过，生产构建通过。

隔离浏览器工作区完成两个单项/单位工程的编制、清单归属、独立账号复核及新报价生成。两个单位金额735.07与840.08，项目分部分项1575.15，项目级费用47.25，项目总价1622.40。均为合成数学数据，无真实专业划分或签审效力。

本版为主动启用的结构化流程，不静默迁移旧文字分组；尚未启用的工程仍兼容旧汇总，不能据此宣称完整三级结构验收。官方标准模板与定额/价格接入、单位/单项独立取费、复杂图纸识别、完整专业算量、厂商授权软件接口和真实工程黄金底稿验收仍未完成。
