# 0.39 工程事实目录、单位归一与冲突复核

补齐PRD F02的受控事实字段、原值与标准值、置信类别、跨文件冲突分组及来源校验。项目基本信息仍由编制人维护，提取结果不会自动改名、调整工期或决定计价日期。

## 字段与明确文字提取

`GET /api/v1/fact-types`返回17类事实及允许单位：项目名称、建设单位、设计单位、施工单位、监理单位、建设地点、标段、工程范围、投标截止时间、质量要求、计价要求、合同条款、处理规模、施工工期、施工标金额、监理报价费率和合同金额。人工表单与模型提示共用服务端目录。

本地文本提取支持以冒号标注、换行/分号/制表符分隔的明确文字字段，保留字段别名与实际摘录；无字段内容、相邻标签无法可靠分隔或超过摘录上限时留给人工核对，不使整份文件解析失败。截止时间作为来源文字保存，不推定时区或自动参与计价日期裁决。扫描图OCR、跨段落合同语义解释仍需模型/人工能力与真实资料验收。

保留既有四类数值提取，并支持施工金额及合同金额的元/万元/亿元、规模的万立方米/日；施工与监理单位及金额/费率分别保存，不将监理中标金额当施工标价。施工工期不采用仅标明监理的工期条款。未限定专业的合同金额单独保存，不能推断为施工标金额。

## 原值、标准值及冲突分组

新记录保存原始值、原始单位、标准值、标准单位、`project-facts-1.0`规则版本、原文、文件与证据哈希及置信类别。明确文字、人工记录、模型候选均为待复核类别，类别不是统计准确率或审批结论。

- 仅使用明确单位与Decimal换算；`0.05万m³/日`和`500m³/日`、`298.24858万元`和`2982485.80元`视为数值相等，但分别保留每条来源。
- 工作日与日历天、月份、未注明单位、百分数与比例不自动换算。拒绝非有限值、指数写法、负数、畸形千分位与超范围数值；文本事实不接受金额或长度单位。
- 项目详情增加只读`fact_conflicts`投影，按字段列出未解决冲突、不同标准值与各自候选ID。等值来源归为同组；来源次数不用于选择正确值。
- 保持“先拒绝不采纳候选，再核准所选候选”的独立复核流程。同名文件替代后，历史候选不再与当前候选产生冲突；历史记录和审批留存。
- 既有事实不批量改写；比较旧记录时按可识别的原单位进行确定性比较。未知历史/自定义单位不猜测换算，自定义人工字段继续兼容。

## 来源校验、模型与成果

人工事实可指定连续摘录，须实际存在于所选来源；留空保存来源前2000字。创建时核对原件实际字节，新事实复核时再核对文件、证据和换算记录；来源变化或缺失须重新记录。已审事实的来源失效会进入报价阻断项。租户、项目成员、编制/独立复核权限继续生效。

模型候选沿用网关确认、引文匹配和视觉框限制。事实按同一目录、单位与冲突逻辑接入，非法字段或单位逐条记录拒绝原因，不能写成已审事实。提示版本升为`drawing-extraction-1.1`，避免沿用旧提示的任务去重结果。没有配置或调用真实付费模型。

PDF、Excel、JSON增加“项目事实与冲突候选”表，列出原值、标准值、类别、审核状态、文件页码和原文证据；JSON另含结构化冲突分组。报价导出读取既有报价快照，当前新增候选不混入历史报价；未计价草稿读取当前项目事实，保留草稿标识。原留档文件不重新生成或修改。
