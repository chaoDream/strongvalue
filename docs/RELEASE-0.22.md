# 0.22 分项合计与逐项扣减

继续补齐PRD F05与6.1的可追溯计算书：原有单体几何之外，增加由多个加项、扣减项组成的构件。每项保留尺寸、重复数量、计量口径、原始证据和独立计算结果，汇总后沿用构件复核、工程量复核、清单编制、组价与版本留档流程。

## 编制与计算

- 图纸与算量页增加分项编辑器，支持新增、修订、预览和逐项查阅。每个构件1至50项，至少一个加项，名称不能重复；各项必须同一计量单位。重复数量为1至1000000的整数。
- 分项使用现有九类受控几何；扣减单列，不允许在分项尺寸内再隐藏一个扣减总数。面积不得直接从体积中扣除，扣减合计不能超过加项合计；允许净量为零。
- 每个尺寸、重复数量和分项计量说明分别绑定本项目当前证据，构件另有总计量口径及其原件。钢筋表分项的全部参数及计量依据必须引用结构资料；不能以历史含钢率生成精确钢筋量。
- 使用Decimal 80位计算精度，分项及净量不额外修约；数量上限沿用确定性引擎。保存毛量、扣量、净量、各项单体与重复数量、公式、规则版本、结构化公式AST、维度索引和证据映射。AST是引擎生成的受控数据，不执行用户表达式。
- `POST /projects/{pid}/components/preview`提供无写入预览；保存仍使用现有构件接口，类型为`compound`，顶层`parameters`为空，明细在`measurement_parts`。预览不替代复核，保存时重新计算并校验原件。

## 审批与历史保护

- 沿用独立编制与复核角色、租户/项目权限、审核对象哈希。分项修订必须带当前`object_hash`，拒绝覆盖其他人的新版本；普通单体编辑器不能误删分项数据。
- 保存、构件审定、计算书生成和工程量审定均校验来源、原件字节与文件哈希。来源摘要绑定参数证据，审批时还核对引擎重算结果。报价编制门禁检查分项来源与原件异常。
- 修订构件保留历史，工程量及下游审批失效；当前计算书必须来自最新已审构件。失败操作不产生部分修改。现有已应用签证的项目仍禁止重建原始算量，防止覆盖签证数量。
- 历史报价快照不因新建或修订分项而改变。新计算书净量直接进入原清单与计价流程，不以目标总价反推数量。

## 成果与验证

- Excel/PDF增加分项算量与扣减明细、规则与精度表；JSON保留AST、维度索引和逐参数证据。重复证据ID在纸面索引去重，完整参数映射保留在结构化记录。草稿缺项继续列在缺项警示表，不混入规则明细。
- 新增30项合成测试，全量367项通过，生产构建通过。覆盖九类几何及AST复算、负数/精度/重复数量/单位/扣减边界、必要证据、角色与跨项目证据隔离、钢筋专业依据、修订冲突和原子性、四个处理关口的原件异常、替代来源失效、清单传递、JSON/Excel/PDF与旧报价快照保护。
- 隔离浏览器完成分项修订、预览、保存、切换reviewer独立复核并生成计算书。合成算例：主底板15.0，加厚区0.8，洞口扣减0.6，净量15.2 m³。截图`docs/qa/v0.22-compound-takeoff.png`。实际导出PDF已渲染核对计算书、分项明细、规则表及其他页面。

## 适用边界

本版是显式列项的几何加扣计算，未自动识别实体空间相交或求几何并集。实体不重叠、重叠区域单列、洞口是否扣除和扣减阈值，以及模板接触面、防水展开面、土方坡度和施工方案，均须由专业人员依真实依据确认。软件数学测试不代表专业计量规则验收。

PRD仍有完整专业算量、官方授权数据、厂商接口往返、真实施工图与独立黄金底稿、生产基础设施及上线验收等未完成范围，不能据本次增量宣称全量需求已经完成。
