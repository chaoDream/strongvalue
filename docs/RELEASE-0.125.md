# 0.125 余料在库盘点与差异调整

日期：2026-10-28。前后端与使用手册版本0.125.0。

已验收余料组现在可按实际在库原段根数登记盘点，包括再加工后代组。填写同日日期、盘点人、盘点及差异核查原件，先预览账面→实盘、盈亏根数和精确长度／质量差异，再保存、由另一账号复核并显式执行。执行追加差异事件，保留原验收及领用、退回、在加工、加工结果历史；无差异也保留确认事件。详见[使用手册15.13](USER-GUIDE.md#stock-offcut-counts)。

该组发生实物流转或另一次盘点后旧快照失效，即使在库数量恢复原值也须重盘；过日须取消未执行单并重新现场核对。实盘不得低于未释放预留，不自动减占用或改配。原件四道字节门禁；历史盘点依据失效保留数量并隔离该组及后代可用量，新盘点不能绕过。执行后不可重审、取消或冲销。库存JSON增加盘点、复核、事件和当前余额，旧文件字节不改写。

40项盘点专项最终通过，含低精度上下文精确正负换算及四阶段原件门禁；796项相关库存、排料、权限、报价、手册、交付和PDF历史预览回归通过。两组检查有35项重叠，不重复计为836项独立检查。前端类型／生产构建及手册检查通过。合成浏览器流程验证保存／复核不调账、输入修改清预览、显式执行1→2根、原验收仍1、盘盈另记1，以及三个历史JSON原字节和SHA256。
