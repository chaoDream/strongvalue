# 0.79 线材搭接与损耗备料附表

继续补齐PRD F05材料计量及F09可追溯报表。连续线材、独立定长件及八种立柱模式可单独启用有原件依据的搭接、损耗备料附表，展示净用量、搭接增量、损耗增量及备料量。附表不自动改变净质量工程量、kg清单、定额消耗、资源价格或报价，避免与计价中已有的材料损耗重复。

## 输入与计算范围

每个适用材料项可选`stock_allowance`：`joint_count`每组接头总数、`lap_length`每处搭接长度、`length_unit`、`loss_percent`、`base_excludes_allowance: true`、`measurement_basis`，以及接头数、搭接长度、损耗率、说明四项独立关联的`evidence`。启用时参数及依据为空，净下料未含本次余量的确认未勾选；不预填损耗、搭接或接头数。

接头总数为整个材料项每组总数，不再乘道数、件数或柱数，不从来源路径、定尺、柱距或长度反推接头数。接头数须为0至1000000整数；无搭接时接头数及搭接长度都须明确为0，有接头则长度须大于0。每处采用同一搭接长，不同做法须拆项。损耗率的当前输入范围为0至100%，属于软件范围，不能作为行业默认损耗率；须由原件核定。原净下料若已经包括本次搭接、损耗或相同余量，不可重复追加。板网片不支持该线材结构。

计算采用既有净线材单组总长和每米质量，保持原单位换算及来源重复口径：

- 单组搭接增量 = 每组接头总数 × 每处搭接长。
- 单组损耗增量 =（净总长 + 搭接增量）× 损耗率 / 100。
- 单组备料长 = 净总长 + 搭接增量 + 损耗增量。
- 各项质量 = 对应长度 × 已核定每米质量；全部用量在单组结果上只乘一次来源重复。

采用Decimal 80位运算，分项不作额外中间修约。超过既有工程量引擎范围时拒绝，不截断。结果保留单组和全部长度/质量、逐项公式AST、输入、单位换算、原件及规则。材料表只汇总已启用项，明确展示未编备料项数（包括不适用的板网片）；不能把部分覆盖表认作整个项目的采购单。没有启用项时不添加附表或隐藏余量。

## 复核、版本与导出

备料规则为`railing-linear-stock-allowance-1.0`；启用后的材料表规则为`railing-material-mass-1.12`。未启用时保留旧规则和完整输出，区间/连续路径柱距均可同时使用，立柱数量、位置、柱距和净质量计算不变。

备料配置及派生明细参与保存重建、审核哈希与原件字节校验。即使净质量不变，只修改接头数、搭接、损耗或依据也必须重新独立复核，旧计算书失效，旧构件历史及旧清单完整保留。来源变化、异项目依据、角色租户、并发修改限制延续。恢复修订保留参数及依据，撤销总确认；关闭附表删除参数及依据，重新启用为空，模式/来源切换不保留旧项的隐藏配置。

界面预览、材料详情、独立复核与JSON/Excel/PDF均包含附表。新增四类报表：线材备料汇总、线材搭接损耗备料、线材备料参数依据、线材备料规则与范围。旧报价快照保持原内容。
