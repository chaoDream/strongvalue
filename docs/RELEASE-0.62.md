# 0.62 上下净面的两点斜线分区

继续补齐PRD F05、6.1中的局部模板和防水做法范围。已审水平等厚多边形的顶部、底部扣孔净面，支持用两个有据设计坐标点定义无限直线分割，可与已有X/Y窗口及原边侧面S/Z分区组合。

## 输入与范围

每个上下原面最多4条斜线，每线保留两点四坐标原值、一种长度单位、逐坐标原始依据、分割做法说明及做法原始依据。单位支持m/mm/cm/dm/km，使用来源相同的共同设计XY。两点仅定义方向和位置，分割延伸到整个原净面，不能当作有限线段。两个点的X和Y均须不同，水平或竖直线请使用已有轴向分割；相同点、重复/共线的无限线、原净面以外或仅接触边界的线均阻断。每条线在原净面两侧须均有正净面积。

沿用来源一个直边凹形外轮廓及严格包含、互不接触的孔；不增加多实体、曲面、坡面或变厚几何。每轴最多8条X/Y分割。斜线在X/Y窗口内形成凸裁剪框，但工程量是该框与原外轮廓扣孔后的交集，不能直接使用凸框面积。同一区内可能有多块不连通净区，仍合为一个核定项；不同做法须进一步分割或另建范围。零净量区不生成计量面。裁剪候选区域及其他计量面合计超过1000项时阻断，不截断计算。

## 确定性计算与身份

含斜线分区的构件使用`polygon-boundary-1.3`及`xy-line-rational-1.0`。两点换算后的精确十进制转为有理数，将直线化为互素整数规范式A×X+B×Y+C=0，A取正；“正侧/负侧”由该式值的正负决定，不随两点录入方向变化。重合线即使使用不同端点、反向或等价单位也不能重复。

按规范式排序，逐半平面精确裁剪原XY外包框，得到凸区域；分别裁剪原外轮廓和每个孔，按有理数鞋带面积扣减。凹形裁剪有向连接边的往返贡献抵消，不把分离净区之间的桥接当面积。保存凸框顶点80位显示坐标及精确分子/分母、各原轮廓裁剪面积、每区精确净面积、分割规范侧和版本。净面积AST由派生分子除以分母构成，不接受客户端自报面积。保存、复核及重算从原坐标和分割重新生成并核对全部结果。

每原面精确有理数子区合计必须等于原净面；Decimal 80位转换显示，不逐区另行修约，200位记录显示面积合计与原面积精度差，不调平某区。继承来源重复数量，仅在核定计入面合计后乘一次。8192位有理数复杂度保护沿用上一版。分面身份基于原面、去冗余并规范起点后的精确凸裁剪框和算法版本；等价单位、同线其他端点、反向和分割线顺序不改变区域身份，追加斜线时未改变区域保留身份。

未分区、仅侧面、仅X/Y分区仍分别沿用原1.0、1.1、1.2计算输出，不修改旧快照。没有新增依赖或数据库迁移。

## 页面、修订与导出

分区编辑器仅在上下净面显示两点斜线录入。示意图按凸框裁剪原外轮廓和孔后着色，孔及区域外空白，虚线框仅定位，不能测量。逐面决定仍要求全部面明确计入或排除、说明及原件依据。专业复核页可查两点原值、单位、规范式、逐坐标依据、分割说明、每区规范侧、凸框坐标、逐孔净量及精确闭合。

修改设置清除预览，应用前预览/保存禁用；应用后变化区域的决定、说明及依据清空，未变区域按几何身份保留。修订须当前对象哈希，保存回到待复核并使下游计算书和清单失效，旧已审构件及历史报价、留档件保持不变。实际原件字节、证据、来源已审版本、保存几何和计算书内容继续经门禁校验。

JSON保留完整有理数和算法资料；Excel/PDF新增“净面斜线分割依据”“净面斜线裁剪范围”。沿用逐面决定、逐轮廓扣孔和闭合表；历史报价不混入后来新增数据。凸框表明确不是净区外轮廓，规范式中的X/Y明确单位m。
