# 0.63 分离净块独立核定

继续补齐PRD F05、6.1的局部模板、防水做法范围。多边形上下净面可在原有X/Y窗口或两点斜线分区上，选择“分离净块独立核定”，将同一裁剪区内互不连通的净块分别填写决定、做法及原件依据。默认不启用，旧分区仍按原裁剪区合计。

## 范围与操作

先为顶部或底部原面录入分割线，再启用独立净块。选项按原面保存，可与其他未启用的上下原面、斜线及原边侧面S/Z分区混用。一个原裁剪区即使只含一块也生成其派生边界和核查记录，不把上区左右两块自动当作同一做法。

每块保存实际派生外轮廓及其孔。孔完全在块内时单独扣除；孔被裁剪线打开后成为派生外轮廓的凹口，不再伪造为封闭内孔。分离前原裁剪区的逐原轮廓、逐孔扣减完整保留在独立记录中，防止把派生轮廓编号误当原图点号或原孔编号。只选择左块计入时不会同时计入右块，也不重复扣孔或重复乘数量。

本版仅自动处理边界没有分支的独立净块。裁剪后孔与外边界仅在一点相接等情况，可能形成零宽点接触或边界分支，系统明确拒绝，要求进一步分割并核定实际范围；不猜测连接方向或按浮点容差吸附。仍限一个原始直边简单外轮廓、严格包含且互不接触的孔，以及原有水平等厚实体。

## 精确边界与计量

启用后的规则为`polygon-boundary-1.4`、边界分离规则为`xy-connected-rational-1.0`。从同版原始轮廓及精确凸裁剪范围重建：统一外轮廓为正向、孔为反向，以有理数逐半平面裁剪有向边链；将同线重叠边按所有有效端点拆成原子边，抵消反向边和凹形往返连接边；检查每个边界顶点唯一进入及离开，再提取独立闭环。正向闭环为派生外边界，负向孔闭环必须唯一归属一个外边界。

每块以派生外面积扣其派生孔，保存精确分子/分母AST、每个派生点的十进制显示与精确分数、原裁剪区身份、块序号及总块数。每原裁剪区的各块精确有理数净面积合计必须等于分离前净量，并更新原面闭合记录。Decimal 80位转换显示，200位记录显示合计精度差，不调平某块，不逐块另行修约；计入块合计后仅乘一次来源重复数量。

块身份依据原面、规范化后的实际派生外边界及孔和规则版本，不依赖原裁剪区序号或同线冗余顶点。等价分割单位、未改变实际边界的追加分割可保留相应块身份；实际边界改变须重新核定。源原件、证据、已审来源版本、预览及计算书继续从原始数据重新生成并核对，不能提交自报派生边界代替重建。

独立块及其他计量面合计超过1000项阻断；连通边界拆分和内部定位扫描合计超过2000000次精确校验预算阻断，要求拆分计量范围。沿用8192位有理数复杂度保护。未启用独立净块时完整沿用原1.0/1.1/1.2/1.3结果，不修改旧快照；无新依赖或数据库迁移。

## 图示、复核与修订

图示按每块实际派生边界着色，孔和外部空白，不再把同一凸框重复涂成两个计量面。块编号采用精确竖向交点扫描定位到净区内部，避免落在孔内或凹形空隙；示意仍不可测量，浏览器尺度不足时查看精确坐标。复核页可展开逐块外轮廓/孔坐标、原裁剪区逐孔扣减及块合计闭合，明确派生点不是原图点号。

修改分割或启用/停用模式清除旧预览，应用前预览和保存禁用。应用后只按实际几何身份保留未变面决定，变化块的决定、说明、依据清空。修订须当前对象哈希，新版待复核，下游旧计算书和清单失效；独立审核、重新算量及清单重建后使用新量。旧已审版本、原数量、报价快照和留档件保留。
