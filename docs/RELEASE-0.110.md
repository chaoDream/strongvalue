## 本次完成

水平顶底、台阶平台及内部孔端增加2至4块分离的直边窗口净区，每块可带0至4个排除内孔；各轮廓3至12点，每块最多36点，全部最多8孔及48点。逐块填写名称、实际支模说明及原件，逐点坐标及原件，共用单位、基础中心XY、已审Z及全部基础个数。外轮廓精确校验严格分离，不允许接触、交叠、包含或嵌套岛区；孔继续严格在所属外轮廓内并相互分离。

各块分别复用简单／带孔窗口的200位直线与圆弧解析积分，保留80位过程，用80位累计块结果后继承全部基础个数一次，仅总量修约。窗口空隙、凹口和内孔不填实，不生成新的基础实体孔或孔壁，不改变来源基础及混凝土。保留逐块及整体的实际毛、实体孔扣、净量与有序AST。全部块的全部有效片段无剩余才证明整体严格零接触，不以容差或显示0.000归零。

同端面完整窗口净区用精确有理数竖向扫描防重，另窗在块间或窗口内孔空区可分项，跨记录及混合旧窗口同样检查。整体外包边界只作定位，不能用于填实空区或代替防重。旧整面、矩形、凸、凹及带孔模式保持原规则与结果。

页面接通逐块／逐孔录入、增删、确认撤销、预览修订和独立复核，三格式新增多块窗口顶点、净区、分段积分及拓扑校验，按需增加零接触和精确防重表。详细操作见[手册16.10](USER-GUIDE.md#foundations)。
