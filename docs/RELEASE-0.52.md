# 0.52 CAD原始顶点取段与分范围采用

补齐F04、F05中同一CAD折线按实际计量范围分开编制的流程。当前支持从符合[0.49读取范围](RELEASE-0.49.md)的LINE或开放3D POLYLINE中，明确选择连续原始顶点范围，并选择按原方向或反向采用。原对象和原始坐标完整保留，不改写上传原件。既有投影定位及整对象组装继续见[0.51](RELEASE-0.51.md)、[0.50](RELEASE-0.50.md)。

## 使用流程

在“图纸与算量 → DXF设计坐标读取与单位校核”读取原件，选择原对象后展开“按原始顶点拆分此CAD对象”。起止点按原始编号从小到大选择，反向另行明确。点击“读取所选顶点范围”后形成只读取段候选；范围改变时禁止直接使用旧校核预览。读取范围会清空采用信息，页面提前说明；选错可返回原对象重新选段。

取段保留范围内全部中间顶点，分别显示当前P1、P2等与原P4、原P3等的映射、原始XYZ字符串及声明单位。独立已知两点距离校核使用当前取段编号，选项同时标明原始点编号。编制人仍须填写共同WCS及高程基准、设计中心线用途与计量范围、重复数量、修约位数、独立原始依据和采用原因，主动确认原CAD用途。

校核通过后只生成待复核设计管线；独立reviewer核对原始范围、方向、顶点映射、独立距离与逐段计算后审定，再由编制人生成计算书。计算书独立复核后进入清单编制。读取范围、校核预览均不写入构件、工程量或采用记录。

## 同一原始管段不能重复计入

防重复采用按当前构件实际占用的原始管段检查。原P1至P2与原P2至P4可以共用一个端点；原P1至P3与原P2至P4包含同一段，禁止同时采用。反向选择和改变重复数量不能绕过检查。整原对象、已有多对象组装与新取段之间同样互查，不能先整条采用再额外采用其中一段。

可明确选择现有CAD管线及其对象哈希，将整条管线修订为其中一段。旧修订与采用记录留存，下游失效；当前不再占用的剩余范围可另行采用。扩展范围碰到另一当前构件已占用的原始管段仍会阻断。历史记录不会继续占用已经替换的范围。

当前每个取段候选单独采用，不混入多对象组装；组装仍使用完整原对象。只支持已有顶点之间的完整连续管段，不插值、不吸附、不补段、不按屏幕量距；不支持在两原始点之间任意切分、自动按专业/管径识别分界或自动拆分全图管网。不同原对象的物理空间重叠仍需专业核查，不能由相同坐标自行认定为重复工程量。

## 来源、接口与导出

新增认证只读接口 `POST /api/v1/projects/{pid}/documents/{did}/dxf-route-fragment`，严格要求原对象候选ID、对象哈希、整型原始起止编号及布尔反向决定；无效或超出范围拒绝，不静默截断。响应保存完整原对象、明确范围、采用顺序下的原始编号及逐点坐标。预览和采用接口增加可选`fragment`，禁止同时提交`segments`；旧单对象与组装请求的哈希保持兼容。

复核、计算书与后续证据验证重新读取实际原件和任务，按保存范围重建候选并比对全部来源；文件、任务、原对象、顶点映射、坐标或独立依据变化时阻断。仍保留旧版的显式转人工坐标、修订及来源失效规则。无新增第三方依赖或数据库迁移。

JSON、Excel、PDF新增“DXF原对象取段范围”台账，记录管线修订、原对象/图层、范围与方向、取段点到原始点映射、采用起终点、单组长度与原件哈希。使用报价快照中的采用记录；旧报价和已导出文件不被后来取段改写。
