# 0.103 基础整体顶底面的XY局部窗口模板

## 本次补齐

基础水平模板的整体最顶面、最底面新增有原件的XY轴向矩形窗口。支持既有矩形、圆柱、同心同轴矩形/圆形台阶来源的实际端层；窗口原点固定为来源基础中心，正向与已审孔位共用，不随俯视或仰视翻转。四个原始起止坐标、长度单位、逐坐标原件、共用坐标基准及其原件均必填，并须分别确认窗口坐标和整体接触范围。不能手填面积、截面尺寸、标高或重复数量。

每基础毛面积=窗口矩形∩所选真实端层截面。窗口允许越出基础轮廓，只计交集；每个到达该端面的实际孔再与窗口裁切后扣减。孔的Z边界口径沿用原整体顶底面，体积扣孔阈值不填实物理孔。来源数量继承全部最终基础个数一次，仅总净面积按有据位数HALF_UP修约；保留空交集、零孔扣和零接触。来源体积、物理孔和材料量不受模板范围改变。

矩形逐轴精确裁切。圆截面与矩形窗口沿用既有四象限解析交集、200位Decimal工作精度、80位输出与记录固定π；基础中心和各孔心先减窗口中心，形成可独立重放的相对位置公式。保存完整毛扣净、原始坐标、换算、全端面/窗口矩形/实际交集、逐孔全截面/窗口内部分、曲线有向分项及公式AST。数值界限无法确认时阻止计量。

同来源同基础项的全部窗口，跨端面及跨记录均须相同基准说明和基准原件。同基础项同端面，整面与任何窗口不能并计；两窗口只要X和Y都正重叠就拒绝，包括仅在孔洞或基础外侧重叠的情况。这是保守的矩形范围重复检查，不自动判断实体内重叠并集。分离或共享边界可分项，并留存有向间隔及AST。全部原件字节校验、跨租户隔离、独立重建复核、并发保护和完整修订历史沿用原流程。

页面可填写窗口并展开实际毛扣净、完整数值、逐孔交集和解析过程。修改窗口参数或原件会撤销窗口及整体确认并清除预览；更换来源基础项或端面清除不再适用的窗口；读取变更后的已审来源清空旧范围、材料、原件、修约及确认。局部台阶平台和局部孔底/孔顶明确拒绝，仍可使用原整面入口。

有实际窗口的计算使用`foundation-horizontal-formwork-1.4`，不含窗口的旧记录继续保留1.0/1.1/1.2/1.3及其结果。JSON保存完整计算，Excel/PDF按窗口增加“基础水平窗口裁切”“基础水平窗口孔交集”“基础水平窗口坐标原件”“基础水平窗口分离校验”，有曲线时增加“基础水平窗口曲线过程”。无窗口旧成果不增加新空表，旧报价不会混入新窗口数据。
