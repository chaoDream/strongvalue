# 0.29 设计坐标管线三维长度

补齐PRD F05及6.2中“平纵坐标已确认才可计量”的管线场景。由人工按共同设计原点、XYZ方向及高程基准建立有序转折点，逐段计算三维中心线长度；每个X、Y、Z分别关联当前原件证据，不能缺省高程或以图面像素推算。

## 计算与输入约束

- 新增结构化构件`design_route`，2至101个点、最多100段；每点有名称、XYZ、原始长度单位及逐坐标依据。支持负坐标和m、mm、cm、dm、km，同点三轴共用原始单位，各点可不同。
- 每段计算`√(ΔX²+ΔY²+ΔZ²)`，保留有符号坐标差、长度平方、三维段长及独立水平投影长。竖向段水平投影为零，但空间段长保留；交叉投影不自动连接或缩短路径。
- 各段平方根、汇总及重复数量使用Decimal 80位；先累加段长，再乘1至1000000的整数重复数量，最后仅总量HALF_UP。小数位须按原始依据明确选择0至12，界面不预填专业精度；保存未修约总量与修约差额。
- 保留原值、单位固定换算、逐段公式AST及最终修约节点。AST新增单参数`sqrt`，最终`round`包含`digits`和`mode=HALF_UP`，不执行用户脚本，不影响计价费用表达式。
- 拒绝重复名称、重复坐标、零长段、闭环、同一路径内任意两段的共线正长度重叠，不能通过增加中间点重复计长。相邻端点接触和不重叠共线分段允许。跨构件去重、支路、曲线及闭环须另行建模核定。
- 沿用18位有效数字、18位小数、换算前后1e12坐标与1e18工程量范围保护。

## 编制、审核及报表

算量页新增设计管线编辑器，支持增删与上移/下移转折点、坐标证据、重复数量、修约精度、预览和修订。编辑后旧预览立即清除；请求处理中锁定输入。详情及审核窗口显示XY/XZ/YZ投影、有序点号、逐段空间及水平长度、原始坐标和来源链接、总量与修约过程。投影只作定位，不用于几何计算。

接入既有构件与计算书双重复核、清单生成、版本哈希、失效传播及报价门禁。预览不落库；保存、构件审定、重新算量、计算书审定及报价门禁均重验原件和保存计算。原件损坏、来源替代、跨项目证据或旧并发哈希会阻断，失败保持原子性。修订保留旧构件与计算书，已有报价快照保持原样。

JSON包含全部坐标、逐段公式、单位换算及修约节点；Excel/PDF增加“设计管线长度汇总”“管线设计坐标”“三维管段计算”，并进入已有原始单位换算表、证据和审核记录。旧报价表不会混入新管线。

## 验证及边界

新增38项合成测试，全量580项通过，生产构建通过。覆盖3-4-12斜段、竖管、负坐标、单位与方向反转、35组固定种子随机路径及独立距离对照、AST复算、重复数量后一次修约、重复与共线重叠拒绝、输入字段/高程/精度约束、原件5个门禁、租户与角色隔离、旧哈希和原子失败、保存与计算书篡改、清单与三种导出、旧报价不变。

隔离浏览器完成V2修订和独立reviewer审定。测试终点高程17改18时长度18变19，恢复后旧预览清除，再算得18.000m；斜段13m（水平5m）加竖段5m（水平0m），与原始合成依据相符。截图`docs/qa/v0.29-design-route.png`。实际16页草稿PDF已渲染检查，新增汇总/续页、坐标、逐段表和换算可读，未见裁切重叠。

本版仅计算已确认设计中心线开放折线；不自动推断管网拓扑、弯头弧长、管件、接口扣减、施工附加量或适用计量规范。测试数据没有真实工程专业效力。全专业自动算量、授权定额与价格、真实厂商接口、真实图纸/独立底稿验收和生产部署仍待完成。
