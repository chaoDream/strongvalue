# 0.37 新增构件的有据清单编码映射

补齐PRD F06与F05之间的连接：原映射仅支持早期九类单体几何，现在新增的分项、平面/空间区域、逐面、设计管线、沟槽、回填、管道外包、垫层、井筒及井板也能从已审规则推荐编码。系统不生成官方编码，不改变工程量，也不自动认定材料和施工适用性。

## 类型、计量口径和单位

独立只读接口`GET /api/v1/boq-mapping-types`提供20类构件、27种计量口径。原`/takeoff-types`仍只提供九类原始几何输入表，避免新增类型进入错误的尺寸编辑器。

| 新增类型 | 必须明确的口径 |
|---|---|
| 分项合计与扣减 | 净长度m、净面积m²、净体积m³、钢筋表净质量kg |
| 平面区域 | 净面积m²或等厚净实体体积m³ |
| 空间区域 | 净实体体积m³ |
| 逐面计量 | 模板接触面或防水展开面m² |
| 设计管线 | 中心线三维长度m |
| 变断面沟槽 | 按水平投影计开挖体积m³ |
| 关联回填 | 已审开挖扣占位后的回填体积m³ |
| 管道外包 | 含管内空腔的外包占位体积m³ |
| 分段垫层 | 按水平投影计本层垫层体积m³ |
| 圆形井筒 | 材料体积或含空腔的外包占位体积m³ |
| 圆形井板 | 井底板或井盖板净实体体积m³ |

新增结构化规则须保存`measurement_profile`，不能只用同单位替代口径判断。旧九类规则缺少此字段时沿用`standard`口径，旧记录不自动迁移或改变哈希。新规则及修订版本绑定`boq-mapping-v2`和原始编码证据指纹；编码仍须完整出现在当前原件证据中，并保留地区、专业、标准/版本、有效期、许可、项目特征及全部名称关键词约束。

## 匹配、审核与采用

逐一核对清单全部来源贡献，要求当前计算书已审定、构件已审定且版本哈希一致，重算内容和单位与计算书一致，结构化构件继续验证完整上游及保存预览。构件及编码原件均验证实际字节哈希和证据版本。拆分再合并的同一计算书按来源汇总贡献，不改变原清单数量。

合并项的每个独立来源都必须命中类型、计量口径、单位和所有关键词，不能只匹配第一个来源。材料/外包、模板/防水、底板/盖板不同口径的合并项不推荐。外部导入或签证工程量缺少当前设计构件口径，继续由人工核定编码；预览显示来源问题，不虚构候选。

前端增加口径选择、审核详情及每项来源的构件版本、计量用途与贡献量。无候选保持待补，多候选必须人工选择；采用受清单与规则哈希保护，任一选择失效整批不应用。采用仅替换编码、名称和特征，清单回到待复核，报价审批失效。规则修订获审后，旧规则及相关清单失效，历史报价快照保持原数据。

## 导出及验收

JSON保留新规则字段、证据指纹及引用。Excel/PDF保留原“清单编码映射依据”，新增“清单映射适用范围”，列出编码、来源计算书/构件版本、类型/计量口径、贡献量与映射规则版本。两表支持长内容续行，不从当前外部规则重写历史报价。

2026-10-22：新增46项合成测试，含旧映射的49项检查通过，全量910项通过，最终生产构建通过。覆盖11类新增构件的18种口径端到端规则复核、匹配、采用及导出；同单位不同用途不匹配；旧版九类目录及无新字段规则兼容；非法口径/单位；拆并贡献闭合；两个独立来源须全部命中；混合口径不匹配；来源数量、公式、预览、版本、审批、原件及负贡献异常；编码原件与证据指纹变化；权限/租户；歧义、整批原子性及修订失效；报价快照保护；JSON/Excel/PDF。

本版解决受控构件到有据编码规则的连接，不替代官方清单库、完整特征/工法语义审查或真实专业签审。真实图纸/黄金底稿、授权定额/价格、完整全专业自动算量、真实厂商接口和商业部署运营仍待完成，不能认定PRD全量商业验收通过。
