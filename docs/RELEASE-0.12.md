# 0.12 项目内批量调量

本版实现PRD F12的项目内批量调量流程，复用现有变更、计算书、数量分配和独立复核规则，不从目标总价反推工程量，不修改历史报价。

## 已实现

- 在清单页建立1至200项批量调量单。每项明确填写调整后的总数量、逐项计量依据和当前原始证据；填写调量单名称及共同原因。0表示调整为零，不允许负数、非有限数、重复清单项或未变数量。
- 读取调量目标时，同一次读取返回显示数量、名称、单位和对应对象哈希，防止界面旧数量搭配新哈希。提交后不立即改量，形成独立待审变更子项。
- 组价、规则和日期满足条件时，以当前全部清单、原综合单价及同一费用规则和修约重算条件性影响，保存提交时的原总价、新总价、差额、费用、规则副本和计价日期。输入不完整时明确不提供金额，不把缺失值显示为零。
- 子项逐项由独立reviewer复核，可使用既有批量复核功能，但每项仍有独立决定、依据及对象哈希。全部子项通过才允许编制账号整批应用，禁止通过单项应用接口拆开执行批量单。
- 应用前核对全部清单及规则/适用日期指纹、子项原清单哈希、审核状态和原件版本/内容完整性。任一不符整批拒绝；执行期间出错时，数量、历史、应用标记和审计均在同一事务回滚。
- 应用后形成逐项变更计算书及来源贡献量，清单回到待复核。共享原算量书仅在没有当前清单引用后归档，数量分配仍须闭合；旧清单与计算书进入历史。已应用调量单重复应用不再改量。
- 提交标识支持网络重试幂等：同标识同内容返回原单，不重复创建；同标识不同内容拒绝。重复请求已取消或已应用的单据仍返回原记录，不暗中建立新单。
- 未应用调量单可填写原因后整批取消，保留原复核记录与取消审计，子项标记已取消且不再阻断成果；取消不伪造拒绝审核。已取消子项不能重新签署或应用，已应用调量不能通过取消接口撤销。
- 新报价快照及无价交付证据包包含批量单；Excel/PDF增加批量调量台账，并沿用逐项变更签证台账。长说明和子项索引按续行展示、自适应Excel行高。后续更新不改写过去报价及导出字节。

## 操作与审核边界

编制账号在“清单编制 → 批量调量单”选择已审清单并逐项填写。复核账号核对每项数量、合同及计量依据；全部通过后，编制账号点击“整批应用调量”。随后重新审核清单并生成新计价快照，成果仍受原有完整性、价格、规则及黄金底稿门禁约束。

影响值是提交时的条件性试算，不是签证价款审定，也不自动批准新报价。修改清单、规则或适用日期后，需取消旧单并重新建立。已应用子项的审批撤回会按原变更流程使受影响清单/计算书失效，应通过新的修正变更处理，不能编辑历史报价。工程结算与竣工财务决算不因本版合并建模。

本版沿用原单项变更的数量来源机制：新量来自有原件依据且已独立审定的变更记录，不根据调量单自动重建原几何模型；需要回到图纸重新算量的情况仍须修订构件并专业核查。单项原变更入口继续可用，批量子项必须从整批入口应用。

## 验证

158项自动测试通过，TypeScript检查和生产构建通过。新增20个用例覆盖共享来源的两项调量、费用与修约影响、应用后新报价一致、数量分配闭合、零量、未变/非法/重复输入拒绝、跨租户与角色隔离、版本绑定读取、重复提交及应用、部分复核阻断、禁止单项绕过、第二项执行失败时整批及审计回滚、规则/日期/来源/原件内容变化、取消及后续拒绝、缺少已审规则时不推测金额，以及实际Excel/PDF和历史报价不变。

浏览器在独立合成工作区实际将两项7、8m³申请调整为8、9m³；切换复核账号逐项核查，再切回编制账号整批应用。当前来源数量分配闭合，清单回到待复核。测试程序随后独立复核新清单并生成新报价，含同一费用规则的总价由1622.40变为1838.73，与提交时试算一致；实际导出PDF含批量和逐项台账。截图 `qa/v0.12-quantity-batch.png`。所有数量、价格和签审意见均为合成数据，未修改实际工程。
