# 0.117 基础水平模板圆形直边混合岛区

日期：2026-10-28。前后端及使用手册版本0.117.0。

## 本次完成

整体顶底、台阶平台及内部孔端支持2至4块圆形／直边混合岛区，每块外轮廓及0至4个W同类，至少一块圆、一块直边及一项真实嵌套，全部最多8个W、48个直边顶点。共同基础中心XY及单位，逐尺寸、实际支模／不支模和最近父关系均有原件。圆在凹孔内严格检查圆心内外及全部有限边段距离，直边在圆内严格检查全部外顶点；不以外包框或圆周抽样替代，拒绝接触、交叠、跳层、自指、成环及错误父关系。

各块分别裁切真实接触，平台排上层、孔端取正确侧层、实际孔H只扣各块净区；200位直线／圆弧解析积分保留80位累计，数量继承一次，仅总量有据修约。混合模式统一相同水平线／圆交点表达式，避免同一事件的不同计算路径产生伪区间；不引入容差。全部块全部有效分段无剩余才证明整体严格零；完整窗口及跨记录逐块对精确防重，父孔未用空区可另项，岛区正重叠阻断。

页面接通类型选择、逐块／逐W及逐顶点原件、父关系重选、改动撤销确认与预览、严格拓扑和实际净量复核；JSON／Excel／PDF保留规范轮廓、有理数距离与源尺寸AST、整体覆盖及全部块对的距离／逐边／分段见证。详见[使用手册16.17](USER-GUIDE.md#foundation-mixed-islands)。
