# 0.53 CAD指定取段参与多对象管线组装

接通[0.52原始顶点取段](RELEASE-0.52.md)与[0.50多对象组装](RELEASE-0.50.md)。同一DXF原件中的指定连续顶点范围可先加入候选序列，与完整原对象混合组装；按实际设计中心线的顺序和方向形成一条管线，再统一完成独立长度校核、用途确认和专业复核。

## 取段加入候选序列

在“图纸与算量 → DXF设计坐标读取与单位校核”选择原对象，读取明确的原始顶点范围后，点击“将此取段加入组装序列”。此操作不要求先填单独采用表单，也不创建构件、坐标证据、采用记录或工程量。可以继续选其他原对象或其指定范围，并在序列中明确反向、上移、下移或移除。

序列标明原对象句柄、图层、原始范围、采用方向和该范围单组长度。已有整对象或取段与新范围重叠时，加入按钮禁用并说明；同一原对象的相邻不重叠范围可以共用端点，分次加入。投影视图的蓝色表示该原对象的全部或部分范围已入序列，不表示整对象都已采用。选择及组装仍不等同于全图管网识别。

“检查连接并组装候选”要求每一连接点的XYZ数值精确相等；方向或顺序错误明确阻断，不自动反转、吸附或补段。数值相等而原始字符串不同的连接点两侧分别留存，计算保留一个连接顶点。每项取段保留全部中间原始顶点，反向只执行一次。最多20项、合并后最多101个顶点，继续拒绝闭环、回走和不支持的原始几何；不能从不合格原对象中裁出一段来绕过读取限制。

## 原始顶点到组装顶点的双向核对

候选和复核面板的“CAD原对象顺序、方向与连接点”逐项显示：原始范围与方向、组装点范围、组装点到原始点的映射，以及采用方向下的原始起终点坐标。例如A原P2至P4对应组装P1至P3，B原P2至P3反向对应组装P3至P4；共享的组装P3可分别回查A原P4与B原P3。完整原对象同样显示逐点映射。

采用前须以整条组装管线的顶点编号选择独立已知两点距离、明确容差，并核定共同WCS及高程、中心线用途、计量范围、重复数量及修约口径。校核通过只形成待复核构件；独立账号审定后才可生成计算书，计算书再次独立复核后进入清单。

## 占用范围、版本与追溯

组装内部及不同当前构件之间按每个原对象实际选中的原始管段检查重复。完整对象、单独取段、旧组装和新取段组装互相校验；反向、重复数量或取段候选的新ID不能绕过检查。同一原对象的未采用范围保留，可另行编制。不同原对象的空间重合仍需专业核查，不能仅根据同坐标推断重复或连接。

明确修订原管线时保留旧版和采用历史，当前构件释放不再使用的原始范围，受影响下游失效并须重新复核。通用流程在新增构件后要求当前构件及计算书重新满足审核门禁，不沿用已经失效的审批。

实际文件、解析任务、原始对象、取段范围、方向、原始编号及坐标均保存在来源中；复核和算量时从实际原件重建，任一不一致即阻断。独立长度依据同样校验原件与证据。原有明确转人工坐标、幂等、租户和编制/复核角色限制继续有效。

## 接口兼容与导出

现有 `POST /api/v1/projects/{pid}/documents/{did}/dxf-route-assembly` 的 `segments` 每项可使用完整原对象引用，或额外显式提交`from_point`、`to_point`组成取段引用；仍要求原对象ID、原对象哈希与布尔`reverse`。编号必须严格整数，范围必须成对、从小到大且有效；不接受嵌套组装、屏幕参数、隐式方向、空编号或自动连接容差。引用必须指向原对象，不能用取段候选ID冒充原始来源。

完整原对象组装保留原来的1.0来源结构、候选ID和请求哈希；包含取段的组装来源版本为`dxf-wcs-assembly-1.1`。预览/采用沿用`segments`，不与顶层单对象`fragment`同时提交。共享严格输入模型，无新增第三方依赖或数据库迁移。

JSON、Excel、PDF新增“DXF组装取段顶点映射”台账，按组装项记录管线修订、原对象/图层、原始范围及方向、组装点到原始点映射、实际采用起终点、原单位和原件哈希。既有组装来源、坐标采用及单位校核台账继续保留。所有台账读取报价快照，旧报价和已导出字节不被后来组装改写。
