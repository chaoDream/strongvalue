# 0.32 管道外包占位体积

继续补齐PRD F05管网扩展：在已审设计坐标管线之上，逐段核定实际外径，生成有证据、来源版本及独立复核的圆管外包占位体积，并可作为关联回填的已审占位来源。

## 计算及适用边界

- 新增结构化构件`pipe_envelope`，只引用当前已审`design_route`；来源全部输入、原件及保存结果须可复验。来源快照由服务器生成，客户端提交的快照不能覆盖。
- 每个有序直段均须提供实际外径、原始长度单位、外径证据、计量范围说明及其原件依据。不以公称直径DN推定实际外径；不同直段允许不同外径，支持m、mm、cm、dm、km。
- `外包体积=Σ(π/4×实际外径²×未修约三维段长)×来源重复数量`。保留竖段与坡段的三维长度，水平长度只作对照；不复用来源已修约的长度总量，也不允许额外重复乘数量。
- 采用Decimal 80位及记录的固定π常量；各段长度、面积和体积不单独修约，仅最终总量按有据选择的0至12位HALF_UP。计算书保留原始参数公式树、单位换算、逐段面积/体积、未修约总量及修约差额。
- 外包占位包括管内空腔，不能作为管壁材料体积。不自动计弯头弧长、管件、承插口、交接重复、包封或施工附加量。复杂形状与边界须另行专业核定，不能将开放折线外包累计认定为管网空间并集。

## 编制、复核及依赖

算量页新增来源读取、逐段实际外径及原件、范围确认、预览、修订和独立复核。重新读取来源或修改外径/单位/逐段依据后撤销确认并清除旧预览，须重新确认才可预览或保存。来源版本变化清空旧外径与逐段依据。

`GET /projects/{pid}/pipe-envelope-candidates?component_id=...`为只读接口，返回当前已审管线的原始点与未修约段长；仍受成员和租户权限控制。来源、原件、并发哈希、保存结果在编制、复核、计算书和计价门禁继续校验，旧版本不能仅重新点击审定放行。

已审外包构件可作为`volume_balance`的占位来源。回填读取外包构件既定已审体积，保留其修约，不再乘数量。扣除比例、同域包含与不重复范围仍须单独核定并独立复核；系统不自动判断空间包含关系。

修订派生构件时，依赖它的已审构件会沿来源关联失效。例如修订管道外径会使关联回填失效，未变化的设计管线与沟槽审批保持有效；计算书及下游继续失效。已保存历史计算书及报价不被覆盖。
