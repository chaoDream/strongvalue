# 0.134 供应商采购成本测算

“组价审核 → 供应商采购成本测算”支持从同一材料资源最新且有效独立复核的报价中选择1～10份，按人工核定数量、同税制运费及其他费用独立计算方案成本。完整精度单价乘数量后，货款逐方案四舍五入至分，再加非负两位附加费用；保留原供货条件、许可、费用不重复说明及来源。

只读预览后保存不可覆盖的待审快照，另一账号独立复核。变更来源、报价修订／撤审、原件字节或当前资源、计价日期后旧记录提示待核查，不能据旧快照通过。独立JSON保留冻结输入、报价和复核记录、计算、本测算审核及下载时有效性；旧文件原字节保持。

测算不改变工程量、消耗、资源单价、报价或库存，不自动排序或选商、不跨供应商加总、不换税，不生成订单、付款或入库。当前仍缺自动采购优化、订单及入库闭环、修订／损耗追加、冲销、跨项目库存及真实商业工程验收。详细步骤、角色、字段、错误和边界见[使用手册19.7](USER-GUIDE.md)。

51项新增采购测算专项与212项既有供应商报价、修订／重新询价、未计价资源、项目计价日期、资源替换、整批复核、工程报价、权限、库存领料复核、手册、交付及历史PDF检查，共263项检查通过（56.75秒）。51项专项复跑通过，不重复累计。前端类型／生产构建及普通／本次基线手册检查通过。

隔离合成浏览器核查15.75m³采购量，两方案成本1396.15与1311.94元，编辑费用清预览并禁保存，重新确认及预览后保存待审，再由另一账号复核。原件文件变化但项目业务内容不变时，刷新项目重新读取供应商和测算有效性，显示历史待核查、撤去当前复核有效标记，保留原金额；恢复原件再刷新可恢复当前核查状态。预览、保存、复核及原件变化核对中工程、消耗、价格、报价及库存摘要保持；三个阶段JSON原字节与SHA256及36条审计链通过。
