# 0.114 基础水平模板可偏心内圆窗口

日期：2026-10-27。前后端及使用手册版本0.114.0。

## 本次完成

整体顶底、台阶平台及内部孔端支持外圆减一个严格内部可偏心内圆W，六项尺寸分别有据，两个圆心共用来源基础中心原点及XY正向。精确有理数严格比较圆心距平方与半径差平方，内圆相切／越界拒绝。W用途及原件独立核定，不创建实体孔H或改变混凝土；200位真实圆弧解析积分保留80位及有序AST，平台排上层、孔端取正确侧层、实际孔只扣净区交集；全部基础个数继承一次，仅总净量修约。

与圆／圆环／另一个偏心内圆窗口检查外圆分离或完整外圆落入另一内圆；与直边净区按每个连通块到外圆心的最小距离、到内圆心的最大距离分别检查，不能混用两个圆心或拼接不同块极值。精确有理数无容差，正重叠阻断，未用内圆可有据另项，跨记录同样防重。全部有效外圆候选片段排除W及H后无剩余才证明严格零接触，W不记入实体孔扣。

页面、确认撤销、预览修订、独立复核、原件字节门禁及历史／来源失效接通。JSON保留严格包含AST及完整两圆心防重见证；Excel/PDF新增偏心内圆参数、严格包含、分段积分及按需覆盖、防重、逐边距离表。详见[使用手册16.14](USER-GUIDE.md#foundation-eccentric-window)。
