# 0.61 上下扣孔净面的设计XY窗口分区

继续补齐PRD F05、6.1中的局部模板与防水范围核定。已审等厚多边形实体的顶部、底部净面可按共同设计X/Y分割线划分窗口，计算窗口内外轮廓与孔洞分别裁剪后的净面积。窗框用于界定范围，不直接将矩形窗口面积当作工程量。

## 输入与计量范围

每个上下原面每轴最多8条分割线，保留原始值、长度单位及依据。坐标必须严格在原净面外包范围内，不得重复、落在范围端点或越界；范围内部经过原轮廓顶点、边或孔边允许，交集按实际面积核定。分割使用共同设计X/Y，可以为负数，不是距窗口起点的相对距离。侧面继续使用原边局部S/Z，界面随所选原面明确切换，不能混用。

裁剪支持原有直边凹形及严格包含、互不接触的孔。每个非零窗口形成一个核定项；同一窗口内可能包含多个互不连通净区，本版合计为同一项，若做法不同须进一步分区或另建计量范围。完全位于孔内、原轮廓外或仅接触边界的零净量窗口不生成计量面，闭合记录保留零窗口数。每原面最多81个窗口，窗口及其他计量面预算合计不超过1000项；超限阻断，不截断后计算。

## 确定性裁剪与精度

新规则`polygon-boundary-1.2`，窗口裁剪版本`xy-window-rational-1.0`。原始十进制设计坐标及分割值转为精确有理数，逐轮廓依次按四个窗口半平面裁剪有向边链，再计算鞋带面积。凹形交集的连接往返边不贡献面积；外轮廓和每个孔分别裁剪，按精确面积扣孔，不因孔跨窗口重复或遗漏扣减。

每个净区保存派生有理数分子/分母、逐轮廓裁剪面积、窗口范围及算法版本，净面积AST为派生分子除以分母；它是原始几何经版本化裁剪得到的结果，不是人工面积输入。重建时从同版原始坐标、分割及依据重新裁剪，逐字段核对保存结果，不能用客户端提供的面积、快照或有理数替代。

精确有理数子区合计必须等于原净面；面积转换为Decimal 80位后保存显示及合计精度差，不调平某个子区，不逐区另行修约。计入面合计后仅乘一次来源重复数量，不用修约后的体积反推面积。任一有理数分子或分母超过8192个二进制位时明确要求拆分范围，不静默降精度。未分区多边形沿用1.0，只有侧面分区时完整沿用1.1计算内容；原长方体分区不变。未新增依赖或数据库迁移。

## 界面、复核与修订

上下净面分区设置展示服务器计算的精确原XY范围。示意使用原始轮廓与孔洞，按窗口裁切着色；孔和轮廓外保持空白，虚线窗框不代表计量面积。逐项显示共同XY范围、局部Z、裁剪外面积、逐孔面积和净量，可展开逐孔明细及原面/子区闭合校验。

全部最终计量面仍须明确计入或排除、做法说明及原件依据。修改设置清除旧预览，应用前禁止预览/保存；应用后新净区决定、说明及依据清空，未变化面按几何身份保留，移除分区恢复原面也须核定。窗口身份使用原面、等价换算后的XY范围与裁剪规则，不随分割输入顺序或等价单位变化。

来源当前审批、版本哈希、实际原件字节、文档/证据和保存预览继续在候选、保存、构件复核、重算及计算书复核时校验。来源或分割修订后旧结果失效；旧已审构件、计算书、清单和报价按既有规则留存，新数量须重新核定、复核和重建。
