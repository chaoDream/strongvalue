# 0.104 矩形台阶平台的XY局部窗口模板

## 本次补齐

基础水平模板新增矩形台阶平台的有据XY矩形窗口。选择已审下层平台后，标高取下层顶Z，截面与紧邻上层、实际孔位、全部最终基础个数均只读继承。窗口与整体顶底面沿用相同基础中心和XY正向、四坐标及单位、逐坐标原件、共用基准原件和范围确认。实际接触和做法仍须独立核定，不由平台或土面自动推断支模。

每基础窗口毛面积=(下层截面∩窗口)−(上层完整名义截面∩窗口)。只扣起Z<平台Z≤止Z的实际孔；孔扣=(孔∩窗口)−(孔∩上层∩窗口)，再由毛面积减孔扣。上层名义截面内的孔底不混入平台，体积扣孔阈值不填实物理孔；零接触、无交集和边界相切保留零面积。窗口可越出下层，仅计实际外露平台范围，不改变基础体积和材料量。

上层为矩形时，先将上层与窗口逐轴裁切，形成共同矩形、中心、宽高及可重放的边界选择公式；再将孔相对该共同矩形平移，求实际共同覆盖。轴向矩形孔逐轴精确裁切；圆孔与窗口、圆孔与共同矩形分别采用既有200位Decimal解析计算、80位输出与记录固定π，分别保存曲线分项，不将共同覆盖误写成外露孔扣。数值精度无法确认或交集超过毛面积时阻断。

同来源同基础项的全部窗口继续要求相同基准说明和原件。同一平台内，整面与窗口、X/Y均正重叠窗口及跨记录重复仍拒绝，即使重叠只在上层覆盖、孔或外轮廓之外；分离或共享边界可分项。不同下层序号对应不同标高平台，可以使用同一XY范围；分离校验只比较同一平台。各项继承全部最终基础个数一次，仅总净面积按有据位数HALF_UP修约。

页面新增矩形平台窗口入口、窗口内下层/上层覆盖、全孔/孔与窗口交集/共同覆盖/实际扣减和两份圆孔解析过程。修改窗口坐标或原件撤销确认；更换平台清空不再适用的窗口；重新读取修订来源清空旧范围、材料、依据、修约及确认。圆形平台和孔底/孔顶局部窗口仍明确阻断，原整面入口保留。

含矩形平台窗口的记录采用`foundation-horizontal-formwork-1.5`，旧整体端面窗口继续1.4，其他旧整面记录保留1.0至1.3及原结果。JSON保存完整原始输入、共同交集及AST。Excel/PDF新增“基础平台窗口截面差”“基础平台窗口孔裁切”，既有平台孔表和窗口曲线表按实际对象区分孔与窗口交集和上层共同覆盖；没有平台窗口的旧成果不增加新空表。
