# 0.58 多边形净体积关联回填与来源轮廓复核

继续补齐PRD F05、6.1中算量结果关联及可追溯复核。已审定的水平设计多边形体积可明确选作回填开挖来源，也可作为占位扣减来源；支持多边形与既有沟槽、底板等来源混用。面积模式始终排除，不能通过伪造显示单位变成体积。

## 数量和核定口径

读取来源已审数量，保留来源版本、哈希、规则及完整原始结构快照。来源数量已包含其逐孔扣减、整组重复数量和既定修约；回填不再扣一次孔或重乘数量。占位按人员有据核定的比例扣除，扣除项不逐项修约，只对最终净回填量按原有规则修约。既有回填算法版本保持`reviewed-volume-balance-1.0`，未新增依赖及数据库迁移。

几何类型属于结构化类型时，候选读取及后续保存/复核/重算都调用该类型的原件与保存结果校验；多边形的实际原件字节、逐坐标证据、轮廓、逐边映射、保存预览及来源校验值发生变化会阻断。客户端夹带的来源几何不能覆盖服务器重建的来源快照。

## 来源轮廓和版本变化

回填明细、预览和独立复核内增加“核查回填引用的多边形轮廓与孔位”。分别展开本次保存的开挖/占位来源，可核查净量、孔位示意、原始顶点及单位、逐坐标证据、逐边叉积和孔关系。显示的是该回填所锁定的版本，不能编辑图形或由示意推算尺寸。

修改字段清除范围确认。重新读取来源时立即清除旧预览和确认，读取失败不能继续沿用旧候选；占位版本变化还清空该行比例、说明和依据，须重新填写。来源修订使旧回填及下游失效，旧数量保留，不能使用旧哈希直接重新计算；新回填修订保留精确旧对象历史。

## 验证

2026-10-23：新增32项合成测试，全量1630项通过；前端类型检查及生产构建通过。覆盖双角色及旧类型混用、孔/组数/来源修约只计一次、面积与伪造单位拒绝、两类来源各8种原件/证据/结构损坏、后续审核及计算门禁、来源快照伪造、修订及历史/清单闭环、权限/租户/成员/跨项目、重复及递归来源、三格式和旧报价隔离。

隔离浏览器以开挖100m³和占位10m³形成90m³回填，确认面积50m²不在来源列表、候选和预览前后持久化数据一致；独立账号核查引用的凹形轮廓、三角孔/菱形孔及依据后审定。合成占位修订至15m³后，旧回填与计算书失效，旧来源哈希被拒；界面清空该行比例、说明、依据及确认，重新填写后保存同一回填V2为85m³。后续接口完成独立复核、计算书/复核及清单85m³，并导出JSON、Excel和PDF。42页合成草稿PDF第22至24页回填三表逐页渲染检查可读。仅验证软件流程与算术，合成厚度变更不代表原件专业核定；真实工程库无合成数据。
