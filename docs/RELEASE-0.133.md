# 0.133 库存领料单批量独立复核

独立复核人在“图纸与算量 → 原材库存与预留”使用“批量独立复核领料单”，按原材领料或余料分批领用类型选择最多200单；逐项展开原件、日期、接收人、规格、原分配行及当前未领余额，填写共同决定及依据。

复用整批事务与逐项审核，任一对象摘要、可复核条件或通过校验失败，整批回滚。每单保留审核记录，批次审计关联审核编号。取消及实际执行以事件留档，候选接口同步排除已关闭单；可重新读取并清空选择，避免用旧快照盲目重试。

审核不改变在库、在外、预留或工程、报价。多个草稿可共享原预留余额，批准不是额外数量保证；实际执行仍独立核查并受余额约束。拒绝、补件不记账；已执行历史、原审核及旧导出保持。详细操作见[使用手册15.21](USER-GUIDE.md)。

本次不支持整批出库、自动分配共享余额、修订／损耗追加、采购或跨项目共享；不代表PRD全量或真实仓库、工程、商业运维验收。

18项新增库存批量复核专项与353项既有相关检查，共371项不同检查通过。覆盖两类单据的逐单留痕、摘要冲突、取消、原件字节变化、来源余额耗尽、整批回滚、拒绝／补件、权限、重复选择、空依据、审批不扩大共享额度及逐单执行。前端类型／生产构建与普通／基线手册检查通过。

隔离合成浏览器验证并发取消导致整批失败，重读后移除已取消单并清空选择，再次提交保留每单审核；原材审定、余料补件及再次通过均不出库。单独执行后完整原材在库5→4、余料在库1→0，两账各在外1；共享余额不足的后续已审单被阻止。工程及供应预留摘要保持，三个阶段历史JSON原字节及SHA256、65条审计链和三批六条审核关联核对通过。另用最终构建验证切换类型清空选择、明细及中文状态、提交成功且无页面警告或错误。
