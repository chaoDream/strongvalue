# 0.65 多边形边线栏杆计长

补齐PRD F05、6.1的栏杆受控计量。可从当前已审水平设计多边形读取原边，逐边明确排除、整边计入或一个/多个局部计入区间。来源可为面积或等厚体积模式，外轮廓、孔边及每个轮廓末点回到首点的闭合边全部列出，不能遗漏决定。

## 口径与计算

这是原边设计水平长度，不从轮廓自动认定真实栏杆安装中心线。须填写栏杆材料做法、安装位置与水平计长范围、总体计量说明及对应原始依据，并显式确认范围和重复数量。坡段三维长、栏杆高度、立柱数量、多道扶手、弯头搭接及材料质量尚不自动计算，不能将候选周长直接当作栏杆工程量。

每边的S从所列原起点P沿边增加到终点P。整边采用原始XY坐标的平方根长度；局部区间保留起终距、长度单位、逐端依据，满足0≤起距<终距≤原边实际长度。同一边区间不得重叠或重复，相邻区间可以端点相接，跨边范围须分边填写；排除及整边模式不得混带局部区间。每边最多20个局部区间，合计最多1000个，沿用来源轮廓200点上限。

原边长度上限用精确有理数平方比较，避免把显示的斜边长度或容差当作合法终点；区间长为终距减起距，不反推比例计长。采用Decimal 80位，各边和区间不单独修约，累计后只乘一次来源重复数量，最后按有据选择的0至12位HALF_UP修约。使用来源原始坐标和数量，不从已修约面积或体积反推周长。规则版本为`polygon-railing-length-1.0`，保存公式AST、原始单位换算、每边决定、标准S区间及完整来源快照。

## 编制、复核和修订

“图纸与算量”新增“多边形边线栏杆计长”，支持读取原边、批量明确排除及逐边覆盖、追加/移除局部区间、只读预览和保存送审。图示按原坐标画外/孔边，整边或有效区间绿色、排除灰色、未核定黄色；可选择原边定位，小孔编号按选择显示避免堆叠。图示不可测量。

独立复核页显示材料、安装范围、来源版本、原边方向、区间原值及标准值、逐项证据、总长与修约；可展开来源原始轮廓及逐坐标依据。预览、保存、审核、计算书、清单映射及导出均重建来源和计算记录，检查当前原件、证据与快照，拒绝自报或篡改数据。

同版修订恢复原决定和区间，仍清除旧预览及范围确认；来源修订后旧栏杆及下游失效，重新读取会清空全部原边决定、说明、依据、局部区间和范围确认。修订使用当前对象哈希，保留完整已审旧版。重新独立复核、重算、复核计算书及重建清单后使用新量。新增长度口径的清单映射，仍需合法编码、标准及依据，不预填官方编码。旧类型、报价和导出留档不改写；没有新增依赖或数据库迁移。
