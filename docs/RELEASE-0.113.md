# 0.113 基础水平模板同心圆环窗口

日期：2026-10-27。前后端及使用手册版本0.113.0。

## 本次完成

整体顶底、台阶平台及内部孔端支持单个同心圆环XY窗口，逐项核定圆心、实际内外径、共同单位及基准、内圆不支模说明与原件，严格0＜内径＜外径。窗口内圆W只排除本窗支模，不创建实体孔H或改变混凝土。外圆、内圆及真实截面／孔参与全部边界事件分段，200位解析积分保留80位及有序AST，平台排上层，孔端取正确侧层，实体孔只扣环带内实际交集；全部基础个数继承一次，仅总净量修约。

圆／圆环以精确有理数圆心距平方及内外半径判定分离或内圆包含；与直边净区按每个连通块的最小／最大距离平方判定，不能拼接不同块的极值。内外切可分项、内圆残余空区可另项，正重叠阻断，跨记录及混合旧窗口同样检查。全部外圆候选片段排除W及实际孔后无剩余才证明严格零接触，W不计为实体孔扣减。

页面、确认撤销、预览修订、历史并发、来源失效、独立复核及原件字节门禁接通。JSON保留所有AST和径向／逐边见证；Excel/PDF新增圆环参数、分段积分及按需覆盖、防重与逐边距离表。详细操作见[使用手册16.13](USER-GUIDE.md#foundations)。
