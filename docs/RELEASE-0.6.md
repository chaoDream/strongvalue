# 0.6 补件任务跟踪与独立关闭复核

本版补充 PRD F03 的补件任务及缺项跟踪，使资料完整性诊断中的具体缺口可以分配、提交和复核。任务关闭不等同于专业资料充分或全工程审核通过。

## 操作与约束

| 功能 | 已实现行为 |
|---|---|
| 登记缺口 | 在完整性诊断页填写任务名称、具体缺项、所属专业、负责人、完成日期及范围内阻断标记。负责人从当前企业启用中的编制/负责人/管理员账号选择；不授予任何额外项目访问权限。 |
| 计划与处理 | 当前任务负责人或企业管理员/项目负责人可开始处理、调整期限。重分配负责人、调整阻断等级、取消和重开仅允许管理员/项目负责人；必须填写原因并记录前后对象。已送审任务不能直接调整计划，已关闭任务须先重开。 |
| 提交依据 | 上传对应专业资料后，选择1至20条不重复的当前原始证据并填写补充说明，送交关闭复核。专业不符、原件缺失或版本被替代时拒绝提交。历次说明、提交人、时间及依据保留，退回后可以重新补充。 |
| 独立关闭 | 由reviewer核对任务、历次补充及原文，批准关闭、拒绝或要求补充。未提交依据不能批准；编制及管理员不能代审。支持现有批量复核，任一任务来源失效则整批回滚。取消任务不能直接审核恢复。 |
| 成果门禁 | 本次试点范围内标记阻断的任务，在未关闭或关闭依据失效时阻断成果审定；范围外任务只跟踪，范围扩展后自动纳入。非阻断任务不单独增加业务阻断，但任务修改仍使旧报价失效，需要重算以更新交付快照。 |
| 来源与历史 | 已关闭依据被新版文件替代或原件缺失时，重新阻断成果并提示依据失效。重开清空当前依据而保留历次提交；审核撤回会重启阻断。旧报价及旧导出不重写。 |
| 交付留档 | 新报价快照保存补件任务，使用这些任务的报表增加补件任务台账；无价ZIP快照也包含任务。操作日志记录任务原因、版本及前后状态。 |

期限按上海时区的日历日期显示逾期提示，不按历史计价日期判断。当前仅工作台内跟踪，无邮件、短信、外部通知或自动催办。

## 验证

90项自动测试通过，前端类型检查及生产构建通过。新增覆盖独立关闭、未提交拒绝、关闭不自动通过专业覆盖、退回重提、依据替代及缺失、角色/租户/跨项目边界、无效负责人/日期、旧哈希冲突、取消/重开、范围变化、非阻断任务、批量关闭回滚、报价快照及台账。

浏览器在独立合成工作区实际完成登记任务、提交原始依据、切换独立复核账号、核对原文并关闭，展开提交历史查看原始依据。截图 `qa/v0.6-document-request.png`。未向实际工程写入测试数据。

## 尚未完成

任务由业务人员登记，系统不能自动判断所有缺图或专业语义缺项；关闭任务不能自动批准专业完备性，也不能证明新增资料确实足够。项目内细分访问权限、专业资质审核、组织多级审批、外部催办和生产任务基础设施仍待实现。
