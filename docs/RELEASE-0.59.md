# 0.59 等厚多边形实体的模板与防水逐面计量

继续补齐PRD F05、6.1中的非矩形构件、模板及防水算量。已审定的`polygon_region`等厚体积可作为`surface_faces`来源，沿用独立逐面核定、复核、计算书、清单和历史快照流程。面积模式没有厚度，始终不能作为实体表面来源。未增加依赖或数据库迁移。

## 候选面与数量

- 上下各一个净面：原始外轮廓面积减全部贯通孔面积。上下两面分别核定，不把带孔或凹形净面当作包围矩形。
- 每条外轮廓边生成一个外侧面，每条孔边生成一个孔内侧面，保留轮廓、边和原始起终点编号。边长为设计XY差的平方和开方，侧面积为该边长乘来源统一竖向厚度。共线相邻边仍按原始边分别列示，不自动合并。
- 竖向位置明确使用局部底面0至来源厚度，仅定位上下与沿边展开，不推断设计绝对高程。轮廓先通过既有多边形有效性、孔严格包含及分离检查。
- 使用来源未修约净面积、厚度及原始设计坐标，不能用已修约体积反推面积。Decimal 80位计算；非有理边长的平方根按80位精度计算，逐面不另行修约，明确计入的单组面合计后仅乘一次来源重复数量。

新规则版本`polygon-boundary-1.0`。来源尺寸、单位换算及逐面公式AST全部保存，可独立重算；既有长方体边界及分区规则版本不改写。

## 编制、复核与修订

“模板与防水逐面计量”来源可选已审长方体或已审多边形等厚体积。上下净面以带孔设计轮廓示意，侧面按该边局部展开显示；逐面标识计入、排除或待核定，并显示精确XY起终点、局部厚度、面积和计算式。示意只供定位，不可测量或拖点修改。

全部候选面必须明确计入/排除、计量说明及原始依据，不能遗漏或由客户端覆盖面积。批量决定仍明确按所选类别应用；重新读取候选重置筛选和批量输入，来源版本变化清空旧分面决定。独立复核中可核查逐面依据与保存的来源原始多边形、顶点单位及逐坐标证据。

候选、保存、构件复核、重算及计算书复核重新校验来源原件实际字节、文档/证据、源几何、逐边映射、预览及校验值，拒绝过期哈希或伪造来源快照。来源修订使旧表面计量与下游失效，重新核定后保存同一表面构件新版本，完整旧对象历史保留。

## 未完成的范围
