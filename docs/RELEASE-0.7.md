# 0.7 PDF原图证据区域定位

本版补充 PRD F01/F04 的原图页内来源定位。框选仅标识原文位置，不将像素距离作为设计尺寸，不自动识图、计算工程量或批准参数。

## 操作

1. 在图纸与算量页选择PDF原件和页码，点击“框选原图证据”，在显示页上拖动，再点击“记录所选区域”。也可以选择“按百分比填写区域”，用数字填写距左、距上、宽度和高度。
2. 在窗口中预览高亮区域，填写图号及准确原文后保存。保存原文件哈希、实际页码、区域及页面旋转/裁切信息；当前不提供覆盖或修改既有证据的接口。
3. 点击原图证据索引、构件参数或复核内容中的来源链接，回到该文件对应页并高亮区域。缩放与窗口尺寸变化时，区域随页同比例显示。翻到其他页时隐藏该框，再点击同一证据可重新定位。
4. 在后续构件参数中引用该证据，仍按原有构件、算量和成果独立审核流程处理；新增证据本身不产生任何工程数量。

## 坐标与校验

- 新坐标约定为 `pdf_display_normalized_v1`，格式 `[x,y,width,height]`，以PDF默认旋转及裁切后的显示页左上角为原点，数值范围0至1。宽高须大于零，区域须完整位于页内。它不是PDF底部原点的绝对坐标，也不是CAD工程坐标。
- 服务端校验原件实际内容哈希及实际页数，不依赖客户端自报页数；区域提交须携带当前文件哈希和坐标约定。拒绝旧版本、被替代原件、缺失/损坏文件、非PDF区域、无效数字和越界页码。
- 既有纯页码/原文证据继续可用。旧记录或模型候选中的未确认坐标约定不直接套用新高亮规则，仅跳页核对原文，避免显示一个看似精确但含义未知的框。
- 历史PDF原件及既有区域记录保留不变；来源更新后，旧证据依然只能用于历史定位，当前参数审定仍受版本门禁约束。非PDF文件不提供框选。
- 报价快照保留证据区域元数据，PDF/Excel/JSON报表的依据索引增加坐标约定、区域、页面旋转及裁切信息；交付ZIP继续保留对应原件和结构化快照。

## 验证

95项自动测试通过，前端类型检查及生产构建通过。新增覆盖旋转及裁切页、原始哈希、区域与实际页数、非法/非有限数字、旧版本、角色及租户限制、原件缺失/损坏、非PDF兼容、原件替代后旧记录及字节保持不变、报表留档。

浏览器在独立合成PDF工作区实际完成：在第2页（旋转90°并裁切）拖框、填写原文并保存；放大到125%时验证高亮框的相对坐标与保存值一致；切到第1页确认隐藏，再点击证据返回第2页。截图以50%展示完整测试页及高亮区域，见 `qa/v0.7-evidence-region.png`。未对实际工程写入测试标注。
