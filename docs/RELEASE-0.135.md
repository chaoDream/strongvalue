# 0.135 内部采购申请与有据取消

“组价审核 → 内部采购申请”从当前有效且独立复核的成本测算中人工选择一份供应商方案，填写申请／需求日期、计划收货地点、选商依据和原件。数量、单价、费用及成本按原方案冻结，不能在申请中直接修改。只读预览后保存待独立复核申请，生成内部编号；同一测算只能有一份未取消申请，包含已拒、待补件及来源失效申请，并发或重复保存不重复取用。

另一账号独立复核，来源、报价及原件变化后旧申请待核查，不回写工程、报价、原测算或库存。编辑账号据原件确认未对外下单后，可取消内部申请；原记录与审核保持，取消后才能从当前测算人工选择方案另建新编号。取消原件失效提示待核查，取消事实不自动撤回。JSON独立留档申请、原方案、审核、取消及当前有效性，旧文件不改写。

这只是内部申请，不向供应商发送，不自动选低价，不生成对外订单、合同、付款或采购入库；不同测算之间仍须人工核查重复采购范围。完整外部采购、修订／损耗追加、冲销、跨项目库存及真实商业工程验收未完成。详细字段、步骤、角色、错误及边界见[使用手册19.8](USER-GUIDE.md)。

54项新增内部申请专项与263项既有相关回归，共317项检查通过（69.83秒）；覆盖权限、本人回避、日期及当前报价有效性、冻结选择与不可改量价、重复／并发、各阶段失效阻断、审核与取消、取消依据失效、取消后重建、整批复核失败回滚、历史文件及旧项目兼容。前端类型／生产构建及普通／本次基线手册检查通过。

隔离合成浏览器验证：人工选A方案15.75m³／1396.15元，只读预览不保存，改地点清确认及预览，重新确认保存待审，另一账号独立复核；同一测算已有未取消申请时不可再次选择。原件确认未对外下单后有据取消，再人工选B生成新编号1311.94元待审申请；A的1396.15元、原复核及取消事件保留。改变被A取消及B申请共同引用的合成依据文件后，A仍取消且提示取消依据待核查，B自身来源也待核查，不产生重开或实物事件；恢复原件后重新核查。工程、资源价、原测算与供应商记录、工程报价及库存摘要保持，五阶段JSON原字节与SHA256及48条审计链核对通过。历史文件明确标为内部采购申请，不冒作工程报价；页面无警告或错误。
