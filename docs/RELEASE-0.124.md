# 0.124 余料实际投入加工与分批结果验收

日期：2026-10-28。前后端及使用手册版本0.124.0。

## 本次完成

在尚无完整实测结果时，按已执行余料领用逐分配未加工余额登记实际投入日期、地点、接收人或班组、根数及当前原件。预览、保存、独立复核不记账；显式执行后将未加工转为在加工待验收，不生成成品、损耗或新余料。未执行可有据取消，已执行不能取消、重审或按未加工原段退回。

后续结果专门引用已执行投入单及其原领用快照，可分批实测、独立复核及显式验收；只结转本投入单待验收数量，不重复扣未加工或在库。显示投入／已验收／待验收及部分或全部验收状态，不能借另一单数量超验收。原件失效保留在加工和已验收事实，凭新实测可记真实结果，但关联新余料采用仍检查投入依据。旧一步完整结果保留，已投入数量不能再走直接模式重复记账。详见[使用手册15.12](USER-GUIDE.md#stock-offcut-jobs)。
