# 0.76 含构造加柱布置的禁布与显式移柱

继续补齐PRD F05的栏杆计量。新增“定距加柱及禁布移柱”“均分加柱及禁布移柱”，先建立合法的原规则柱及原构造加柱，再逐根按原件移动其中的内部柱。两类原柱共同检查闭区间禁布、重合及交叉换序，保留身份、原位、移后位置、数量组成及独立依据，接通复核、计算书、kg清单和三格式报表。

## 原布置与柱身份

原规则沿用已审来源及有据间距、端部归属；定距模式还须明确起端或终端锚向，均分模式不接受锚向字段。构造加柱先按原件给出名称、原段S及单位、说明和分别关联的依据，必须严格在本计入区间内，且不与原规则柱及其他加柱重合。移柱不能用于修复非法的原布置。

移柱新增明确的原柱类型和独立依据。原规则内部柱按节点j识别，j按原规则S递增，从1至N−1；原构造加柱按本区间加柱表的输入序号识别，不因S排序改变编号。两类编号可以相同，不是全部柱的总编号。接口分别采用`node_type=regular`及`node_type=additional`，`node_index`始终为对应原编号，类型、编号、新S及说明各自有原件。原构造加柱的名称与输入序号、所有柱的原类型、原编号、原S及原位置表达式保留。

原均分节点按a+L×j/N计算，不能以最大间距乘j代替实际均分端距；原定距位置继续按所选锚向建立。新S始终从来源原段起点、沿已审三维或水平口径增加，局部区间不改为相对起距。

## 禁布与移柱校验

各区间明确填写禁布及移柱列表，无则为空。全项须至少有一根原构造加柱，以及至少一个禁布范围或一根实际移柱。禁布为含两端的闭区间，须在所选计入区间内；不同范围可重叠并独立溯源，相同名称或等值范围阻断，不因重叠扣除根数。

两类柱均只能移到本区间严格内部，不得移动端柱、原位不变、重复移动同一身份、与任一其他柱重合或交叉换序。最终顺序按移前全部柱的精确S顺序检查，原加柱与原规则柱共同参加；多个同时移柱可经过彼此的原位置，但最终顺序必须严格保持。移后全部计入柱均须位于所有禁布闭区间外。端柱仍通过原两端归属核定，不自动删柱、补柱、重新排序或重新均分。

数量组成保持“原规则柱数＋原构造加柱数”，同材料项下料长和单位长度质量不变；来源重复数量只在单组材料合计后乘一次。每区间最多100根原构造加柱、100根移柱、20个禁布范围，每项最多1000根、每表最多5000根单组立柱，材料项仍为1至50项。不同规格应分项核定。

位置采用精确有理数与原边根式a+b×√q比较，原加柱排序、重合、禁布边界及换序均不按显示小数或容差判断。仅用于原规则的间距、跨数及余跨不能证明移后实际柱距合规；全局柱距和专业构造须另核。

## 界面、审核与报表

编制页同时显示原加柱表、禁布范围和含原柱类型的移柱表，类型不能默认选择。字段变化清空预览和确认；模式切换清除旧加柱、移柱和隐藏锚向。复核示意保留灰色虚线原位、紫色新位及红色禁布范围，逐根表明确显示移动的是原规则节点还是原构造加柱。

沿用原件完整性、角色与租户隔离、对象哈希、并发修订、精确历史和独立复核门禁。质量相同的位置修订也使旧计算书与审批失效；重建前旧清单保留。来源范围更新后材料及下游失效，重新读取清空旧材料行、加柱、禁布、移柱及逐项依据，必须重新核定。

新规则分别为`railing-fixed-added-adjusted-posts-1.0`及`railing-equal-added-adjusted-posts-1.0`，含本模式材料表为`railing-material-mass-1.9`，沿用Decimal 80位及总质量有据HALF_UP修约。旧六种立柱模式保持原记录及版本；独立载入0.75代码核对25组来源×6种旧模式，共150条完整结果一致。两种新模式可同表使用，参数依据命名空间独立。无需新增依赖或数据库迁移。

JSON保留完整记录。Excel/PDF提供原规则四表、构造加柱数量组成和原始端距、禁布范围、移前移后端距及规则宽表，共九类表。移柱表明确“原柱类型及编号”，构造加柱输入序号与名称可对应追溯，逐根表标注原S；完整规则以宽表呈现。
