# 0.95 矩形基础局部横向条带模板

本次继续补齐PRD F05的基础模板。已审矩形或矩形台阶基础的四个竖直外侧面，可选整宽或有据横向条带，并按条带与侧开口在横向、标高两个方向的实际交集扣面积。接通编制、修订、独立复核、计算书、面积清单和三格式导出。未选范围不计，不从外表面积推断支模工法。

## 坐标与范围

沿用来源基础中心和局部XY：X正负侧的横向坐标均沿Y，Y正负侧均沿X。中心为0，正向随局部轴，不随观察面翻转。每项起止坐标必须满足本层负半宽≤起坐标<止坐标≤本层正半宽。X侧半宽取基础宽的一半，Y侧取基础长的一半；台阶逐层使用各层实际尺寸。越界、零宽和反向范围直接拒绝，不自动裁切、调换或取绝对值。

横向坐标独立选择mm、cm、dm、m、km，支持负坐标，沿用18位有效数字与原始/换算后18位小数检查。起止Z仍使用自己的长度单位，以共同基础底为0向上，须在所选层内；跨层分项。横向条带仅限矩形外侧，不得用于圆柱或与圆弧角度混填。圆柱整周及局部圆弧沿用0.94的方向、角度及周期边界规则。

每条带须填写逐坐标原件、基础局部XY与图纸对应的共同基准说明、基准原件并确认。同一来源基础项的全部条带，跨侧面、跨层、跨记录均须引用相同基准说明和同一原件，比较时忽略首尾空白。不同基准直接阻断，不能通过改变方向绕过重复检查。基准哈希仅供核对，不代表自动完成图纸坐标校准。

同一基础项内全部基础采用相同范围，存在个体差异须先拆分来源。材料和全部最终基础个数仍由当前已审来源继承，不再乘来源重复、层数或条带数。

## 实际面积及重复检查

条带毛面积=（横向止坐标−起坐标）×（终止Z−起始Z）。来源矩形孔仅在确实接到当前外侧面时参与扣减；分别求横向、标高交集，两个方向均为正范围才扣面积。内部孔、点或边界相切不扣正面积；只与另一侧接触的孔不扣本侧。混凝土体积阈值不恢复物理上不存在的模板接触面。条带全部落在侧开口中时可为零净面积。

逐条带保留本层整宽、选带宽、横向轴及起止米坐标；逐开口保留实际交集横向起止、Z起止、宽、高、每基础扣减及AST。只有累计全部基础净面积最终按核定0至12位HALF_UP修约，逐条带、逐孔不修约；计算采用Decimal 80位，不受调用方低精度上下文影响。

同一来源基础项、同层、同外侧面的横向与标高两个方向均正交叠才重复。边界相接、横向分离、标高分离可共存；整宽也参与检查。记录内逐对记录横向间隔、标高间隔、结论及AST，负为该方向正交叠、零为相接、正为分离。跨记录在保存、复核和重算时核验共同基准和重复；失效记录仍保留范围占用，需修订原记录。

## 编制、修订及来源变化

“基础外侧模板”在矩形侧面新增“按原件选取横向条带”。启用时坐标、原件、基准和确认均为空。切换整宽/条带会清空本项接触说明及依据；再次启用不恢复旧坐标。坐标、坐标原件和基准编辑撤销该条带确认，标高或其单位改变也撤销条带确认。所有编辑撤销整体确认；基础项、层或面改变移除旧条带配置。

同来源修订恢复完整原始范围及原件，整体须重新确认。读取修订后的来源会清空旧接触范围、做法、原件及修约，防止旧条带用于新尺寸。保存和独立复核完整重建计算、来源快照、原件完整性、校验记录及AST，延续角色、租户、原件五门禁、异项目依据、篡改、伪造ID和乐观并发保护。

预览及放弃编辑不改项目；修订保留精确历史和旧清单，使旧计算书失效。来源或上游变化沿依赖链使模板失效；旧报价及导出文件保留。

## 接口及报表

继续使用`kind: foundation_formwork`、原候选与构件预览/新增/修订接口。矩形行可选新增以下完整配置；示例尺寸仅为合成接口说明，不是默认工程参数：

```json
{
  "lateral_range": {
    "parameters": {"lateral_start": "-100", "lateral_end": "20"},
    "unit": "mm",
    "evidence": {
      "lateral_start": "当前项目起坐标原件证据ID",
      "lateral_end": "当前项目止坐标原件证据ID"
    },
    "coordinate_basis": "据图核定基础中心和局部XY与图纸的对应；所有同来源基础项条带采用同一基准",
    "coordinate_evidence_id": "当前项目共同坐标基准原件证据ID",
    "scope_confirmed": true
  }
}
```

配置不接受宽度、比例或其他额外键，空配置/null不能退回整宽。含条带的记录使用`foundation-outer-formwork-1.2`，无条带的原圆弧仍为1.1、原整宽/整周仍为1.0。结果新增`lateral_checks`；保留原始配置、全部维度、证据索引、单位换算、基准哈希及对应AST。矩形条带和独立基础项的圆弧可在同份模板中混合。

计算书审定后生成m²清单，有据编码映射不改变面积；编码、标准、工法及特征仍需核定。JSON保留完整数据；Excel/PDF在原五张模板表之外新增“基础模板横向条带”“基础模板条带基准与原件”“基础模板条带分离校验”“基础模板条带开口交集”。长说明和原件续行、行高适配；旧模板不新增空条带表。
