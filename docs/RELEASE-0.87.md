# 0.87 同心矩形台阶立柱基础

继续补齐PRD F05基础计量，并贯通F06清单口径、F09报表及F11独立复核和修订。已审立柱基础新增2至10层同心矩形台阶，逐层有据填写长、宽和净层高，按逐层体积之和计算每个基础；原矩形单体保留原输入和计算结果。

## 逐层尺寸与范围

在已选立柱项中选择“同心矩形台阶基础”。`shape: stepped_rectangular`的行仅含来源`material_index`、`levels`、`length_unit`、范围说明及原件、`stacking_confirmed: true`；每层仅含`parameters: {length,width,height}`和对应三项原件。原矩形行保持不带`shape`的旧结构。支持mm/m/cm/dm/km，同项各层共用单位且必须同一材料做法。

台阶从下往上填写，各层同心同轴垂直紧接、无空隙；上层长和宽分别不得大于下层，相等允许。每层高度是该层净高，不是累计高度。服务端精确比较尺寸，不按显示小数放行微小外伸。局部Z从本基础底面0起累计，仅用于核对叠置层次，不代表工程定位或绝对高程。各层范围须据原件确认，不能输入额外数量、累计高程或隐藏系数。

基础数量继续引用来源最终布置立柱根数，兼容均分、定距及各自加柱、移柱和组合八种模式。每根对应一个基础，层数不乘基础数量，来源重复仅乘一次。逐层长×宽×净高相加后乘最终单组根数，累计乘来源重复，仅总体积按明确位数HALF_UP修约。Decimal 80位保留原尺寸、单位换算、逐层相对底顶Z、单层/单基础/单组/全部体积及公式AST；不改来源材料质量、布柱和下料。

## 编辑、审核及成果

切换基础形式清空本项尺寸及原件。切换形式或增删层还清空本项及总体范围说明和依据、撤销叠置及整体确认，须重新核定；新增层从空白开始，删除保留层的尺寸仍须重新确认。修改逐层尺寸、单位或本项依据撤销叠置确认，所有编辑撤销总体确认和预览。恢复同来源修订保留逐层输入及原件，总体确认撤销；读取新来源沿用原清空规则。

预览不改变持久化项目。保存、独立复核、重算及计算书复核重建全部来源、原件、逐层参数、数量和AST；来源修改使基础及下游失效。相同来源立柱项的重复选入、伪造ID、角色租户及并发门禁延续。修订保留精确历史、旧清单和报价快照。

有台阶时规则为`railing-post-foundation-1.1`，纯旧矩形仍为1.0。清单仍用`post_foundation / volume`实体体积口径，显示名称补充矩形/同心台阶；映射不更改体积，编码、材料做法及项目特征仍须人工据原件核定，不自动生成官方编码。JSON包含完整逐层记录，Excel/PDF增加“台阶基础逐层体积”“台阶基础逐层原件”，保留四张原基础表；旧矩形的基础表内容不改变。
