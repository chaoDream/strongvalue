# 0.107 基础水平模板凸多边形与旋转窗口

日期：2026-10-27。前后端及使用手册版本：0.107.0。

## 本次完成

从[0.106未完成清单](RELEASE-0.106.md#尚未完成)推进旋转／斜线水平窗口。基础整体顶底、矩形及圆形台阶平台、内部孔底／孔顶新增3至12顶点的严格凸多边形窗口。按原件输入边界顶点XY，支持旋转矩形、三角形及其他凸直边轮廓；顺／逆时针均可，不从角度、比例或屏幕距离猜坐标。每个坐标、共同XY基准、材料做法和修约均须关联原件，数量与Z继续继承已审来源。

沿窗口顶点、直边交点、直边与圆及圆圆交点划分X区间，逐段确定上下边界并以直线／圆弧原函数积分；平台先排除紧邻上层完整截面，孔端沿用孔底下侧／孔顶上侧混凝土条件，再扣同侧相接孔。200位Decimal工作、80位输出，不用网格或几何容差。直接净接触单独积分，全部边界区间无剩余时保留覆盖分段见证，并用分割恒等式核定最后一孔实际扣减，各孔直接积分另存。极小正缝隙不签发零接触证明。

共享顶点的交点由原始隐式直线方程识别，避免先除出斜率造成伪分段。重复表达式保存为有序依赖定义：`window_expression_definitions`中的每项含中间维度名称、200位值和从先前维度计算的AST；最终公式通过维度引用复用。可从原始输入按序重建所有中间量，再重放分段及最终量，不把中间数值当作独立输入。来源变更仍须重新计算、撤销旧确认和审批。

同端面凸窗口／旧矩形窗口按全部边法向分离轴检查，外包矩形重叠而真实窗口分离或仅共边允许；正面积重叠、包含、整面与窗口重复均拒绝，跨记录同样检查。仍按完整窗口防重，不借实体外或孔内的重叠绕过登记。共同XY依据、权限、租户、原件字节和独立复核门禁沿用。

页面接通轮廓选择、增减顶点、逐坐标依据、规范坐标、毛／扣／净解析明细及零接触提示。JSON保留完整依赖定义、分段AST和净接触见证；Excel／PDF新增“基础凸窗口顶点”“基础凸窗口分段积分”，完整覆盖时新增“基础凸窗口零接触校验”。旧整面及旧矩形窗口仍走原算法与规则版本；新凸窗口使用`foundation-horizontal-formwork-1.8`。

收尾补充：页面预览与独立复核可展开“凸窗口零接触分段覆盖校验”，查看各区间起止、中点、毛接触及覆盖轮廓上下界和剩余片段数，不只显示零接触摘要。此为已有几何证明的只读展示，计算及审批口径保持。

详细入口、角色、前置资料、字段单位、操作、复核、导出与错误处理见[使用手册16.7](USER-GUIDE.md#foundations)。
