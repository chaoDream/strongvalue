# 0.93 基础外侧模板实际接触面积

本次补齐PRD F05中的一类模板算量：从当前已审立柱独立基础读取真实尺寸、孔洞及最终全部基础个数，明确选入各层外侧竖直接触范围，计算实际净模板面积。不是由混凝土体积换算面积，也不将全部外表面默认认作支模范围。

## 可用范围

支持独立矩形、矩形台阶、圆柱、圆形台阶基础。矩形局部X沿基础长、Y沿基础宽，逐项选择X负/X正/Y负/Y正侧；圆形只支持所选层整周圆柱侧面。未选面不计。每项填写实际接触起止Z，采用同一基础实体底面Z=0向上，必须在所选层内，跨层另列范围。可在同面按标高分段，相邻端面允许接触，正高度交叠拒绝。

选入的某基础项内，所有基础采用相同模板做法及接触范围，差异范围须先拆分来源。个数直接继承基础已核定的全部最终个数，包含原布柱的加柱/移柱及来源重复，模板不再乘重复、层数或选面数。尺寸、根数或孔洞不能在模板中另填覆盖；模板材料做法、接触范围说明、逐参数原件和修约位数须明确，无默认施工工法。

矩形侧面展开宽为对应轴向边长，圆柱整周展开宽为π×本层实际直径，毛接触面积为展开宽×有效接触高。内部圆孔/矩形孔不扣外侧面积；圆孔点相切不形成正面积外侧开口。在矩形基础中，轴向矩形孔与某一外侧边界重合时，扣其实际开口宽×与本项接触标高的正相交高。角部开口可分别扣其触及的两个不同外侧面。多个孔沿用已审基础的包含、分离及实际几何约束，不做孔并集推断。

混凝土体积的单孔阈值不会改变真实接触面：即使孔按核定规则不扣混凝土体积，侧面真实开口仍扣模板面积。每基础毛面积、实际侧开口、净面积，全部基础的三项面积及各开口相交范围分别记录。允许所选范围恰好全为空口时净面积为零，不将不存在的面算成模板。

逐面、逐孔不修约，尺寸换算、标高相交、继承个数及面积累计采用Decimal 80位；仅总净面积按明确位数HALF_UP修约。圆形采用随记录固定的π常量。保存各项公式AST、维度、来源证据、原始/标准单位、来源换算记录和修约差额，独立复核可完整重建。

## 编制、修订与独立复核

“图纸与算量”新增“基础外侧模板”。读取已审基础候选后，逐项选择基础项、层和外侧面，填写有据标高、接触说明及依据，确认实际接触范围，再预览或保存送审。新增范围不预填基础项、层、面、实际标高或原件。选择基础项/层会清空旧层面、标高和依据；面/单位变化清空该项范围说明及其依据，所有编辑撤销整体范围确认。确认后仍须由独立复核账号审定。

同来源修订恢复原始范围、做法、单位、原件及修约，撤销整体确认。更换来源或来源版本改变后，读取候选会清空旧范围、做法、依据和修约，须重新据图填写。来源基础或其上游材料/栏杆/设计线修订，模板审批沿依赖链失效。

同一来源基础项、同层、同面的正高度重叠范围，在单份记录及跨记录中均禁止。现有记录包括失效记录仍占用原范围，应修订原模板记录，不能通过再建一份绕过重复检查。修订通过服务端当前对象ID核查，不能借伪造ID跳过重复门禁。乐观并发、精确历史、原件五门禁、角色租户及异项目证据检查延续。预览不写项目，修订使旧计算书失效并保留旧清单，旧报价快照和既有导出字节不改变。

## 接口及清单

新增候选接口：`GET /api/v1/projects/{pid}/foundation-formwork-candidates?component_id={当前已审基础ID}`。通过既有构件预览/新增/修订接口提交`kind: foundation_formwork`，顶层`parameters: {}`、`quantity_type: area`，`source_component_id/source_component_hash`绑定当前来源。须有名称、材料及做法与原件、总体计量说明与原件、修约位数与原件及`scope_confirmed: true`。

`contact_ranges`为1至200项，示例单项：

```json
{
  "name": "按原件核定的实际接触范围",
  "material_index": 1,
  "level_index": 1,
  "face": "x_plus",
  "parameters": {"z_start": "0", "z_end": "600"},
  "unit": "mm",
  "measurement_basis": "本项实际选面、起止Z、同项全部基础做法及不重复计量的原件说明",
  "evidence": {
    "z_start": "当前项目原件证据ID",
    "z_end": "当前项目原件证据ID",
    "measurement_basis": "当前项目原件证据ID"
  }
}
```

上列尺寸仅作接口示例，不能作为实际工程默认值。`face`仅支持`x_minus/x_plus/y_minus/y_plus/circumference`且须匹配基础形态。标高单位支持mm/cm/dm/m/km，原始及标准值沿用18位有效数字、小数和有限值检查。

计算书审定后生成m²模板清单。清单类型新增“立柱基础外侧模板 / 基础已选竖直外侧实际接触净面积”，适用于有据编码映射；不会把混凝土m³、栏杆m或材料kg混入模板。编码和项目特征仍需独立核定，不提供官方编码或价格默认值。

JSON完整保留`formwork_summary`、`contact_ranges`、`apertures`、逐项全部AST及来源快照。Excel/PDF新增“基础模板接触面积汇总”“基础模板逐面标高与净量”“基础模板侧开口实际扣减”“基础模板原始范围与依据”“基础模板做法与计算规则”五表，长说明续行及行高适配。无模板的旧报表和历史报价不新增空模板表。

## 验证

2026-10-24：专项及清单映射176项通过，全量4342项测试通过；类型检查、生产构建通过，本机8000确认0.93.0。3100份旧完整计算与0.92一致，24套旧完整报表逐表一致。全量结果见[工程验证记录](QA.md)。

专项覆盖四形态、八种最终布柱、五种独立标高单位及低调用精度，四侧及角部开口、正高度相交裁剪和精确边界、圆孔点相切/内部孔零侧扣、两层及多基础项、相邻段与同面重叠、跨记录不同单位重复、70组独立面积/修约对照、全部逐面及逐开口AST、来源证据、严格式及7类篡改、原件五门禁、角色租户/异项目依据、来源及祖先修订失效、并发/历史/旧清单、200范围长原件PDF、有据清单映射、四形态三格式及旧报价隔离。

隔离浏览器从空模板编制起，选入已审22个矩形基础的X正侧Z0至600mm。每基础毛.300m²，真实侧开口宽60mm、相交高150mm扣.009m²，净.291m²，全部6.402m²；混凝土阈值100m²全部不扣孔时，仍保留侧开口。基础计量2.640m³、材料79.200kg不变。超层高601mm及重复同面范围被阻断，成功/失败预览未改变持久化项目，编辑撤销确认。独立复核、计算书重算复核、面积清单和三格式通过。

同来源恢复原范围后修订起始Z为100mm，真实开口只相交50mm，每基础毛.250、扣.003、净.247m²，合计5.434m²；V2独立复核、重算复核及三格式通过，V1历史精确、旧清单和来源保持。两版PDF五张模板专表均渲染逐页检查。两版PDF共66/68页，模板专表分别为第34至38页、第36至40页，长说明和原件续行完整；浏览器实际PDF复核V2第38页。原生界面截图：[模板V2独立复核](qa/v0.93-foundation-formwork-review.png)、[实际PDF侧开口扣减](qa/v0.93-export-foundation-formwork.png)。

基础来源随后修订至V2，原模板自动失效；浏览器修订入口读取新来源后，旧接触范围、做法、原件和修约均清空。另核对圆台阶下层Φ600mm整周Z0至200mm，22基础共2.64πm²→8.294m²，展开宽完整值可展开查看，界面无警告。
