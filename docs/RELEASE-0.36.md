# 0.36 圆形井板偏心与多圆孔

继续补齐PRD F05检查井扩展：从已审井筒继承选定井号及数量，为水平等厚圆板逐孔填写局部XY、实际直径、原始单位及定位/贯通原件，形成可复核的多孔净实体工程量。旧版同心通孔记录保留原规则、公式和编辑器。

## 几何及计量口径

- 沿用`chamber_plate`，新增显式`opening_mode=offset_circles`。每板0至20个圆形贯通孔；空孔表表示有据核定无孔。每板以板中心为原点，明确局部XY方向和原件，不能从井筒高程、示意图或像素距离推断孔位。
- 实际板径、厚度及板底标高独立核定，支持负标高；每孔独立填写有正负号的中心XY、正孔径，支持m/mm/cm/dm/km并保存原始值与换算过程。无孔须移除孔项，不能用零孔径代替完整孔参数。
- 设板半径为R、孔半径为r，校验`x²+y²≤(R−r)²`且`r<R`；孔i与j校验`Δx²+Δy²≥(ri+rj)²`。按Decimal 80位比较平方距离，不用浮点容差放过越界或重叠。孔与板边界、孔与孔相切允许；正面积重叠、相互包含、重复中心及越界阻断。本版不计算重叠圆孔并集，几何通过也不代表结构安全或最小净距合格。
- `净板体积=Σ[(π/4×实际板径²×厚度−Σπ/4×圆孔直径²×厚度)×来源已审井数]`。孔位只参与包含/分离判定，不改变已合法确定的圆孔体积。逐孔、逐板不单独修约，继承井数一次并仅最终总净量HALF_UP至有据选择的0至12位；保留固定π、公式树、校验公式、原始精度和修约差额。
- 各板独立保留材料、施工做法、标高基准、计量范围、局部坐标、逐参数及逐孔原件。仍按选定井号本层一板继承井数，不再乘管线数量；不同材料、用途和层次分别编制。井盖框、钢筋、收口、流槽、踏步、预埋件、异形孔及非贯通凹槽须另核。

## 编制、审核及依赖

新建编辑器支持逐孔增删、混合单位、位置/孔径原件、局部坐标说明、孔位示意、包含/分离明细及净量预览。每次修改清除预览并撤销范围确认；读取新来源版本清空旧板孔参数，必须重新核定。旧版记录不自动迁移或更换公式。

服务器继续验证当前已审井筒及上游管线、原件字节、证据和完整来源快照；独立审核、计算书和计价门禁重算保存结果及校验。角色/租户/项目权限、并发对象哈希及失败原子性保持有效。孔位置修改即使净量不变，也使关联回填及下游审批失效。

回填采用已审井板净实体体积，不再次乘数量、不回加孔扣减。实际同域包含、标高以及与井筒或其他占位扣减不重复仍须另外核定；本版只判断单板内圆孔几何关系，未自动判断跨构件空间包含。

JSON保留完整孔位、换算、原件、公式及判定。Excel/PDF新增“井板逐孔定位与扣减”和“井板孔包含与分离校验”，原井板表同时兼容旧孔径及新孔数。页面版本改为读取前端包版本，修正页脚旧版本号残留。
