# 0.34 圆形检查井井筒

继续补齐PRD F05管网检查井扩展：关联当前已审设计管线站点，逐井填写实际内外径、独立高度及数量，明确计算井筒材料体积或含空腔的外包占位体积，接入独立复核、计算书、清单及回填联动。

## 适用范围与数量口径

- 新增结构化构件`circular_chamber`，结果为m³。每个构件只编制同一材料规格、同类竖直等径圆筒井段，逐项可有不同尺寸、原始单位及井数。每项井号/井段与关联站点不能重复，最多50项；同站不同材料或井段另建构件。
- 用途必须明确为`wall_material`或`outer_envelope`。材料量为`Σ[π/4×(实际外径²−实际内径²)×高度×核定井数]`；外包量为`Σ[π/4×实际外径²×高度×核定井数]`。两种原始量均留作对照，只有本次选择的用途进入工程量、计算书和清单，不将两者相加。
- 实际内径、外径及独立核定高度均为正数，内径严格小于外径。原始长度单位支持m、mm、cm、dm、km，保留换算及公式树。井数逐项为1至1000000整数，每项尺寸、数量及定位范围说明分别关联原始依据。
- **不继承管线重复数量**。来源站点只作定位索引，不代表软件确认其为井中心、井底或地面，不从管线高程或路由长度推断井深，不把所有转折点自动认定为检查井。重复井组的具体定位及数量范围仍须人工有据核定。
- 材料规格、材料原件、施工做法/适用条件、用途/定位/计量范围、修约依据必填，并明确确认当前只计等径圆筒井段。Decimal 80位及记录的固定π常量，逐井不单独修约，仅所选用途总体积按有据选择的0至12位HALF_UP；保留修约前总量及差额。
- 本版不是整井自动算量：不含井底垫层、底板、盖板、井盖、收口、流槽、踏步、洞口扣减或施工附加量。特殊形状、做法及不同材料分开核定；不同构件之间不自动判断空间重叠。

## 编制、复核与回填

算量页新增用途选择、关联站点读取、逐井新增/移除、实际尺寸、独立井数、材料做法及逐项原件、范围确认、预览、修订和独立复核。修改用途或任一编制字段清除旧预览并撤销确认；重新核定后才可预览/保存。来源版本变化后重新读取清空旧井号、定位、尺寸、数量及逐项依据，不能沿用旧定位继续审定。

只读接口`GET /projects/{pid}/chamber-location-candidates?component_id=...`返回当前已审管线站点、版本哈希及不继承的管线数量。成员/租户、原件字节、证据及来源版本、并发对象哈希、保存预览/公式继续沿用现有门禁。完整来源快照由服务器生成，所有处理门禁复验来源管线，客户端不能伪造快照或跳过复核。

回填候选只列出已审`outer_envelope`井筒。后端候选、编制、复核和复算同样拒绝`wall_material`，不能仅因单位都是m³就以井壁材料代替占位。回填采用来源既定已审体积与修约，不另乘井数。井筒与沟槽的同域包含、管线接口/其他实体扣减之间的不重复范围仍须独立核定，不作自动空间判断。

井筒修改后，关联回填及其下游失效；未变化的管线、材料用途构件及沟槽审批保留。历史计算书、报价及已保存导出文件独立保留。
