# 0.101 基础平台曲线孔交集解析裁切

## 本次补齐

基础台阶平台新增圆孔与圆形上层、圆孔与轴向矩形上层、轴向矩形孔与圆形上层的局部交集计算。原先因曲线部分相交而禁用的平台，在来源几何有效、数值界限可确认时可以编制、预览、独立复核、修订并进入面积清单与导出。

计量范围沿用完整外露平台：毛面积=下层截面−紧邻上层完整名义截面；孔只有起Z<平台Z≤止Z时参与，实际扣减=全孔截面−与上层完整截面的交集。上层孔内的孔底不混入平台。没有修改基础体积、体积阈值、孔的包含/分离验证、基础个数或源单位换算。

圆圆局部交集拆为两个圆弓形，以公共弦半长、有向弦距和小弓形半角构造面积；弦距负时通过整圆减小弓形取得大弓形。圆矩形交集以圆心为原点，将有向象限面积按右上−左上−右下＋左下组合；每个象限在矩形完全位于圆内时取矩形面积，否则用四分之一圆减两个半弓形。保留半径、弦距、半弦、角度或象限坐标、有向分项面积、完整来源及可重放AST。数学参考：[圆圆交集](https://mathworld.wolfram.com/Circle-CircleIntersection.html)、[圆弓形](https://mathworld.wolfram.com/CircularSegment.html)。

来源坐标及相交分类仍按已审几何精确比较，解析过程使用200位Decimal工作精度、十进制半角缩减反角级数及既有记录固定π，计算后以HALF_EVEN保留80位。数值工作位数不增加原始图纸精度，固定π仍为已有有限常量；不是无限符号精度。没有网格近似、浮点几何容差或边界吸附。局部交集须严格在0与孔/上层截面较小面积之间，否则阻止计量并明确要求另核。计量总净面积仍按原件明确的0至12位HALF_UP修约。

新增曲线元数据只出现在实际使用局部曲线裁切的孔上；这些记录使用`foundation-horizontal-formwork-1.2`。原整体顶底及原可计算平台保持1.0/1.1、原结果和旧报表。独立审核会重建全部解析过程；分项、角度公式、方法、精度、π、覆盖面积被改写均不能通过复核。原件校验、跨记录重复、来源失效、并发及完整修订历史沿用既有门禁。

页面可展开完整未修约交集及解析分项。JSON保留表达式和精度协议；Excel/PDF仅在存在新曲线交集时增加“基础平台曲线交集过程”，长数自动续行、跨页重复表头；无曲线的旧成果不增加空表。另修复登录后项目列表尚未载入时立即切换工程可能被初始选择覆盖的问题：载入工程后再进入已登录工作区。

## 公式重放协议

原加、减、乘、除、平方根、计量修约节点不变。新增`atan2(y,x)`用于上半平面弧度角，按记录固定π、半角缩减及交错级数计算；不调用二进制浮点反三角函数。新增`decimal_precision`包装节点记录`working_digits=200`、`output_digits=80`及`mode=HALF_EVEN`：先在指定工作精度和舍入模式下递归计算子式，再保留80位。分项及交集AST都带该包装；外层计量总量修约节点仍为HALF_UP。算法版本为`decimal-disk-intersection-1.0`，实现见[解析模块](../backend/curved_intersections.py)。
