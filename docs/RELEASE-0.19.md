# 0.19 有据定额候选与采用追溯

继续补齐PRD F07的受控候选流程：在本项目已审组价基础上登记适用专业、定额年度、适用期间、构造工法、复用许可及原始依据，独立复核后检索和采用。没有引入官方定额数据或模型生成编码。

## 保存与独立复核

- 组价页可选择当前来源完整的已审清单保存候选。候选绑定原清单完整版本校验值，保存时核对并发变化；已采用的候选不允许循环发布。
- 每条候选明确专业、定额年度、适用构造及换算条件、本项目复用许可范围、许可原件与生效/截止日期。保留地区、计价标准和计价规则版本。
- 全部定额子目须属于声明的同一定额年度，保留原子目、资源消耗、单价、换算、来源和许可。源清单、价格、定额和换算依据须有效；保存和通过复核核对原件字节。
- 使用既有独立reviewer审核流程。审核详情逐项显示子目、通用系数、分类换算、原始消耗量、完整精度价格、适用期及证据。普通编制账号不能通过审核。

## 检索、预览与采用

- 明确选择目标清单、专业和定额年度；筛选地区、计量单位、计价规则版本及价格/来源有效性，返回最多5条候选。
- 评分基于相同编码、相同名称与文字交集，显示匹配解释。该评分仅为文字检索，不是语义模型或专业适用结论，不自动选择候选。
- 采用前展示全部定额与资源、原件入口，以及目标清单采用前后的综合单价和合价。试算沿用当前计价规则的修约方式，明确不含任何单位、单项或项目级附加取费。缺价或无定额的目标不伪装成零价差额。
- 采用须明确确认构造工法、消耗换算、资源规格、当前价格及复用许可，并填写采用理由。目标清单、候选、原清单、当前规则或计价日期变化后，原试算不能直接提交。
- 整体替换目标定额与资源，保留目标编码、名称、特征、数量、单位及工程归属；目标回到待复核，并使当前报价审批失效。采用不是通过目标清单审核。
- 请求幂等；重复提交同一内容返回原采用记录，不重复修改清单。相同请求标识不能用于另一内容。失败时不部分修改资料或计价结果。

## 依赖、人工修订与历史成果

- 原清单修改或撤审、候选撤审、原件失效、日期或规则不适用时，阻断新采用及关联清单/报价审核、后续计价；历史报价内容不改写。
- 如需脱离候选独立维护，可填写原因“转为人工编制”，保留当前数值、历史采用记录和原始证据，解除当前候选依赖并重新复核。直接修改定额资源也会解除当前候选绑定并记录审计。该操作不自动取得新的专业适用性结论。
- 报价快照保留候选与采用记录；Excel/PDF/JSON/ZIP增加“定额候选采用台账”，可追溯来源、专业/年度、适用条件、许可、理由、人员时间和候选校验值。旧报价继续使用原快照。
- 旧候选可查阅并兼容原接口检索；缺少新字段的记录不能通过新采用流程，须从已审原清单重新保存，不能静默补造许可。

## 验证与边界

新增22项合成测试，全量291项通过，生产构建通过。覆盖独立复核、筛选/版本、保存原子性、并发与试算校验、采用幂等、源清单变更/候选撤审、原件缺失和篡改、缺价目标、转人工编制、四种导出及旧快照保护。非零差额用例中清单合价924.08降至840.08，差额-84.00；重新计价的清单金额与试算一致，费用另由现有计价引擎计算。
