# 0.73 均分布置中的指定构造加柱

继续补齐PRD F05的栏杆计量。新增“最大间距均分及指定构造加柱”，按核定最大间距建立原均分布置，再按原件端距S逐根增加内部构造柱。原均分位置、跨数及端部归属保持，不以新增位置重新分段或重新均分。

## 规则与精度

每个已审计入区间都须明确加柱列表，无加柱填空列表；本模式至少有一根指定加柱。每根名称、S及单位、构造说明须完整，S与说明分别引用当前原件。S始终从来源原段起点按已审三维或水平口径增加，局部区间也不改为从本区间起点计距。新模式不接受定距锚向参数或依据，避免混用规则。

加柱严格位于本计入区间内部；越界、端部、缺口、重复端距（含不同单位等值）、重复名称和与原均分柱重合均阻断。端柱通过既有两端归属核定，共享端点不能借加柱重复计入。加柱与本材料项原柱采用同一独立核定下料长、每米质量，不同规格须另列并核对范围。每区间最多100根加柱，每材料项最多1000根（含原柱），每表最多5000根单组布置立柱、1至50材料项。

原均分跨数N仍以精确平方关系确定。对原段整段内部节点j，使用(S−起端S)²×N²=原边长度²×j²判断重合；对局部区间使用(S−起端S)×N=区间长度×j。使用精确有理数，不用显示平方根、最大间距倍数或容差推断。例如12m、最大间距5m，实际均分3跨，S4m与原柱重合；S4.00000000000000001m是另一位置，系统不会自动合并。

生成记录按来源S排序并重新编号，原均分节点号与新增名称分别保留，新增柱不冒充均分节点。数量表达式为原规则柱数加指定列表根数；S、原值及单位换算、跨数精确校验、原件均可重建。采用Decimal 80位，分项长度及质量不提前修约，合计只乘一次来源重复数量，仅总质量按有据0至12位HALF_UP修约。

新布置采用`railing-equal-added-posts-1.0`，含此模式的材料表采用`railing-material-mass-1.6`。旧均分、定距及定距加柱结果和规则版本保留。独立载入0.72计算代码，对照35组定距加柱及70组纯均分/纯定距材料表，完整计算记录完全一致。两种加柱模式可以在同表分别计量，参数与表达式独立。

## 界面、审核及导出

编制页逐区间增加或移除构造柱；所有参数变动清空旧预览和确认。切换纯均分、均分加柱或定距加柱会清除原模式参数和隐藏加柱。复核示意以紫色表示加柱、绿色表示原均分柱，展示原柱数加新增根数及逐根S；原跨数和跨间距描述追加前布置，不是加柱后的全局柱距验算。

沿用独立复核、对象哈希、修订并发、精确历史、来源失效、原件完整性及角色租户门禁。保存、审核、计算书和导出重新构建原柱、加柱及表达式。来源范围变化后材料及下游失效，恢复时读取当前范围并清空旧材料、布置规则、加柱和逐项依据及确认；旧清单在重建前保留，旧报价不混入新材料。

JSON保留完整结果；Excel/PDF沿用均分四表，逐根表标明加柱及其名称；两种加柱共用“构造加柱数量组成”“构造加柱端距及依据”。PDF均分及定距逐根表改为整行换页，使同一根柱的编号、位置和完整80位端距留在同页；其他长原文表保留跨页能力。无需新依赖或数据库迁移。
