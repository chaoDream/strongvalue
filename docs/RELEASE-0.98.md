# 0.98 圆孔孔壁局部圆弧模板

继续补齐PRD F05实际接触模板面积：圆孔孔壁支持有据起止角度，使用已审孔自身圆心和实际孔径计算展开宽，结合孔与层共同标高及周期角度检查重复，接通编制、修订、独立复核、计算书、m²清单、映射和三格式导出。可与原矩形孔壁条带在同一记录中分别计量。

## 孔自身圆心与角度

沿用`foundation_void_formwork`，只能引用当前已审`post_foundation`中的真实圆孔。支持矩形、圆柱和同心矩形/圆形台阶基础里的竖直圆孔、有限标高圆孔/凹槽，以及旧版无显式Z的贯通圆孔。模板编辑器不新增孔、修改孔心或孔径，不从基础尺寸、立柱或孔体积推断支模。

圆弧以所选孔自身圆心为角度原点，0°沿来源基础局部+X，从+Z向下俯视、由+X向+Y逆时针为正；孔心偏移不改变共同轴向。界面只读显示当前孔心和实际孔径，孔径不使用基础直径替代。同一来源基础项所有孔、层和跨记录圆弧须使用同一角度基准说明及同一原件，并据原件确认；不同孔的角度原点分别为各自孔心。

角度仅接受度（°），须0≤起角<止角≤360°；不自动求余、倒向、取小弧或将超限角归一化，跨0°拆成两项。0°与360°属于同一周期边界。逐起止角关联当前项目原件；Z仍独立使用mm/cm/dm/m/km并保留换算，须完全位于该孔与所选层的共同标高内，跨层分项。

选弧展开宽=记录的固定π×来源实际孔径×(止角−起角)/360；毛面积乘实际接触高，继承本基础项全部最终个数一次。圆孔与外界或另一孔点相切不产生正面积扣减；来源孔重叠仍由已审几何模型阻断，不允许以圆弧范围绕过。混凝土体积阈值不填实物理孔壁。矩形整宽/条带仍按真实横向和Z交集扣除外界及相邻孔无接触面。

Decimal 80位、固定π、逐弧/逐面/扣减不修约，只有总净面积按有据0至12位HALF_UP修约。原始角度及Z、来源孔心/孔径、整周长、弧角、展开宽、毛扣净、全部个数及对应AST均保留；材料、实际接触做法和修约仍须当前项目原件并独立复核。

## 周期重复与修订

同来源、同基础项、同层、同孔的圆孔内壁，角度及Z均正范围交叠才重复；整周与局部圆弧也检查。角度边界或标高端点仅相接可共存，任一方向正分离可共存，不采用容差吸附。周期比较同时考虑0°、−360°、+360°平移，保留实际间隔和所用平移及AST。不同孔不因角度相同而重复，但其共同轴向原件须一致。

跨记录保存、预览、复核和重算同样检查来源、基准和范围；不能伪造ID、自增记录或利用失效记录绕过占用。矩形条带与圆弧可分行混合，同一行不能同时填条带和角度，矩形孔不能填圆弧。

启用圆弧时起止角、原件、基准及确认均空。切换整周/圆弧或修改圆弧撤销本面接触说明/原件及整体确认，圆弧内部修改撤销基准确认。切换基础项、孔、层或面删除旧角度；换矩形孔只提供矩形范围编辑。同来源修订恢复原始角度、Z单位与原件，整体重新确认；读取新来源清空全部旧范围、做法、原件和修约。

预览及放弃不写项目。修订保留精确历史和旧清单，使旧计算书失效；来源或上游变更沿依赖链使模板失效。沿用当前已审来源递归校验、原件字节五门禁、角色租户、异项目原件阻断、实际ID和乐观并发、证据索引/快照/计算重建防篡改。

## 接口、清单与报表

圆孔`face: circumference`行可额外携带`arc_range`；不填仍为原整周。以下为合成接口结构，角度不是工程默认值：

```json
{
  "arc_range": {
    "parameters": {"angle_start": "0", "angle_end": "120"},
    "unit": "°",
    "evidence": {"angle_start": "当前起角原件ID", "angle_end": "当前止角原件ID"},
    "coordinate_basis": "据原件核定各孔自身圆心、基础局部+X零角及+Z俯视逆时针",
    "coordinate_evidence_id": "当前共同角度原件ID",
    "scope_confirmed": true
  }
}
```

顶层结构、来源锁定、Z参数与逐参数原件、1至200项上限不变。带圆弧结果使用`foundation-void-formwork-1.2`，逐行新增`angle_start/end/span/unit`、`full_circumference`、`arc_center_x/y`、`arc_diameter`、`arc_frame_hash`及相应数值AST，保留原始`arc_range`；`void_arc_checks`记录同孔同层的周期角间隔、平移、Z间隔、状态及AST。角度是度数维度，不伪作长度换算。混合条带继续保留`void_lateral_checks`。不含圆弧的旧整面/整周、条带记录继续分别使用1.0/1.1，完整结果保持一致；关闭圆弧后恢复对应旧规则。外侧模板原规则保持。

沿用独立孔壁实际接触面积m²清单和有据编码映射，映射不改变数量。Excel/PDF在原孔壁表之外按需新增“基础孔壁圆弧角度”“基础孔壁圆弧基准与原件”“基础孔壁圆弧分离校验”三表。报表使用已算高精度值；长数、原件和基准续行及行高适配，JSON保留完整原始值、来源、证据、换算和AST，无圆弧的旧报表不新增空表。
