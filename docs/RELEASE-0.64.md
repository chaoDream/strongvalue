# 0.64 点接触净区的内部连通口径

继续补齐PRD F05、6.1的局部模板、防水范围。在上下净面已启用“分离净块独立核定”后，可明确选择“按净区内部连通处理点接触”，填写处理说明并关联当前原始依据。仅在一点相会的两块面积按各自内部连通范围分别核定；默认不选择时仍沿用0.63的点接触阻断。

## 计量与边界

本选项是明确的几何计量口径，不证明结构连接、施工接触、防水贯通或材料做法。来源仍为已审水平等厚直边多边形，一个简单外轮廓和严格包含、互不接触的孔；本版处理的是合法来源经裁剪后产生的接点，不放宽原始轮廓及孔关系校验。支持既有X/Y窗口、两点无限斜线及上下原面分别选用，可与旧分区及侧面局部S/Z混用。

规则为`polygon-boundary-1.5`、接点规则为`xy-interior-contact-rational-1.0`。沿用精确有理数裁剪、原子边拆分及反向边抵消；接点出边按半平面和精确叉积排序，为每条入边选择其反向射线的顺时针前驱，保持净区在边界左侧。检查出入平衡、重叠射线、未抵消折返边及配对一一对应；不使用浮点角度、吸附或容差。不能唯一重建的情形明确拒绝。

两块仅一点接触时生成独立派生边界。孔在一点接触裁剪边时，可能形成重复经过接点的派生外边界；仍按有向面积和奇偶填充保留孔空白，原孔扣减记录不丢失。各块精确面积合计必须等于原裁剪区净量，保存精确分数、AST及接点边界配对。80位显示、200位记录显示合计差，不调平某块，计入净块合计后只乘一次来源重复数量。

接点处理共用2000000次精确校验预算，沿用8192位有理数保护和1000面上限。未选本模式的旧1.0至1.4结果及历史快照沿用原规则；选择后即使某个裁剪区没有接点，也保留显式口径及零接点核查记录。没有新增依赖或数据库迁移。

## 编制、复核及导出

分区设置新增选择、说明和原件依据。选择变化清除旧预览，应用前预览和保存禁用；应用后按几何和规则身份保留未变面，变化面清空决定、说明及依据，须重新核定。图示用橙色空心圆标注共享接点；独立复核页可展开接点坐标、进入/离开邻点、配对组数及边界重访数。几何图只供定位，不可测量。

来源、原件、证据、派生边界和接点记录均由服务端重建后核对；审核及计算书不能采用自报记录或篡改快照。修订使用当前对象哈希，保留完整已审旧版，旧计算书失效，重新复核、计算和重建清单后使用新量。JSON保存完整精确记录；Excel/PDF新增“点接触处理依据”“接点边界配对记录”，旧报价不会混入后加表格。
