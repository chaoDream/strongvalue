# 0.92 基础孔洞单孔阈值与实际、计量分账

补齐PRD F05“核定扣减规则”的一个受控子集，并贯通F06计量清单、F09报表及F11修订与独立复核。栏杆立柱独立基础的圆孔、轴向矩形孔/凹槽，可按当前项目原件指定单孔截面积或实际孔体积阈值，明确等值边界。实际几何与计量扣减分别保留，不把不扣减的孔当作填实。

## 规则输入及单位

在基础项`through_holes`内可选以下规则；无规则时保持原有全部列孔扣减口径和旧输出：

```json
{
  "deduction_rule": {
    "metric": "section_area",
    "comparison": "gt",
    "threshold": "0.002",
    "unit": "m²",
    "basis": "本项计量适用范围、单孔指标、阈值及等值边界的原件依据",
    "evidence_id": "当前项目原件证据ID",
    "confirmed": true
  }
}
```

`metric`仅支持`section_area`（每基础单孔未修约截面积）或`single_volume`（每基础单孔全部实际相交体积）。`comparison`仅支持`gt`（严格大于，等于不扣）或`gte`（大于等于，等于也扣）。面积单位m²/cm²/mm²，体积单位m³/cm³/mm³，不能跨维度。阈值非负，可为0；原始值及换算后值均沿用18位有效数字/小数及有限数范围检查。

必须完整填写规则、适用范围说明、当前项目原件及确认。不提供官方或合同默认值，不根据地区、孔名、尺寸或使用次数推断适用规则。是否采用此阈值须由专业人员据实际项目原件核定；本次测试阈值仅是合成数学样本。

## 判定、几何和数量

先按每基础每个单孔的未修约指标比较，再乘已审最终立柱数量及来源重复。截面积取实际圆孔π/4×直径²或轴向矩形长×宽；体积取该单孔在全部实际相交层内的体积之和，不能逐层拆开比较，也不能将多孔或多个基础相加凑阈值。

符合时扣该孔全部实际体积；不符合时计量扣减为0。保留指标值、标准单位、与阈值关系、差值、是否符合、实际孔体积、计量扣减及完整公式AST。比较前不修约，不能用界面截取值或最终三位小数判定。

实际孔几何全部保留：未扣孔仍须逐层包含、孔间分离、原件完整及每层实际实体净体积大于0，不能借不计量绕过越界、重叠、整层消除或重复扣减检查。圆/矩形、贯通/有限标高及台阶原约束延续。

- 实际实体净体积 = 毛体积 − 全部实际孔洞体积。
- 未修约计量体积 = 毛体积 − 符合本项规则的计量扣减。

逐孔逐层和阈值比较沿用Decimal 80位，累计最终立柱及来源重复一次后，仅计量总体积HALF_UP修约。孔数、基础个数、来源材料质量、栏杆长度、布柱及下料不变。含阈值记录为`railing-post-foundation-1.6`，未设阈值的旧记录仍按原1.0至1.5规则及输出。

## 编辑、独立复核和历史

启用阈值不预填指标、比较方式、阈值、单位或原件；切换指标/边界清空阈值、单位和规则说明/原件。实际规则字段变更清空本项及总体计量范围并撤销确认；几何、孔位或外尺寸变更也撤销对应规则确认、孔洞/台阶确认及整体确认。确认规则本身不清空已填范围，避免无法完成确认。

停用规则移除该配置，恢复原几何扣减，并要求重新核定本项/总体范围；再次启用为空规则。同来源修订恢复完整原规则及依据，整体需重新确认；来源变更清空旧选择、尺寸、孔位、阈值及依据。

预览不写项目。保存、独立复核、重算和计算书复核重建规则原件、指标、决定、实际/计量两套体积及AST。原件五门禁、异项目依据、角色租户、篡改、并发和伪造ID阻断延续。修订保留精确历史与旧清单并使旧计算书失效；来源修订使旧基础审批失效，既有报价快照和导出字节保留。

## 清单及报表

清单采用按核定规则计算并修约后的基础计量体积；编码映射仍需有据独立复核，不更改数量。项目特征和规则适用性不能由系统自动代替专业判断。

界面把计量扣减、未修约计量体积与实际孔体积、实际实体净体积分表，逐孔显示指标值、与阈值关系及决定。JSON保留原始阈值/单位、标准阈值、差值及AST、全部实际几何和逐层计量扣减。

Excel/PDF新增“基础孔洞扣减阈值”“基础孔洞实际与计量”两表；原基础汇总、逐项和逐层表在此场景明确标记“计量”，孔原始依据及相交表明确实际孔体积。对照表保留每基础、全部基础、逐层和逐孔的实际/计量量，长数及原件说明续行、自动行高。旧无阈值报表和旧报价不新增这两表。

## 尚未完成

阈值只支持当前项目原件确定的单指标、大于/大于等于、符合扣全量/不符合不扣。多指标组合、分级阈值、例外条件、比例扣减、按并集或其他计量边界判阈值、专业标准规则包和自动适用性判断仍未完成。

几何仍限竖直圆孔及轴向矩形孔/凹槽；旋转矩形、斜孔、任意异形凹槽、椭圆/多边形孔、重叠孔并集、逐层变径/变截面孔、预埋实体扣减及逐柱不同孔样待补齐。偏心/混合形态叠置、坡面/连续变截面、基础交叠去重、定位承载、基础模板/钢筋/土方及回填占位也未完成。

完整PRD仍有自动避让、跨边内部交叉去重、曲线及专业构造、变截面材料、任意接触板孔并集/折弯拼接、有限折线面分区、多实体接触、坡面/变厚与防水搭接、真实库存预留/余料回用/跨组共享供应、采购成本优化和采购入库、全专业图纸提取、真实图纸及独立顾问黄金底稿验收、DWG/BIM/商业软件授权往返、授权定额价格库及商用部署运维验收。本次合成验收不能代表PRD全部完成。
