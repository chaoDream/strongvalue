# 0.118 项目完整原材库存与排料预留

日期：2026-10-28。前后端及使用手册版本0.118.0。

## 本次完成

“图纸与算量”新增“原材库存与预留”：按实物批次登记仓库、材质截面、定尺、单位长度质量、根数及逐项原件，独立复核后可用；同仓库同批号防重复，修正须先解除占用并有据停用原登记。

从当前有效已审材料表的单项定尺、单定尺混排、多定尺或有限供应方案读取全部选用根数，数量只继承一次。按需求向一个或多个批次完整分配，定尺和每米质量逐项精确一致，另核材质截面兼容性原件。事务内核对全部可用根数后整单占用，同材料表仅一份未释放预留，重复请求幂等、过期库存及争用阻断。

预留提交即占用，独立复核确认；被拒、待补件、原件缺失或来源修订保持占用并警示，须显式有据整单释放。登记仍有占用不能停用，已释放或停用对象不可再审定，原编制人改任复核角色也不能自审。全部操作保留人员、原件、时间、对象哈希和审计；库存JSON台账按哈希留档，历史字节不随后续操作变化。

详见[使用手册15.6](USER-GUIDE.md#stock-inventory)。库存操作不改变原几何、排料、净工程量、清单、报价或工程成果审批。
