# 0.3 审核、资源调价与企业模板

本版在0.2及独立密钥服务基础上，补充 PRD F06、F07、F09、F11、F12 的业务操作。这里只说明已实现的软件能力，不代表真实工程的专业验收。

## 新增功能

| 功能 | 操作与约束 |
|---|---|
| 批量专业复核 | 以 reviewer 登录，在算量、清单、组价、成果或系统配置页选择“批量专业复核”，选择对象类型，逐项展开完整内容及原始依据后勾选。一次1至200项，统一审核意见，但逐项记录审核人、原对象哈希与决定。任意对象过期或业务门禁失败，整批及其审计记录回滚。管理员、负责人和编制账号不能代审。 |
| 清单数量分配检查 | 清单页列出每份当前算量书的登记量、已分配量及余额，检查漏编、超量分配、单位不一致、来源失效、贡献量不闭合及编码/特征缺失。问题同时进入成果审核门禁。 |
| 资源调价单 | 编制账号在组价页明确选择资源，逐行填价或给选中项填写统一单价；补齐来源类型、许可、期次、地区、税制、有效期及原件证据，填写合同/调价依据后形成待审单与影响试算。不会直接替换当前价格。 |
| 调价应用与修正 | reviewer 审定调价后，由编制账号应用；价格被写入当前清单，受影响项回到待复核，已有报价失效。来源、清单或规则变更后拒绝应用旧调价。重复应用不会重复修改。撤回已应用调价审批后，其价格阻断计价；通过新的调价单修正，不能借清单重新审核绕过。 |
| 调价影响与交付台账 | 展示受影响清单在同一修约规则下的原金额、新金额及差额，不包括措施、费用和税金，不冒充最终总价。正式报价需重算。新报价快照保存调价依据；包含已应用调价的导出增加资源调价台账。历史报价和历史导出保持原值。 |
| 企业报表样式 | 企业管理员或项目负责人在系统配置/成果页创建模板，可填写编制单位、内部说明、页脚及选择配色。按企业隔离，只能追加不可覆盖的新版本；从过期版本修订会提示冲突。编制及复核账号可以选用模板，不能维护企业模板。 |
| 模板导出留档 | 实际PDF预览与PDF、Excel、JSON下载使用当前选中模板。导出记录保留完整模板版本及哈希；模板后续修订不改变旧文件。模板不能隐藏草稿状态、审核记录、来源或更改计算结果，也不提供自动签章。 |

## 业务边界

- 分配检查只验证系统已登记的算量书，不能识别未建模构件、语义漏项或验证官方清单编码。一个构件存在混凝土、模板等多个计量用途时，须分别建立对应单位和证据的算量书；不重复消费同一份数量以制造不同用途。
- 调价按显式选择的资源行应用，不会仅按名称自动替换不同材质、规格、地区或税制的资源。合法价格及合同适用性仍由专业人员确认。历史审核价保留参考属性，不能直接升级成当前有效资源价。
- 费用规则、地区、税制及有效期仍受原审核门禁约束。待审或已审未应用调价会阻断完整成果审核；可以拒绝不采用的调价单后继续原基线。
- 企业模板是内部样式，不能代替当地正式表式、TPL-A/B样板复现或电子标格式验收。页面封面摘要保留导航用途，选定样式以实际生成文件为准。
- `transfer/local-snapshot/` 是此前0.2工作区的迁移快照，不自动用后续测试或运行数据覆盖；恢复后启动会执行兼容的数据库建表迁移。新增测试全部在独立临时数据库或独立本机验收工作区运行。

## 当前验证

自动测试覆盖批次原子性与审计回滚、旧哈希拒绝、租户及角色边界、调价影响精度、审批撤回与修正、旧清单及规则变化阻断、历史报价不变、调价台账、漏编审核阻断、模板跨企业拒绝、模板版本冲突、模板不可普通更新/删除、PDF/Excel实际样式、公式注入防护及历史导出不变。前端使用TypeScript检查和生产构建验证。

本机浏览器在独立合成数据工作区完成两项清单批量复核、两条资源调价单建立、企业模板创建和实际PDF渲染。测试价格、数量、合同依据和单位名称均为合成数据，不是豆门乡专业底稿。截图见 `docs/qa/v0.3-batch-review.png`、`docs/qa/v0.3-template-preview.png`。
