# 0.26 空间长方体并集与扣减

继续补齐PRD F05及6.1中的几何布尔计算：在平面区域基础上，增加同一XYZ设计坐标系下的轴向长方体并集与差集。逐体录入起点标高和高度，处理不同标高、不同高度的相交，避免把相同XY位置但互不接触的构件误作重叠。

## 录入与确定性计算

- 每组1至20个长方体，至少一个加项；逐体录入XYZ起点、沿正X/Y/Z方向的长宽高、加扣、原始单位、计量说明及逐参数证据。XYZ可为负数，长宽高必须为正数。
- 必须核定共同原点、轴向、标高基准及原图依据。Z为共同基准下的底面起点，不把不同楼层的相对标高直接混算。坐标来自设计标注，不从像素或分层示意图量取。
- 每体坐标与尺寸使用一种明确长度单位，可为m、mm、cm、dm、km。固定物理关系沿用measurement-units-1.0；保留原值、精确换算因子、标准值和证据。
- 先按全部Z边界分层，再在每层按X边界分条带，合并加项及扣减Y区间。每层净截面乘层高后求和，再乘整组重复数量。重复数量须为1至1000000的整数并关联来源。
- 加项和扣减各自去重；扣减体必须完全位于加项空间并集内。允许跨相邻加项的水平或垂直接缝扣减；越界或穿过没有加项的空层/空隙会明确拒绝，不静默裁切。接触面不计重叠，净量允许为零。
- 采用Decimal 80位精度；沿用18位有效数字、18位小数、换算前后参数范围和最终工程量上限保护。公式AST从原始XYZ与长宽高、固定单位因子构建，可独立复算。

## 页面、审核与计算书

图纸与算量页新增空间构件编辑及预览，按Z区间选择XY净截面，展示当前层的加扣截面、净面积和净体积。B编号对应原始长方体；原始坐标和标准坐标、逐参数依据、所有分层及条带均可展开核查。两两相交体积只用于定位，多重覆盖时不能相加代替实际并集扣重。

保存、构件复核、重新算量、计算书审定和报价门禁均检查原件、来源指纹及计算内容。修订须提交当前对象哈希，不能省略结构化类型或静默转成平面/普通构件；坐标、标高、尺寸、单位或依据改变后重新复核。历史报价及留档文件保持原样。

JSON保留长方体、单位、分层、条带、相交和AST；Excel/PDF新增“空间并集与扣减”“长方体原始坐标”“空间分层计算”“空间分层条带”“空间相交定位”。逐参数换算继续进入“算量原始单位换算”表。算法版本orthogonal-solid-1.0，原有平面与分项计算版本保持不变。
