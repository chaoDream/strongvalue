# 0.121 实物余料按核定定尺回用

日期：2026-10-28。前后端及使用手册版本0.121.0。

## 本次完成

已验收入库且原件有效的余料，可按当前已审材料表的全部定尺需求申请回用。逐段长度及每米质量须与定尺精确相等，材质截面及质量另据原件确认。实际交接日期、领用人、兼容性及交接原件必填；只读预览后保存立即预留，独立复核后显式整单领用，转为在外待加工。拒绝、待补件和来源失效不自动放回数量，未领用可有据释放，已领用不可重审或释放。

同材料表完整原材预留与余料回用互斥，禁止二次领用和超占；有余料预留或在外待加工数量时禁止停用。验收原数、当前在库、预留、可用和在外数量分列，原件失效保留实物事实。回用申请、复核、事件和余额纳入独立JSON台账与历史留档，不改变工程净量、原排料、报价、完整原材账及原加工核对额度。详见[使用手册15.9](USER-GUIDE.md#stock-offcut-reuse)。
